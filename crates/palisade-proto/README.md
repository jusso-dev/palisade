# palisade-proto

Wire types between agent and server: messages, the event schema and schema versioning.

**Status:** skeleton. The crate compiles but has no functionality yet. Work is tracked in [#4](https://github.com/jusso-dev/palisade/issues/4) and [#10](https://github.com/jusso-dev/palisade/issues/10).

## Allowed dependencies

`palisade-core`, `palisade-fileid`, `palisade-policy`. The rules are enforced by `cargo xtask check-deps`.

## Platform support

All platforms.

## Feature flags

None yet.

## Stability

Unstable and not published. Anything may change.
