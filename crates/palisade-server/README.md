# palisade-server

The central management server: policy distribution, approvals, inventory and event storage.

**Status:** skeleton. The crate compiles but has no functionality yet. Work is tracked in [#10](https://github.com/jusso-dev/palisade/issues/10).

## Allowed dependencies

`palisade-core`, `palisade-fileid`, `palisade-policy`, `palisade-proto`. The rules are enforced by `cargo xtask check-deps`.

## Platform support

All platforms.

## Feature flags

None yet.

## Stability

Unstable and not published. Anything may change.
