# palisade-console

The web console frontend and the code that embeds its assets.

**Status:** skeleton. The crate compiles but has no functionality yet. Work is tracked in [#136](https://github.com/jusso-dev/palisade/issues/136).

## Allowed dependencies

`palisade-proto` only. The rules are enforced by `cargo xtask check-deps`.

## Platform support

All platforms.

## Feature flags

None yet.

## Stability

Unstable and not published. Anything may change.
