# Support

Palisade is an educational, personal-development project. Support is **community best effort**.

- There is **no service level agreement**. Questions, bugs and pull requests are answered when the
  maintainer has time, and some may not be answered.
- There is **no commercial support**, and none is planned. Nobody sells support, consulting or a
  hosted version of Palisade on the project's behalf.
- Palisade is not a replacement for commercial application control products. Do not rely on it
  to protect production systems.

## Where to go

| You want to | Use |
|---|---|
| Ask a question or discuss an idea | [GitHub Discussions](https://github.com/jusso-dev/palisade/discussions) (the **Q&A** category for questions) |
| Report a bug | [A bug report issue](https://github.com/jusso-dev/palisade/issues/new/choose) |
| Propose a feature or a new rule type | [A feature or rule-type issue](https://github.com/jusso-dev/palisade/issues/new/choose) |
| Report a security vulnerability | **Privately**, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |
| Report a Code of Conduct concern | Privately, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#enforcement) |

Before you ask, please search existing issues and discussions, and check the
[README](README.md) and the [docs](docs/).

When you post logs or policy excerpts, remove secrets, enrolment tokens, override codes, host
names and user names first.
