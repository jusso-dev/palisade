# Getting started

Palisade is not usable as a product yet (see the [Introduction](../introduction.md)). What you can
do today is build it, write and validate policies, and run the policy engine's tests and examples.

- [Lab install](lab-install.md): build from source, and the planned disposable-VM lab.
- [Your first policy](first-policy.md): write a policy, validate it, and plan the audit-to-enforce
  rollout.
