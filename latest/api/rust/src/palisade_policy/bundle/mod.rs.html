1//! The canonical compiled policy bundle (#43).
2//!
3//! A bundle is the one artefact that the agent enforces, the simulator
4//! evaluates and #225 signs, so it has exactly one byte encoding for a given
5//! content. This module builds it in layers:
6//!
7//! - [`cbor`]: a small, strict subset of CBOR (RFC 8949) in the core
8//!   deterministic encoding of §4.2. The encoder writes only canonical
9//!   bytes, and the decoder accepts only canonical bytes, so decoding and
10//!   encoding again always gives the input back.
11//! - [`keys`]: the stable registry of integer keys that stand for field and
12//!   variant names, each critical or ignorable.
13//! - [`serial`]: the policy model through serde as CBOR values, with
14//!   registered keys in place of names and text in NFC.
15//! - [`format`](mod@format): the bundle itself, a header that decodes on its own and a
16//!   body in canonical order, with the bundle hash and the decision hash.
17//! - [`compile`](mod@compile): builds a bundle from a validated or effective policy and
18//!   the library catalogue, and [`compile::BundleSets`] resolves the
19//!   inlined sets when a loaded bundle is evaluated.
20//! - [`delta`]: the difference between two bundles, applied only to the
21//!   exact base and checked against the result's hash.
22

24pub mod compile;
25pub mod delta;
26pub mod format;
27pub mod keys;
28pub mod serial;
