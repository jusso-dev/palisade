1//! The evaluation pipeline: from one object to one [`Decision`] (#35,
2//! ADR 0004).
3//!
4//! An [`Evaluator`] is built once from a [`ValidatedPolicy`]. It compiles
5//! the match tree of every enabled rule in the rule sets the policy
6//! references. [`Evaluator::evaluate`] then evaluates every rule that
7//! applies to the object's type and runs the stages below, in this fixed
8//! order, whatever the precedence model. Each stage either decides or
9//! passes to the next.
10//!
11//! 1. **Mandatory deny.** Rules in a `mandatory` blocklist. If one
12//!    matches, the object is blocked (`mandatory_deny`). No allow, trust
13//!    source, elevation or exclusion can change that, under any model.
14//! 2. **Exclusion.** `ignore` rules. If one matches, the object is
15//!    `ignored`.
16//! 3. **Override session.** An active session (#9) lowers the effective
17//!    mode of stages 4 and 6 ([`crate::mode`]). It never affects stage 1.
18//! 4. **Policy.** The policy's precedence model ([`crate::precedence`])
19//!    chooses among the matching `allow`, `allow_contained`,
20//!    `allow_elevated` and `deny` rules.
21//! 5. **Attribute.** Not yet: post-allow attribute rules are #33.
22//! 6. **Unknown.** If nothing decided, the policy's unknown-application
23//!    policy decides ([`crate::unknown`], #39). Its default blocks
24//!    (`implicit_deny_unknown`), the implicit deny of ADR 0004.
25//!
26//! Between stages 1 and 2, an object that is one of Palisade's own pinned
27//! images ([`Evaluator::with_self_images`]) is allowed (`self_allow`).
28//!
29//! # Scopes
30//!
31//! A rule is a candidate only if it is in scope (#38, [`crate::scope`]):
32//! its own `scope`, the scopes of its rule set's assignment and the
33//! policy's `scope` are evaluated first, and a rule applies when the `AND`
34//! of those scopes and its match tree is `Match` (or `Unknown`, for a deny
35//! with `unknown_as: match`). A rule that is out of scope behaves as if it
36//! were absent in every stage: it never decides and is not listed as
37//! overridden. The scope notes of every rule whose tree was not `NoMatch`
38//! (in scope or not) are in [`Decision::scope_notes`].
39//!
40//! Two scope settings act on the deciding rule:
41//!
42//! - **Instance limit.** If an allow that decides has a scope with
43//!   `max_instances_per_session` and the session already runs that many
44//!   instances (or the count is unknown), the object is blocked with
45//!   `instance_limit`, naming the allow. A mode that relaxes the block
46//!   runs the object with the allow's directives.
47//! - **Window close.** If the object is allowed and a scope on the way to
48//!   the deciding rule has a schedule with `on_window_close`, the decision
49//!   carries a [`WindowClose`] directive with the instant the schedule
50//!   closes.
51//!
52//! Two kinds of rule never decide:
53//!
54//! - `audit` rules that match are listed in [`Decision::annotations`],
55//!   whichever stage decides.
56//! - `trust_source` rules that match add their grant to
57//!   [`Directives::trust_sources`](crate::decision::Directives::trust_sources),
58//!   but only when the object is allowed. A trust source never lets an
59//!   object run by itself (#114). When the object is blocked or ignored,
60//!   they are listed as overridden instead.
61//!
62//! `defer` rules have no opinion. They are never evaluated, so a `defer`
63//! that matches makes `first_match` continue with the next rule.
64//!
65//! When several mandatory denies match, or several exclusions, the one
66//! with the most specific identity decides, then the one with the lowest
67//! rule ID.
68//!
69//! # Overridden rules
70//!
71//! [`Decision::overridden`] lists every other rule that matched and would
72//! have decided, or attached a grant, if the deciding rule had not: the
73//! other candidates of the deciding stage (including those with the same
74//! outcome), every candidate of the later stages, and every `trust_source`
75//! rule when the object is not allowed.
76//!
77//! # Unknown facts
78//!
79//! A rule applies only when its match tree is `Match` ([`crate::condition`]),
80//! so an unknown fact never allows, trusts or excludes. A `deny` rule
81//! decides how it treats an unknown result with two options:
82//!
83//! - `unknown_as: match` makes it apply when its tree is `Unknown`, so it
84//!   blocks unless the precedence model prefers an allow. The default,
85//!   `no_match`, means an unknown fact does not block.
86//! - `on_unparseable: match` makes each criterion whose version fact is not
87//!   a version count towards the deny applying
88//!   ([`Unparseable::FavourMatch`]). The default leaves it `Unknown`.
89//!
90//! A file the agent could not parse has no facts, so no rule can allow it,
91//! and unless a deny fails closed it gets the implicit deny (ADR 0012).
92//!
93//! Mandatory denies follow the same options. They default to `no_match`
94//! like any other deny; making the criteria of the shipped blocklists
95//! `safety_critical`, which defaults them to `match`, is #32 and #87.
96//!
97//! # Modes
98//!
99//! [`Evaluator::evaluate`] computes the enforce-mode decision, before
100//! anything relaxes it: its [`Decision::mode`] is always `enforce`.
101//! [`Evaluator::evaluate_in`] applies the effective mode of the device
102//! ([`crate::mode`]): the policy's `mode`, the modes per object type, each
103//! rule set's `mode_override`, each rule's `enforcement_override`, the
104//! per-class control levels, connectivity, override sessions and
105//! emergency lockdown. It keeps the enforce-mode outcome in
106//! [`Decision::would_have_been`].
107//!
108//! # Determinism
109//!
110//! Evaluation is a pure function of the policy and the object. Every
111//! stage chooses by keys that end with the unique rule ID, and the lists in
112//! a decision are sorted by rule ID, so the decision does not depend on
113//! the order of rule sets in the policy or of rules in a rule set. Only
114//! `first_match` and `priority` depend on rules' `order` and `priority`.
115

169/// What a rule does in the pipeline.
170#[derive(Clone, Copy, Debug, PartialEq, Eq)]
171enum Role {
172    /// A deny in a mandatory rule set: stage 1.
173    Mandatory,
174    /// An `ignore` rule: stage 2.
175    Exclusion,
176    /// An allow or a deny for the precedence model: stage 4.
177    Policy(Verdict),
178    /// An `audit` rule: an annotation.
179    Annotation,
180    /// A `trust_source` rule: a grant if the object is allowed.
181    Trust,
182}

184/// One enabled rule, ready to evaluate.
185#[derive(Debug)]
186struct Compiled<'p> {
187    set: &'p RuleSet,
188    rule: &'p Rule,
189    tree: CompiledMatch,
190    role: Role,
191    spec: Spec,

197    scopes: Vec<(ScopeLevel, Arc<CompiledScope>)>,

204impl Compiled<'_> {
205    fn candidate(&self, verdict: Verdict) -> Candidate {
206        Candidate {
207            rule: self.reference,
208            verdict,
209            spec: self.spec,
210            order: self.rule.order,
211            priority: self.rule.priority,
212            curated: self.set.read_only,
213            band: self.set.band,
214        }
215    }

217    /// The scopes on the way to the rule, evaluated for the subject.
218    pub(crate) fn scope_eval(&self, subject: &Subject<'_>) -> ScopeEvaluation {
219        if self.scopes.is_empty() {
220            return ScopeEvaluation::MATCH;
221        }
222        eval_chain(&self.scopes, subject.context, self.bias)
223    }
224
225    /// Whether the rule applies to the subject. The scopes are evaluated
226    /// before the tree; when they are `NoMatch` and noticed nothing, the
227    /// tree is not evaluated. `notes` gathers the scope notes of a rule
228    /// whose tree is not `NoMatch`, including one its scopes took out:
229    /// a stale group or an untrusted clock is worth reporting exactly when
230    /// it kept a matching rule from applying.
231    fn applies(&self, subject: &Subject<'_>, notes: &mut ScopeNotes) -> bool {
232        if !self.rule.object_types.is_empty()
233            && !self.rule.object_types.contains(&subject.object_type)
234        {
235            return false;
236        }
237        let scope = self.scope_eval(subject);
238        if scope.result == Tri::NoMatch && scope.notes.is_empty() {
239            return false;
240        }
241        let ctx = EvalContext {
242            action: self.rule.action.kind(),
243            variables: subject.variables,
244            context: subject.context,
245        };
246        let evaluation = if self.role == Role::Mandatory {
247            self.tree
248                .eval_mandatory(subject.facts, &ctx, self.unparseable)
249        } else {
250            self.tree.eval_with(subject.facts, &ctx, self.unparseable)
251        };
252        let tree = evaluation.result;
253        if tree == Tri::NoMatch {
254            return false;
255        }
256        notes.extend(scope.notes);
257        match scope.result.and(tree) {
258            Tri::Match => true,
259            Tri::Unknown => self.unknown_as == UnknownAs::Match,
260            Tri::NoMatch => false,
261        }
262    }
263
264    /// The per-session instance limit of the rule's scopes, the smallest
265    /// that is set, or `None`.
266    fn instance_limit(&self) -> Option<u32> {
267        self.scopes
268            .iter()
269            .map(|(_, s)| s.max_instances_per_session())
270            .filter(|n| *n > 0)
271            .min()
272    }
273
274    /// What to do when a schedule on the way to the rule closes: the
275    /// strictest action, the earliest close, and the shortest grace period
276    /// of the schedules that terminate.
277    ///
278    /// Only a schedule whose closing ends the rule's match counts: one in
279    /// a scope with `combine: all` and no `negate`. Validation rejects
280    /// `on_window_close` anywhere else, so this only matters for library
281    /// schedules.
282    fn window_close(&self, subject: &Subject<'_>) -> Option<WindowClose> {
283        let facts = &subject.context.scope;
284        let mut out: Option<WindowClose> = None;
285        for (_, scope) in &self.scopes {
286            let Some(schedule) = scope.closing_schedule() else {
287                continue;
288            };
289            if schedule.on_window_close() == OnWindowClose::None {
290                continue;
291            }
292            let closes_at = facts.time.filter(|t| t.trusted).and_then(|t| {
293                let (tz, _) = schedule.zone(facts).ok()?;
294                schedule.closes_at(t.unix_secs, &tz)
295            });
296            let this = WindowClose {
297                action: schedule.on_window_close(),
298                grace_secs: schedule.grace_secs(),
299                closes_at,
300            };
301            out = Some(match out {
302                None => this,
303                Some(o) => WindowClose {
304                    action: o.action.max(this.action),
305                    grace_secs: match (o.action, this.action) {
306                        (OnWindowClose::WarnThenTerminate, OnWindowClose::WarnThenTerminate) => {
307                            o.grace_secs.min(this.grace_secs)
308                        }
309                        (OnWindowClose::WarnThenTerminate, _) => o.grace_secs,
310                        (_, OnWindowClose::WarnThenTerminate) => this.grace_secs,
311                        _ => o.grace_secs.min(this.grace_secs),
312                    },
313                    closes_at: match (o.closes_at, this.closes_at) {
314                        (Some(a), Some(b)) => Some(a.min(b)),
315                        (a, b) => a.or(b),
316                    },
317                },
318            });
319        }
320        out
321    }
322}

324/// The result of one relaxation layer of [`Evaluator::evaluate_in`].
325struct Layer<'a, 'p> {
326    /// The decision over the rules kept.
327    decision: Decision,
328    /// Its deciding rule, or `None` for the implicit deny.
329    winner: Option<&'a Compiled<'p>>,
330    /// The rules decided over.
331    kept: Vec<&'a Compiled<'p>>,
332    /// The denies set aside because they do not enforce.
333    dropped: Vec<RuleRef>,
334    /// Whether the decision blocks in an enforcing mode.
335    blocks: bool,
336}

338impl Layer<'_, '_> {
339    /// The directives an object that runs gets: an allow's, if one
340    /// decided (also one its instance limit blocked), otherwise none.
341    fn directives(&self) -> Directives {
342        self.decision.runnable_directives()
343    }

363impl<'p> Evaluator<'p> {
364    /// Compiles every enabled rule of the rule sets the policy references,
365    /// with no library: every library set a scope references is unknown.
366    ///
367    /// # Errors
368    ///
369    /// Returns [`BuildError`] if a tree does not compile, which validation
370    /// rules out.
371    pub fn new(validated: &'p ValidatedPolicy) -> Result<Self, BuildError> {
372        Self::with_library(validated, &NoLibrary)
373    }
374
375    /// Compiles every enabled rule of the rule sets the policy references,
376    /// resolving the library sets scopes reference through `library` (#37).
377    ///
378    /// # Errors
379    ///
380    /// Returns [`BuildError`] if a tree does not compile, which validation
381    /// rules out.
382    pub fn with_library(
383        validated: &'p ValidatedPolicy,
384        library: &dyn ScopeLibrary,
385    ) -> Result<Self, BuildError> {
386        let doc = validated.document();
387        let policy = &doc.policy;
388        let sets: BTreeMap<RuleSetId, &RuleSet> = doc.rule_sets.iter().map(|s| (s.id, s)).collect();
389        let env = Env {
390            library,
391            basis: policy.settings.time_zone_basis,
392        };
393        let max_age = policy.settings.group_cache_max_age_secs;
394        let compile = |s| Arc::new(CompiledScope::compile(s, env, max_age));
395        let policy_scope = policy.scope.as_ref().map(compile);
396        let mut rules = Vec::new();
397        for id in &policy.rule_sets {
398            let Some(set) = sets.get(id).copied() else {
399                continue;
400            };
401            let mut chain: Vec<(ScopeLevel, Arc<CompiledScope>)> = Vec::new();
402            if let Some(s) = &policy_scope {
403                chain.push((ScopeLevel::Policy, Arc::clone(s)));
404            }
405            for assignment in policy.rule_set_scopes.iter().filter(|a| a.rule_set == *id) {
406                for s in &assignment.scopes {
407                    chain.push((ScopeLevel::RuleSet, compile(s)));
408                }
409            }
410            for rule in set.rules.iter().filter(|r| r.enabled) {
411                let role = match &rule.action {
412                    _ if set.mandatory => Role::Mandatory,
413                    Action::Ignore {} => Role::Exclusion,
414                    Action::Audit {} => Role::Annotation,
415                    Action::TrustSource(_) => Role::Trust,
416                    Action::Defer {} => continue,
417                    action => match Verdict::of(action) {
418                        Some(v) => Role::Policy(v),
419                        None => continue,
420                    },
421                };
422                let tree = CompiledMatch::compile(&rule.match_).map_err(|errors| BuildError {
423                    rule_id: rule.id,
424                    errors,
425                })?;
426                let (unknown_as, unparseable) = match &rule.action {
427                    Action::Deny(o) => (
428                        o.unknown_as,
429                        match o.on_unparseable {
430                            UnknownAs::Match => Unparseable::FavourMatch,
431                            UnknownAs::NoMatch => Unparseable::Unknown,
432                        },
433                    ),
434                    _ => (UnknownAs::NoMatch, Unparseable::Unknown),
435                };
436                let mut scopes = chain.clone();
437                if let Some(s) = &rule.scope {
438                    scopes.push((ScopeLevel::Rule, compile(s)));
439                }
440                rules.push(Compiled {
441                    set,
442                    rule,
443                    tree,
444                    role,
445                    spec: Spec::of(&rule.match_),
446                    unknown_as,
447                    unparseable,
448                    reference: RuleRef::new(policy, set, rule),
449                    scopes,
450                    bias: Bias::of(rule.action.kind()),
451                    floor: crate::unknown::baseline::is_system_baseline(set),
452                });
453            }
454        }
455        let unknown_scope = UnknownScope::new(
456            policy_scope,
457            policy.unknown.scopes.iter().map(compile).collect(),
458            policy
459                .unknown
460                .scope_limits
461                .iter()
462                .map(|l| {
463                    (
464                        l.all_of.iter().map(compile).collect(),
465                        l.any_of.iter().map(compile).collect(),
466                    )
467                })
468                .collect(),
469        );
470        Ok(Self {
471            policy,
472            rules,
473            resolver: Resolver::new(policy.precedence_model, &policy.precedence_options),
474            self_images: Vec::new(),
475            unknown_scope,
476        })
477    }

488    /// The inputs of stages 2 to 6 for one subject.
489    fn inputs<'a>(&'a self, subject: &Subject<'a>, matched: &[&Compiled<'p>]) -> Inputs<'a> {
490        let blocklisted = matched.iter().any(|r| {
491            r.set.kind == RuleSetKind::Blocklist
492                || matches!(r.role, Role::Mandatory | Role::Policy(Verdict::Deny))
493        });
494        Inputs {
495            six: StageSix::new(
496                &self.policy.unknown,
497                &self.unknown_scope,
498                subject.object_type,
499                subject.facts,
500                subject.variables,
501                subject.context,
502                blocklisted,
503            ),
504            pinned: self
505                .self_images
506                .iter()
507                .any(|i| i.matches(subject.object_type, subject.facts)),
508        }

511    /// The policy being evaluated.
512    #[must_use]
513    pub const fn policy(&self) -> &'p Policy {
514        self.policy
515    }

517    /// Decides one object, as enforce mode sees it: [`Decision::mode`] is
518    /// `enforce`, whatever the policy's modes. This is the simulated result
519    /// that readiness reports use (#41); [`evaluate_in`](Self::evaluate_in)
520    /// applies the modes.
521    #[must_use]
522    pub fn evaluate(&self, subject: &Subject<'_>, trace_id: TraceId) -> Decision {
523        let (matched, notes) = self.matching_with_notes(subject);
524        let inputs = self.inputs(subject, &matched);
525        self.run(&matched, subject, &inputs, trace_id)
526            .0
527            .with_scope_notes(notes)
528    }

530    /// Decides one object on a device in `state`, applying the effective
531    /// mode ([`crate::mode`]). Returns `None` when the device is disabled:
532    /// the engine is not consulted, and nothing is decided or reported.
533    ///
534    /// [`Decision::would_have_been`] is the enforce-mode outcome
535    /// ([`evaluate`](Self::evaluate)). An object that enforce mode allows
536    /// or ignores gets the same decision, in its effective mode. A block
537    /// is relaxed in two layers, so that each relaxation is reported as
538    /// what it is:
539    ///
540    /// 1. **Modes.** Using the modes without the override session, every
541    ///    matching deny whose effective mode does not enforce is set
542    ///    aside, and the remaining rules are decided again. If that still
543    ///    blocks in an enforcing mode (an enforcing deny, a mandatory deny,
544    ///    or an enforcing implicit deny), the object is blocked by it: a
545    ///    blocklist in `audit` never lets through what another rule blocks.
546    ///    Otherwise the object runs as `allowed_audit`, naming the rule
547    ///    enforce mode decided by.
548    /// 2. **Session.** If layer 1 blocks and an override session is active,
549    ///    the same is done with the session's modes, starting from the
550    ///    rules layer 1 kept. If that still blocks in an enforcing mode,
551    ///    the object is blocked. Otherwise it runs as `allowed_override`,
552    ///    naming the rule layer 1 blocked by: the one the session bypassed.
553    ///
554    /// Every deny set aside is listed as overridden. A relaxed decision
555    /// keeps the named rule's effects except the notification, so the
556    /// would-block event is still logged. Its directives are those of the
557    /// last decision taken: if an allow decided it, the object runs with
558    /// that allow's containment, elevation and trust-source grants (which
559    /// are then no longer listed as overridden); otherwise it has none, so
560    /// nothing is terminated or requested. In `learning`, an object that
561    /// only the implicit deny would block is a learning candidate.
562    ///
563    /// Mandatory denies always enforce (ADR 0004, #125).
564    #[must_use]
565    pub fn evaluate_in(
566        &self,
567        subject: &Subject<'_>,
568        state: &DeviceState,
569        trace_id: TraceId,
570    ) -> Option<Decision> {
571        if mode::device_mode(self.policy, state) == Mode::Disabled {
572            return None;
573        }
574        let (matched, notes) = self.matching_with_notes(subject);
575        self.decide_in(subject, &matched, state, trace_id)
576            .map(|d| d.with_scope_notes(notes))
577    }
578
579    /// [`evaluate_in`](Self::evaluate_in) over the rules that apply.
580    fn decide_in(
581        &self,
582        subject: &Subject<'_>,
583        matched: &[&Compiled<'p>],
584        state: &DeviceState,
585        trace_id: TraceId,
586    ) -> Option<Decision> {
587        let t = subject.object_type;
588        let inputs = self.inputs(subject, matched);
589        let (full, winner) = self.run(matched, subject, &inputs, trace_id);
590        // Only stage 6 follows `driver_boot_policy`.
591        let boot = inputs.six.boot_audit && full.unhandled();
592        if !full.outcome().stops() {
593            let mode = self.mode_of(t, winner, state, boot).mode;
594            let learning = mode == Mode::Learning && full.unhandled();
595            return Some(full.in_mode(mode).with_learning(learning));
596        }
597        // Layer 1: the modes, without the session.
598        let base = DeviceState {
599            session: None,
600            ..*state
601        };
602        let one = self.enforcing(
603            subject,
604            matched,
605            (full.clone(), winner),
606            &base,
607            &inputs,
608            trace_id,
609        );
610        if !one.blocks {
611            let effective = self.mode_of(t, winner, &base, boot);
612            let learning = effective.mode == Mode::Learning && full.unhandled();
613            let directives = one.directives();
614            return Some(full.relaxed(effective, directives, learning));
615        }
616        let Some(_) = state.session else {
617            return Some(
618                one.decision
619                    .with_overridden(one.dropped)
620                    .in_mode(Mode::Enforce),
621            );
622        };
623        // Layer 2: what the session relaxes of what layer 1 enforced.
624        let two = self.enforcing(
625            subject,
626            &one.kept,
627            (one.decision.clone(), one.winner),
628            state,
629            &inputs,
630            trace_id,
631        );
632        let mut dropped = one.dropped.clone();
633        dropped.extend(two.dropped.iter().copied());
634        if two.blocks {
635            return Some(two.decision.with_overridden(dropped).in_mode(Mode::Enforce));
636        }
637        let effective = self.mode_of(t, one.winner, state, boot);
638        let directives = two.directives();
639        Some(
640            one.decision
641                .with_overridden(one.dropped)
642                .relaxed(effective, directives, false),
643        )
644    }
645
646    /// The effective mode of a decision decided by `rule`, or by stage 6
647    /// when `rule` is `None`. With `boot_audit` (a driver in early boot
648    /// under `driver_boot_policy: audit`), stage 6 does not enforce, except
649    /// in lockdown.
650    fn mode_of(
651        &self,
652        t: ObjectType,
653        rule: Option<&Compiled<'_>>,
654        state: &DeviceState,
655        boot_audit: bool,
656    ) -> mode::EffectiveMode {
657        let mut m = mode::resolve(self.policy, t, rule.map(|r| (r.set, r.rule)), state);
658        if rule.is_none() && boot_audit && !state.lockdown {
659            m.mode = mode::capped(m.mode, Mode::Audit);
660            m.by_session = false;
661        }
662        m
663    }
664
665    /// One relaxation layer. `first` is the decision over `rules`. If it
666    /// blocks in a mode that enforces under `state`, it stands. Otherwise
667    /// every deny that does not enforce under `state` is set aside, and the
668    /// rest are decided again.
669    fn enforcing<'a>(
670        &self,
671        subject: &Subject<'_>,
672        rules: &[&'a Compiled<'p>],
673        first: (Decision, Option<&'a Compiled<'p>>),
674        state: &DeviceState,
675        inputs: &Inputs<'_>,
676        trace_id: TraceId,
677    ) -> Layer<'a, 'p> {
678        let t = subject.object_type;
679        let enforces = |d: &Decision, r: Option<&Compiled<'_>>| {
680            let boot = inputs.six.boot_audit && d.unhandled();
681            self.mode_of(t, r, state, boot).mode == Mode::Enforce
682        };
683        let (decision, winner) = first;
684        if decision.outcome().stops() && enforces(&decision, winner) {
685            return Layer {
686                decision,
687                winner,
688                kept: rules.to_vec(),
689                dropped: Vec::new(),
690                blocks: true,
691            };
692        }
693        let (dropped, kept): (Vec<&Compiled<'p>>, Vec<&Compiled<'p>>) =
694            rules.iter().partition(|r| {
695                matches!(r.role, Role::Policy(Verdict::Deny)) && !enforces(&decision, Some(r))
696            });
697        let (decision, winner) = self.run(&kept, subject, inputs, trace_id);
698        let blocks = decision.outcome().stops() && enforces(&decision, winner);
699        Layer {
700            decision,
701            winner,
702            kept,
703            dropped: dropped.iter().map(|r| r.reference).collect(),
704            blocks,
705        }
706    }
707
708    /// The enabled rules that apply to the subject.
709    fn matching(&self, subject: &Subject<'_>) -> Vec<&Compiled<'p>> {
710        self.matching_with_notes(subject).0
711    }
712
713    /// The enabled rules that apply to the subject, and the scope notes of
714    /// every rule whose tree was not `NoMatch`.
715    fn matching_with_notes(&self, subject: &Subject<'_>) -> (Vec<&Compiled<'p>>, ScopeNotes) {
716        let mut notes = ScopeNotes::default();
717        let matched = self
718            .rules
719            .iter()
720            .filter(|r| r.applies(subject, &mut notes))
721            .collect();
722        (matched, notes)
723    }
724
725    /// Runs the stages over the rules that apply, and returns the decision
726    /// and the deciding rule (`None` when stage 6 or a pinned image
727    /// decided).
728    fn run<'a>(
729        &self,
730        matched: &[&'a Compiled<'p>],
731        subject: &Subject<'_>,
732        inputs: &Inputs<'_>,
733        trace_id: TraceId,
734    ) -> (Decision, Option<&'a Compiled<'p>>) {
735        let mut mandatory = Vec::new();
736        let mut exclusions = Vec::new();
737        let mut policy = Vec::new();
738        let mut annotations = Vec::new();
739        let mut trust = Vec::new();
740        for &rule in matched {
741            match rule.role {
742                Role::Mandatory => mandatory.push(rule),
743                Role::Exclusion => exclusions.push(rule),
744                Role::Policy(v) => policy.push((rule, v)),
745                Role::Annotation => annotations.push(rule.reference),
746                Role::Trust => trust.push(rule),
747            }
748        }
749
750        // Stage 1, then stage 2. Every candidate of a stage does the same
751        // thing, so the most specific one decides; `most_specific` does not
752        // read the verdict. A pinned Palisade image is allowed between them.
753        for (n, stage) in [&mandatory, &exclusions].into_iter().enumerate() {
754            if n == 1 && inputs.pinned {
755                let overridden = exclusions
756                    .iter()
757                    .chain(policy.iter().map(|(r, _)| r))
758                    .chain(&trust)
759                    .map(|r| r.reference)
760                    .collect();
761                let d = Decision::self_allow(trace_id).with_context(
762                    overridden,
763                    annotations,
764                    Vec::new(),
765                );
766                return (d, None);
767            }
768            let set = MatchSet {
769                candidates: stage.iter().map(|r| r.candidate(Verdict::Deny)).collect(),
770            };
771            if let Some(i) = most_specific(&set) {
772                let winner = stage[i];
773                let overridden = mandatory
774                    .iter()
775                    .chain(&exclusions)
776                    .chain(policy.iter().map(|(r, _)| r))
777                    .chain(&trust)
778                    .filter(|r| r.rule.id != winner.rule.id)
779                    .map(|r| r.reference)
780                    .collect();
781                let d =
782                    self.decide(winner, trace_id)
783                        .with_context(overridden, annotations, Vec::new());
784                return (d, Some(winner));
785            }
786        }
787
788        // Stage 4: the precedence model. The managed `system_baseline` is a
789        // floor: its rules are decided over only when no other rule matched,
790        // so under no model does it override a tenant's rule.
791        let deciding: Vec<(&Compiled<'p>, Verdict)> = if policy.iter().any(|(r, _)| !r.floor) {
792            policy.iter().filter(|(r, _)| !r.floor).copied().collect()
793        } else {
794            policy.clone()
795        };
796        let set = MatchSet {
797            candidates: deciding.iter().map(|(r, v)| r.candidate(*v)).collect(),
798        };
799        let Some(i) = self.resolver.resolve(&set).winner else {
800            // Stage 6: nothing decided. Trust sources only grant to an
801            // object a rule allowed, so they are overridden here.
802            let overridden = trust.iter().map(|r| r.reference).collect();
803            let d = inputs
804                .six
805                .decide(trace_id)
806                .with_context(overridden, annotations, Vec::new());
807            return (d, None);
808        };
809        let (winner, verdict) = deciding[i];
810        let mut overridden: Vec<RuleRef> = policy
811            .iter()
812            .filter(|(r, _)| r.rule.id != winner.rule.id)
813            .map(|(r, _)| r.reference)
814            .collect();
815        let grants = if verdict.allows() {
816            trust
817                .iter()
818                .filter_map(|r| match &r.rule.action {
819                    Action::TrustSource(d) => Some(TrustGrant::new(r.reference, d)),
820                    _ => None,
821                })
822                .collect()
823        } else {
824            overridden.extend(trust.iter().map(|r| r.reference));
825            Vec::new()
826        };
827        let mut d = self
828            .decide(winner, trace_id)
829            .with_context(overridden, annotations, grants);
830        if verdict.allows() {
831            if let Some(close) = winner.window_close(subject) {
832                d = d.with_window_close(close);
833            }
834            if let Some(limit) = winner.instance_limit() {
835                // The count is a fact like any other: unknown never allows.
836                let running = subject.context.scope.instances_in_session;
837                if running.is_none_or(|n| n >= limit) {
838                    return (
839                        d.instance_limit()
840                            .with_scope_notes(note(ScopeNote::InstanceLimit)),
841                        Some(winner),
842                    );
843                }
844            }
845        }
846        (d, Some(winner))
847    }
848
849    /// The decision of a deciding rule. Only enabled rules with a terminal
850    /// action reach this, so `from_rule` always gives one; if it ever did
851    /// not, the object is blocked rather than allowed.
852    fn decide(&self, winner: &Compiled<'_>, trace_id: TraceId) -> Decision {
853        Decision::from_rule(self.policy, winner.set, winner.rule, trace_id)
854            .unwrap_or_else(|| Decision::implicit_deny(trace_id))
855    }
856}

858// The decision trace (#41, `crate::trace`) lists the rules that applied as
859// `evaluate` found them, so it can never disagree with the evaluator.
860impl Evaluator<'_> {
861    /// The IDs of the enabled rules that apply to the subject.
862    pub(crate) fn matching_ids(&self, subject: &Subject<'_>) -> Vec<RuleId> {
863        self.matching(subject).iter().map(|r| r.rule.id).collect()
864    }
865
866    /// The scopes of an enabled rule, evaluated for the subject (#38), as
867    /// the evaluator reads them; `None` for a rule it does not hold.
868    pub(crate) fn scope_of(&self, rule: RuleId, subject: &Subject<'_>) -> Option<ScopeEvaluation> {
869        self.rules
870            .iter()
871            .find(|r| r.rule.id == rule)
872            .map(|r| r.scope_eval(subject))
873    }
874}

876/// A set of one note.
877fn note(n: ScopeNote) -> ScopeNotes {
878    let mut notes = ScopeNotes::default();
879    notes.insert(n);
880    notes
881}
