1//! Rule lifecycle (#40): when a rule is active, which rules are
2//! exceptions, review dates, expiry notices, review campaigns and bulk
3//! changes. Everything here is pure: the caller supplies the time.
4//!
5//! # Active rules and the clock
6//!
7//! A rule is active when it is enabled, `activates_at` (if set) has been
8//! reached, and `expires_at` (if set) has not. An inactive rule behaves
9//! exactly as if it were absent: it never decides, annotates or grants
10//! ([`Evaluator::at`](crate::evaluate::Evaluator::at)). The decision trace
11//! (#41) reports it as inactive with [`Activity`]'s reason.
12//!
13//! Activity is checked against a [`RuleClock`]: the agent's time `now`,
14//! its **floor** (the lower bound on real time that the agent keeps in
15//! protected storage and never lowers), and whether the agent is
16//! **anchored** (ADR 0012, ADR 0018). While the agent is anchored, `now`
17//! is anchored time and the floor is raised to it, so the two agree. An
18//! **offline-started** agent (after a restart, before its next check-in)
19//! has only the wall clock for `now`, which anyone who can change the
20//! clock controls.
21//!
22//! While the agent is offline-started, a time-bounded rule that lets an
23//! object run, trusts it or excludes it ([`ActionKind::needs_identity`]) is
24//! inactive, whatever the readings say: grants from the policy bundle do
25//! not start or continue until the next check-in (ADR 0018, rule 2). It is
26//! reported as `expired` once the floor has passed its expiry, and as
27//! `not_yet_active` otherwise. This is the same result as with no clock at
28//! all ([`activity_at`]). Every other rule, and every rule while anchored,
29//! is judged from the two readings, each in the closed direction:
30//!
31//! - A rule that lets an object run, trusts it or excludes it
32//!   ([`ActionKind::needs_identity`]) is active only while **both**
33//!   readings are inside its window. It has expired once either reading
34//!   reaches `expires_at`, and the floor never goes back, so **an expired
35//!   allow never revives** after a clock rollback. It activates only once
36//!   both readings reach `activates_at`, so setting the clock forwards
37//!   cannot start it early.
38//! - A deny, `audit` or `defer` rule is active while **either** reading is
39//!   inside its window: it activates once either reaches `activates_at`,
40//!   and expires only once both reach `expires_at`. Setting the clock
41//!   forwards cannot end a deny early.
42//!
43//! With `on_expire: convert_to_audit` an expired rule becomes an `audit`
44//! rule instead of absent: it records matches but never decides.
45//! `delete_after_days` behaves as absent at once, and [`retire_due`] lists
46//! it for deletion once the days have passed.
47//!
48//! # Exceptions
49//!
50//! An exception ([`is_exception`]) is a rule that weakens the default-deny
51//! posture by its nature: an `ignore`, an allow whose path identity is in
52//! a user-writable location (#31), an allow with a weak identity (file
53//! name, metadata, or SHA-1 or MD5 only), or any rule with
54//! `metadata.exception: true`. In governance mode an exception needs
55//! `approved_at`, `expires_at` at most 365 days after it, `justification`,
56//! `approved_by` and `risk_rating` ([`crate::validate`], `exception_*`
57//! codes). The year counts from `approved_at` only ([`exception_start`]):
58//! only a renewal in a review ([`ReviewAction::Renew`]) moves it, so an
59//! attestation or a bulk extension never stretches an exception past a
60//! year from its approval.

75/// The agent's view of time for rule activity (ADR 0012, ADR 0018).
76#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
77pub struct RuleClock {
78    /// The current time: anchored time while the agent is anchored, or
79    /// the wall clock while it is offline-started. The server and tests
80    /// pass real time.
81    pub now: Timestamp,
82    /// The lower bound on real time the agent keeps in protected storage,
83    /// which never goes backwards. Pass `now` where there is none (the
84    /// server, the policy assistant).
85    pub floor: Timestamp,
86    /// Whether `now` is trusted time: the agent holds anchored time, or
87    /// the caller is the server. `false` while the agent is
88    /// offline-started; time-bounded permissive rules are then inactive
89    /// (see the module documentation).
90    pub anchored: bool,
91}
92
93impl RuleClock {
94    /// An anchored clock whose floor is `now`: for the server, the policy
95    /// assistant and tests.
96    #[must_use]
97    pub const fn at(now: Timestamp) -> Self {
98        Self {
99            now,
100            floor: now,
101            anchored: true,
102        }
103    }
104
105    /// The clock of an offline-started agent: the wall clock `now` and
106    /// the stored floor.
107    #[must_use]
108    pub const fn offline_started(now: Timestamp, floor: Timestamp) -> Self {
109        Self {
110            now,
111            floor,
112            anchored: false,
113        }
114    }
115
116    /// The earlier of the two readings.
117    #[must_use]
118    pub const fn earliest(&self) -> Timestamp {
119        if self.now.0 < self.floor.0 {
120            self.now
121        } else {
122            self.floor
123        }
124    }
125
126    /// The later of the two readings.
127    #[must_use]
128    pub const fn latest(&self) -> Timestamp {
129        if self.now.0 > self.floor.0 {
130            self.now
131        } else {
132            self.floor
133        }
134    }
135}

137/// Whether a rule is active, and why not.
138#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize)]
139#[serde(rename_all = "snake_case")]
140pub enum Activity {
141    /// Active.
142    Active,
143    /// `enabled: false`.
144    Disabled,
145    /// `activates_at` is in the future.
146    NotYetActive,
147    /// `expires_at` has passed.
148    Expired,
149}

151impl Activity {
152    /// Whether the rule takes part in evaluation as written.
153    #[must_use]
154    pub const fn is_active(self) -> bool {
155        matches!(self, Self::Active)
156    }
157}

159/// Whether `rule` is active at `clock`.
160#[must_use]
161pub fn activity(rule: &Rule, clock: &RuleClock) -> Activity {
162    if !rule.enabled {
163        return Activity::Disabled;
164    }
165    let permissive = rule.action.kind().needs_identity();
166    let timed = rule.activates_at.is_some() || rule.expires_at.is_some();
167    // Offline-started: no bundle grant starts or continues (ADR 0018).
168    if permissive && timed && !clock.anchored {
169        return if rule.expires_at.is_some_and(|e| e <= clock.floor) {
170            Activity::Expired
171        } else {
172            Activity::NotYetActive
173        };
174    }
175    // A permissive rule needs both readings inside its window; any other
176    // rule needs only one.
177    let (start, end) = if permissive {
178        (clock.earliest(), clock.latest())
179    } else {
180        (clock.latest(), clock.earliest())
181    };
182    if rule.expires_at.is_some_and(|e| e <= end) {
183        return Activity::Expired;
184    }
185    if rule.activates_at.is_some_and(|a| a > start) {
186        return Activity::NotYetActive;
187    }
188    Activity::Active
189}

191/// Whether `rule` is active at `clock`, or with no clock at all: then a
192/// time-bounded rule that lets an object run, trusts it or excludes it is
193/// `not_yet_active`, and any other rule is active (the closed direction).
194/// The evaluator, the decision trace and the effective view all judge
195/// activity with this.
196#[must_use]
197pub fn activity_at(rule: &Rule, clock: Option<&RuleClock>) -> Activity {
198    if !rule.enabled {
199        return Activity::Disabled;
200    }
201    if rule.activates_at.is_none() && rule.expires_at.is_none() {
202        return Activity::Active;
203    }
204    match clock {
205        Some(clock) => activity(rule, clock),
206        None if rule.action.kind().needs_identity() => Activity::NotYetActive,
207        None => Activity::Active,
208    }
209}

211/// What the rule does in an evaluation at `clock`: its own action, an
212/// `audit` (an expired rule with `on_expire: convert_to_audit`), or
213/// nothing.
214#[must_use]
215pub fn effective_action(rule: &Rule, clock: &RuleClock) -> Option<Action> {
216    match activity(rule, clock) {
217        Activity::Active => Some(rule.action.clone()),
218        Activity::Expired if rule.on_expire == OnExpire::ConvertToAudit => Some(Action::Audit {}),
219        Activity::Expired | Activity::Disabled | Activity::NotYetActive => None,
220    }
221}

223/// Whether `rule` is an exception by its nature or by its metadata (see
224/// the module documentation).
225#[must_use]
226pub fn is_exception(rule: &Rule) -> bool {
227    if rule.metadata.exception || matches!(rule.action, Action::Ignore {}) {
228        return true;
229    }
230    if !rule.action.kind().permits() {
231        return false;
232    }
233    let weak = crate::analysis::identity::weakest_identity(&rule.match_);
234    weak.is_weak() || crate::analysis::identity::has_path_identity(&rule.match_)
235}

243/// When the object is due for review: `review_by`, or for an allow or trust
244/// rule without one, a year after `created_at`. `None` if neither is known.
245#[must_use]
246pub fn review_by(metadata: &Metadata, kind: Option<ActionKind>) -> Option<Date> {
247    metadata.review_by.or_else(|| {
248        kind.filter(|k| needs_review(*k))
249            .and(metadata.created_at)
250            .and_then(|c| c.plus_days(REVIEW_PERIOD_DAYS))
251            .map(Timestamp::date)
252    })
253}

255/// When an exception's year starts: its approval, `approved_at`. Neither
256/// `created_at` nor `last_reviewed_at` counts, so a creation date written
257/// in the future or an attestation cannot stretch it. Only a renewal in a
258/// review ([`ReviewAction::Renew`]) re-approves an exception and so moves
259/// its start.
260#[must_use]
261pub const fn exception_start(m: &Metadata) -> Option<Timestamp> {
262    m.approved_at
263}
264
265/// The latest expiry an exception may have: 365 days after its approval,
266/// counted from no later than `now` when a time is known, so an approval
267/// dated in the future cannot stretch it. `None` without `approved_at`.
268#[must_use]
269pub fn exception_limit(m: &Metadata, now: Option<Timestamp>) -> Option<Timestamp> {
270    let start = exception_start(m)?;
271    let start = now.map_or(start, |n| start.min(n));
272    start.plus_days(crate::model::lifecycle::limits::MAX_EXCEPTION_DAYS)
273}

298/// The rules a review campaign covers: enabled allow and trust rules of
299/// the policy's referenced rule sets, other than the managed
300/// `system_baseline` the engine adds after validation ([`managed_baseline`]). A
301/// read-only (curated) rule set is reviewed like any other.
302fn reviewable(doc: &PolicyDocument) -> impl Iterator<Item = (&RuleSet, &Rule)> {
303    let exempt = managed_baseline(doc);
304    referenced(doc)
305        .filter(move |set| Some(set.id) != exempt)
306        .flat_map(|set| set.rules.iter().map(move |r| (set, r)))
307        .filter(|(_, r)| r.enabled && needs_review(r.action.kind()))
308}
309
310/// The rules due for review on or before `as_of`: their [`review_by`] date
311/// is at or before it, or cannot be determined. Sorted, undated first, then
312/// by date, rule set and rule ID, so the result is deterministic evidence
313/// (ISM-1582).
314#[must_use]
315pub fn review_due(doc: &PolicyDocument, as_of: Date) -> Vec<ReviewItem> {
316    let mut out: Vec<ReviewItem> = reviewable(doc)
317        .filter_map(|(set, r)| {
318            let due = review_by(&r.metadata, Some(r.action.kind()));
319            due.is_none_or(|d| d <= as_of).then(|| ReviewItem {
320                rule: RuleLocation {
321                    rule_set_id: set.id,
322                    rule_id: r.id,
323                },
324                review_by: due,
325                owner: r.metadata.owner.clone(),
326                exception: is_exception(r),
327            })
328        })
329        .collect();
330    out.sort_by_key(|a| (a.review_by, a.rule));
331    out
332}

344    pub reviewed_last_year: usize,

351/// The review summary of a policy on `as_of`.
352#[must_use]
353pub fn review_summary(doc: &PolicyDocument, as_of: Date) -> ReviewSummary {
354    let due = review_due(doc, as_of);
355    let since = as_of.start().plus_days(-REVIEW_PERIOD_DAYS);
356    let rules: Vec<&Rule> = reviewable(doc).map(|(_, r)| r).collect();
357    ReviewSummary {
358        reviewable: rules.len(),
359        due: due.len(),
360        exceptions_due: due.iter().filter(|d| d.exception).count(),
361        reviewed_last_year: rules
362            .iter()
363            .filter(|r| {
364                r.metadata
365                    .last_reviewed_at
366                    .is_some_and(|t| since.is_none_or(|s| t >= s))
367            })
368            .count(),
369        undated: due.iter().filter(|d| d.review_by.is_none()).count(),
370        earliest_due: due.iter().find_map(|d| d.review_by),
371    }
372}

420/// Whether `actor` is a valid metadata name: 1 to 128 trimmed characters
421/// with no control characters.
422fn valid_actor(actor: &str) -> bool {
423    !actor.is_empty()
424        && actor.trim() == actor
425        && actor.chars().count() <= crate::model::limits::MAX_NAME_CHARS
426        && !actor.chars().any(char::is_control)
427}

429/// Applies a review action to `rule`, by `reviewer` at `now`: sets
430/// `last_reviewed_at` and `last_reviewed_by`, and `review_by` a year on.
431/// The rule stays valid: renewing an exception re-approves it, so its
432/// expiry is checked from the review. Attesting never moves
433/// `approved_at`.
434///
435/// # Errors
436///
437/// Returns [`ChangeError`] for an invalid reviewer or expiry; the rule is
438/// then unchanged.
439pub fn review(
440    rule: &mut Rule,
441    action: &ReviewAction,
442    reviewer: &str,
443    now: Timestamp,
444) -> Result<(), ChangeError> {
445    if !valid_actor(reviewer) {
446        return Err(ChangeError::InvalidActor);
447    }
448    let next = now
449        .plus_days(REVIEW_PERIOD_DAYS)
450        .map(Timestamp::date)
451        .ok_or(ChangeError::TimeOverflow)?;
452    if let ReviewAction::Renew { expires_at } = action {
453        if *expires_at <= now || rule.activates_at.is_some_and(|a| *expires_at <= a) {
454            return Err(ChangeError::InvalidExpiry);
455        }
456        if is_exception(rule)
457            && now
458                .plus_days(crate::model::lifecycle::limits::MAX_EXCEPTION_DAYS)
459                .is_none_or(|l| *expires_at > l)
460        {
461            return Err(ChangeError::ExceptionTooLong);
462        }
463    }
464    rule.metadata.last_reviewed_at = Some(now);
465    rule.metadata.last_reviewed_by = Some(reviewer.to_owned());
466    rule.metadata.updated_at = Some(now);
467    rule.metadata.updated_by = Some(reviewer.to_owned());
468    match action {
469        ReviewAction::Attest => {}
470        ReviewAction::Renew { expires_at } => {
471            rule.expires_at = Some(*expires_at);
472            if is_exception(rule) {
473                rule.metadata.approved_by = Some(reviewer.to_owned());
474                rule.metadata.approved_at = Some(now);
475            }
476        }
477        ReviewAction::Retire => rule.enabled = false,
478    }
479    rule.metadata.review_by = Some(next);
480    Ok(())
481}

500/// The expiry notices due in `(since, until]`, for every rule of the
501/// policy's referenced rule sets with an `expires_at`. The server calls
502/// this on a schedule with the previous run's `until` as `since`, so each
503/// notice is sent once. Sorted by due time, then rule.
504#[must_use]
505pub fn expiry_notices(
506    doc: &PolicyDocument,
507    since: Timestamp,
508    until: Timestamp,
509) -> Vec<ExpiryNotice> {
510    let days = &doc.policy.governance.expiry_notice_days;
511    let mut out = Vec::new();
512    for set in referenced(doc) {
513        for r in set.rules.iter().filter(|r| r.enabled) {
514            let Some(expires_at) = r.expires_at else {
515                continue;
516            };
517            for d in days {
518                let Some(due_at) = expires_at.plus_days(-i64::from(*d)) else {
519                    continue;
520                };
521                if since < due_at && due_at <= until {
522                    out.push(ExpiryNotice {
523                        rule: RuleLocation {
524                            rule_set_id: set.id,
525                            rule_id: r.id,
526                        },
527                        owner: r.metadata.owner.clone(),
528                        expires_at,
529                        days_before: *d,
530                        due_at,
531                    });
532                }
533            }
534        }
535    }
536    out.sort_by_key(|a| (a.due_at, a.rule, a.days_before));
537    out.dedup_by(|a, b| a.rule == b.rule && a.due_at == b.due_at);
538    out
539}

541/// The expired rules whose `on_expire: delete_after_days` has passed at
542/// `now`: the server deletes them in a change set. Sorted.
543#[must_use]
544pub fn retire_due(doc: &PolicyDocument, now: Timestamp) -> Vec<RuleLocation> {
545    let mut out: Vec<RuleLocation> = doc
546        .rule_sets
547        .iter()
548        .flat_map(|set| set.rules.iter().map(move |r| (set, r)))
549        .filter_map(|(set, r)| match (r.on_expire, r.expires_at) {
550            (OnExpire::DeleteAfterDays(days), Some(e))
551                if e.plus_days(i64::from(days)).is_some_and(|t| t <= now) =>
552            {
553                Some(RuleLocation {
554                    rule_set_id: set.id,
555                    rule_id: r.id,
556                })
557            }
558            _ => None,
559        })
560        .collect();
561    out.sort();
562    out
563}

630                write!(f, "rule {} is not in rule set {}", r.rule_id, r.rule_set_id)
631            }
632            Self::ReadOnly(r) => write!(f, "rule set {} is read-only", r.rule_set_id),
633            Self::Invalid(e) => e.fmt(f),
634            Self::ExceptionTooLong(r) => write!(
635                f,
636                "rule {} is an exception, and the new expiry is more than 365 days after its approval; renew it in a review",
637                r.rule_id
638            ),
639            Self::Governance(r, codes) => {
640                let names: Vec<&str> = codes.iter().map(|c| c.as_str()).collect();
641                write!(
642                    f,
643                    "rule {} cannot be enabled in governance mode until its metadata is complete: {}",
644                    r.rule_id,
645                    names.join(", ")
646                )
647            }
648        }
649    }
650}

654/// Applies `op` to every rule in `rules`, as one change set with `reason`.
655/// Nothing changes unless every rule can be changed.
656///
657/// # Errors
658///
659/// Returns [`BulkError`] if there is no reason, a rule is missing, a rule
660/// set is read-only, an exception would be extended past a year from its
661/// approval, or a rule to enable lacks the metadata governance mode needs.
662pub fn bulk(
663    doc: &mut PolicyDocument,
664    rules: &[RuleLocation],
665    op: &BulkOp,
666    actor: &str,
667    reason: &str,
668    at: Timestamp,
669) -> Result<ChangeSet, BulkError> {
670    if reason.trim().is_empty() {
671        return Err(BulkError::ReasonRequired);
672    }
673    if !valid_actor(actor) {
674        return Err(BulkError::Invalid(ChangeError::InvalidActor));
675    }
676    for loc in rules {
677        let set = doc
678            .rule_sets
679            .iter()
680            .find(|s| s.id == loc.rule_set_id)
681            .ok_or(BulkError::UnknownRule(*loc))?;
682        let rule = set
683            .rules
684            .iter()
685            .find(|r| r.id == loc.rule_id)
686            .ok_or(BulkError::UnknownRule(*loc))?;
687        if set.read_only {
688            return Err(BulkError::ReadOnly(*loc));
689        }
690        if let BulkOp::Extend(t) = op {
691            if *t <= at || rule.activates_at.is_some_and(|a| *t <= a) {
692                return Err(BulkError::Invalid(ChangeError::InvalidExpiry));
693            }
694            if is_exception(rule)
695                && exception_limit(&rule.metadata, Some(at)).is_none_or(|l| *t > l)
696            {
697                return Err(BulkError::ExceptionTooLong(*loc));
698            }
699        }
700        if *op == BulkOp::Enable && !rule.enabled {
701            let mut enabled = rule.clone();
702            enabled.enabled = true;
703            let codes: Vec<_> = crate::validate::governance_problems(doc, set, &enabled)
704                .into_iter()
705                .map(|(code, _, _)| code)
706                .collect();
707            if !codes.is_empty() {
708                return Err(BulkError::Governance(*loc, codes));
709            }
710        }
711    }
712    let mut changes = Vec::new();
713    let mut wanted: Vec<RuleLocation> = rules.to_vec();
714    wanted.sort();
715    wanted.dedup();
716    for loc in wanted {
717        let Some(rule) = doc
718            .rule_sets
719            .iter_mut()
720            .filter(|s| s.id == loc.rule_set_id)
721            .flat_map(|s| s.rules.iter_mut())
722            .find(|r| r.id == loc.rule_id)
723        else {
724            continue;
725        };
726        let before = (rule.enabled, rule.expires_at, rule.metadata.comment.clone());
727        match op {
728            BulkOp::Enable => rule.enabled = true,
729            BulkOp::Disable => rule.enabled = false,
730            BulkOp::Extend(t) => rule.expires_at = Some(*t),
731            BulkOp::Retire => {
732                rule.enabled = false;
733                // Kept within the text limit; the full reason is in the
734                // change set.
735                let note = format!("retired: {}", reason.trim());
736                let text = match &rule.metadata.comment {
737                    Some(c) => format!("{c}\n{note}"),
738                    None => note,
739                };
740                rule.metadata.comment = Some(
741                    text.chars()
742                        .take(crate::model::limits::MAX_TEXT_CHARS)
743                        .collect(),
744                );
745            }
746        }
747        rule.metadata.updated_by = Some(actor.to_owned());
748        rule.metadata.updated_at = Some(at);
749        changes.push(RuleChange {
750            rule: loc,
751            enabled: (before.0, rule.enabled),
752            expires_at: (before.1, rule.expires_at),
753            comment: (before.2, rule.metadata.comment.clone()),
754        });
755    }
756    Ok(ChangeSet {
757        actor: actor.to_owned(),
758        at,
759        reason: reason.trim().to_owned(),
760        changes,
761    })
762}

764/// The rules that would have matched `subject` but are inactive at
765/// `clock`, with why, sorted by rule ID: what the decision trace (#41)
766/// reports as "would have matched disabled rule R" or "expired rule R".
767/// Not for the hot path: it compiles each inactive rule's tree.
768#[must_use]
769pub fn inactive_matches(
770    validated: &crate::validate::ValidatedPolicy,
771    subject: &crate::evaluate::Subject<'_>,
772    clock: &RuleClock,
773) -> Vec<(RuleRef, Activity)> {
774    let doc = validated.document();
775    let mut out: Vec<(RuleRef, Activity)> = referenced(doc)
776        .flat_map(|set| set.rules.iter().map(move |r| (set, r)))
777        .filter_map(|(set, rule)| {
778            let why = activity(rule, clock);
779            if why.is_active() {
780                return None;
781            }
782            // `defer` is never evaluated, active or not.
783            if matches!(rule.action, Action::Defer {})
784                || (!rule.object_types.is_empty()
785                    && !rule.object_types.contains(&subject.object_type))
786            {
787                return None;
788            }
789            let tree = crate::condition::CompiledMatch::compile(&rule.match_).ok()?;
790            let ctx = crate::ops::EvalContext {
791                action: rule.action.kind(),
792                variables: subject.variables,
793                context: subject.context,
794            };
795            // As the evaluator applies it: a deny's unknown handling counts.
796            let (unknown_as, unparseable) = match &rule.action {
797                Action::Deny(o) => (
798                    o.unknown_as,
799                    match o.on_unparseable {
800                        crate::model::UnknownAs::Match => {
801                            crate::condition::Unparseable::FavourMatch
802                        }
803                        crate::model::UnknownAs::NoMatch => crate::condition::Unparseable::Unknown,
804                    },
805                ),
806                _ => (
807                    crate::model::UnknownAs::NoMatch,
808                    crate::condition::Unparseable::Unknown,
809                ),
810            };
811            let matched = match tree.eval_with(subject.facts, &ctx, unparseable).result {
812                crate::ops::Tri::Match => true,
813                crate::ops::Tri::Unknown => unknown_as == crate::model::UnknownAs::Match,
814                crate::ops::Tri::NoMatch => false,
815            };
816            matched.then(|| (RuleRef::new(&doc.policy, set, rule), why))
817        })
818        .collect();
819    out.sort_by_key(|(r, _)| r.rule_id);
820    out
821}

823impl PolicyDocument {
824    /// The document without its governance metadata: what decides (#40,
825    /// #43). Metadata never changes a decision, so a bundle's
826    /// decision-relevant hash is taken over this form, and editing a
827    /// justification or a review date does not make agents re-verify
828    /// their decision caches. The full content hash still covers it.
829    #[must_use]
830    pub fn decision_relevant(&self) -> Self {
831        let mut doc = self.clone();
832        doc.policy.metadata = Metadata::default();
833        doc.policy.governance = crate::model::GovernanceSettings::default();
834        for set in &mut doc.rule_sets {
835            set.metadata = Metadata::default();
836            for rule in &mut set.rules {
837                rule.metadata = Metadata::default();
838            }
839        }
840        doc
841    }
842}

844/// The managed `system_baseline` rule set, if the document holds it. Only
845/// the engine adds it, after validation
846/// ([`crate::validate::ValidatedPolicy::with_system_baseline`]); an
847/// authored document that uses its ID is rejected, so this is never a set
848/// a policy author wrote. It is the only rule set exempt from review
849/// campaigns and the assistant's governance checks; `read_only` alone
850/// exempts nothing.
851pub(crate) fn managed_baseline(doc: &PolicyDocument) -> Option<RuleSetId> {
852    doc.rule_sets
853        .iter()
854        .find(|s| crate::unknown::baseline::is_system_baseline(s))
855        .map(|s| s.id)
856}
857
858/// The rule sets the policy references, in its order.
859pub(crate) fn referenced(doc: &PolicyDocument) -> impl Iterator<Item = &RuleSet> {
860    doc.policy
861        .rule_sets
862        .iter()
863        .filter_map(|id| doc.rule_sets.iter().find(|s| s.id == *id))
864}

866/// The reference a decision uses for `rule`.
867#[must_use]

869    RuleRef::new(policy, set, rule)
