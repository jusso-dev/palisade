1//! Matching one criterion against the facts about one object (#31, #32).
2//!
3//! A [`Criterion`] is compiled once, when the policy is loaded, into a
4//! [`CompiledCriterion`]: regular expressions and wildcards become
5//! automata, and literal values are normalised and case-folded. Matching
6//! then does no compilation and runs in time linear in the fact's length.
7//!
8//! # Three-valued results
9//!
10//! Every evaluation gives a [`Tri`]: `Match`, `NoMatch`, or `Unknown` when a
11//! fact the criterion needs is missing or cannot be trusted. A negative
12//! operator is the Kleene negation of its positive form, so a negated test
13//! of an unknown fact is `Unknown`, never `Match`: "does not contain X" is
14//! not satisfied by a value nobody computed. A whole tree combines these
15//! results with the same logic, and a rule only matches on `Match`
16//! ([`crate::condition`]), so `Unknown` never allows.
17//!
18//! # Several values
19//!
20//! A positive operator matches if **any** value matches. A negative
21//! operator matches if **no** value matches: `not_contains [a, b]` means
22//! the fact contains neither `a` nor `b`.
23//!
24//! # Comparing text
25//!
26//! Strings are compared after Unicode NFC normalisation, so composed and
27//! decomposed spellings of one name are equal. Unless the criterion sets
28//! `case_sensitive: true`, both sides are then folded with the Unicode
29//! simple upper-case mapping: one character to one character, with no
30//! locale rules, so the result does not depend on the machine's language.
31//! This is how NTFS compares names: `i`, `I` and the dotless `ı` are equal
32//! everywhere, and the dotted capital `İ` is distinct from all three. A
33//! character whose upper case is several characters, such as `ß`, is left
34//! as it is. Hash values are compared as hex digits in either case.
35//!
36//! Names in a path (`path.full`, `path.directory`, `path.file_name`,
37//! `path.extension` and `path.share`) are compared as NTFS compares them
38//! instead (#399, [`fold_path`]): the fact is not NFC-normalised, since
39//! the volume stores names as written and a composed and a decomposed
40//! spelling are two files, and both sides are upper-cased with the NTFS
41//! upcase table ([`palisade_core::upcase`]), which leaves `ı`, `ſ` and the
42//! Kelvin sign apart from ASCII (`ſetup.exe` is not `SETUP.EXE`) and folds
43//! some characters Unicode does not (`ᾀ` is `ᾈ`). A rule's value is read in
44//! NFC, the form a bundle stores text in, before it is upper-cased.
45//!
46//! # Paths
47//!
48//! Path facts and path values pass through the same lexical normalisation
49//! ([`palisade_core::path`]). A path criterion evaluates to `Unknown` when
50//! the path is missing, is not a drive or UNC path, or contains a short
51//! (8.3) name the agent could not expand. A mapped network drive matches in
52//! both its drive form and its UNC form ([`PathFact::alias`]).
53//!
54//! On a volume whose case folding is not known to be the standard NTFS
55//! table ([`PathFact::fold_unknown`], every network share among them), the
56//! folded key is not proof either way: the volume may treat `ſetup.exe`
57//! and `SETUP.EXE` as one name. A path test is then `Unknown`, with
58//! [`Note::FoldUnknown`], whenever its result would relax its rule: a miss
59//! (or, negated, a match) in a `deny` or `audit`, so the decision falls to
60//! `unknown_as` and the implicit deny (ADR 0018); and a match in a rule
61//! that lets the object run, trusts it or excludes it, so a path allow
62//! there never matches. The direction counts the `not` nodes above the
63//! criterion ([`CompiledCriterion::eval_under`]).
64//!
65//! On `path.full` and `path.directory`:
66//!
67//! - `starts_with` ends at a component boundary: `C:\Tools` matches
68//!   `C:\Tools\a.exe` but not `C:\ToolsX\a.exe`.
69//! - A value may start with a path variable, such as `%PROGRAMFILES%\App`,
70//!   for `equals`, `starts_with` and `wildcard` and their negations. The
71//!   variable is expanded for this evaluation ([`PathVariables`]); a
72//!   variable with no value makes the criterion `Unknown`.
73//! - In wildcards, `*` matches any run of characters within one component
74//!   (as a whole component it needs at least one character, so `C:\*`
75//!   does not match the bare root `C:\`),
76//!   `?` exactly one character other than `\`, and `**` any run of
77//!   characters across components. As a whole component (`\**\`, a
78//!   trailing `\**` or a leading `**\`), `**` matches zero or more whole
79//!   components, so `C:\a\**` matches `C:\a` itself and everything below
80//!   it, and `C:\a\**\b.exe` matches `C:\a\b.exe`. `[*]` and `[?]` match
81//!   a literal `*` or `?`. A value written with `/` is read with `\`.
82//! - An alternate data stream is its own object. On `path.full`, a value
83//!   that does not name a stream never matches one, and a value that names
84//!   a stream only matches streams: `C:\x\*` does not match
85//!   `C:\x\a.txt:payload`, `C:\x\*:*` does, and `**:**` matches no plain
86//!   file. A value names a stream when its last component has a `:` that is
87//!   not a drive letter's. `match_ads: true`, on a positive test of
88//!   `path.full`, lets a value that names no stream also match the streams
89//!   of a file it matches; a negative test cannot take it, so a stream never
90//!   escapes a rule written for its file. A regular expression is never
91//!   tested against a stream's own name, so by default it never matches a
92//!   stream; with `match_ads: true` it is tested against the file that holds
93//!   the stream, and matches the stream if it matches that file. `path.directory`, `path.file_name` and
94//!   `path.extension` describe the file that holds the stream.
95//!
96//! On every other string field, `*` and `**` match any run of characters,
97//! and `?` matches one.
98//!
99//! **Path identity is only trusted where users cannot write.** In a rule
100//! that lets an object run, trusts it or excludes it (an allow, and the
101//! other actions with [`ActionKind::needs_identity`], #34), a positive
102//! `path.*` test that would match evaluates to `Unknown`,
103//! with the note [`Note::PathAclUnsafe`], unless the facts show that the
104//! file is on a fixed local volume and that no non-administrative principal
105//! can write it or a directory above it ([`PathFact::acl_proven`]). On a
106//! removable, optical or network volume, or one of unknown kind, the ACL
107//! proves nothing: whoever holds the disk, or the server, decides what its
108//! folders hold.
109//! `Unknown` rather than `NoMatch`, so that the test also fails closed under
110//! negation.
111//!
112//! # Regular expressions
113//!
114//! `regex` and `not_regex` use a linear-time engine with RE2 semantics (a
115//! lazy DFA with a PikeVM fallback; no backtracking).
116//! Patterns are anchored at both ends and are case-insensitive unless
117//! `case_sensitive: true`. Case-insensitive matching uses the engine's
118//! Unicode simple case folding, which differs from the folding above for a
119//! few characters (the dotless `ı` does not match `i` or `I`). On path
120//! fields the fact is the normalised path, so write `\\` for each
121//! separator. These constructs are not supported and are rejected when the
122//! policy is validated:
123//!
124//! - look-around: `(?=…)`, `(?!…)`, `(?<=…)`, `(?<!…)`. Write the negative
125//!   part as a second criterion with `not_regex`, in an `all` with the first.
126//! - backreferences: `\1`, `\k<name>`.
127//! - patterns whose compiled form exceeds [`REGEX_SIZE_LIMIT`].
128//!
129//! Path variables are not expanded inside regular expressions.
130//!
131//! `anchored: false` lets a pattern match anywhere in the fact instead of
132//! the whole fact (`Suite [0-9]+` then matches `Example Suite 12 (x64)`).
133//! Only `regex` and `not_regex` take it.
134//!
135//! # Versions
136//!
137//! A version is up to four dot-separated numbers, each at most 65535, with
138//! missing parts read as zero: `10.0` equals `10.0.0.0`. Facts may also
139//! separate the numbers with commas (`10, 0, 19041, 1`). A fact with a
140//! non-numeric suffix (`10.0.19041.1 (release)`) is compared without it,
141//! with the note [`Note::VersionSuffixStripped`]. A fact that is not a
142//! version at all is `Unknown`, with [`Note::VersionUnparseable`], so it
143//! never satisfies a version test in either direction. The bounds mean the
144//! same in allow and deny rules: `version_between [min, max]` includes both.
145//! On version fields, `equals` and `not_equals` compare versions too.
146//!
147//! # Signers
148//!
149//! A signer criterion looks at every signature on the object and matches
150//! if any of them matches. By default only signatures whose status is
151//! valid, valid with an expired but timestamped certificate, or
152//! catalog-signed take part: a revoked, untrusted, expired or
153//! digest-mismatched signature never vouches for an object, and an
154//! unsigned object matches no signer. The criterion's `signer` options
155//! choose other statuses, a source and an index, and add constraints on the
156//! same signature; see [`signer`].
157//!
158//! # Context
159//!
160//! Context criteria (#33) test the user, device and session in
161//! [`EvalContext::context`] rather than the object. They follow the same
162//! rules: a fact that was not collected is `Unknown`, and so is its
163//! negation.
164//!
165//! - SIDs (`user.sid`, `user.primary_group`) are compared in canonical
166//!   form: `s-1-5-32-544` equals `S-1-5-32-544`, and leading zeros are
167//!   ignored. A SID fact that is not a SID is `Unknown`, with
168//!   [`Note::FactMalformed`].
169//! - Sets (`user.groups`, `device.groups`, `device.tags`) take `member_of`
170//!   and `not_member_of`: `member_of` matches if the set holds any value,
171//!   `not_member_of` if it holds none. Group members are SIDs or
172//!   cloud-directory object IDs (GUIDs, in any case); a member of the fact
173//!   that is neither is unknown, with [`Note::FactMalformed`], so it never
174//!   lets `not_member_of` match. Tags are text, and case-insensitive unless
175//!   `case_sensitive: true`.
176//! - `user.name` is tested against both the account name (`DOMAIN\user`)
177//!   and the user principal name, and matches if either does. A form that
178//!   was not collected counts as `Unknown`, so a negative test only matches
179//!   when both forms are known. Regular expressions are not allowed on it
180//!   (#32); match principals by SID where you can.
181//! - Yes-or-no facts take `is_true` and `is_false`, with no values.
182//! - `session.type` takes `equals` and `not_equals` with the names
183//!   `console`, `rdp`, `remote_shell`, `service`, `batch` and `network`.
184//! - The other device and session facts are text or versions, compared as
185//!   above.
186//!
187//! ## Numbers, levels and dates
188//!
189//! `eq`, `ne`, `gt`, `ge`, `lt`, `le` and `between` compare whole numbers
190//! (`device.os_build`, `session.id`), integrity levels (`user.integrity_level`,
191//! ordered `untrusted` < `low` < `medium` < `medium_plus` < `high` <
192//! `system` < `protected`) and dates (`time.date`, `YYYY-MM-DD`, which also
193//! takes `date_between`). `between` and `date_between` take a minimum and a
194//! maximum and include both. Numbers are decimal with no sign, at most
195//! 2^64 - 1.
196//!
197//! ## Addresses
198//!
199//! `session.client_ip` is one address and `net.ip` the set of local
200//! addresses; a test of the set matches if any address matches.
201//! `ip_in_cidr` takes CIDR blocks (`10.0.0.0/8`, `2001:db8::/32`, whose
202//! address must be the first of the block), `ip_between` takes ranges
203//! (`192.168.1.10-192.168.1.20`, or `192.168.1.10-20`), and `ip_wildcard`
204//! takes IPv4 octet patterns (`10.*.*.*`). `equals` compares addresses, and
205//! the set operators test members of `net.ip`. An IPv4 address written in
206//! IPv6 form (`::ffff:10.0.0.1`) is the IPv4 address. [`net`] parses all of
207//! these, and scopes (#38) use it too. `net.mac` holds MAC addresses
208//! (`aa:bb:cc:01:02:03`, `AA-BB-CC-01-02-03` or `aabbcc010203`).
209//!
210//! ## Sets
211//!
212//! `member_of` and `any_of` match if the set holds any value, `all_of` if it
213//! holds every value, and `not_member_of` if it holds none. A member of a
214//! principal set that is neither a SID nor an object ID makes a value it
215//! might be unknown, so it never lets `not_member_of` match or `all_of` fail.
216//! `net.ip` is a set of addresses: a set test (`member_of`, `any_of`,
217//! `all_of`, `not_member_of`) compares the listed addresses with it, so
218//! `all_of` needs every one present, while a network test (`ip_in_cidr`,
219//! `ip_between`, `ip_wildcard`) matches if any local address does.
220//! `net.dns_suffix` and `net.location` are sets of names, compared like tags.
221//!
222//! ## Directory units
223//!
224//! `user.ou` and `device.ou` read the distinguished name of the user's or
225//! device's directory object and test the unit it is in: the name without
226//! its first component. Names are compared component by component, without
227//! case or spaces around `=` and `,`, after decoding the escapes of RFC 4514
228//! (`\,` and `\2C` are the same comma). A name with an escape RFC 4514
229//! does not define cannot be compared: as a rule value it is invalid, and as
230//! a fact it is unknown. `include_sub_ous: true` also matches units below
231//! the named one.
232//!
233//! ## Time
234//!
235//! The agent supplies the weekday, time of day and date in the clock the
236//! policy's `time_zone_basis` names, from its trusted clock, and leaves them
237//! out when the clock cannot be trusted, so every time test is then unknown
238//! and an allow that depends on the time fails closed (#18). `weekday_in`
239//! takes `mon` to `sun`. `time_between [start, end]` (`HH:MM`) includes the
240//! start and excludes the end, and wraps midnight when the end is before
241//! the start (`22:00`, `06:00`); an empty window is rejected.
242//!
243//! ## Failing closed in mandatory blocklists
244//!
245//! A criterion in a mandatory blocklist may be `safety_critical: true`. When
246//! it is unknown, it counts towards the deny applying, so a shipped
247//! blocklist blocks an object whose facts are missing instead of letting it
248//! through ([`crate::condition::CompiledMatch::eval_mandatory`], #87).
249//! Validation rejects the option anywhere else.

277/// A three-valued result, with Kleene logic.
278#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
279#[repr(u8)]
280pub enum Tri {
281    /// The test failed.
282    NoMatch = 0,
283    /// The test passed.
284    Match = 1,
285    /// A fact the test needs is missing or cannot be trusted.
286    Unknown = 2,
287}
288
289impl Tri {
290    /// `Match` for `true`, `NoMatch` for `false`.
291    #[must_use]
292    pub const fn from_bool(b: bool) -> Self {
293        if b { Self::Match } else { Self::NoMatch }
294    }
295
296    /// Kleene AND: `NoMatch` if either is `NoMatch`, else `Unknown` if
297    /// either is `Unknown`, else `Match`.
298    #[must_use]
299    pub const fn and(self, other: Self) -> Self {
300        match (self, other) {
301            (Self::NoMatch, _) | (_, Self::NoMatch) => Self::NoMatch,
302            (Self::Unknown, _) | (_, Self::Unknown) => Self::Unknown,
303            (Self::Match, Self::Match) => Self::Match,
304        }
305    }
306
307    /// Kleene OR: `Match` if either is `Match`, else `Unknown` if either is
308    /// `Unknown`, else `NoMatch`.
309    #[must_use]
310    pub const fn or(self, other: Self) -> Self {
311        match (self, other) {
312            (Self::Match, _) | (_, Self::Match) => Self::Match,
313            (Self::Unknown, _) | (_, Self::Unknown) => Self::Unknown,
314            (Self::NoMatch, Self::NoMatch) => Self::NoMatch,
315        }
316    }
317
318    /// Kleene NOT: `Unknown` stays `Unknown`.
319    #[must_use]
320    pub const fn not(self) -> Self {
321        match self {
322            Self::NoMatch => Self::Match,
323            Self::Match => Self::NoMatch,
324            Self::Unknown => Self::Unknown,
325        }
326    }
327}

329/// Something an evaluation noticed, for the decision trace (#41).
330#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
331#[repr(u8)]
332pub enum Note {
333    /// A fact the criterion needs was not provided.
334    FactMissing = 0,
335    /// A path test in a rule that lets an object run, trusts it or excludes
336    /// it matched a path that users may be able to write, whose
337    /// permissions are unknown, or that is not on a fixed local volume.
338    PathAclUnsafe = 1,
339    /// The path contains a short (8.3) name the agent could not expand.
340    ShortNameUnresolved = 2,
341    /// The path is not a drive or UNC path, such as an unmapped device path.
342    PathUnresolved = 3,
343    /// A value names a path variable that has no value here.
344    UnknownVariable = 4,
345    /// A version fact is not a version.
346    VersionUnparseable = 5,
347    /// A version fact had a non-numeric suffix, which was ignored.
348    VersionSuffixStripped = 6,
349    /// The object has signatures, but none with a trusted status.
350    SignerNotTrusted = 7,
351    /// A fact is not in the form its field needs, such as a digest of the
352    /// wrong length.
353    FactMalformed = 8,
354    /// The agent ran out of the rule's budget before it collected a probed
355    /// fact (#33, #329).
356    ConditionTimeout = 9,
357    /// The path is on a volume whose case folding is not known to be the
358    /// standard NTFS table, such as any network share (#399): two names
359    /// that fold apart here may be one name there, and the reverse.
360    FoldUnknown = 10,
361}

372        Self::VersionSuffixStripped,

384            Self::PathAclUnsafe => "path_acl_unsafe",

386            Self::PathUnresolved => "path_unresolved",
387            Self::UnknownVariable => "unknown_variable",
388            Self::VersionUnparseable => "version_unparseable",
389            Self::VersionSuffixStripped => "version_suffix_stripped",
390            Self::SignerNotTrusted => "signer_not_trusted",
391            Self::FactMalformed => "fact_malformed",
392            Self::ConditionTimeout => "condition_timeout",
393            Self::FoldUnknown => "fold_unknown",
394        }
395    }
396}

398/// A set of [`Note`]s.
399#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash)]
400pub struct Notes(u16);
401
402impl Notes {
403    /// Adds a note.
404    pub fn insert(&mut self, note: Note) {
405        self.0 |= 1 << (note as u8);
406    }
407
408    /// Adds every note in `other`.
409    pub fn extend(&mut self, other: Self) {
410        self.0 |= other.0;
411    }
412
413    /// Whether the set holds `note`.
414    #[must_use]
415    pub const fn contains(self, note: Note) -> bool {
416        self.0 & (1 << (note as u8)) != 0
417    }
418
419    /// Whether the set is empty.
420    #[must_use]
421    pub const fn is_empty(self) -> bool {
422        self.0 == 0
423    }
424
425    /// The notes in the set, in code order.
426    pub fn iter(self) -> impl Iterator<Item = Note> {
427        Note::ALL.into_iter().filter(move |n| self.contains(*n))
428    }
429}

454/// A version: four 16-bit parts, compared part by part.
455#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
456pub struct Version(pub [u16; 4]);
457
458impl Version {
459    /// Reads a version written as 1 to 4 dot-separated decimal numbers,
460    /// each at most 65535, with nothing else: the form a criterion value
461    /// must have.
462    #[must_use]
463    pub fn parse_strict(s: &str) -> Option<Self> {
464        if !s.bytes().all(|b| b.is_ascii_digit() || b == b'.') {
465            return None;
466        }
467        match Self::parse_fact(s)? {
468            (version, false) => Some(version),
469            (_, true) => None,
470        }
471    }
472
473    /// Reads a version fact: leading white space is skipped, then 1 to 4
474    /// numbers are read, separated by `.` or by `,` and optional spaces (as
475    /// some version resources write them, `10, 0, 19041, 1`). Anything after
476    /// them is ignored if it does not start with a digit, `.` or `,`.
477    /// Returns the version and whether a suffix was ignored.
478    #[must_use]
479    pub fn parse_fact(s: &str) -> Option<(Self, bool)> {
480        let mut parts = [0u16; 4];
481        let mut rest = s.trim_start();
482        for (i, part) in parts.iter_mut().enumerate() {
483            let digits = rest.bytes().take_while(u8::is_ascii_digit).count();
484            if digits == 0 {
485                return None;
486            }
487            *part = rest[..digits].parse().ok()?;
488            rest = &rest[digits..];
489            if i == 3 {
490                break;
491            }
492            if let Some(after) = rest.strip_prefix('.') {
493                rest = after;
494            } else if let Some(after) = rest.strip_prefix(',') {
495                rest = after.trim_start_matches(' ');
496            } else {
497                break;
498            }
499        }
500        if rest.starts_with(|c: char| c.is_ascii_digit() || c == '.' || c == ',') {
501            return None;
502        }
503        Some((Self(parts), !rest.is_empty()))
504    }
505}

507impl core::fmt::Display for Version {
508    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
509        let [a, b, c, d] = self.0;
510        write!(f, "{a}.{b}.{c}.{d}")
511    }
512}

678impl CompiledCriterion {
679    /// Compiles a criterion. Policy validation compiles every criterion, so
680    /// a validated policy always compiles. Compiling also enforces the rules
681    /// that validation checks on the criterion's shape, so a criterion that
682    /// was never validated cannot compile past them: the operator must fit
683    /// the field, the number of values must fit the operator, values are at
684    /// most [`MAX_VALUE_BYTES`] bytes, and `case_sensitive` may only be set
685    /// on a field with a case ([`FieldClass::has_case`]).
686    ///
687    /// # Errors
688    ///
689    /// Returns every problem found: one for the criterion as a whole, or one
690    /// per value at fault.
691    pub fn compile(c: &Criterion) -> Result<Self, Vec<CompileError>> {
692        let whole = |kind| vec![CompileError { value: None, kind }];
693        let class = c.field.class();
694        if !c.operator.applies_to_field(c.field) {
695            return Err(whole(CompileErrorKind::OperatorFieldMismatch));
696        }
697        let (min, max) = c.operator.value_count();
698        if c.values.len() < min || c.values.len() > max {
699            return Err(whole(CompileErrorKind::ValueCount));
700        }
701        // Checked before the default applies, so an explicit `false` is
702        // rejected as well.
703        if c.case_sensitive.is_some() && !class.has_case() {
704            return Err(whole(CompileErrorKind::CaseSensitivityNotApplicable));
705        }
706        let mut options = option_problems(c);
707        options.extend(signer::option_problems(c).into_iter().map(|(_, kind)| kind));
708        options.extend(arg_index_out_of_range(c));
709        if !options.is_empty() {
710            return Err(options
711                .into_iter()
712                .map(|kind| CompileError { value: None, kind })
713                .collect());
714        }
715        // Before any value is compiled, so an oversized pattern costs
716        // nothing.
717        let oversized: Vec<CompileError> = c
718            .values
719            .iter()
720            .enumerate()
721            .filter_map(|(i, v)| {
722                value_too_long(v).map(|why| CompileError {
723                    value: Some(i),
724                    kind: CompileErrorKind::InvalidValue(why),
725                })
726            })
727            .collect();
728        if !oversized.is_empty() {
729            return Err(oversized);
730        }
731        let operator = c.operator.positive();
732        let case_sensitive = c.case_sensitive.unwrap_or(false);
733        let anchored = c.anchored.unwrap_or(true);
734        let values = compile_values(c.field, operator, case_sensitive, anchored, &c.values)?;
735        let probe = match (c.field.is_probe(), c.target.as_deref()) {
736            (false, _) => None,
737            (true, None) => {
738                return Err(whole(CompileErrorKind::InvalidValue(
739                    "this field needs a `target`: what to probe".to_owned(),
740                )));
741            }
742            (true, Some(t)) => Some(
743                crate::context::probe::probe_key(c.field, t, c.value_name.as_deref()).ok_or_else(
744                    || {
745                        let why = crate::context::probe::canonical_target(c.field, t)
746                            .err()
747                            .unwrap_or_default();
748                        whole(CompileErrorKind::InvalidValue(why))
749                    },
750                )?,
751            ),
752        };
753        Ok(Self {
754            field: c.field,
755            negated: !c.operator.is_positive(),
756            operator,
757            case_sensitive,
758            match_ads: c.match_ads.unwrap_or(false),
759            include_sub_ous: c.include_sub_ous.unwrap_or(false),
760            safety_critical: c.safety_critical,
761            signer: signer::compile_options(c),
762            probe,
763            arg_index: c.arg_index,
764            values,
765        })
766    }

768    /// Checks one value against the criterion's field and operator, even
769    /// when the operator does not fit the field or the number of values is
770    /// wrong, so validation can report every bad value in one pass. This
771    /// compiles the value, so a regular expression or wildcard costs its
772    /// compilation. Checks that need several values together, such as the
773    /// order of a `version_between` range, are left to [`Self::compile`].
774    ///
775    /// # Errors
776    ///
777    /// Returns what is wrong with the value.
778    pub fn check_value(c: &Criterion, value: &str) -> Result<(), CompileErrorKind> {
779        let case_sensitive = c.case_sensitive.unwrap_or(false);
780        compile_values(
781            c.field,
782            c.operator.positive(),
783            case_sensitive,
784            c.anchored.unwrap_or(true),
785            &[value.to_owned()],
786        )
787        .map(drop)
788        .map_err(|mut errors| errors.remove(0).kind)
789    }

811    /// Evaluates the criterion against one object's facts, in a match tree
812    /// where it is under an odd number of `not` nodes if `under_not`.
813    ///
814    /// On a path whose volume's case folding is not known
815    /// ([`PathFact::fold_unknown`], #399), a test of a name in the path is
816    /// `Unknown`, with [`Note::FoldUnknown`], whenever its result would make
817    /// the rule less strict: for a rule that lets the object run, trusts it
818    /// or excludes it, a result that pulls the rule towards applying; for
819    /// any other rule (a `deny` or `audit`), one that pulls it away. The
820    /// standard table can fold apart two names the volume treats as one,
821    /// or fold together two it keeps apart, so neither a match nor a miss
822    /// by key is proof there.
823    #[must_use]
824    pub fn eval_under(
825        &self,
826        facts: &ObjectFacts,
827        ctx: &EvalContext<'_>,
828        under_not: bool,
829    ) -> Evaluation {
830        let mut notes = Notes::default();
831        let positive = self.eval_positive(facts, ctx, &mut notes);
832        let mut result = if self.negated {
833            positive.not()
834        } else {
835            positive
836        };
837        if result != Tri::Unknown
838            && is_path_name(self.field)
839            && facts.path.as_ref().is_some_and(|p| p.fold_unknown)
840        {
841            // The leaf result that pulls the rule towards applying.
842            let towards = Tri::from_bool(!under_not);
843            let lenient = if ctx.action.needs_identity() {
844                result == towards
845            } else {
846                result != towards
847            };
848            if lenient {
849                notes.insert(Note::FoldUnknown);
850                result = Tri::Unknown;
851            }
852        }
853        Evaluation { result, notes }
854    }

856    fn eval_positive(&self, facts: &ObjectFacts, ctx: &EvalContext<'_>, notes: &mut Notes) -> Tri {
857        if let Some(key) = &self.probe {
858            return match ctx.context.probes.get_by_key(key) {
859                Some(probe) => self.eval_probe(probe, notes),
860                None => {
861                    notes.insert(Note::FactMissing);
862                    Tri::Unknown
863                }
864            };
865        }
866        if self.field.is_context() {
867            return match ctx.context.fact(self.field) {
868                Some(fact) => self.eval_context(fact, notes),
869                None => {
870                    notes.insert(Note::FactMissing);
871                    Tri::Unknown
872                }
873            };
874        }
875        match self.field {
876            field if field.is_signer() => self.eval_signers(facts.signers.as_deref(), notes),
877            Field::PathFull | Field::PathDirectory | Field::PathFileName | Field::PathExtension => {
878                let Some(path) = &facts.path else {
879                    notes.insert(Note::FactMissing);
880                    return Tri::Unknown;
881                };
882                let raw = self.eval_path(path, ctx, notes);
883                // A path only identifies an object for a rule that lets it
884                // run, trusts it or excludes it when users cannot replace
885                // what is at that path.
886                if raw == Tri::Match && ctx.action.needs_identity() && !path.acl_proven() {
887                    notes.insert(Note::PathAclUnsafe);
888                    return Tri::Unknown;
889                }
890                raw
891            }
892            field if field.is_path_location() => {
893                let Some(path) = &facts.path else {
894                    notes.insert(Note::FactMissing);
895                    return Tri::Unknown;
896                };
897                match (path.location(field), &self.values) {
898                    (crate::facts::PathLocation::Text(Some(t)), _) => self.eval_value(t, notes),
899                    (crate::facts::PathLocation::Bool(Some(b)), Values::Bool(want)) => {
900                        Tri::from_bool(b == *want)
901                    }
902                    (crate::facts::PathLocation::None, _) => Tri::NoMatch,
903                    (crate::facts::PathLocation::Bool(Some(_)), _) => malformed(notes),
904                    (
905                        crate::facts::PathLocation::Text(None)
906                        | crate::facts::PathLocation::Bool(None),
907                        _,
908                    ) => {
909                        notes.insert(Note::FactMissing);
910                        Tri::Unknown
911                    }
912                }
913            }
914            field => match facts.get(field) {
915                Some(fact) => self.eval_stored(fact, notes),
916                None => {
917                    notes.insert(Note::FactMissing);
918                    Tri::Unknown
919                }
920            },
921        }
922    }

924    /// A fact about the user, device or session.
925    fn eval_context(&self, fact: ContextFact<'_>, notes: &mut Notes) -> Tri {
926        match (fact, &self.values) {
927            (ContextFact::Bool(have), Values::Bool(want)) => Tri::from_bool(have == *want),
928            (ContextFact::Session(have), Values::Session(want)) => {
929                Tri::from_bool(want.contains(&have))
930            }
931            (ContextFact::Set(members), Values::Principals(want)) => {
932                // A member that is neither a SID nor an object ID could be
933                // any principal, so a value it might be is unknown rather
934                // than absent: it must not let `not_member_of` match, nor
935                // fail an `all_of` that the readable members satisfy. The
936                // members are normalised into a reused buffer, so the test
937                // does not allocate (#42).
938                scratch::with_buffer(|canon| {
939                    let mut unreadable = false;
940                    for member in members {
941                        canon.clear();
942                        unreadable |= !normalize_principal_into(member, canon);
943                    }
944                    if unreadable {
945                        notes.insert(Note::FactMalformed);
946                    }
947                    let mut held = |w: &String| {
948                        let found = members.iter().any(|member| {
949                            canon.clear();
950                            normalize_principal_into(member, canon) && canon == w
951                        });
952                        if found {
953                            Tri::Match
954                        } else if unreadable {
955                            Tri::Unknown
956                        } else {
957                            Tri::NoMatch
958                        }
959                    };
960                    if self.operator == Operator::AllOf {
961                        want.iter().map(&mut held).fold(Tri::Match, Tri::and)
962                    } else {
963                        want.iter().map(&mut held).fold(Tri::NoMatch, Tri::or)
964                    }
965                })
966            }
967            (ContextFact::Set(members), Values::Tags(want)) => {
968                self.set_test(want.iter().map(|w| {
969                    members
970                        .iter()
971                        .any(|m| with_folded(m, self.case_sensitive, |m| m == w))
972                }))
973            }
974            (ContextFact::Number(n), _) => self.ordered(Ordinal::Number(n)),
975            (ContextFact::Level(l), _) => self.ordered(Ordinal::Level(l)),
976            (ContextFact::Date(d), _) => self.ordered(Ordinal::Date(d)),
977            (ContextFact::Ip(ip), _) => Tri::from_bool(self.ip_matches(ip)),
978            (ContextFact::Ips(ips), Values::Ips(want)) if self.operator.is_set() => {
979                let have: Vec<IpAddr> = ips.iter().map(|ip| net::canonical(*ip)).collect();
980                self.set_test(want.iter().map(|w| have.contains(w)))
981            }
982            // A network test of a set of addresses: any address may match.
983            (ContextFact::Ips(ips), _) => Tri::from_bool(ips.iter().any(|ip| self.ip_matches(*ip))),
984            (ContextFact::Macs(macs), Values::Macs(want)) => {
985                self.set_test(want.iter().map(|w| macs.contains(w)))
986            }
987            (ContextFact::Weekday(day), Values::Weekdays(want)) => {
988                Tri::from_bool(want.contains(&day))
989            }
990            (ContextFact::Minute(m), Values::TimeWindow(start, end)) => {
991                Tri::from_bool(if start < end {
992                    *start <= m && m < *end
993                } else {
994                    // The window wraps midnight.
995                    m >= *start || m < *end
996                })
997            }
998            (ContextFact::Text(dn), Values::Dns(want)) => match dn_components(dn) {
999                // The object's own name is its first component; the unit it
1000                // is in is the rest.
1001                Some(have) if have.len() >= 2 => {
1002                    let unit = &have[1..];
1003                    Tri::from_bool(want.iter().any(|w| {
1004                        if self.include_sub_ous {
1005                            unit.len() >= w.len() && unit.ends_with(w)
1006                        } else {
1007                            unit == w.as_slice()
1008                        }
1009                    }))
1010                }
1011                _ => {
1012                    notes.insert(Note::FactMalformed);
1013                    Tri::Unknown
1014                }
1015            },
1016            (ContextFact::Text(fact), Values::Sid(want)) => scratch::with_buffer(|have| {
1017                if normalize_sid_into(fact, have) {
1018                    Tri::from_bool(want.iter().any(|w| w == have))
1019                } else {
1020                    notes.insert(Note::FactMalformed);
1021                    Tri::Unknown
1022                }
1023            }),
1024            (ContextFact::Names(account, upn), _) => {
1025                let mut result = Tri::NoMatch;
1026                for form in [account, upn] {
1027                    if result == Tri::Match {
1028                        break;
1029                    }
1030                    result = result.or(match form {
1031                        Some(name) => self.eval_value(name, notes),
1032                        None => {
1033                            notes.insert(Note::FactMissing);
1034                            Tri::Unknown
1035                        }
1036                    });
1037                }
1038                result
1039            }
1040            (ContextFact::Text(fact), _) => self.eval_value(fact, notes),
1041            (ContextFact::Args(args), _) => match self.arg_index {
1042                // A position: no argument there is nothing to compare, so no
1043                // comparison holds, and its negation does.
1044                Some(i) => match crate::context::cmdline::arg_at(args, i) {
1045                    Some(arg) => self.eval_value(arg, notes),
1046                    None => Tri::NoMatch,
1047                },
1048                // Any argument after the program name.
1049                None => args
1050                    .iter()
1051                    .skip(1)
1052                    .map(|a| self.eval_value(a, notes))
1053                    .fold(Tri::NoMatch, Tri::or),
1054            },
1055            // A fact of another shape than the field's values: the
1056            // collector produced something this field does not hold.
1057            _ => {
1058                notes.insert(Note::FactMalformed);
1059                Tri::Unknown
1060            }
1061        }
1062    }

1064    /// What the agent found at a probed target (#329). The operator is
1065    /// positive here; `eval` negates it.
1066    fn eval_probe(&self, probe: &crate::context::Probe, notes: &mut Notes) -> Tri {
1067        use crate::context::Probe;
1068        match (probe, &self.values) {
1069            // The budget ran out before the agent looked: unknown, and so
1070            // is every negation (ADR 0018).
1071            (Probe::TimedOut, _) => {
1072                notes.insert(Note::ConditionTimeout);
1073                Tri::Unknown
1074            }
1075            (Probe::Absent, Values::Exists) => Tri::NoMatch,
1076            (_, Values::Exists) => Tri::Match,
1077            // Nothing to compare: no comparison holds, so its negation does.
1078            (Probe::Absent, _) => Tri::NoMatch,
1079            (Probe::Number(n), Values::Ordered(_) | Values::OrderedRange(..)) => {
1080                self.ordered(Ordinal::Number(*n))
1081            }
1082            (Probe::Text(t), Values::Ordered(_) | Values::OrderedRange(..)) => match number(t) {
1083                Some(n) => self.ordered(Ordinal::Number(n)),
1084                None => malformed(notes),
1085            },
1086            (Probe::Number(n), _) => scratch::with_buffer(|text| {
1087                use core::fmt::Write as _;
1088                text.clear();
1089                let _ = write!(text, "{n}");
1090                self.eval_value(text, notes)
1091            }),
1092            (Probe::Text(t), _) => self.eval_value(t, notes),
1093            // A key, file or folder has no value, and a binary value none
1094            // this can compare.
1095            (Probe::Present | Probe::Other, _) => malformed(notes),
1096        }
1097    }

1120                ("false", Values::Bool(want)) => Tri::from_bool(!*want),
1121                _ => malformed(notes),
1122            },
1123            FieldClass::Guid => match (canonical_guid(fact), &self.values) {
1124                (Some(have), Values::Text(want)) => Tri::from_bool(want.contains(&have)),
1125                _ => malformed(notes),
1126            },
1127            _ => self.eval_value(fact, notes),
1128        }

1142    /// A hash, text or version fact.
1143    fn eval_value(&self, fact: &str, notes: &mut Notes) -> Tri {
1144        match &self.values {
1145            Values::Hash(values, hex_len) => {
1146                // A malformed digest is a fault in whoever computed it, not
1147                // evidence that the object differs.
1148                let mut have = [0u8; 64];
1149                let Some(have) = have.get_mut(..hex_len / 2) else {
1150                    notes.insert(Note::FactMalformed);
1151                    return Tri::Unknown;
1152                };
1153                if fact.len() != *hex_len || anchor::decode_hex_into(fact, have).is_none() {
1154                    notes.insert(Note::FactMalformed);
1155                    return Tri::Unknown;
1156                }
1157                Tri::from_bool(values.chunks_exact(have.len()).any(|v| v == have))
1158            }
1159            Values::Version(values) => match version_fact(fact, notes) {
1160                Some(have) => Tri::from_bool(values.iter().any(|want| match self.operator {
1161                    Operator::VersionGt => have > *want,
1162                    Operator::VersionGe => have >= *want,
1163                    Operator::VersionLt => have < *want,
1164                    Operator::VersionLe => have <= *want,
1165                    // `equals` and `version_eq`.
1166                    _ => have == *want,
1167                })),
1168                None => Tri::Unknown,
1169            },
1170            Values::VersionRange(min, max) => match version_fact(fact, notes) {
1171                Some(have) => Tri::from_bool(*min <= have && have <= *max),
1172                None => Tri::Unknown,
1173            },
1174            // A name in a path is matched as the volume stores it, with no
1175            // NFC (#399).
1176            Values::Regex(patterns) if is_path_name(self.field) => {
1177                Tri::from_bool(patterns.iter().any(|p| p.is_match(fact)))
1178            }
1179            Values::Regex(patterns) => with_nfc(fact, |text| {
1180                Tri::from_bool(patterns.iter().any(|p| p.is_match(text)))
1181            }),
1182            Values::Wildcard(patterns) => self.with_fact_folded(fact, |text| {
1183                Tri::from_bool(patterns.iter().any(|p| p.is_match(text)))
1184            }),
1185            Values::Text(values) => self.with_fact_folded(fact, |fact| {
1186                Tri::from_bool(values.iter().any(|v| self.text_op(fact, v)))
1187            }),
1188            // Only built for path fields, which `eval_path_form` handles,
1189            // and for context fields, which `eval_context` handles.
1190            Values::PathLiteral(_)
1191            | Values::PathWildcard(_)
1192            | Values::Sid(_)
1193            | Values::Principals(_)
1194            | Values::Tags(_)
1195            | Values::Session(_)
1196            | Values::Bool(_)
1197            | Values::Ordered(_)
1198            | Values::OrderedRange(..)
1199            | Values::Ips(_)
1200            | Values::IpRanges(_)
1201            | Values::IpWildcards(_)
1202            | Values::Macs(_)
1203            | Values::Dns(_)
1204            | Values::Weekdays(_)
1205            | Values::TimeWindow(..)
1206            | Values::Exists => {
1207                notes.insert(Note::FactMalformed);
1208                Tri::Unknown
1209            }
1210        }
1211    }

1224    /// An ordered comparison of a number, an integrity level or a date.
1225    fn ordered(&self, have: Ordinal) -> Tri {
1226        let ok = match &self.values {
1227            Values::Ordered(want) => want.iter().any(|w| {
1228                // Values of another kind never compare; compilation only
1229                // builds values of the field's kind.
1230                core::mem::discriminant(w) == core::mem::discriminant(&have)
1231                    && match self.operator {
1232                        Operator::Gt => have > *w,
1233                        Operator::Ge => have >= *w,
1234                        Operator::Lt => have < *w,
1235                        Operator::Le => have <= *w,
1236                        _ => have == *w,
1237                    }
1238            }),
1239            Values::OrderedRange(min, max) => {
1240                core::mem::discriminant(min) == core::mem::discriminant(&have)
1241                    && *min <= have
1242                    && have <= *max
1243            }
1244            _ => return Tri::Unknown,
1245        };
1246        Tri::from_bool(ok)
1247    }

1286    /// One spelling of the object's path.
1287    fn eval_path_form(
1288        &self,
1289        path: &NormalizedPath,
1290        ctx: &EvalContext<'_>,
1291        notes: &mut Notes,
1292    ) -> Tri {
1293        // A bare root (`C:\`) has no file name and no parent directory: a
1294        // test of either is unknown, so its negation cannot match.
1295        let bare_root = path.file_name().is_none();
1296        if bare_root && self.field != Field::PathFull {
1297            notes.insert(Note::FactMissing);
1298            return Tri::Unknown;
1299        }
1300        let raw = match self.field {
1301            // A file with no extension has the empty extension.
1302            Field::PathFileName => return self.eval_value(path.file_name().unwrap_or(""), notes),
1303            Field::PathExtension => return self.eval_value(path.extension().unwrap_or(""), notes),
1304            Field::PathDirectory => path.directory().unwrap_or(""),
1305            _ => path.as_str(),
1306        };
1307        // Only `path.full` can name a stream; on `path.directory` no value
1308        // or fact names one.
1309        let fact_stream = self.field == Field::PathFull && path.stream().is_some();
1310        // With `match_ads`, a value that names no stream also matches the
1311        // streams of a file it matches: it is tested against the file.
1312        if fact_stream && self.match_ads {
1313            let mut result = self.eval_path_text(path.as_str(), true, ctx, notes);
1314            if result != Tri::Match {
1315                result = result.or(self.eval_path_text(path.without_stream(), false, ctx, notes));
1316            }
1317            return result;
1318        }
1319        self.eval_path_text(raw, fact_stream, ctx, notes)
1320    }

1322    /// A path test of `raw` (the whole path, or for `path.directory` the
1323    /// directory), which is a stream if `fact_stream`.
1324    fn eval_path_text(
1325        &self,
1326        raw: &str,
1327        fact_stream: bool,
1328        ctx: &EvalContext<'_>,
1329        notes: &mut Notes,
1330    ) -> Tri {
1331        match &self.values {
1332            Values::PathLiteral(values) => with_path_folded(raw, self.case_sensitive, |fact| {
1333                let mut result = Tri::NoMatch;
1334                for value in values {
1335                    // On `path.full`, a value that names a stream only
1336                    // matches streams, and one that does not only matches
1337                    // files.
1338                    if value.names_stream != fact_stream {
1339                        continue;
1340                    }
1341                    result = result.or(self.with_base(value.variable, ctx, notes, |base| {
1342                        let (want_base, want_rest) = joined(base, &value.rest);
1343                        match self.operator {
1344                            Operator::StartsWith => strip_joined(fact, want_base, want_rest)
1345                                .is_some_and(|rest| {
1346                                    rest.is_empty()
1347                                        || rest.starts_with('\\')
1348                                        || joined_ends_with_separator(want_base, want_rest)
1349                                }),
1350                            _ => {
1351                                strip_joined(fact, want_base, want_rest).is_some_and(str::is_empty)
1352                            }
1353                        }
1354                    }));
1355                }
1356                result
1357            }),
1358            Values::PathWildcard(values) => with_path_folded(raw, self.case_sensitive, |fact| {
1359                let mut result = Tri::NoMatch;
1360                for value in values {
1361                    if value.names_stream != fact_stream {
1362                        continue;
1363                    }
1364                    result = result.or(self.with_base(value.variable, ctx, notes, |base| {
1365                        fact.strip_prefix(base).is_some_and(|rest| {
1366                            // A drive root (`C:\`) is the variable itself.
1367                            let rest = if rest == "\\" && base.len() == 2 && base.ends_with(':') {
1368                                ""
1369                            } else {
1370                                rest
1371                            };
1372                            value.rest.is_match(rest)
1373                        })
1374                    }));
1375                }
1376                result
1377            }),
1378            // A regular expression cannot say whether it names a stream, so
1379            // on `path.full` it never matches one.
1380            Values::Regex(_) if fact_stream => Tri::NoMatch,
1381            // Text tests on `path.full` only count values that name a
1382            // stream when the fact is one, and only values that do not when
1383            // it is not.
1384            Values::Text(values) if self.field == Field::PathFull => {
1385                with_path_folded(raw, self.case_sensitive, |fact| {
1386                    Tri::from_bool(
1387                        values
1388                            .iter()
1389                            .any(|v| names_stream(v) == fact_stream && self.text_op(fact, v)),
1390                    )
1391                })
1392            }
1393            _ => self.eval_value(raw, notes),
1394        }
1395    }

1397    /// Runs `test` with the folded expansion of `variable` (without a
1398    /// trailing separator), or with `""` when there is no variable. Matches
1399    /// if any expansion passes; `Unknown` if the variable has no value.
1400    fn with_base(
1401        &self,
1402        variable: Option<PathVariable>,
1403        ctx: &EvalContext<'_>,
1404        notes: &mut Notes,
1405        test: impl Fn(&str) -> bool,
1406    ) -> Tri {
1407        let Some(variable) = variable else {
1408            return Tri::from_bool(test(""));
1409        };
1410        let bases = ctx.variables.get(variable);
1411        if bases.is_empty() {
1412            notes.insert(Note::UnknownVariable);
1413            return Tri::Unknown;
1414        }
1415        Tri::from_bool(bases.iter().any(|base| {
1416            with_path_folded(
1417                base.as_str().trim_end_matches('\\'),
1418                self.case_sensitive,
1419                &test,
1420            )
1421        }))
1422    }

1425/// Whether a text value on a path names a stream: its last component (the
1426/// text after the last `\`) contains a `:`. A value that is only a drive
1427/// (`C:`) names none, and neither does `:\Program Files\`; `a.txt:s` and
1428/// `a:payload` do.
1429fn names_stream(v: &str) -> bool {
1430    let last = v.rsplit('\\').next().unwrap_or(v);
1431    let b = v.as_bytes();
1432    let only_drive = b.len() == 2 && b[0].is_ascii_alphabetic() && b[1] == b':';
1433    !only_drive && last.contains(':')
1434}

1436/// `base` followed by `rest`, keeping the separator of a drive root (`C:`
1437/// and `""` give `C:\`), as two parts, so it is never built.
1438fn joined<'a>(base: &'a str, rest: &'a str) -> (&'a str, &'a str) {
1439    if rest.is_empty() && base.len() == 2 && base.ends_with(':') {
1440        (base, "\\")
1441    } else {
1442        (base, rest)
1443    }
1444}
1445
1446/// `fact` without the joined prefix `base` `rest`, if it starts with it.
1447fn strip_joined<'a>(fact: &'a str, base: &str, rest: &str) -> Option<&'a str> {
1448    fact.strip_prefix(base)?.strip_prefix(rest)
1449}
1450
1451/// Whether the joined text `base` `rest` ends with `\`.
1452fn joined_ends_with_separator(base: &str, rest: &str) -> bool {
1453    if rest.is_empty() {
1454        base.ends_with('\\')
1455    } else {
1456        rest.ends_with('\\')
1457    }
1458}

1536/// Compiles the values of a criterion whose operator fits its field.
1537fn compile_values(
1538    field: Field,
1539    operator: Operator,
1540    case_sensitive: bool,
1541    anchored: bool,
1542    values: &[String],
1543) -> Result<Values, Vec<CompileError>> {
1544    fn each<T>(
1545        values: &[String],
1546        f: impl Fn(&str) -> Result<T, CompileErrorKind>,
1547    ) -> Result<Vec<T>, Vec<CompileError>> {
1548        let mut out = Vec::with_capacity(values.len());
1549        let mut errors = Vec::new();
1550        for (i, v) in values.iter().enumerate() {
1551            match f(v) {
1552                Ok(t) => out.push(t),
1553                Err(kind) => errors.push(CompileError {
1554                    value: Some(i),
1555                    kind,
1556                }),
1557            }
1558        }
1559        if errors.is_empty() {
1560            Ok(out)
1561        } else {
1562            Err(errors)
1563        }
1564    }
1565    let invalid = |why: &str| CompileErrorKind::InvalidValue(why.to_owned());
1566
1567    Ok(match field.class() {
1568        FieldClass::Hash { hex_len } => Values::Hash(
1569            each(values, |v| {
1570                match normalize_hex(v).as_deref().and_then(anchor::decode_hex) {
1571                    Some(bytes) if bytes.len() * 2 == hex_len => Ok(bytes),
1572                    _ => Err(CompileErrorKind::InvalidValue(format!(
1573                        "expected {hex_len} hexadecimal digits, optionally after `0x`"
1574                    ))),
1575                }
1576            })?
1577            .concat()
1578            .into_boxed_slice(),
1579            hex_len,
1580        ),
1581        FieldClass::Digest => Values::Text(each(values, |v| match normalize_hex(v) {
1582            Some(hex) if matches!(hex.len(), 40 | 64 | 96 | 128) => Ok(hex),
1583            _ => Err(invalid(
1584                "expected 40, 64, 96 or 128 hexadecimal digits (a SHA-1 to SHA-512 digest), optionally after `0x`",
1585            )),
1586        })?),
1587        FieldClass::Guid => Values::Text(each(values, |v| {
1588            canonical_guid(v).ok_or_else(|| {
1589                invalid("expected a GUID such as `{12345678-9ABC-DEF0-1234-56789ABCDEF0}`, with or without braces")
1590            })
1591        })?),
1592        FieldClass::OidSet => Values::Tags(each(values, |v| {
1593            signer::canonical_oid(v).ok_or_else(|| {
1594                invalid("expected an object identifier in dotted form, such as `1.3.6.1.5.5.7.3.3`")
1595            })
1596        })?),
1597        FieldClass::Version => {
1598            let versions = each(values, |v| {
1599                Version::parse_strict(v).ok_or_else(|| {
1600                    invalid(
1601                        "expected a version of 1 to 4 dot-separated numbers, each at most 65535",
1602                    )
1603                })
1604            })?;
1605            match (operator, versions.as_slice()) {
1606                (Operator::VersionBetween, [min, max]) => {
1607                    if min > max {
1608                        return Err(vec![CompileError {
1609                            value: Some(1),
1610                            kind: CompileErrorKind::InvalidValue(format!(
1611                                "the maximum {max} is below the minimum {min}"
1612                            )),
1613                        }]);
1614                    }
1615                    Values::VersionRange(*min, *max)
1616                }
1617                _ => Values::Version(versions),
1618            }
1619        }
1620        FieldClass::Sid => Values::Sid(each(values, |v| {
1621            normalize_sid(v).ok_or_else(|| invalid("expected a SID, such as `S-1-5-32-544`"))
1622        })?),
1623        FieldClass::PrincipalSet => Values::Principals(each(values, |v| {
1624            normalize_principal(v).ok_or_else(|| {
1625                invalid(
1626                    "expected a SID, such as `S-1-5-32-544`, or a directory object ID, such as `00000000-0000-0000-0000-000000000000`",
1627                )
1628            })
1629        })?),
1630        FieldClass::TagSet => Values::Tags(each(values, |v| Ok(fold(v, case_sensitive)))?),
1631        FieldClass::SessionType => Values::Session(each(values, |v| {
1632            SessionType::from_name(v).ok_or_else(|| {
1633                invalid("expected one of `console`, `rdp`, `remote_shell`, `service`, `batch`, `network`")
1634            })
1635        })?),
1636        // The operator alone says what the fact must be; the number of
1637        // values (none) is checked with the operator.
1638        FieldClass::Bool => Values::Bool(operator == Operator::IsTrue),
1639        // `exists` and `not_exists` (#329), with no values.
1640        FieldClass::Presence | FieldClass::ProbeValue if operator == Operator::Exists => {
1641            Values::Exists
1642        }
1643        // A registry number is compared as a number.
1644        FieldClass::ProbeValue if operator.is_ordered() => {
1645            let parsed = each(values, |v| {
1646                number(v).map(Ordinal::Number).ok_or_else(|| {
1647                    invalid("expected a whole number from 0 to 18446744073709551615, in decimal")
1648                })
1649            })?;
1650            match (operator, parsed.as_slice()) {
1651                (Operator::Between, [min, max]) if min > max => {
1652                    return Err(vec![CompileError {
1653                        value: Some(1),
1654                        kind: invalid("the maximum is below the minimum"),
1655                    }]);
1656                }
1657                (Operator::Between, [min, max]) => Values::OrderedRange(*min, *max),
1658                _ => Values::Ordered(parsed),
1659            }
1660        }
1661        FieldClass::Number | FieldClass::IntegrityLevel | FieldClass::Date => {
1662            let parse = |v: &str| -> Result<Ordinal, CompileErrorKind> {
1663                match field.class() {
1664                    FieldClass::Number => number(v)
1665                        .map(Ordinal::Number)
1666                        .ok_or_else(|| invalid("expected a whole number from 0 to 18446744073709551615, in decimal")),
1667                    FieldClass::IntegrityLevel => IntegrityLevel::from_name(v)
1668                        .map(Ordinal::Level)
1669                        .ok_or_else(|| invalid("expected one of `untrusted`, `low`, `medium`, `medium_plus`, `high`, `system`, `protected`")),
1670                    _ => Date::parse(v)
1671                        .map(Ordinal::Date)
1672                        .ok_or_else(|| invalid("expected a date as `YYYY-MM-DD`")),
1673                }
1674            };
1675            let parsed = each(values, parse)?;
1676            match (operator, parsed.as_slice()) {
1677                (Operator::Between | Operator::DateBetween, [min, max]) => {
1678                    if min > max {
1679                        return Err(vec![CompileError {
1680                            value: Some(1),
1681                            kind: invalid("the maximum is below the minimum"),
1682                        }]);
1683                    }
1684                    Values::OrderedRange(*min, *max)
1685                }
1686                _ => Values::Ordered(parsed),
1687            }
1688        }
1689        FieldClass::Ip | FieldClass::IpSet => match operator {
1690            Operator::IpInCidr => Values::IpRanges(each(values, |v| {
1691                net::IpRange::parse_cidr(v).map_err(CompileErrorKind::InvalidValue)
1692            })?),
1693            Operator::IpBetween => Values::IpRanges(each(values, |v| {
1694                net::IpRange::parse_range(v).map_err(CompileErrorKind::InvalidValue)
1695            })?),
1696            Operator::IpWildcard => Values::IpWildcards(each(values, |v| {
1697                net::IpWildcard::parse(v).map_err(CompileErrorKind::InvalidValue)
1698            })?),
1699            _ => Values::Ips(each(values, |v| {
1700                net::parse_ip(v).ok_or_else(|| invalid("expected an IPv4 or IPv6 address"))
1701            })?),
1702        },
1703        FieldClass::MacSet => Values::Macs(each(values, |v| {
1704            net::parse_mac(v)
1705                .ok_or_else(|| invalid("expected a MAC address, such as `aa:bb:cc:01:02:03`"))
1706        })?),
1707        FieldClass::NameSet => Values::Tags(each(values, |v| Ok(fold(v, case_sensitive)))?),
1708        FieldClass::DistinguishedName => Values::Dns(each(values, |v| {
1709            dn_components(v).ok_or_else(|| {
1710                invalid("expected a distinguished name, such as `OU=Finance,DC=corp,DC=example`")
1711            })
1712        })?),
1713        FieldClass::Weekday => Values::Weekdays(each(values, |v| {
1714            Weekday::from_name(v).ok_or_else(|| invalid("expected one of `mon` to `sun`"))
1715        })?),
1716        FieldClass::TimeOfDay => {
1717            let minutes = each(values, |v| {
1718                parse_time_of_day(v).ok_or_else(|| {
1719                    invalid("expected a time of day as `HH:MM`, from `00:00` to `23:59`")
1720                })
1721            })?;
1722            match minutes.as_slice() {
1723                [start, end] if start == end => {
1724                    return Err(vec![CompileError {
1725                        value: Some(1),
1726                        kind: invalid("the window is empty: the end equals the start"),
1727                    }]);
1728                }
1729                [start, end] => Values::TimeWindow(*start, *end),
1730                // One value on its own, from `check_value`: the number of
1731                // values is checked with the operator.
1732                _ => Values::TimeWindow(0, 1),
1733            }
1734        }
1735        _ if operator == Operator::Regex => Values::Regex(each(values, |v| {
1736            compile_regex(&v.nfc().collect::<String>(), case_sensitive, anchored)
1737        })?),
1738        FieldClass::Path => match operator {
1739            Operator::Wildcard => Values::PathWildcard(each(values, |v| {
1740                let (variable, text, names_stream) = path_value(v, true)?;
1741                let rest = wildcard_regex(&fold_path_value(&text, case_sensitive), true)?;
1742                Ok(PathValue {
1743                    variable,
1744                    rest,
1745                    names_stream,
1746                })
1747            })?),
1748            Operator::Equals | Operator::StartsWith => Values::PathLiteral(each(values, |v| {
1749                let (variable, text, names_stream) = path_value(v, false)?;
1750                Ok(PathValue {
1751                    variable,
1752                    rest: fold_path_value(&text, case_sensitive),
1753                    names_stream,
1754                })
1755            })?),
1756            // `ends_with` and `contains` test the text: the value is only
1757            // folded, with `/` read as `\`. They do not expand path
1758            // variables, so a value that names one is a mistake.
1759            _ => Values::Text(each(values, |v| {
1760                if let Some(name) = known_variable_anywhere(v) {
1761                    return Err(CompileErrorKind::InvalidValue(format!(
1762                        "`%{name}%` is only expanded by `equals`, `starts_with` and `wildcard`"
1763                    )));
1764                }
1765                Ok(fold_path_value(&v.replace('/', "\\"), case_sensitive))
1766            })?),
1767        },
1768        FieldClass::FileName
1769        | FieldClass::Text
1770        | FieldClass::PrincipalName
1771        | FieldClass::ProbeValue
1772        | FieldClass::Presence => {
1773            let check = |v: &str| {
1774                if field == Field::PathExtension && v.starts_with('.') {
1775                    return Err(invalid("write the extension without its leading `.`"));
1776                }
1777                if matches!(field, Field::PathFileName | Field::PathExtension)
1778                    && v.contains(['\\', '/'])
1779                {
1780                    return Err(invalid("a file name cannot contain `\\` or `/`"));
1781                }
1782                Ok(if is_path_name(field) {
1783                    fold_path_value(v, case_sensitive)
1784                } else {
1785                    fold(v, case_sensitive)
1786                })
1787            };
1788            match operator {
1789                Operator::Wildcard => {
1790                    Values::Wildcard(each(values, |v| wildcard_regex(&check(v)?, false))?)
1791                }
1792                _ => Values::Text(each(values, check)?),
1793            }
1794        }
1795    })
1796}

1798/// Splits a value on `path.full` or `path.directory` into its variable and
1799/// the normalised rest, and reports whether it names a stream.
1800///
1801/// Without a variable, a literal must be a drive or UNC path; a wildcard
1802/// may be anything, such as `**\cmd.exe`. After a variable, the rest must
1803/// be empty or start with `\`, and must not contain `.` or `..` components,
1804/// which could climb out of the variable's directory.
1805fn path_value(
1806    v: &str,
1807    wildcard: bool,
1808) -> Result<(Option<PathVariable>, String, bool), CompileErrorKind> {
1809    let invalid = |why: String| CompileErrorKind::InvalidValue(why);
1810    let after_leading = variable_syntax(v).map_or(v, |(_, rest)| rest);
1811    if let Some(name) = known_variable_anywhere(after_leading) {
1812        return Err(invalid(format!(
1813            "`%{name}%` is only expanded at the start of a value"
1814        )));
1815    }
1816    let Some((name, rest)) = variable_syntax(v) else {
1817        // A wildcard drive (`?:\`, `*:\`) is read as a drive, under a
1818        // stand-in letter, so its `:` is not taken for a stream.
1819        let b = v.as_bytes();
1820        if wildcard
1821            && b.len() >= 2
1822            && matches!(b[0], b'?' | b'*')
1823            && b[1] == b':'
1824            && matches!(b.get(2), Some(b'\\' | b'/'))
1825        {
1826            let path = normalize(&format!("Q:\\{}", &v[2..]));
1827            let text = format!("{}{}", char::from(b[0]), &path.as_str()[1..]);
1828            return Ok((None, text, path.stream().is_some()));
1829        }
1830        let path = normalize(v);
1831        if !wildcard && !path.is_resolved() {
1832            return Err(invalid(
1833                "expected a full drive or UNC path, such as `C:\\Tools` or `\\\\server\\share`, or a path variable such as `%PROGRAMFILES%`".to_owned(),
1834            ));
1835        }
1836        let names_stream = path.stream().is_some();
1837        return Ok((None, path.as_str().to_owned(), names_stream));
1838    };
1839    let Some(variable) = PathVariable::from_name(name) else {
1840        return Err(invalid(format!("`%{name}%` is not a known path variable")));
1841    };
1842    let body = rest.trim_start_matches(['\\', '/']);
1843    if body.len() == rest.len() && !rest.is_empty() {
1844        return Err(invalid(format!(
1845            "`%{name}%` must be followed by `\\` or end the value"
1846        )));
1847    }
1848    // A stream-type suffix does not hide a `.` or `..` (`..::$DATA`).
1849    if body
1850        .split(['\\', '/'])
1851        .map(|part| part.split(':').next().unwrap_or(part))
1852        .any(|part| part == "." || part == "..")
1853    {
1854        return Err(invalid(
1855            "a value that starts with a path variable cannot contain `.` or `..` components"
1856                .to_owned(),
1857        ));
1858    }
1859    if body.is_empty() {
1860        return Ok((Some(variable), String::new(), false));
1861    }
1862    // Normalise under a stand-in root, so the rest is read as path
1863    // components and never as a UNC or device prefix.
1864    let path = normalize(&format!("C:\\{body}"));
1865    let text = match &path.as_str()[2..] {
1866        "\\" => String::new(),
1867        rest => rest.to_owned(),
1868    };
1869    Ok((Some(variable), text, path.stream().is_some()))
1870}

1990/// The components of a distinguished name, such as `OU=Finance,DC=corp`,
1991/// from the leaf: each `TYPE=value` with the type upper-cased and the value
1992/// decoded, trimmed and folded. The escapes of RFC 4514 are decoded, so
1993/// `\,` and `\2C` are the same comma, kept inside its component. `None` if
1994/// a component has no `=`, an empty type or value, or an escape that RFC
1995/// 4514 does not define (`\q`, a lone `\` or hex digits that are not
1996/// UTF-8): such a name cannot be compared, so a fact is unknown and a rule
1997/// value is invalid.
1998fn dn_components(s: &str) -> Option<Vec<String>> {
1999    /// One component being read: its type once `=` was seen, and its
2000    /// characters, each with whether it was escaped (escaped spaces are
2001    /// not trimmed).
2002    #[derive(Default)]
2003    struct Part {
2004        kind: Option<String>,
2005        chars: Vec<(char, bool)>,
2006        bytes: Vec<u8>,
2007    }
2008    impl Part {
2009        /// Moves pending hex-escaped bytes into `chars`; `None` if they
2010        /// are not UTF-8.
2011        fn flush(&mut self) -> Option<()> {
2012            if !self.bytes.is_empty() {
2013                let text = String::from_utf8(core::mem::take(&mut self.bytes)).ok()?;
2014                self.chars.extend(text.chars().map(|c| (c, true)));
2015            }
2016            Some(())
2017        }
2018        fn finish(mut self, out: &mut Vec<String>) -> Option<()> {
2019            self.flush()?;
2020            let kind = self.kind?;
2021            let kind = kind.trim();
2022            let start = self
2023                .chars
2024                .iter()
2025                .position(|&(c, e)| e || !c.is_whitespace())?;
2026            let end = self
2027                .chars
2028                .iter()
2029                .rposition(|&(c, e)| e || !c.is_whitespace())?;
2030            let value: String = self.chars[start..=end].iter().map(|&(c, _)| c).collect();
2031            if kind.is_empty() || !kind.bytes().all(|b| b.is_ascii_alphanumeric()) {
2032                return None;
2033            }
2034            out.push(format!(
2035                "{}={}",
2036                kind.to_ascii_uppercase(),
2037                fold(&value, false)
2038            ));
2039            Some(())
2040        }
2041    }
2042    let mut out = Vec::new();
2043    let mut part = Part::default();
2044    let mut chars = s.chars().peekable();
2045    while let Some(c) = chars.next() {
2046        match c {
2047            '\\' => {
2048                let next = chars.next()?;
2049                if next.is_ascii_hexdigit() {
2050                    let low = chars.next().filter(char::is_ascii_hexdigit)?;
2051                    let hex = [next, low].iter().collect::<String>();
2052                    part.bytes.push(u8::from_str_radix(&hex, 16).ok()?);
2053                } else if matches!(
2054                    next,
2055                    ' ' | '"' | '#' | '+' | ',' | ';' | '<' | '=' | '>' | '\\'
2056                ) {
2057                    part.flush()?;
2058                    part.chars.push((next, true));
2059                } else {
2060                    return None;
2061                }
2062                // An escape inside the type is not a valid type.
2063                part.kind.as_ref()?;
2064            }
2065            ',' => {
2066                core::mem::take(&mut part).finish(&mut out)?;
2067            }
2068            '=' if part.kind.is_none() => {
2069                part.flush()?;
2070                part.kind = Some(part.chars.drain(..).map(|(c, _)| c).collect());
2071            }
2072            _ => {
2073                part.flush()?;
2074                part.chars.push((c, false));
2075            }
2076        }
2077    }
2078    part.finish(&mut out)?;
2079    Some(out)
2080}

2117/// Compiles a user's regular expression, anchored at both ends unless
2118/// `anchored` is false.
2119fn compile_regex(
2120    pattern: &str,
2121    case_sensitive: bool,
2122    anchored: bool,
2123) -> Result<Regex, CompileErrorKind> {
2124    use regex_syntax::ast::ErrorKind;
2125    use regex_syntax::hir::{Hir, Look};
2126
2127    // Parse first, and reject anything that does not parse on its own. The
2128    // anchors are added to the parsed tree, and the engine is built from
2129    // that tree, so no pattern text is ever joined to other text: no
2130    // pattern can escape the anchors (`a)|(?:b` is a syntax error), and
2131    // nothing is printed and parsed again.
2132    let hir = regex_syntax::ParserBuilder::new()
2133        .case_insensitive(!case_sensitive)
2134        .build()
2135        .parse(pattern)
2136        .map_err(|e| match &e {
2137            regex_syntax::Error::Parse(ast) => match ast.kind() {
2138                ErrorKind::UnsupportedLookAround => CompileErrorKind::RegexLookAround,
2139                ErrorKind::UnsupportedBackreference => CompileErrorKind::RegexBackreference,
2140                _ => CompileErrorKind::RegexSyntax(e.to_string()),
2141            },
2142            _ => CompileErrorKind::RegexSyntax(e.to_string()),
2143        })?;
2144    let tree = if anchored {
2145        Hir::concat(vec![Hir::look(Look::Start), hir, Hir::look(Look::End)])
2146    } else {
2147        hir
2148    };
2149    engine().build_from_hir(&tree).map_err(|e| build_error(&e))
2150}

2152/// One piece of a wildcard pattern.
2153#[derive(Clone, Copy, PartialEq, Eq)]
2154enum Token {
2155    Literal(char),
2156    Separator,
2157    Star,
2158    DoubleStar,
2159    One,
2160}
2161
2162fn tokens(pattern: &str, path: bool) -> Vec<Token> {
2163    let chars: Vec<char> = pattern.chars().collect();
2164    let mut out = Vec::with_capacity(chars.len());
2165    let mut i = 0;
2166    while i < chars.len() {
2167        match chars[i] {
2168            '[' if matches!(chars.get(i + 1), Some('*' | '?'))
2169                && chars.get(i + 2) == Some(&']') =>
2170            {
2171                out.push(Token::Literal(chars[i + 1]));
2172                i += 3;
2173            }
2174            '*' => {
2175                let run = chars[i..].iter().take_while(|c| **c == '*').count();
2176                out.push(if run > 1 {
2177                    Token::DoubleStar
2178                } else {
2179                    Token::Star
2180                });
2181                i += run;
2182            }
2183            '?' => {
2184                out.push(Token::One);
2185                i += 1;
2186            }
2187            '\\' if path => {
2188                out.push(Token::Separator);
2189                i += 1;
2190            }
2191            c => {
2192                out.push(Token::Literal(c));
2193                i += 1;
2194            }
2195        }
2196    }
2197    out
2198}

2200/// Compiles a folded wildcard pattern to an anchored regular expression.
2201fn wildcard_regex(pattern: &str, path: bool) -> Result<Regex, CompileErrorKind> {
2202    let mut toks = tokens(pattern, path);
2203    if path {
2204        // `**\**` is the same as `**`: drop a whole-component `**` that
2205        // directly follows another.
2206        let mut i = 0;
2207        while i + 2 < toks.len() {
2208            let whole_first =
2209                toks[i] == Token::DoubleStar && (i == 0 || toks[i - 1] == Token::Separator);
2210            let whole_second = toks[i + 2] == Token::DoubleStar
2211                && matches!(toks.get(i + 3), None | Some(Token::Separator));
2212            if whole_first && toks[i + 1] == Token::Separator && whole_second {
2213                toks.drain(i + 1..i + 3);
2214            } else {
2215                i += 1;
2216            }
2217        }
2218    }
2219    let mut re = String::from(r"(?s)\A");
2220    let mut i = 0;
2221    while i < toks.len() {
2222        let next = toks.get(i + 1).copied();
2223        let after = toks.get(i + 2).copied();
2224        match toks[i] {
2225            // `\**\`: zero or more whole components.
2226            Token::Separator
2227                if path && next == Some(Token::DoubleStar) && after == Some(Token::Separator) =>
2228            {
2229                re.push_str(r"\\(?:.*\\)?");
2230                i += 3;
2231            }
2232            // A trailing `\**`: the directory itself or anything below it.
2233            Token::Separator if path && next == Some(Token::DoubleStar) && after.is_none() => {
2234                re.push_str(r"(?:\\.*)?");
2235                i += 2;
2236            }
2237            // A leading `**\`: any number of leading components.
2238            Token::DoubleStar if path && i == 0 && next == Some(Token::Separator) => {
2239                re.push_str(r"(?:.*\\)?");
2240                i += 2;
2241            }
2242            tok => {
2243                match tok {
2244                    Token::Separator => re.push_str(r"\\"),
2245                    // A `*` that is a whole component matches a component,
2246                    // which is never empty: `C:\*` does not match `C:\`.
2247                    Token::Star
2248                        if path
2249                            && (i == 0 || toks[i - 1] == Token::Separator)
2250                            && matches!(next, None | Some(Token::Separator)) =>
2251                    {
2252                        re.push_str(r"[^\\]+");
2253                    }
2254                    Token::Star if path => re.push_str(r"[^\\]*"),
2255                    Token::One if path => re.push_str(r"[^\\]"),
2256                    Token::Star | Token::DoubleStar => re.push_str(".*"),
2257                    Token::One => re.push('.'),
2258                    Token::Literal(c) => {
2259                        let mut buf = [0u8; 4];
2260                        re.push_str(&regex_syntax::escape(c.encode_utf8(&mut buf)));
2261                    }
2262                }
2263                i += 1;
2264            }
2265        }
2266    }
2267    re.push_str(r"\z");
2268    // The text is generated here, with every literal escaped.
2269    engine().build(&re).map_err(|e| build_error(&e))
2270}
