1//! Signature validity: timestamps, expiry, revocation and the
2//! verification-error taxonomy (#50).
3//!
4//! [`evaluate_validity`] takes a file's verified signatures
5//! ([`SignatureReport`], #48) and their chains and trust verdicts
6//! ([`TrustReport`], #49), and decides for each signature whether it is
7//! **valid as of when it was made**. The answer for each is one
8//! [`VerificationError`] code from the shared table in `palisade-core`,
9//! whose codes 0 to 28 are the OS code integrity ones, plus the evidence
10//! behind it.
11//!
12//! # Signing time
13//!
14//! Every timestamp is verified ([`super::verify_timestamps`]) against the
15//! TSA trust configuration. A timestamp is also not used when it is SHA-1
16//! and its time is after [`ValidityPolicy::sha1_timestamp_cutoff`], or
17//! when a certificate of its TSA chain is revoked (by the same timing rule
18//! as below). The **trusted signing time** is the earliest remaining valid
19//! timestamp. Nothing else is: the `signingTime` authenticated attribute is
20//! the signer's own claim and never counts.
21//!
22//! # Expiry
23//!
24//! The validity periods checked are those of every certificate in the full
25//! chain except a configured anchor at its top (an anchor's lifetime is
26//! policy's business, #224). "Now" is the later of the caller's clock and
27//! its clock floor ([`ValidityContext::clock_floor`]), so setting the clock
28//! back can never revive an expired certificate.
29//!
30//! - With a trusted signing time whose accuracy window lies inside every
31//!   period: [`TimeValidity::ValidTimestamped`], even if a certificate has
32//!   expired since. A trusted time outside a period is
33//!   [`TimeValidity::SignedOutsideValidity`].
34//! - Without one: [`TimeValidity::Valid`] while now is inside every period,
35//!   otherwise [`TimeValidity::Expired`] or [`TimeValidity::NotYetValid`].
36//! - A leaf with the Lifetime Signing EKU is [`TimeValidity::Expired`] once
37//!   it has expired, whatever the timestamp says.
38//! - [`ExpiryPolicy`] decides what fails: `TimestampAware` (the default)
39//!   fails anything but `Valid` and `ValidTimestamped`; `Strict` also fails
40//!   a certificate that has expired by now, timestamp or not; `Ignore` never
41//!   fails on expiry (the state is still reported).
42//! - When the clock is suspect (before the floor), "not yet valid" alone is
43//!   not a failure; it is reported as a warning.
44//!
45//! # Revocation
46//!
47//! Revocation data comes from the caller ([`RevocationSet`]); nothing here
48//! does I/O. Every certificate of the full chain, and of each TSA chain, is
49//! checked. A revoked certificate still counts as good for a signature whose
50//! trusted signing time (its latest bound) is before the revocation date,
51//! when [`ValidityPolicy::revocation_honours_timestamp`] is on, unless the
52//! reason is a key, CA or attribute authority compromise and
53//! [`ValidityPolicy::strict_key_compromise`] is on. With no trusted signing
54//! time, any matching entry revokes: the wall clock is never used to judge a
55//! revocation date. A file whose hash is listed is
56//! [`VerificationError::RevokedByHash`].
57//!
58//! # Per-certificate relaxations
59//!
60//! [`CertificateOptions`] carry an [`ErrorIgnoreFlags`] mask for one
61//! certificate, pinned by SHA-256 thumbprint or TBS hash (forms that bind
62//! the key; issuer and serial do not, so they cannot pin). When a pinned
63//! certificate is on a signature's full chain, the flags relax the matching
64//! checks for that signature, and every relaxation actually used is
65//! recorded in [`SignatureValidity::relaxed`] for the decision trace (#41).
66//!
67//! Two flags reach into chain building (#49).
68//! [`ErrorIgnoreFlags::IGNORE_BASIC_CONSTRAINTS`] lets a pinned certificate
69//! issue although it is not a CA or its path length is exceeded
70//! ([`ValidityPolicy::relax_trust`] passes it to the [`TrustConfig`]); any
71//! chain that used such a relaxation for an issuer no option allows fails
72//! with code 1008. [`ErrorIgnoreFlags::IGNORE_TIME_NESTING`] excuses a
73//! chain that is not time nested when
74//! [`ValidityPolicy::require_time_nesting`] asks for it (code 1007).
75

98/// What certificate expiry does to a signature.
99#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Default, Serialize)]
100#[serde(rename_all = "snake_case")]
101pub enum ExpiryPolicy {
102    /// Expiry never fails a signature (compatibility mode). The state is
103    /// still reported.
104    Ignore,
105    /// A signature is good while its chain is valid now, or when a trusted
106    /// timestamp proves it was made while the chain was valid (the default).
107    #[default]
108    TimestampAware,
109    /// As `TimestampAware`, and a certificate that has expired by now
110    /// always fails, timestamp or not.
111    Strict,
112}

114/// A per-certificate relaxation mask, carried on trusted-publisher rules.
115#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Default, Serialize)]
116pub struct ErrorIgnoreFlags(pub u8);
117
118impl ErrorIgnoreFlags {
119    /// Expiry does not fail the signature.
120    pub const IGNORE_EXPIRY: u8 = 0x01;
121    /// A revocation state that could not be obtained does not fail the
122    /// signature, even when [`RevocationFailure::FailClosed`] is set.
123    pub const IGNORE_REVOCATION_UNKNOWN: u8 = 0x02;
124    /// A chain that restricts its extended key usage away from code signing,
125    /// or a leaf whose key usage lacks `digitalSignature`, does not fail the
126    /// signature.
127    pub const IGNORE_INVALID_USAGE: u8 = 0x04;
128    /// A **complete** chain (one that ends at a self-signed root) that
129    /// reaches no configured anchor does not fail the signature. The pinned
130    /// certificate must be on the chain, every link of which is still
131    /// verified. An incomplete chain still fails: the embedded certificates
132    /// are unsigned, so anyone could strip the issuers above the pin to
133    /// escape their revocation, usage, expiry and key-size checks.
134    pub const ALLOW_UNTRUSTED_ROOT: u8 = 0x08;
135    /// A chain whose certificates are not time nested (a certificate valid
136    /// outside its issuer's period) does not fail the signature when
137    /// [`ValidityPolicy::require_time_nesting`] is set.
138    pub const IGNORE_TIME_NESTING: u8 = 0x10;
139    /// The pinned certificate may issue although it is not a CA or its
140    /// path length is exceeded. Unlike the other flags, it pins the
141    /// **issuer** itself: it relaxes only links that this certificate
142    /// issued. [`ValidityPolicy::relax_trust`] passes it to chain building
143    /// ([`TrustConfig::ignore_basic_constraints`]), which keeps every other
144    /// link check; [`evaluate_validity`] then fails, with code 1008, any
145    /// chain that used the relaxation for an issuer no option allows.
146    pub const IGNORE_BASIC_CONSTRAINTS: u8 = 0x20;
147    /// Every flag.
148    pub const ALL: u8 = 0x3f;
149
150    /// Whether every bit of `flag` is set.
151    #[must_use]
152    pub const fn contains(self, flag: u8) -> bool {
153        self.0 & flag == flag
154    }
155}

157/// One relaxation flag, as recorded in the decision trace.
158#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize)]
159#[serde(rename_all = "snake_case")]
160pub enum IgnoreFlag {
161    /// [`ErrorIgnoreFlags::IGNORE_EXPIRY`].
162    IgnoreExpiry,
163    /// [`ErrorIgnoreFlags::IGNORE_REVOCATION_UNKNOWN`].
164    IgnoreRevocationUnknown,
165    /// [`ErrorIgnoreFlags::IGNORE_INVALID_USAGE`].
166    IgnoreInvalidUsage,
167    /// [`ErrorIgnoreFlags::ALLOW_UNTRUSTED_ROOT`].
168    AllowUntrustedRoot,
169    /// [`ErrorIgnoreFlags::IGNORE_TIME_NESTING`].
170    IgnoreTimeNesting,
171    /// [`ErrorIgnoreFlags::IGNORE_BASIC_CONSTRAINTS`].
172    IgnoreBasicConstraints,
173}
174
175impl IgnoreFlag {
176    const fn bit(self) -> u8 {
177        match self {
178            Self::IgnoreExpiry => ErrorIgnoreFlags::IGNORE_EXPIRY,
179            Self::IgnoreRevocationUnknown => ErrorIgnoreFlags::IGNORE_REVOCATION_UNKNOWN,
180            Self::IgnoreInvalidUsage => ErrorIgnoreFlags::IGNORE_INVALID_USAGE,
181            Self::AllowUntrustedRoot => ErrorIgnoreFlags::ALLOW_UNTRUSTED_ROOT,
182            Self::IgnoreTimeNesting => ErrorIgnoreFlags::IGNORE_TIME_NESTING,
183            Self::IgnoreBasicConstraints => ErrorIgnoreFlags::IGNORE_BASIC_CONSTRAINTS,
184        }
185    }
186}

199/// The validity settings, from policy.
200#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
201pub struct ValidityPolicy {
202    /// What expiry does. Default [`ExpiryPolicy::TimestampAware`].
203    pub expiry_policy: ExpiryPolicy,
204    /// SHA-1 timestamps whose time (latest bound) is after this, in seconds
205    /// since the Unix epoch, are not used. `None` (the default) sets no
206    /// cutoff.
207    pub sha1_timestamp_cutoff: Option<i64>,
208    /// The rule-level minimum signing time: a signature passes only if its
209    /// trusted signing time (earliest bound) is at or after this. With no
210    /// trusted signing time it fails. Default `None`.
211    pub sign_time_after: Option<i64>,
212    /// A trusted timestamp is required. Default `false`.
213    pub requires_countersignature: bool,
214    /// A certificate revoked after the trusted signing time is still good
215    /// for that signature. Default `true`.
216    pub revocation_honours_timestamp: bool,
217    /// A key, CA or attribute authority compromise revokes whatever the
218    /// timestamp says. Default `true`.
219    pub strict_key_compromise: bool,
220    /// The smallest RSA key allowed anywhere on the full chain, in bits.
221    /// Default `None` (no minimum).
222    pub min_rsa_bits: Option<u32>,
223    /// The smallest elliptic-curve key allowed, in bits. Default `None`.
224    pub min_ec_bits: Option<u32>,
225    /// Every certificate on the full chain must be time nested: valid only
226    /// within its issuer's period (code 1007 otherwise). Default `false`,
227    /// as the OS ignores time nesting for code signing.
228    pub require_time_nesting: bool,
229    /// Per-certificate relaxations.
230    pub certificate_options: Vec<CertificateOptions>,
231}
232
233impl ValidityPolicy {
234    /// Passes every [`ErrorIgnoreFlags::IGNORE_BASIC_CONSTRAINTS`] option
235    /// to chain building, so `config` lets those certificates issue. Call it
236    /// on the [`TrustConfig`] given to [`super::evaluate_trust`]; without
237    /// it, chains are built with basic constraints in force everywhere.
238    pub fn relax_trust(&self, config: &mut TrustConfig) {
239        for option in &self.certificate_options {
240            if option
241                .flags
242                .contains(ErrorIgnoreFlags::IGNORE_BASIC_CONSTRAINTS)
243            {
244                config.ignore_basic_constraints(option.pin.clone());
245            }
246        }
247    }
248}

441/// Judges every signature of a file. `report` and `trust` must come from
442/// the same file ([`super::verify_pe`] and [`super::evaluate_trust`]).
443#[must_use]
444pub fn evaluate_validity(
445    report: &SignatureReport,
446    trust: &TrustReport,
447    ctx: &ValidityContext<'_>,
448) -> ValidityReport {
449    let effective_now = ctx.clock_floor.map_or(ctx.now, |f| f.max(ctx.now));
450    let clock_suspect = ctx.clock_floor.is_some_and(|f| ctx.now < f);
451    let file_revoked = ctx.revocation.file_revoked(ctx.file_digests).is_some();
452    let mut budget = TimestampBudget::for_file();
453    let mut crl_cache = CrlCache::new();
454    let mut judge = Judge {
455        ctx,
456        effective_now,
457        clock_suspect,
458        file_revoked,
459        crl_cache: &mut crl_cache,
460    };
461    let signatures: Vec<SignatureValidity> = report
462        .signatures
463        .iter()
464        .map(|sig| {
465            let signer = trust.signers.iter().find(|s| s.signature == sig.index);
466            judge.signature(sig, signer, &mut budget)
467        })
468        .collect();
469
470    let mut best: Option<(usize, u8)> = None;
471    for v in signatures.iter().filter(|v| v.is_ok()) {
472        let Some(sig) = report.signatures.get(v.signature) else {
473            continue;
474        };
475        let rank = digest_rank(sig.digest_alg).min(digest_rank(sig.signer_digest_alg));
476        if best.is_none_or(|(_, b)| rank > b) {
477            best = Some((v.signature, rank));
478        }
479    }
480    let primary = best.map(|(i, _)| i);
481    let identity = primary.and_then(|p| {
482        let signer = trust.signers.iter().find(|s| s.signature == p)?;
483        let mut id = identity(
484            p,
485            signer.chain.as_ref()?,
486            signer.os_ci_compatible,
487            ctx.version,
488        );
489        // A package publisher name already checked against this signer
490        // (#53) carries over.
491        if let Some(t) = trust.identity.as_ref().filter(|t| t.signature == p) {
492            id.package_display_name.clone_from(&t.package_display_name);
493        }
494        Some(id)
495    });
496    let error = match (primary, signatures.first(), &report.signing_state) {
497        (Some(_), _, _) => VerificationError::Ok,
498        (None, Some(first), _) => first.error,
499        (None, None, _) if file_revoked => VerificationError::RevokedByHash,
500        (None, None, SigningState::Invalid(_)) => VerificationError::MalformedSignature,
501        (None, None, _) => VerificationError::NotSigned,
502    };
503    ValidityReport {
504        signatures,
505        primary,
506        identity,
507        error,
508        effective_now,
509        clock_suspect,
510        file_revoked,
511    }
512}

522/// Collects failures and relaxations for one signature.
523struct Verdict<'p> {
524    options: &'p [CertificateOptions],
525    /// Which options pin a certificate on the full chain.
526    pinned: Vec<usize>,
527    failures: Vec<VerificationError>,
528    relaxed: Vec<RelaxedCheck>,
529    warnings: Vec<ValidityWarning>,
530}
531
532impl Verdict<'_> {
533    fn fail(&mut self, error: VerificationError) {
534        if !self.failures.contains(&error) {
535            self.failures.push(error);
536        }
537    }
538
539    /// Fails with `error` unless a pinned option carries `flag`, in which
540    /// case the relaxation is recorded instead.
541    fn fail_unless(&mut self, error: VerificationError, flag: IgnoreFlag) {
542        let option = self.pinned.iter().copied().find(|i| {
543            self.options
544                .get(*i)
545                .is_some_and(|o| o.flags.contains(flag.bit()))
546        });
547        match option {
548            Some(option) => self.relax(RelaxedCheck {
549                flag,
550                option,
551                suppressed: error,
552            }),
553            None => self.fail(error),
554        }
555    }
556
557    fn relax(&mut self, relaxed: RelaxedCheck) {
558        if !self.relaxed.contains(&relaxed) {
559            self.relaxed.push(relaxed);
560        }
561    }
562
563    fn warn(&mut self, warning: ValidityWarning) {
564        if !self.warnings.contains(&warning) {
565            self.warnings.push(warning);
566        }
567    }
568}

570impl Judge<'_, '_> {
571    fn signature(
572        &mut self,
573        sig: &SignatureInfo,
574        signer: Option<&SignerTrust>,
575        budget: &mut TimestampBudget,
576    ) -> SignatureValidity {
577        let policy = self.ctx.policy;
578        let chain = signer.and_then(|s| s.chain.as_ref());
579        let chain_certs: Vec<&CertSummary> = chain
580            .map(|c| c.full_chain_certs().collect())
581            .unwrap_or_default();
582        let pinned = policy
583            .certificate_options
584            .iter()
585            .enumerate()
586            .filter(|(_, o)| chain_certs.iter().any(|c| o.pin.matches(c)))
587            .map(|(i, _)| i)
588            .collect();
589        let mut v = Verdict {
590            options: &policy.certificate_options,
591            pinned,
592            failures: Vec::new(),
593            relaxed: Vec::new(),
594            warnings: Vec::new(),
595        };
596
597        // 1. The file's hash is revoked.
598        if self.file_revoked {
599            v.fail(VerificationError::RevokedByHash);
600        }
601        // 2. The signature itself.
602        if let Some(e) = status_error(&sig.status) {
603            v.fail(e);
604        }
605        // 3. Trust.
606        match signer {
607            Some(signer) => self.trust_failures(signer, chain, &mut v),
608            // No trust verdict for this signature: `trust` is not this
609            // file's. Never valid.
610            None => v.fail(VerificationError::Generic),
611        }
612        if let Some(chain) = chain {
613            self.chain_constraints(chain, &mut v);
614        }
615        if sig.status.is_valid() && chain.is_none() && v.failures.is_empty() {
616            // A valid signature with no chain must have a reason on record;
617            // fail closed if it does not.
618            v.fail(VerificationError::ChainIncomplete);
619        }
620
621        // Timestamps, and the trusted signing time.
622        let mut timestamps = if sig.status.is_valid() {
623            verify_timestamps_within(sig, self.ctx.tsa_trust, budget)
624        } else {
625            Vec::new()
626        };
627        let mut sha1_dropped = false;
628        for ts in &mut timestamps {
629            self.post_check_timestamp(ts, &mut v, &mut sha1_dropped);
630        }
631        let trusted = timestamps
632            .iter()
633            .filter(|t| t.valid)
634            .min_by_key(|t| t.time.unwrap_or(i64::MAX))
635            .map(|t| t.index);
636        let trusted_ts = trusted.and_then(|i| timestamps.get(i));
637        let signing_time = trusted_ts.and_then(|t| t.time);
638        let any_timestamp = !timestamps.is_empty();
639        // The code for "needed a trusted time and had none".
640        let no_time_code = if sha1_dropped {
641            VerificationError::Sha1TimestampPastCutoff
642        } else {
643            VerificationError::SigningTimeUntrusted
644        };
645
646        let mut revocation = Vec::new();
647        let mut validity = None;
648        let mut lifetime_signing = false;
649        if let Some(chain) = chain {
650            // 4. Revocation, for chains that can pass: anchored, or with an
651            // untrusted root that policy allows. Anything else has already
652            // failed, and checking CRLs against keys only the file vouches
653            // for would spend the file's CRL budget for nothing.
654            let can_pass = chain.full_chain.anchored
655                || v.relaxed
656                    .iter()
657                    .any(|r| r.flag == IgnoreFlag::AllowUntrustedRoot);
658            if can_pass {
659                let window = trusted_ts.and_then(|t| t.latest());
660                self.revocation(&chain_certs, window, &mut revocation, &mut v);
661            }
662            // 5. Key sizes.
663            if policy.min_rsa_bits.is_some() || policy.min_ec_bits.is_some() {
664                let ok = chain_certs
665                    .iter()
666                    .all(|c| match (&c.public_key_alg, c.key_bits) {
667                        (KeyAlgorithm::Rsa, Some(bits)) => bits >= policy.min_rsa_bits.unwrap_or(0),
668                        (KeyAlgorithm::Ec(_), Some(bits)) => {
669                            bits >= policy.min_ec_bits.unwrap_or(0)
670                        }
671                        _ => false,
672                    });
673                if !ok {
674                    v.fail(VerificationError::KeyTooSmall);
675                }
676            }
677            // 6. Expiry.
678            let checked = periods(chain, &chain_certs);
679            lifetime_signing = chain.leaf_has_eku(&eku::LIFETIME_SIGNING.id());
680            let state = self.time_validity(&checked, trusted_ts, lifetime_signing, chain);
681            validity = Some(state);
682            self.expiry_failures(state, signing_time, any_timestamp, no_time_code, &mut v);
683        }
684
685        // 7. Signing-time constraints, for a signature that verified (any
686        // other has already failed, and has no timestamps checked).
687        if sig.status.is_valid() {
688            if let Some(after) = policy.sign_time_after {
689                match trusted_ts.and_then(TimestampInfo::earliest) {
690                    Some(earliest) if earliest >= after => {}
691                    Some(_) => v.fail(VerificationError::SigningTimeUntrusted),
692                    None => v.fail(no_time_code),
693                }
694            }
695            if policy.requires_countersignature && trusted.is_none() {
696                v.fail(VerificationError::CountersignatureRequired);
697            }
698        }
699
700        let error = v.failures.first().copied().unwrap_or(VerificationError::Ok);
701        SignatureValidity {
702            signature: sig.index,
703            timestamps,
704            trusted_timestamp: trusted,
705            signing_time,
706            validity,
707            lifetime_signing,
708            revocation,
709            relaxed: v.relaxed,
710            failures: v.failures,
711            error,
712            warnings: v.warnings,
713        }
714    }
715
716    fn trust_failures(
717        &self,
718        signer: &SignerTrust,
719        chain: Option<&ChainReport>,
720        v: &mut Verdict<'_>,
721    ) {
722        for reason in &signer.untrusted {
723            match reason {
724                // Already reported from the signature status.
725                UntrustedReason::NotValid => {}
726                UntrustedReason::SignerCertificate(_) => {
727                    v.fail(VerificationError::MalformedSignature);
728                }
729                UntrustedReason::NoTrustAnchor => {
730                    if chain.is_some_and(|c| c.chain_complete) {
731                        v.fail_unless(
732                            VerificationError::UntrustedRoot,
733                            IgnoreFlag::AllowUntrustedRoot,
734                        );
735                    } else {
736                        // Never relaxed: see `ALLOW_UNTRUSTED_ROOT`.
737                        v.fail(VerificationError::ChainIncomplete);
738                    }
739                }
740                UntrustedReason::CodeSigningNotPermitted | UntrustedReason::SignerKeyUsage => {
741                    v.fail_unless(
742                        VerificationError::MissingRequiredEku,
743                        IgnoreFlag::IgnoreInvalidUsage,
744                    );
745                }
746            }
747        }
748    }

750    /// The chain-building relaxations (#49) the chain used, against the
751    /// options that allow them, and time nesting.
752    fn chain_constraints(&self, chain: &ChainReport, v: &mut Verdict<'_>) {
753        let options = &self.ctx.policy.certificate_options;
754        // Each relaxed issuer must be pinned, as itself, by an option that
755        // allows it.
756        for issuer in &chain.basic_constraints_ignored {
757            let Some(cert) = chain.cert(*issuer) else {
758                v.fail(VerificationError::BasicConstraintsViolated);
759                continue;
760            };
761            let allowed = options.iter().position(|o| {
762                o.pin.matches(cert) && o.flags.contains(ErrorIgnoreFlags::IGNORE_BASIC_CONSTRAINTS)
763            });
764            match allowed {
765                Some(option) => v.relax(RelaxedCheck {
766                    flag: IgnoreFlag::IgnoreBasicConstraints,
767                    option,
768                    suppressed: VerificationError::BasicConstraintsViolated,
769                }),
770                None => v.fail(VerificationError::BasicConstraintsViolated),
771            }
772        }
773        if self.ctx.policy.require_time_nesting && !chain.time_nesting_violations.is_empty() {
774            v.fail_unless(
775                VerificationError::TimeNotNested,
776                IgnoreFlag::IgnoreTimeNesting,
777            );
778        }
779    }

781    /// The SHA-1 cutoff and TSA revocation, after a timestamp verified.
782    fn post_check_timestamp(
783        &mut self,
784        ts: &mut TimestampInfo,
785        v: &mut Verdict<'_>,
786        sha1_dropped: &mut bool,
787    ) {
788        if !ts.valid {
789            return;
790        }
791        let policy = self.ctx.policy;
792        if let (Some(cutoff), Some(latest)) = (policy.sha1_timestamp_cutoff, ts.latest()) {
793            if ts.uses_sha1() && latest > cutoff {
794                ts.set_status(TimestampStatus::Sha1PastCutoff);
795                *sha1_dropped = true;
796                v.warn(ValidityWarning::Sha1TimestampPastCutoff {
797                    timestamp: ts.index,
798                });
799                return;
800            }
801        }
802        let Some(chain) = ts.tsa_chain.as_ref() else {
803            return;
804        };
805        let certs: Vec<&CertSummary> = chain.full_chain_certs().collect();
806        let latest = ts.latest();
807        let mut unknown = false;
808        let mut not_checked = false;
809        let mut revoked = false;
810        for position in 0..certs.len() {
811            let state =
812                self.ctx
813                    .revocation
814                    .check(&certs, position, self.effective_now, self.crl_cache);
815            let (entries, coverage) = state.parts();
816            if self.any_counts(entries, latest) {
817                revoked = true;
818            }
819            match coverage {
820                Coverage::Good => {}
821                Coverage::Unknown => unknown = true,
822                Coverage::NotChecked => not_checked = true,
823            }
824        }
825        if revoked {
826            ts.set_status(TimestampStatus::TsaRevoked);
827        } else if not_checked {
828            // The CRL budget ran out: the timestamp is not used, whatever
829            // `revocation_failure` says.
830            ts.set_status(TimestampStatus::TsaRevocationUnknown);
831        } else if unknown {
832            if self.ctx.revocation.failure == RevocationFailure::FailClosed {
833                ts.set_status(TimestampStatus::TsaRevocationUnknown);
834            } else {
835                v.warn(ValidityWarning::TsaRevocationUnknown {
836                    timestamp: ts.index,
837                });
838            }
839        }
840    }

842    /// Whether any of `entries` counts against the signature: each is
843    /// judged on its own date and reason, so a compromise entry cannot hide
844    /// behind an earlier, milder one.
845    fn any_counts(&self, entries: &[RevokedCertificate], latest: Option<i64>) -> bool {
846        entries.iter().any(|e| self.counts_against(e, latest))
847    }
848
849    /// Whether a revocation entry counts against a signature whose trusted
850    /// signing time has `latest` as its latest bound.
851    fn counts_against(&self, entry: &RevokedCertificate, latest: Option<i64>) -> bool {
852        let policy = self.ctx.policy;
853        match (entry.revoked_at, latest) {
854            (Some(revoked_at), Some(latest)) => {
855                let before = latest < revoked_at;
856                let strict = policy.strict_key_compromise && entry.reason.is_compromise();
857                !(policy.revocation_honours_timestamp && before && !strict)
858            }
859            // No date, or no trusted signing time: the entry revokes.
860            _ => true,
861        }
862    }
863
864    fn revocation(
865        &mut self,
866        certs: &[&CertSummary],
867        latest: Option<i64>,
868        out: &mut Vec<ChainRevocation>,
869        v: &mut Verdict<'_>,
870    ) {
871        for (position, cert) in certs.iter().enumerate() {
872            let state =
873                self.ctx
874                    .revocation
875                    .check(certs, position, self.effective_now, self.crl_cache);
876            let (entries, coverage) = state.parts();
877            if entries.is_empty() && coverage == Coverage::Good {
878                continue;
879            }
880            // Every entry is judged; if none counts, the certificate is
881            // still judged on its coverage.
882            let effective = if self.any_counts(entries, latest) {
883                v.fail(VerificationError::Revoked);
884                true
885            } else {
886                if !entries.is_empty() {
887                    v.warn(ValidityWarning::RevokedAfterSigning { position });
888                }
889                match coverage {
890                    Coverage::Good => false,
891                    // The CRL budget ran out: fail closed, never relaxed.
892                    Coverage::NotChecked => {
893                        v.fail(VerificationError::RevocationUnavailable);
894                        true
895                    }
896                    Coverage::Unknown
897                        if self.ctx.revocation.failure == RevocationFailure::FailClosed =>
898                    {
899                        v.fail_unless(
900                            VerificationError::RevocationUnavailable,
901                            IgnoreFlag::IgnoreRevocationUnknown,
902                        );
903                        true
904                    }
905                    Coverage::Unknown => {
906                        v.warn(ValidityWarning::RevocationUnknown { position });
907                        false
908                    }
909                }
910            };
911            out.push(ChainRevocation {
912                position,
913                sha256_thumbprint: cert.sha256_thumbprint.clone(),
914                state,
915                effective,
916            });
917        }
918    }

920    fn time_validity(
921        &self,
922        checked: &[&CertSummary],
923        trusted: Option<&TimestampInfo>,
924        lifetime_signing: bool,
925        chain: &ChainReport,
926    ) -> TimeValidity {
927        let now = self.effective_now;
928        let now_state = now_state(checked, now);
929        let mut state = match trusted.and_then(|t| t.earliest().zip(t.latest())) {
930            Some((earliest, latest)) => {
931                if checked
932                    .iter()
933                    .all(|c| earliest >= c.not_before && latest <= c.not_after)
934                {
935                    TimeValidity::ValidTimestamped
936                } else {
937                    TimeValidity::SignedOutsideValidity
938                }
939            }
940            None => now_state,
941        };
942        if lifetime_signing && chain.leaf_cert().is_some_and(|leaf| now > leaf.not_after) {
943            state = TimeValidity::Expired;
944        }
945        if self.ctx.policy.expiry_policy == ExpiryPolicy::Strict
946            && now_state == TimeValidity::Expired
947        {
948            state = TimeValidity::Expired;
949        }
950        state
951    }
952
953    fn expiry_failures(
954        &self,
955        state: TimeValidity,
956        signing_time: Option<i64>,
957        any_timestamp: bool,
958        no_time_code: VerificationError,
959        v: &mut Verdict<'_>,
960    ) {
961        let error = match state {
962            TimeValidity::Valid | TimeValidity::ValidTimestamped => return,
963            TimeValidity::NotYetValid if self.clock_suspect => {
964                v.warn(ValidityWarning::NotYetValidClockSuspect);
965                return;
966            }
967            // The chain needed a trusted time, and the file carries
968            // timestamps but none could be used: say why.
969            TimeValidity::Expired | TimeValidity::NotYetValid
970                if signing_time.is_none() && any_timestamp =>
971            {
972                no_time_code
973            }
974            _ => VerificationError::Expired,
975        };
976        if self.ctx.policy.expiry_policy == ExpiryPolicy::Ignore {
977            v.warn(ValidityWarning::ExpiryIgnored);
978            return;
979        }
980        v.fail_unless(error, IgnoreFlag::IgnoreExpiry);
981    }
982}

984/// The certificates whose validity periods are checked: the full chain,
985/// without a configured anchor at its top. A leaf is always checked, even
986/// when it is itself the anchor (a pinned signer).
987fn periods<'c>(chain: &ChainReport, certs: &[&'c CertSummary]) -> Vec<&'c CertSummary> {
988    let take = if chain.full_chain.anchored && certs.len() > 1 {
989        certs.len().saturating_sub(1)
990    } else {
991        certs.len()
992    };
993    certs.iter().take(take).copied().collect()
994}
995
996fn now_state(checked: &[&CertSummary], now: i64) -> TimeValidity {
997    if checked.iter().any(|c| now > c.not_after) {
998        TimeValidity::Expired
999    } else if checked.iter().any(|c| now < c.not_before) {
1000        TimeValidity::NotYetValid
1001    } else {
1002        TimeValidity::Valid
1003    }
1004}

1006/// The code for a signature that is not [`SignatureStatus::Valid`].
1007#[must_use]
1008pub fn status_error(status: &SignatureStatus) -> Option<VerificationError> {
1009    Some(match status {
1010        SignatureStatus::Valid => return None,
1011        SignatureStatus::DigestMismatch | SignatureStatus::NonConformantImage => {
1012            VerificationError::InvalidHash
1013        }
1014        SignatureStatus::BadSignature(BadSignature::MessageDigestMismatch) => {
1015            VerificationError::DigestMismatch
1016        }
1017        SignatureStatus::BadSignature(BadSignature::SignerCertificateNotFound) => {
1018            VerificationError::ChainIncomplete
1019        }
1020        SignatureStatus::WeakAlgorithm(_)
1021        | SignatureStatus::Unsupported(Unsupported::WeakAlgorithm(_)) => {
1022            VerificationError::WeakHashAlgorithm
1023        }
1024        SignatureStatus::Unsupported(
1025            Unsupported::KeyAlgorithm(_)
1026            | Unsupported::Curve(_)
1027            | Unsupported::CurveDigest { .. }
1028            | Unsupported::KeyAlgorithmMismatch
1029            | Unsupported::RsaKeySize(_),
1030        ) => VerificationError::UnsupportedKeyAlgorithm,
1031        SignatureStatus::Malformed(_) => VerificationError::MalformedSignature,
1032        // A bad signature value, and anything else that could not be
1033        // verified.
1034        _ => VerificationError::Generic,
1035    })
