1//! Certificate chain building (#49).
2//!
3//! For one signer certificate and the certificates embedded beside it, this
4//! module builds:
5//!
6//! - the **as-provided chain**: the embedded certificates only, ordered from
7//!   the leaf up as far as they reach, with no online lookups;
8//! - the **full chain**: the same search over the embedded certificates
9//!   plus a [`TrustConfig`]: the Palisade-managed anchor bundle and extra
10//!   intermediates that policy ships (#6, #9). It reports whether the chain
11//!   is complete and which anchor, if any, it reaches.
12//!
13//! The PCA (the highest certificate provided in the file below the root)
14//! and the root are taken from the **full chain**: its embedded prefix
15//! from the leaf up. The embedded certificate set is not signed, so anyone
16//! can add certificates to it; a certificate that is not on the path to the
17//! trusted anchor must never become the PCA.
18//!
19//! Every link is checked: the issuer's subject must equal the child's issuer
20//! name byte for byte, key identifiers must agree when both are present,
21//! the issuer must be a CA allowed to sign certificates (`cA` set, and
22//! `keyCertSign` if it has a key usage), path length constraints must
23//! hold, and the child's signature must verify with the issuer's key. These
24//! apply to configured anchors too, when they issue a certificate: an
25//! anchor that is an end-entity certificate (a pinned self-signed signer)
26//! can be the top of a chain but can issue nothing. Only an anchor of
27//! version 1 or 2, which has no extensions to say so, is taken to be a CA.
28//! A certificate with a critical extension this crate does not process is
29//! never used, unless it is itself a configured anchor. A name match alone
30//! never links two certificates.
31//!
32//! **Trust is decided downwards from the anchors.** Starting from each
33//! configured anchor, every certificate whose issuer name matches a trusted
34//! certificate's subject is checked with that trusted key, breadth first;
35//! a certificate whose signature verifies becomes trusted in turn. Only
36//! links verified this way can make an anchored path. So every check that
37//! decides trust uses a key from policy, or one an anchor vouched for, and
38//! only certificates reachable upwards from the leaf by issuer name are
39//! looked at, so unrelated policy entries cost nothing. Each certificate is
40//! checked at most once per trusted key, and at most
41//! [`MAX_EMBEDDED_CERTIFICATES`] embedded certificates are used, so what a
42//! file adds costs at most that many checks per trusted key sharing a
43//! name. This phase has its own budget, [`MAX_TRUST_CHECKS`] per build,
44//! which earlier and nested signatures cannot spend. Links into the leaf
45//! and into policy certificates are checked first, on a separate pool of
46//! checks and candidate steps from links into other embedded certificates,
47//! so nothing a file adds can spend what those links need. That pool can
48//! still run out, but only through the trust configuration itself (more
49//! than 64 trusted keys sharing one subject name); it then fails closed
50//! and is reported as [`ChainIssue::WorkLimitReached`].
51//!
52//! The as-provided chain, and the full chain when nothing is anchored, are
53//! then searched upwards from the leaf with whatever keys the file holds.
54//! The search enumerates every path, detects loops, stops at
55//! [`MAX_CHAIN_LENGTH`] certificates and keeps the best [`MAX_CHAIN_PATHS`]
56//! paths (anchored before unanchored, complete before incomplete, then
57//! paths whose every certificate permits code signing, then the shortest);
58//! the others are reported as alternatives, which is how
59//! cross-signed paths show up. These checks, with the self-signatures of
60//! self-issued certificates, spend at most [`MAX_SIGNATURE_CHECKS`] per
61//! build and [`MAX_FILE_SIGNATURE_CHECKS`] per file. Verification results
62//! are cached per issuer key, so copies of one key cost one check. Running
63//! out fails closed: a link not checked is not made, and a certificate
64//! whose self-signature was not checked is not self-signed. Neither ever
65//! affects trust.
66//!
67//! Policy can relax one certificate's basic constraints
68//! ([`TrustConfig::ignore_basic_constraints`]): it may then issue although it
69//! is not a CA or its path length is exceeded, with every other check kept,
70//! and the links that needed it are reported. Certificates the Windows
71//! backend reads from the OS stores are added with
72//! [`TrustConfig::add_os_store_anchor`] and
73//! [`TrustConfig::add_os_store_intermediate`] and reported as
74//! [`AnchorSource::OsStore`].
75//!
76//! Not checked here: validity periods (whose nesting is only reported, in
77//! [`ChainReport::time_nesting_violations`]), timestamps and revocation
78//! (#50). Reading the OS stores and the OS trust-verification cross-check
79//! are the Windows backend's (`os-trust`, #48).

93/// The longest path built, in certificates, leaf and root included.
94pub const MAX_CHAIN_LENGTH: usize = 10;
95/// The most candidate paths recorded per search.
96pub const MAX_CHAIN_PATHS: usize = 8;
97/// The most certificate signatures verified with keys a file supplies
98/// (self-signatures, and links in the untrusted searches) per chain build.
99pub const MAX_SIGNATURE_CHECKS: usize = 128;
100/// The most certificate signatures verified with keys a file supplies
101/// (self-signatures and the untrusted searches) for all the signatures of
102/// one file, by [`super::evaluate_trust`]. Trust does not depend on these
103/// checks.
104pub const MAX_FILE_SIGNATURE_CHECKS: usize = 512;
105/// The most signatures verified per chain build while deciding trust,
106/// downwards from the anchors, in each of two pools: links into the leaf
107/// and into policy certificates, and links into other embedded
108/// certificates.
109///
110/// Each certificate is checked at most once per trusted key whose subject
111/// it names as its issuer, and at most [`MAX_EMBEDDED_CERTIFICATES`]
112/// embedded certificates are used, so certificates added to a file cause at
113/// most `MAX_EMBEDDED_CERTIFICATES` checks per trusted key sharing a name.
114/// Added certificates spend only the second pool, checks and candidate
115/// steps alike, so they cannot keep the leaf's link or a policy-supplied
116/// chain from being verified. The first pool is spent only by the leaf and
117/// policy certificates, so it can run out only for a trust configuration
118/// with very many trusted keys sharing a subject name; it then fails closed
119/// and the report says [`ChainIssue::WorkLimitReached`].
120pub const MAX_TRUST_CHECKS: usize = 4096;
121/// The most embedded certificates [`build_chain`] uses: as many as one
122/// signature keeps ([`super::MAX_CERTIFICATES`]). The signer is always
123/// used; later certificates beyond the limit are ignored and reported as
124/// [`ChainIssue::TooManyCertificates`].
125pub const MAX_EMBEDDED_CERTIFICATES: usize = super::MAX_CERTIFICATES;
126/// The most per-certificate issues recorded per chain build. The limit
127/// markers ([`ChainIssue::TooLong`], [`ChainIssue::TooManyPaths`],
128/// [`ChainIssue::TooManyCertificates`], [`ChainIssue::WorkLimitReached`] and
129/// [`ChainIssue::IssuesTruncated`]) are kept beyond it, at most once each,
130/// so a report holds at most `MAX_CHAIN_ISSUES + 5` issues.
131pub const MAX_CHAIN_ISSUES: usize = 32;

145/// How a [`TrustConfig`] names one certificate: only by forms that bind its
146/// key. Issuer and serial do not (anyone can issue a certificate with any
147/// issuer name and serial), so they cannot pin.
148#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize)]
149#[serde(rename_all = "snake_case")]
150pub enum CertificatePin {
151    /// The SHA-256 thumbprint, hex (either case).
152    Sha256Thumbprint(String),
153    /// A TBS hash, hex (either case), under the certificate's own digest or
154    /// SHA-256.
155    TbsHash(String),
156}
157
158impl CertificatePin {
159    /// Whether this pins `cert`. Hex is compared ignoring case.
160    #[must_use]
161    pub fn matches(&self, cert: &CertSummary) -> bool {
162        match self {
163            Self::Sha256Thumbprint(t) => cert.sha256_thumbprint.eq_ignore_ascii_case(t),
164            Self::TbsHash(h) => super::revocation::tbs_matches(cert, h),
165        }
166    }
167}

187/// What chains are built against: trust anchors, extra intermediates and
188/// the well-known root table, all from policy content (#6, #9). Nothing
189/// here is built in; an empty configuration trusts nothing.

191pub struct TrustConfig {

193    intermediates: Vec<CertSummary>,
194    /// The source of each intermediate, in [`Self::intermediates`] order.
195    intermediate_sources: Vec<AnchorSource>,
196    well_known_roots: Vec<WellKnownRoot>,

198    /// issue ([`Self::ignore_basic_constraints`]).

219    /// Adds a trust anchor read from the OS machine root store. The Windows
220    /// backend reads the store (the `os-trust` feature, #48); this crate

222    /// reports [`AnchorSource::OsStore`] and policy can tell the two apart.
223    /// Returns its index in [`Self::anchors`].
224    pub fn add_os_store_anchor(
225        &mut self,
226        label: impl Into<String>,
227        der: &[u8],
228    ) -> Result<usize, CertificateError> {
229        self.push_anchor(label.into(), der, AnchorSource::OsStore)
230    }
231
232    fn push_anchor(
233        &mut self,
234        label: String,
235        der: &[u8],
236        source: AnchorSource,
237    ) -> Result<usize, CertificateError> {
238        let cert = CertSummary::from_der(der)?;
239        self.anchors.push(TrustAnchor {
240            label,
241            cert,
242            source,
243        });
244        Ok(self.anchors.len() - 1)
245    }

247    /// Adds an intermediate certificate from policy that chains may use but
248    /// that is not trusted by itself. Returns its index.
249    pub fn add_intermediate(&mut self, der: &[u8]) -> Result<usize, CertificateError> {
250        self.push_intermediate(der, AnchorSource::Policy)
251    }
252
253    /// Adds an intermediate read from the OS machine intermediate store
254    /// (see [`Self::add_os_store_anchor`]). It is not trusted by itself.
255    /// Returns its index in [`Self::intermediates`].
256    pub fn add_os_store_intermediate(&mut self, der: &[u8]) -> Result<usize, CertificateError> {
257        self.push_intermediate(der, AnchorSource::OsStore)
258    }
259
260    fn push_intermediate(
261        &mut self,
262        der: &[u8],
263        source: AnchorSource,
264    ) -> Result<usize, CertificateError> {
265        self.intermediates.push(CertSummary::from_der(der)?);
266        self.intermediate_sources.push(source);
267        Ok(self.intermediates.len() - 1)
268    }

270    /// Where the intermediate at `index` came from.
271    #[must_use]
272    pub fn intermediate_source(&self, index: usize) -> Option<AnchorSource> {
273        self.intermediate_sources.get(index).copied()
274    }

276    /// Lets the certificate `pin` names issue certificates even though its
277    /// basic constraints forbid it: it is not a CA (`cA` absent or FALSE),
278    /// or its `pathLenConstraint` is exceeded. This is the "ignore basic
279    /// constraints" relaxation of a trusted-publisher rule (#50).
280    ///
281    /// Only those two checks are relaxed, and only for that certificate as
282    /// an issuer. Its key usage must still allow `keyCertSign`, the child's
283    /// signature must still verify with its key, and trust is still decided
284    /// downwards from the anchors. Every link that used the relaxation is
285    /// listed in [`ChainReport::basic_constraints_ignored`].
286    pub fn ignore_basic_constraints(&mut self, pin: CertificatePin) {
287        if !self.basic_constraints_exempt.contains(&pin) {
288            self.basic_constraints_exempt.push(pin);
289        }
290    }
291
292    /// The certificates [`Self::ignore_basic_constraints`] names.
293    #[must_use]
294    pub fn basic_constraints_exempt(&self) -> &[CertificatePin] {
295        &self.basic_constraints_exempt
296    }

298    /// Adds a well-known root. The hash may be upper- or lowercase.
299    pub fn add_well_known_root(
300        &mut self,
301        id: u8,
302        tbs_hash: &str,
303    ) -> Result<(), WellKnownRootError> {
304        let ok_len = matches!(tbs_hash.len(), 40 | 64 | 96 | 128);
305        if !ok_len || !tbs_hash.bytes().all(|b| b.is_ascii_hexdigit()) {
306            return Err(WellKnownRootError::BadHash);
307        }
308        self.well_known_roots.push(WellKnownRoot {
309            id,
310            tbs_hash: tbs_hash.to_ascii_lowercase(),
311        });
312        Ok(())
313    }

319    }

322    #[must_use]
323    pub fn intermediates(&self) -> &[CertSummary] {

325    }
326
327    /// The well-known root table.
328    #[must_use]
329    pub fn well_known_roots(&self) -> &[WellKnownRoot] {
330        &self.well_known_roots
331    }
332
333    /// The well-known ID of `cert`, if its TBS hash is in the table.
334    #[must_use]
335    pub fn well_known_root_id(&self, cert: &CertSummary) -> Option<u8> {
336        self.well_known_roots
337            .iter()
338            .find(|r| {
339                cert.tbs_hash.as_deref() == Some(r.tbs_hash.as_str())
340                    || cert.tbs_hash_sha256 == r.tbs_hash
341            })
342            .map(|r| r.id)
343    }

411/// Something found while building a chain. Certificates are indices into
412/// [`ChainReport::certificates`].
413#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize)]
414#[serde(rename_all = "snake_case")]
415#[non_exhaustive]
416pub enum ChainIssue {
417    /// An embedded certificate could not be parsed and was not used.
418    UnparseableCertificate {
419        /// Its index in the signature's embedded certificates.
420        embedded: usize,
421        /// Why.
422        error: CertificateError,
423    },
424    /// A certificate has a critical extension this crate does not process,
425    /// so it cannot be part of a chain (RFC 5280, 4.2).
426    UnhandledCriticalExtension {
427        /// The certificate.
428        cert: usize,
429        /// The extension.
430        oid: ObjectId,
431    },
432    /// A certificate with the right name is not a CA (no `basicConstraints`
433    /// with `cA` set), so it cannot be an issuer.
434    IssuerNotCa {
435        /// The would-be issuer.
436        issuer: usize,
437    },
438    /// A would-be issuer's `keyUsage` lacks `keyCertSign`.
439    IssuerKeyUsage {
440        /// The would-be issuer.
441        issuer: usize,
442    },
443    /// A would-be issuer's `pathLenConstraint` is exceeded.
444    PathLengthExceeded {
445        /// The would-be issuer.
446        issuer: usize,
447    },
448    /// A child's authority key identifier differs from a would-be issuer's
449    /// subject key identifier.
450    KeyIdMismatch {
451        /// The child.
452        child: usize,
453        /// The would-be issuer.
454        issuer: usize,
455    },
456    /// A certificate's signature does not verify with the key of a
457    /// certificate whose name matches its issuer: a forged or unrelated
458    /// issuer.
459    SignatureInvalid {
460        /// The child.
461        child: usize,
462        /// The would-be issuer.
463        issuer: usize,
464    },
465    /// A certificate's signature could not be checked with a would-be
466    /// issuer's key.
467    SignatureUnsupported {
468        /// The child.
469        child: usize,
470        /// The would-be issuer.
471        issuer: usize,
472        /// Why.
473        why: Unsupported,
474    },
475    /// A path would revisit a certificate.
476    Loop {
477        /// The certificate that would be revisited.
478        cert: usize,
479    },
480    /// A path would be longer than [`MAX_CHAIN_LENGTH`].
481    TooLong,
482    /// More than [`MAX_CHAIN_PATHS`] paths exist; the rest were not built.
483    TooManyPaths,
484    /// More than [`MAX_EMBEDDED_CERTIFICATES`] embedded certificates; the
485    /// rest were ignored.
486    TooManyCertificates,
487    /// The signature-check budget ([`MAX_SIGNATURE_CHECKS`] per build,
488    /// [`MAX_FILE_SIGNATURE_CHECKS`] per file) ran out; further links were
489    /// not made, and further self-issued certificates were not treated as
490    /// self-signed.
491    WorkLimitReached,
492    /// More than [`MAX_CHAIN_ISSUES`] per-certificate issues; the rest were
493    /// dropped.
494    IssuesTruncated,
495}

593    #[must_use]
594    pub fn chain_has_eku(&self, eku: &ObjectId) -> bool {
595        self.leaf_has_eku(eku) && self.full_chain_certs().skip(1).all(|c| c.permits_eku(eku))
596    }
597
598    /// Whether the full chain may sign code: every certificate permits the
599    /// Code Signing EKU (has no `extKeyUsage`, or lists Code Signing or
600    /// `anyExtendedKeyUsage`).
601    #[must_use]
602    pub fn permits_code_signing(&self) -> bool {
603        let code_signing = eku::CODE_SIGNING.id();
604        self.full_chain_certs()
605            .all(|c| c.permits_eku(&code_signing))
606    }
607
608    /// Whether every key in the full chain is at least `min_rsa_bits` (RSA)
609    /// or `min_ec_bits` (elliptic curve) long. Any other key algorithm
610    /// fails.
611    #[must_use]
612    pub fn meets_min_key_bits(&self, min_rsa_bits: u32, min_ec_bits: u32) -> bool {
613        self.full_chain_certs()
614            .all(|c| match (&c.public_key_alg, c.key_bits) {
615                (KeyAlgorithm::Rsa, Some(bits)) => bits >= min_rsa_bits,
616                (KeyAlgorithm::Ec(_), Some(bits)) => bits >= min_ec_bits,
617                _ => false,
618            })
619    }
620
621    /// Whether every certificate signature in the full chain uses an
622    /// algorithm in `allowed`. The signature of a self-signed certificate,
623    /// and of the anchor at the top of an anchored chain, is not counted:
624    /// nothing relies on it.
625    #[must_use]
626    pub fn cert_sig_algs_allowed(&self, allowed: &[SignatureAlgorithm]) -> bool {
627        let last = self.full_chain.certs.len().saturating_sub(1);
628        self.full_chain_certs()
629            .enumerate()
630            .filter(|(pos, c)| !c.is_self_signed && !(self.full_chain.anchored && *pos == last))
631            .all(|(_, c)| allowed.contains(&c.sig_alg))
632    }
633}

647/// Builds the chains of the signer certificate `certs[signer]`, where
648/// `certs` are the DER certificates embedded in its signature.
649///
650/// Fails only when the signer certificate itself cannot be parsed.
651pub fn build_chain(
652    certs: &[Vec<u8>],
653    signer: usize,
654    config: &TrustConfig,
655) -> Result<ChainReport, CertificateError> {
656    build_chain_within(
657        certs,
658        signer,
659        config,
660        &mut Budget::new(MAX_SIGNATURE_CHECKS),
661    )

664/// [`build_chain`], charging `file_budget` for the checks that use keys the
665/// file supplies ([`MAX_SIGNATURE_CHECKS`] at most per build). Trust checks
666/// have a budget of their own, [`MAX_TRUST_CHECKS`] per build.
667pub(crate) fn build_chain_within(
668    certs: &[Vec<u8>],
669    signer: usize,
670    config: &TrustConfig,
671    file_budget: &mut Budget,
672) -> Result<ChainReport, CertificateError> {
673    let mut issues = Issues::default();
674    let anchors_by_thumbprint: HashMap<&str, usize> = config
675        .anchors
676        .iter()
677        .enumerate()
678        .map(|(i, a)| (a.cert.sha256_thumbprint.as_str(), i))
679        .rev()
680        .collect();
681
682    // Parse the embedded certificates; the signer must parse.
683    let leaf_der = certs.get(signer).ok_or(CertificateError::Asn1(Asn1Error {
684        kind: Asn1ErrorKind::Missing {
685            expected: tag::SEQUENCE,
686        },
687        offset: 0,
688    }))?;
689    // Self-signature checks while parsing come out of the same budget as
690    // link checks.
691    let mut parse_budget = Budget::new(file_budget.left().min(MAX_SIGNATURE_CHECKS));
692    let leaf_summary = match x509::parse_within(leaf_der, &mut parse_budget) {
693        Ok(c) => c,
694        Err(e) => {
695            file_budget.absorb(&parse_budget);
696            return Err(e);
697        }
698    };
699    let mut embedded: Vec<(usize, CertSummary)> = vec![(signer, leaf_summary)];
700    // Every entry tried counts against the limit, parsed or not, so
701    // malformed entries cannot make the builder read the whole slice.
702    let mut tried = 1_usize;
703    for (i, der) in certs.iter().enumerate() {
704        if i == signer {
705            continue;
706        }
707        if tried >= MAX_EMBEDDED_CERTIFICATES {
708            issues.push(ChainIssue::TooManyCertificates);
709            break;
710        }
711        tried += 1;
712        match x509::parse_within(der, &mut parse_budget) {
713            Ok(c) => embedded.push((i, c)),
714            Err(error) => issues.push(ChainIssue::UnparseableCertificate { embedded: i, error }),
715        }
716    }
717
718    // The pool: the signer, the other embedded certificates in blob order,
719    // then policy intermediates and anchors. A certificate already present
720    // (same SHA-256 thumbprint) is not added again. The search tries
721    // issuers in the reverse of this order, so policy certificates first.
722    let anchor_of = |cert: &CertSummary| {
723        anchors_by_thumbprint
724            .get(cert.sha256_thumbprint.as_str())
725            .copied()
726    };
727    let policy_thumbprints: HashSet<&str> = config
728        .intermediates
729        .iter()
730        .chain(config.anchors.iter().map(|a| &a.cert))
731        .map(|c| c.sha256_thumbprint.as_str())
732        .collect();
733    let exempt = |cert: &CertSummary| {
734        config
735            .basic_constraints_exempt
736            .iter()
737            .any(|pin| pin.matches(cert))
738    };
739    let mut pool: Vec<Node<'_>> = Vec::new();
740    let mut seen: HashSet<&str> = HashSet::new();
741    for (i, cert) in &embedded {
742        if seen.insert(cert.sha256_thumbprint.as_str()) {
743            pool.push(Node {
744                cert,
745                origin: CertOrigin::Embedded(*i),
746                anchor: anchor_of(cert),
747                from_policy: policy_thumbprints.contains(cert.sha256_thumbprint.as_str()),
748                bc_exempt: exempt(cert),
749            });
750        }
751    }
752    let embedded_count = pool.len();
753    for (i, cert) in config.intermediates.iter().enumerate() {
754        if seen.insert(cert.sha256_thumbprint.as_str()) {
755            pool.push(Node {
756                cert,
757                origin: CertOrigin::PolicyIntermediate(i),
758                anchor: anchor_of(cert),
759                from_policy: true,
760                bc_exempt: exempt(cert),
761            });
762        }
763    }
764    for (i, anchor) in config.anchors.iter().enumerate() {
765        if seen.insert(anchor.cert.sha256_thumbprint.as_str()) {
766            pool.push(Node {
767                cert: &anchor.cert,
768                origin: CertOrigin::PolicyAnchor(i),
769                anchor: Some(i),
770                from_policy: true,
771                bc_exempt: exempt(&anchor.cert),
772            });
773        }
774    }
775    // The signer is pool node 0, and so report certificate 0.
776    let leaf = 0;
777
778    file_budget.absorb(&parse_budget);
779
780    let mut search = Search::new(&pool, &mut issues);
781    // Trust first, verifying downwards from the anchors with trusted keys
782    // only, on a budget of its own that nothing in the file can spend.
783    let mut trust_budget = Budget::new(MAX_TRUST_CHECKS);
784    let mut embedded_trust_budget = Budget::new(MAX_TRUST_CHECKS);
785    search.mark_trusted(leaf, &mut trust_budget, &mut embedded_trust_budget);
786    let anchored_paths = search.run(leaf, pool.len(), Mode::Trusted, &mut trust_budget);
787    // Then the informational paths, checked with whatever keys the file
788    // holds. The per-build cap covers the self-signature checks too.
789    let mut budget = Budget::new(
790        file_budget
791            .left()
792            .min(MAX_SIGNATURE_CHECKS.saturating_sub(parse_budget.used())),
793    );
794    search.relax = false;
795    let provided_paths = search.run(leaf, embedded_count, Mode::Untrusted, &mut budget);
796    search.relax = true;
797    let full_anchored = !anchored_paths.is_empty();
798    let full_paths = if full_anchored {
799        anchored_paths
800    } else {
801        search.run(leaf, pool.len(), Mode::Untrusted, &mut budget)
802    };
803    drop(search);
804    file_budget.absorb(&budget);
805    if budget.exhausted
806        || trust_budget.exhausted
807        || embedded_trust_budget.exhausted
808        || parse_budget.exhausted
809    {
810        issues.push(ChainIssue::WorkLimitReached);
811    }
812
813    let trivial = || vec![leaf];
814    let provided = rank(provided_paths, &pool, false);
815    let full = rank(full_paths, &pool, full_anchored);
816
817    // Map pool indices to report indices: every embedded certificate, then
818    // policy certificates in first-use order.
819    let mut out: Vec<ChainCert> = Vec::new();
820    let mut map: HashMap<usize, usize> = HashMap::new();
821    let mut index_of = |p: usize, out: &mut Vec<ChainCert>| -> usize {
822        *map.entry(p).or_insert_with(|| {
823            if let Some(node) = pool.get(p) {
824                out.push(ChainCert {
825                    origin: node.origin,
826                    anchor: node.anchor,
827                    cert: node.cert.clone(),
828                });
829            }
830            out.len().saturating_sub(1)
831        })
832    };
833    for p in 0..embedded_count {
834        index_of(p, &mut out);
835    }
836    let mut to_path = |path: &[usize], out: &mut Vec<ChainCert>, with_anchor: bool| {
837        let certs: Vec<usize> = path.iter().map(|p| index_of(*p, out)).collect();
838        let (anchored, complete) = path_state(path, &pool, with_anchor);
839        ChainPath {
840            certs,
841            anchored,
842            complete,
843        }
844    };
845    let mut provided_iter = provided.into_iter();
846    let as_provided = to_path(
847        &provided_iter.next().unwrap_or_else(trivial),
848        &mut out,
849        false,
850    );
851    let as_provided_alternatives: Vec<ChainPath> = provided_iter
852        .map(|p| to_path(&p, &mut out, false))
853        .collect();
854    let mut full_iter = full.into_iter();
855    let full_chain = to_path(
856        &full_iter.next().unwrap_or_else(trivial),
857        &mut out,
858        full_anchored,
859    );
860    let alternatives: Vec<ChainPath> = full_iter
861        .map(|p| to_path(&p, &mut out, full_anchored))
862        .collect();
863    let issue_list: Vec<ChainIssue> = issues
864        .list
865        .into_iter()
866        .map(|issue| remap(issue, &mut |p| index_of(p, &mut out)))
867        .collect();
868
869    // The PCA, intermediates and root come from the full chain's embedded
870    // prefix, never from a path the full chain does not take.
871    let embedded_prefix: Vec<usize> = full_chain
872        .certs
873        .iter()
874        .copied()
875        .take_while(|i| {
876            out.get(*i)
877                .is_some_and(|c| matches!(c.origin, CertOrigin::Embedded(_)))
878        })
879        .collect();
880    let prefix_is_whole = embedded_prefix.len() == full_chain.certs.len();
881    // The root: a self-signed top, or a self-issued anchor (whose own
882    // signature is never relied on, and may use an algorithm that is not
883    // verified here).
884    let anchored = full_chain.anchored;
885    let root_as_provided = embedded_prefix
886        .last()
887        .copied()
888        .filter(|t| prefix_is_whole && out.get(*t).is_some_and(|c| is_root(c, anchored)));
889    let below_root = embedded_prefix
890        .len()
891        .saturating_sub(usize::from(root_as_provided.is_some()));
892    let intermediates: Vec<usize> = embedded_prefix
893        .get(1..below_root)
894        .unwrap_or_default()
895        .to_vec();
896    let pca = intermediates.last().copied();
897
898    let top = full_chain.certs.last().and_then(|t| out.get(*t));
899    let anchored_to = if full_chain.anchored {
900        top.and_then(|c| c.anchor)
901            .and_then(|i| config.anchors.get(i).map(|a| (i, a)))
902            .map(|(index, a)| AnchorRef {
903                index,
904                label: a.label.clone(),
905                sha256_thumbprint: a.cert.sha256_thumbprint.clone(),
906            })
907    } else {
908        None
909    };
910    let well_known_root_id = top
911        .filter(|c| full_chain.complete && (is_root(c, anchored) || c.anchor.is_some()))
912        .and_then(|c| config.well_known_root_id(&c.cert));
913    // The issuers on the chosen full chain that issued only because policy
914    // relaxed their basic constraints: worked out from that chain alone,
915    // with the same rules the search applied to it.
916    let basic_constraints_ignored = relaxed_issuers(&full_chain, &out, anchored, config);
917    let time_nesting_violations: Vec<usize> = full_chain
918        .certs
919        .windows(2)
920        .filter_map(|pair| match pair {
921            [child, issuer] => {
922                let (c, i) = (&out.get(*child)?.cert, &out.get(*issuer)?.cert);
923                (c.not_before < i.not_before || c.not_after > i.not_after).then_some(*child)
924            }
925            _ => None,
926        })
927        .collect();
928
929    Ok(ChainReport {
930        leaf,
931        pca,
932        root_as_provided,
933        intermediates,
934        chain_complete: full_chain.complete,
935        anchor_source: anchored_to
936            .as_ref()
937            .and_then(|a| config.anchors.get(a.index))
938            .map_or(AnchorSource::None, |a| a.source),
939        anchored_to,
940        well_known_root_id,
941        basic_constraints_ignored,
942        time_nesting_violations,
943        as_provided,
944        as_provided_alternatives,
945        full_chain,
946        alternatives,
947        issues: issue_list,
948        certificates: out,
949    })
950}

952/// The issuers on `chain` that are not CAs, or whose path length is
953/// exceeded on it, and that a [`TrustConfig::ignore_basic_constraints`] pin
954/// names: the links the chain could make only through that relaxation.
955/// A v1 or v2 anchor counts as a CA in an anchored chain, as the trusted
956/// search treats it.
957fn relaxed_issuers(
958    chain: &ChainPath,
959    certs: &[ChainCert],
960    anchored: bool,
961    config: &TrustConfig,
962) -> Vec<usize> {
963    let mut out = Vec::new();
964    for (pos, &issuer) in chain.certs.iter().enumerate().skip(1) {
965        let Some(node) = certs.get(issuer) else {
966            continue;
967        };
968        let cert = &node.cert;
969        if !config
970            .basic_constraints_exempt
971            .iter()
972            .any(|pin| pin.matches(cert))
973        {
974            continue;
975        }
976        let legacy_anchor = anchored && node.anchor.is_some() && cert.version < 3;
977        let is_ca = cert.basic_constraints.map_or(legacy_anchor, |bc| bc.ca);
978        // Non-self-issued intermediates below this issuer (not the leaf).
979        let below = chain
980            .certs
981            .iter()
982            .take(pos)
983            .skip(1)
984            .filter_map(|i| certs.get(*i))
985            .filter(|c| c.cert.subject.der != c.cert.issuer.der)
986            .count();
987        let path_exceeded = cert
988            .basic_constraints
989            .and_then(|bc| bc.path_len)
990            .is_some_and(|max| u32::try_from(below).unwrap_or(u32::MAX) > max);
991        if !is_ca || path_exceeded {
992            out.push(issuer);
993        }
994    }
995    out
996}

998/// Whether `c`, the top of a full chain, is a root: self-signed, or (in an
999/// anchored chain) a self-issued anchor.
1000fn is_root(c: &ChainCert, anchored: bool) -> bool {
1001    c.cert.is_self_signed
1002        || (anchored && c.anchor.is_some() && c.cert.subject.der == c.cert.issuer.der)
1003}

1005/// Rewrites the certificate indices in `issue` with `f`.
1006fn remap(issue: ChainIssue, f: &mut impl FnMut(usize) -> usize) -> ChainIssue {
1007    match issue {
1008        ChainIssue::UnhandledCriticalExtension { cert, oid } => {
1009            ChainIssue::UnhandledCriticalExtension { cert: f(cert), oid }
1010        }
1011        ChainIssue::IssuerNotCa { issuer } => ChainIssue::IssuerNotCa { issuer: f(issuer) },
1012        ChainIssue::IssuerKeyUsage { issuer } => ChainIssue::IssuerKeyUsage { issuer: f(issuer) },
1013        ChainIssue::PathLengthExceeded { issuer } => {
1014            ChainIssue::PathLengthExceeded { issuer: f(issuer) }
1015        }
1016        ChainIssue::KeyIdMismatch { child, issuer } => ChainIssue::KeyIdMismatch {
1017            child: f(child),
1018            issuer: f(issuer),
1019        },
1020        ChainIssue::SignatureInvalid { child, issuer } => ChainIssue::SignatureInvalid {
1021            child: f(child),
1022            issuer: f(issuer),
1023        },
1024        ChainIssue::SignatureUnsupported { child, issuer, why } => {
1025            ChainIssue::SignatureUnsupported {
1026                child: f(child),
1027                issuer: f(issuer),
1028                why,
1029            }
1030        }
1031        ChainIssue::Loop { cert } => ChainIssue::Loop { cert: f(cert) },
1032        other => other,
1033    }
1034}

1036/// Whether `path` ends at an anchor (only when `with_anchor`), and whether
1037/// it is complete: anchored, or ending at a self-signed certificate.
1038fn path_state(path: &[usize], pool: &[Node<'_>], with_anchor: bool) -> (bool, bool) {
1039    let top = path.last().and_then(|p| pool.get(*p));
1040    let anchored = with_anchor && top.is_some_and(|n| n.anchor.is_some());
1041    let complete = anchored || top.is_some_and(|n| n.cert.is_self_signed);
1042    (anchored, complete)
1043}

1045/// The sort key of a path: anchored, then complete, then permitting code
1046/// signing, then shorter, then earlier certificates. So when one issuer
1047/// key has two certificates and only one restricts its extended key usage
1048/// away from code signing, the chain chosen (and everything taken from it:
1049/// trust, the PCA, identity) is the one that may sign code.
1050fn path_key(
1051    path: &[usize],
1052    pool: &[Node<'_>],
1053    with_anchor: bool,
1054) -> (bool, bool, bool, usize, Vec<usize>) {
1055    let (anchored, complete) = path_state(path, pool, with_anchor);
1056    let code_signing = eku::CODE_SIGNING.id();
1057    let permits = path
1058        .iter()
1059        .filter_map(|p| pool.get(*p))
1060        .all(|n| n.cert.permits_eku(&code_signing));
1061    (!anchored, !complete, !permits, path.len(), path.to_vec())
1062}
1063
1064/// Sorts paths best first (see [`path_key`]).
1065fn rank(mut paths: Vec<Vec<usize>>, pool: &[Node<'_>], with_anchor: bool) -> Vec<Vec<usize>> {
1066    paths.sort_by_cached_key(|p| path_key(p, pool, with_anchor));
1067    paths
1068}

1070/// Issues, deduplicated and capped.
1071#[derive(Default)]
1072struct Issues {
1073    list: Vec<ChainIssue>,
1074}
1075
1076impl Issues {
1077    /// Adds `issue` unless it is already recorded. Past
1078    /// [`MAX_CHAIN_ISSUES`], per-certificate issues are replaced by one
1079    /// [`ChainIssue::IssuesTruncated`]. The limit markers (`TooLong`,
1080    /// `TooManyPaths`, `WorkLimitReached`) are always kept, because they say
1081    /// the search was cut short.
1082    fn push(&mut self, issue: ChainIssue) {
1083        if self.list.contains(&issue) {
1084            return;
1085        }
1086        let marker = matches!(
1087            issue,
1088            ChainIssue::TooLong
1089                | ChainIssue::TooManyPaths
1090                | ChainIssue::TooManyCertificates
1091                | ChainIssue::WorkLimitReached
1092        );
1093        if marker || self.list.len() < MAX_CHAIN_ISSUES {
1094            self.list.push(issue);
1095        } else if !self.list.contains(&ChainIssue::IssuesTruncated) {
1096            self.list.push(ChainIssue::IssuesTruncated);
1097        }
1098    }
1099}

1101/// The most issuer candidates examined in one search. Every step costs a
1102/// few comparisons at most; signature checks are bounded by budgets.
1103const MAX_SEARCH_STEPS: usize = 4096;
1104
1105/// Whether a certificate may issue others.
1106#[derive(Debug, Clone, Copy, PartialEq, Eq)]
1107enum MayIssue {
1108    No,
1109    Yes,
1110    /// Only because [`TrustConfig::ignore_basic_constraints`] relaxes its
1111    /// basic constraints.
1112    Relaxed,
1113}
1114
1115/// Which links a search may make.
1116#[derive(Debug, Clone, Copy, PartialEq, Eq)]
1117enum Mode {
1118    /// Only links verified downwards from an anchor, by
1119    /// [`Search::mark_trusted`]; only paths that end at an anchor count.
1120    Trusted,
1121    /// Any link whose signature verifies, checked as needed with the
1122    /// issuer's key, whoever supplied it. Paths end at self-signed
1123    /// certificates; anchors are not recognised.
1124    Untrusted,
1125}
1126
1127struct Search<'p, 'i> {
1128    pool: &'p [Node<'p>],
1129    /// Pool indices by subject name, policy certificates first.
1130    by_subject: HashMap<&'p [u8], Vec<usize>>,
1131    /// Pool indices by issuer name.
1132    by_issuer: HashMap<&'p [u8], Vec<usize>>,
1133    /// Link verification results, by child and the issuer key's SPKI hash:
1134    /// a signature checked once with a key is not checked again with
1135    /// another certificate for the same key.
1136    verified: HashMap<(usize, &'p str), bool>,
1137    /// Certificates verified downwards from an anchor (anchors included).
1138    trusted: Vec<bool>,
1139    steps: usize,
1140    issues: &'i mut Issues,
1141    /// Whether [`TrustConfig::ignore_basic_constraints`] applies in this
1142    /// search. It does in the trusted search and the unanchored full-chain
1143    /// search, never in the as-provided one, which shows the file's own
1144    /// chain without policy.
1145    relax: bool,
1146    paths: Vec<Vec<usize>>,
1147    /// Only pool indices below this are used.
1148    limit: usize,
1149    mode: Mode,
1150}
1151
1152impl<'p, 'i> Search<'p, 'i> {
1153    fn new(pool: &'p [Node<'p>], issues: &'i mut Issues) -> Self {
1154        let mut by_subject: HashMap<&'p [u8], Vec<usize>> = HashMap::new();
1155        let mut by_issuer: HashMap<&'p [u8], Vec<usize>> = HashMap::new();
1156        // Later pool entries first: policy anchors, then policy
1157        // intermediates, then embedded certificates from the last.
1158        for (i, node) in pool.iter().enumerate().rev() {
1159            by_subject
1160                .entry(node.cert.subject.der.as_slice())
1161                .or_default()
1162                .push(i);
1163        }
1164        for (i, node) in pool.iter().enumerate().rev() {
1165            by_issuer
1166                .entry(node.cert.issuer.der.as_slice())
1167                .or_default()
1168                .push(i);
1169        }
1170        Self {
1171            pool,
1172            by_subject,
1173            by_issuer,
1174            verified: HashMap::new(),
1175            trusted: vec![false; pool.len()],
1176            steps: 0,
1177            issues,
1178            relax: true,
1179            paths: Vec::new(),
1180            limit: pool.len(),

1185    /// Whether `node` may be in a path at all. A certificate with a
1186    /// critical extension this crate does not process may not, unless it
1187    /// is a configured anchor in a trusted search.
1188    fn usable(&mut self, node: usize) -> bool {
1189        let Some(n) = self.pool.get(node) else {
1190            return false;
1191        };
1192        if self.mode == Mode::Trusted && n.anchor.is_some() {
1193            return true;
1194        }
1195        let mut ok = true;
1196        for oid in &n.cert.unhandled_critical_extensions {
1197            self.issues.push(ChainIssue::UnhandledCriticalExtension {
1198                cert: node,
1199                oid: oid.clone(),
1200            });
1201            ok = false;
1202        }
1203        ok
1204    }

1206    /// Whether `issuer` may issue certificates: usable, a CA, and allowed
1207    /// `keyCertSign` by its key usage. A v1 or v2 certificate has no
1208    /// extensions to say it is a CA; it is taken as one only when it is a
1209    /// configured anchor in a trusted search.
1210    ///
1211    /// A certificate [`TrustConfig::ignore_basic_constraints`] names may
1212    /// issue without being a CA; the answer is then [`MayIssue::Relaxed`].
1213    fn may_issue(&mut self, issuer: usize) -> MayIssue {
1214        if !self.usable(issuer) {
1215            return MayIssue::No;
1216        }
1217        let Some(node) = self.pool.get(issuer) else {
1218            return MayIssue::No;
1219        };
1220        let i = node.cert;
1221        let legacy_anchor = self.mode == Mode::Trusted && node.anchor.is_some() && i.version < 3;
1222        let is_ca = match i.basic_constraints {
1223            Some(bc) => bc.ca,
1224            None => legacy_anchor,
1225        };
1226        let answer = match (is_ca, node.bc_exempt && self.relax) {
1227            (true, _) => MayIssue::Yes,
1228            (false, true) => MayIssue::Relaxed,
1229            (false, false) => {
1230                self.issues.push(ChainIssue::IssuerNotCa { issuer });
1231                return MayIssue::No;
1232            }
1233        };
1234        if i.key_usage
1235            .is_some_and(|ku| !ku.contains(KeyUsage::KEY_CERT_SIGN))
1236        {
1237            self.issues.push(ChainIssue::IssuerKeyUsage { issuer });
1238            return MayIssue::No;
1239        }
1240        answer
1241    }

1243    /// Whether the key identifiers of `child` and `issuer` agree (or one is
1244    /// absent).
1245    fn key_ids_agree(&mut self, child: usize, issuer: usize) -> bool {
1246        let (Some(c), Some(i)) = (self.pool.get(child), self.pool.get(issuer)) else {
1247            return false;
1248        };
1249        match (&c.cert.authority_key_id, &i.cert.subject_key_id) {
1250            (Some(aki), Some(ski)) if aki != ski => {
1251                self.issues
1252                    .push(ChainIssue::KeyIdMismatch { child, issuer });
1253                false
1254            }
1255            _ => true,
1256        }
1257    }

1259    /// Verifies `child`'s signature with `issuer`'s key, once per key,
1260    /// charging `budget`.
1261    fn check(&mut self, child: usize, issuer: usize, budget: &mut Budget) -> bool {
1262        let (Some(c), Some(i)) = (self.pool.get(child), self.pool.get(issuer)) else {
1263            return false;
1264        };
1265        let key = (child, i.cert.spki_sha256.as_str());
1266        if let Some(ok) = self.verified.get(&key) {
1267            return *ok;
1268        }
1269        if !budget.take() {
1270            return false;
1271        }
1272        let ok = match verify_link(c.cert, i.cert) {
1273            Verified::Valid => true,
1274            Verified::Invalid => {
1275                self.issues
1276                    .push(ChainIssue::SignatureInvalid { child, issuer });
1277                false
1278            }
1279            Verified::Unsupported(why) => {
1280                self.issues
1281                    .push(ChainIssue::SignatureUnsupported { child, issuer, why });
1282                false
1283            }
1284        };
1285        self.verified.insert(key, ok);
1286        ok
1287    }

1289    /// The pool nodes a path from `leaf` could use: those reached upwards
1290    /// from it by issuer name, within [`MAX_CHAIN_LENGTH`] certificates.
1291    /// No signature is checked; this only keeps the trust walk away from
1292    /// certificates that cannot be on the leaf's chain.
1293    fn reachable_from(&self, leaf: usize) -> Vec<bool> {
1294        let mut seen = vec![false; self.pool.len()];
1295        let mut frontier = vec![leaf];
1296        if let Some(s) = seen.get_mut(leaf) {
1297            *s = true;
1298        }
1299        for _ in 1..MAX_CHAIN_LENGTH {
1300            let mut next = Vec::new();
1301            for n in frontier {
1302                let Some(node) = self.pool.get(n) else {
1303                    continue;
1304                };
1305                for &i in self
1306                    .by_subject
1307                    .get(node.cert.issuer.der.as_slice())
1308                    .map(Vec::as_slice)
1309                    .unwrap_or_default()
1310                {
1311                    if let Some(s) = seen.get_mut(i) {
1312                        if !*s {
1313                            *s = true;
1314                            next.push(i);
1315                        }
1316                    }
1317                }
1318            }
1319            if next.is_empty() {
1320                break;
1321            }
1322            frontier = next;
1323        }
1324        seen
1325    }

1327    /// Verifies downwards from the anchors: every certificate that could be
1328    /// on the leaf's chain and whose issuer name is a trusted certificate's
1329    /// subject is checked with that trusted key, breadth first, at most
1330    /// [`MAX_CHAIN_LENGTH`] deep. Every check uses a key from an anchor or
1331    /// from a certificate an anchor vouched for, never a key someone added
1332    /// to the file.
1333    ///
1334    /// Links into the leaf and into policy certificates are checked on
1335    /// `policy_budget` and their own [`MAX_SEARCH_STEPS`] candidate steps;
1336    /// links into other embedded certificates, which anyone can add, on
1337    /// `embedded_budget` and a separate step count. So added certificates
1338    /// cannot spend the steps or checks that the leaf's own link and
1339    /// policy-supplied chains need.
1340    fn mark_trusted(
1341        &mut self,
1342        leaf: usize,
1343        policy_budget: &mut Budget,
1344        embedded_budget: &mut Budget,
1345    ) {
1346        self.mode = Mode::Trusted;
1347        self.limit = self.pool.len();
1348        let reachable = self.reachable_from(leaf);
1349        let on_chain = |i: usize| reachable.get(i).copied().unwrap_or(false);
1350        let mut depth = vec![0_usize; self.pool.len()];
1351        let mut queue = VecDeque::new();
1352        for (i, node) in self.pool.iter().enumerate() {
1353            if node.anchor.is_some() && on_chain(i) {
1354                if let (Some(t), Some(d)) = (self.trusted.get_mut(i), depth.get_mut(i)) {
1355                    *t = true;
1356                    *d = 1;
1357                }
1358                queue.push_back(i);
1359            }
1360        }
1361        // Candidate steps, in the same two pools as the checks: added
1362        // certificates never spend the leaf's or policy certificates' steps.
1363        let mut policy_steps = 0_usize;
1364        let mut embedded_steps = 0_usize;
1365        while let Some(t) = queue.pop_front() {
1366            let (Some(node), Some(&d)) = (self.pool.get(t), depth.get(t)) else {
1367                continue;
1368            };
1369            if d >= MAX_CHAIN_LENGTH {
1370                continue;
1371            }
1372            // The leaf and policy certificates first, then embedded ones.
1373            let mut children: Vec<usize> = self
1374                .by_issuer
1375                .get(node.cert.subject.der.as_slice())
1376                .map(|v| {
1377                    v.iter()
1378                        .copied()
1379                        // Anchors are trusted already and end every
1380                        // trusted path, so they are never checked as
1381                        // children (two re-keyed roots sharing a name).
1382                        .filter(|c| *c != t && on_chain(*c))
1383                        .filter(|c| self.pool.get(*c).is_some_and(|n| n.anchor.is_none()))
1384                        .collect()
1385                })
1386                .unwrap_or_default();
1387            children.sort_by_key(|c| (!self.privileged(*c, leaf), *c));
1388            if children.is_empty() {
1389                continue;
1390            }
1391            if self.may_issue(t) == MayIssue::No {
1392                continue;
1393            }
1394            for c in children {
1395                let privileged = self.privileged(c, leaf);
1396                let (steps, budget) = if privileged {
1397                    (&mut policy_steps, &mut *policy_budget)
1398                } else {
1399                    (&mut embedded_steps, &mut *embedded_budget)
1400                };
1401                if *steps >= MAX_SEARCH_STEPS {
1402                    budget.exhausted = true;
1403                    if privileged {
1404                        return;
1405                    }
1406                    // Children are sorted privileged first, so the rest of
1407                    // this list is embedded too.
1408                    break;
1409                }
1410                *steps += 1;
1411                if !self.key_ids_agree(c, t) || !self.usable(c) {
1412                    continue;
1413                }
1414                let ok = self.check(c, t, budget);
1415                let newly = !self.trusted.get(c).copied().unwrap_or(true);
1416                if ok && newly {
1417                    if let (Some(tc), Some(dc)) = (self.trusted.get_mut(c), depth.get_mut(c)) {
1418                        *tc = true;
1419                        *dc = d + 1;
1420                    }
1421                    queue.push_back(c);
1422                }
1423            }
1424        }
1425    }

1433    /// The best maximal paths from `leaf` over pool indices below `limit`.
1434    fn run(
1435        &mut self,
1436        leaf: usize,
1437        limit: usize,
1438        mode: Mode,
1439        budget: &mut Budget,
1440    ) -> Vec<Vec<usize>> {
1441        self.limit = limit;
1442        self.mode = mode;
1443        self.paths.clear();
1444        self.steps = 0;
1445        let mut path = vec![leaf];
1446        if self.usable(leaf) {
1447            self.extend(&mut path, budget);
1448        }
1449        std::mem::take(&mut self.paths)
1450    }

1452    /// Keeps `path` if it is among the best [`MAX_CHAIN_PATHS`] so far.
1453    /// Over the cap, the worst path is dropped, so a dead end can never
1454    /// displace an anchored or complete path.
1455    fn record(&mut self, path: &[usize]) {
1456        let anchored = self.mode == Mode::Trusted;
1457        if anchored
1458            && !path
1459                .last()
1460                .and_then(|t| self.pool.get(*t))
1461                .is_some_and(|n| n.anchor.is_some())
1462        {
1463            return;
1464        }
1465        let key = |p: &[usize]| path_key(p, self.pool, anchored);
1466        if self.paths.len() < MAX_CHAIN_PATHS {
1467            self.paths.push(path.to_vec());
1468            return;
1469        }
1470        self.issues.push(ChainIssue::TooManyPaths);
1471        let worst = self
1472            .paths
1473            .iter()
1474            .enumerate()
1475            .max_by_key(|(_, p)| key(p))
1476            .map(|(i, p)| (i, key(p)));
1477        if let Some((i, worst_key)) = worst {
1478            if key(path) < worst_key {
1479                if let Some(slot) = self.paths.get_mut(i) {
1480                    *slot = path.to_vec();
1481                }
1482            }
1483        }
1484    }

1486    fn extend(&mut self, path: &mut Vec<usize>, budget: &mut Budget) {
1487        let Some(&top) = path.last() else {
1488            return;
1489        };
1490        let Some(node) = self.pool.get(top) else {
1491            return;
1492        };
1493        let stop = match self.mode {
1494            Mode::Trusted => node.anchor.is_some(),
1495            Mode::Untrusted => node.cert.is_self_signed,
1496        };
1497        if stop {
1498            self.record(path);
1499            return;
1500        }
1501        let trusted_only = self.mode == Mode::Trusted;
1502        let candidates: Vec<usize> = self
1503            .by_subject
1504            .get(node.cert.issuer.der.as_slice())
1505            .map(|v| {
1506                v.iter()
1507                    .copied()
1508                    // A self-issued certificate names itself as issuer; it
1509                    // is not its own issuer candidate.
1510                    .filter(|c| *c != top && *c < self.limit)
1511                    .filter(|c| !trusted_only || self.trusted.get(*c).copied().unwrap_or(false))
1512                    .collect()
1513            })
1514            .unwrap_or_default();
1515        let mut extended = false;
1516        for issuer in candidates {
1517            if self.steps >= MAX_SEARCH_STEPS {
1518                budget.exhausted = true;
1519                break;
1520            }
1521            self.steps += 1;
1522            if path.contains(&issuer) {
1523                self.issues.push(ChainIssue::Loop { cert: issuer });
1524                continue;
1525            }
1526            if path.len() >= MAX_CHAIN_LENGTH {
1527                // The path is recorded as it is, incomplete.
1528                self.issues.push(ChainIssue::TooLong);
1529                continue;
1530            }
1531            if !self.link(path, issuer, budget) {
1532                continue;
1533            }
1534            extended = true;
1535            path.push(issuer);
1536            self.extend(path, budget);
1537            path.pop();
1538        }
1539        if !extended {
1540            self.record(path);
1541        }
1542    }

1544    /// Whether `issuer` issued the top of `path`, with every constraint
1545    /// that applies to it. Anchors are held to the same CA, key usage and
1546    /// path length rules when they issue a certificate. A trusted search
1547    /// makes no new signature checks: it uses only links
1548    /// [`Self::mark_trusted`] verified.
1549    fn link(&mut self, path: &[usize], issuer: usize, budget: &mut Budget) -> bool {
1550        let Some(&child) = path.last() else {
1551            return false;
1552        };
1553        if !self.key_ids_agree(child, issuer) {
1554            return false;
1555        }
1556        if self.may_issue(issuer) == MayIssue::No {
1557            return false;
1558        }
1559        if let Some(max) = self
1560            .pool
1561            .get(issuer)
1562            .and_then(|n| n.cert.basic_constraints)
1563            .and_then(|b| b.path_len)
1564        {
1565            // Non-self-issued intermediates below this issuer (the leaf
1566            // does not count).
1567            let below = path
1568                .iter()
1569                .skip(1)
1570                .filter_map(|p| self.pool.get(*p))
1571                .filter(|n| n.cert.subject.der != n.cert.issuer.der)
1572                .count();
1573            let exempt = self.relax && self.pool.get(issuer).is_some_and(|n| n.bc_exempt);
1574            if u32::try_from(below).unwrap_or(u32::MAX) > max && !exempt {
1575                self.issues.push(ChainIssue::PathLengthExceeded { issuer });
1576                return false;
1577            }
1578        }
1579        match self.mode {
1580            Mode::Trusted => {
1581                let Some(i) = self.pool.get(issuer) else {
1582                    return false;
1583                };
1584                self.verified
1585                    .get(&(child, i.cert.spki_sha256.as_str()))
1586                    .copied()
1587                    .unwrap_or(false)
1588            }
1589            Mode::Untrusted => self.check(child, issuer, budget),
1590        }
1591    }
1592}

1594/// Verifies `child`'s signature with `issuer`'s key. Weak digests (MD2,
1595/// MD5) are never accepted.
1596fn verify_link(child: &CertSummary, issuer: &CertSummary) -> Verified {
1597    if let Some(d) = x509::signature_digest(&child.sig_alg).filter(|d| d.is_broken()) {
1598        return Verified::Unsupported(Unsupported::WeakAlgorithm(d));
1599    }
1600    let (Ok(c), Ok(i)) = (x509::split(&child.der), x509::split(&issuer.der)) else {
1601        return Verified::Invalid;
1602    };
1603    x509::check_signed_by(&c, &child.sig_alg, &i, &issuer.public_key_alg)
1604}
