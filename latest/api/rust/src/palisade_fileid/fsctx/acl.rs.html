1//! Security descriptors, ownership and the writability decision.
2//!
3//! The OS layer reads a file's security descriptor (owner and DACL) as the
4//! self-relative bytes `GetSecurityInfo` / `GetFileSecurityW` return, and
5//! [`SecurityDescriptor::from_self_relative`] turns them into an abstract
6//! model. Everything after that is pure and runs on every OS:
7//!
8//! - [`evaluate`] works out which write-type rights any **non-administrator**
9//!   principal may hold on one object;
10//! - [`assess_path`] does that for a file and every ancestor folder up to the
11//!   volume root and produces a [`Writability`] summary;
12//! - [`OwnerInfo`] classifies the owner SID.
13//!
14//! # How the evaluation works
15//!
16//! The DACL is walked **in stored order**, as the OS access check does (a
17//! non-canonical order is evaluated as stored and also reported). For a
18//! token, each applicable ACE whose SID is in the token either grants the
19//! bits not already denied, or denies the bits not already granted. ACEs
20//! marked inherit-only apply only to future children and are skipped;
21//! inherited ACEs are already materialised in the DACL and count like any
22//! other.
23//!
24//! The DACL is indexed by trustee once per descriptor: for each SID, the
25//! first applicable ACE that grants or denies each right. A token's rights
26//! are then the earliest entry among its SIDs, right by right, which is
27//! what the ordered walk gives, without walking the DACL once per token
28//! (#332). A property test checks the index against the ordered walk.
29//!
30//! The tokens evaluated are:
31//!
32//! - one per distinct non-administrator SID named by an applicable allow ACE,
33//!   holding that SID plus `Everyone`. This over-approximates every real
34//!   non-administrator token that holds `Everyone`: take the first allow ACE
35//!   that grants a right to a real token. No deny ACE before it applied to
36//!   the real token, so none applied to the smaller token of that ACE's SID
37//!   either, and that token is granted the right too. An anonymous token
38//!   lacks `Everyone` by default and may hold `ANONYMOUS LOGON` and
39//!   `NETWORK`, so `ANONYMOUS LOGON` is evaluated alone, and `NETWORK` both
40//!   alone and with `Everyone`. A deny for `Everyone` is then not assumed
41//!   to stop either;
42//! - the object's owner, if it is not an administrator, with the owner's
43//!   implicit `READ_CONTROL` and `WRITE_DAC` (which a deny ACE cannot
44//!   remove), unless the DACL has an unconditional `OWNER RIGHTS`
45//!   allow ACE, which then replaces them. A descriptor with no owner is
46//!   treated as an unknown, possibly non-administrator owner;
47//! - a synthetic standard user (by default `Everyone`, `Authenticated Users`,
48//!   `BUILTIN\Users`, `INTERACTIVE` and `LOCAL`), reported on its own.
49//!
50//! # Conservative by construction
51//!
52//! When the model cannot tell, it reports the right as possibly held:
53//!
54//! - **Conditional (callback) allow ACEs** and **object allow ACEs** may
55//!   apply; their rights are reported, and also listed as `uncertain`.
56//!   Conditional and object **deny** ACEs are assumed not to apply when
57//!   working out what may be held. They are assumed to apply when working
58//!   out what is held for certain, so a right that such a deny may remove
59//!   is `uncertain`, not certain.
60//! - **Generic rights** (`GENERIC_WRITE`, `GENERIC_ALL`) in an allow ACE are
61//!   mapped to the file rights they stand for. The OS access check does not
62//!   map generic bits stored in an ACE, so such an ACE may in fact grant
63//!   nothing; mapping it can only over-report, and a right that only a
64//!   generic bit grants is `uncertain`. In a deny ACE they are not mapped,
65//!   so they deny nothing, as in the OS.
66//! - **ACE types the model does not know** grant every right, as uncertain,
67//!   to an unknown principal.
68//! - **A NULL or absent DACL** grants everyone everything.
69//! - **An object whose descriptor could not be read** counts as writable.
70//! - **Mandatory integrity labels** (in the SACL) are ignored. A label can
71//!   only take rights away, so ignoring it only over-reports.
72//!
73//! On Windows the OS access check (`AuthzAccessCheck` with a synthetic
74//! token of the standard user's SIDs) runs beside this evaluator, and a
75//! decision uses the **union** of the two ([`OsCheck`],
76//! [`ObjectWritability::merge_os_check`], #332): the OS check is exact but
77//! covers only the standard user, while this evaluator covers every
78//! non-administrator principal and over-reports. So the OS check can add a
79//! right the evaluator missed, never remove one it reports, and if the OS
80//! check fails the evaluator's result stands (ADR 0018).
81//! `palisade_fileid::win::access::assess_file` merges it in, and
82//! `cross_check_writability` reports both on any descriptor (with the
83//! `os-trust` feature).
84//!
85//! # Owner-based trust needs the DACL too
86//!
87//! NTFS keeps a file's owner when its content is overwritten in place; the
88//! owner only changes when a new file is created. So an administrator owner
89//! says nothing about the content if a non-administrator can write to the
90//! file (threat model T-engine-11, AT-19.5b). [`Writability::owner_trust_blockers`]
91//! reports the rights (write, append, delete, `WRITE_DAC`, `WRITE_OWNER`)
92//! that must be absent before owner-based trust (#117) may rely on the owner.
93//! This module only provides the attributes; the trust decision is #9's.

148impl WriteRights {
149    /// No rights.
150    pub const NONE: Self = Self(0);
151    /// Write data, or add a file to a directory.
152    pub const WRITE_DATA: Self = Self(mask::FILE_WRITE_DATA);
153    /// Append data, or add a subdirectory to a directory.
154    pub const APPEND_DATA: Self = Self(mask::FILE_APPEND_DATA);
155    /// Write extended attributes.
156    pub const WRITE_EA: Self = Self(mask::FILE_WRITE_EA);
157    /// Delete any child of a directory.
158    pub const DELETE_CHILD: Self = Self(mask::FILE_DELETE_CHILD);
159    /// Write basic attributes (timestamps, read-only, hidden and so on).
160    pub const WRITE_ATTRIBUTES: Self = Self(mask::FILE_WRITE_ATTRIBUTES);
161    /// Delete, or rename, the object.
162    pub const DELETE: Self = Self(mask::DELETE);
163    /// Change the DACL.
164    pub const WRITE_DAC: Self = Self(mask::WRITE_DAC);
165    /// Change the owner.
166    pub const WRITE_OWNER: Self = Self(mask::WRITE_OWNER);
167
168    /// Every right this module tracks.
169    pub const ALL: Self = Self(
170        mask::FILE_WRITE_DATA
171            | mask::FILE_APPEND_DATA
172            | mask::FILE_WRITE_EA
173            | mask::FILE_DELETE_CHILD
174            | mask::FILE_WRITE_ATTRIBUTES
175            | mask::DELETE
176            | mask::WRITE_DAC
177            | mask::WRITE_OWNER,
178    );
179
180    /// `WRITE_DAC` and `WRITE_OWNER`: whoever holds either can change who
181    /// else may write.
182    pub const CHANGE_PERMISSIONS: Self = Self(mask::WRITE_DAC | mask::WRITE_OWNER);
183
184    /// The rights that let a non-administrator change a file's content (or
185    /// gain the means to) while NTFS keeps its owner (threat model
186    /// T-engine-11): write, append, delete, `WRITE_DAC` and `WRITE_OWNER`.
187    pub const OWNER_TRUST_BLOCKING: Self = Self(
188        mask::FILE_WRITE_DATA
189            | mask::FILE_APPEND_DATA
190            | mask::DELETE
191            | mask::WRITE_DAC
192            | mask::WRITE_OWNER,
193    );

195    /// The rights that count for an object of this kind. A file has no
196    /// children, so `FILE_DELETE_CHILD` is left out for files.
197    #[must_use]
198    pub const fn relevant(kind: ObjectKind) -> Self {
199        match kind {
200            ObjectKind::File => Self(Self::ALL.0 & !mask::FILE_DELETE_CHILD),
201            ObjectKind::Directory => Self::ALL,
202        }
203    }

205    /// The rights in an access mask (bits outside [`WriteRights::ALL`] are

208    pub const fn from_mask(access_mask: u32) -> Self {

210    }

213    #[must_use]
214    pub const fn bits(self) -> u32 {
215        self.0
216    }
217
218    /// True if no right is set.
219    #[must_use]
220    pub const fn is_empty(self) -> bool {
221        self.0 == 0
222    }
223
224    /// True if every right in `other` is set.
225    #[must_use]
226    pub const fn contains(self, other: Self) -> bool {
227        self.0 & other.0 == other.0
228    }
229
230    /// True if any right in `other` is set.
231    #[must_use]
232    pub const fn intersects(self, other: Self) -> bool {
233        self.0 & other.0 != 0
234    }
235
236    /// The rights in either set.
237    #[must_use]
238    pub const fn union(self, other: Self) -> Self {
239        Self(self.0 | other.0)
240    }
241
242    /// The rights in both sets.
243    #[must_use]
244    pub const fn intersection(self, other: Self) -> Self {
245        Self(self.0 & other.0)
246    }
247
248    /// The rights in `self` and not in `other`.
249    #[must_use]
250    pub const fn difference(self, other: Self) -> Self {
251        Self(self.0 & !other.0)
252    }
253
254    /// The `winnt.h` name of each right that is set, in bit order. Bits
255    /// 0x2 and 0x4 use their file names (`FILE_WRITE_DATA`,
256    /// `FILE_APPEND_DATA`), which on a directory mean "add file" and "add
257    /// subdirectory".
258    #[must_use]
259    pub fn names(self) -> Vec<&'static str> {
260        const NAMES: [(u32, &str); 8] = [
261            (mask::FILE_WRITE_DATA, "FILE_WRITE_DATA"),
262            (mask::FILE_APPEND_DATA, "FILE_APPEND_DATA"),
263            (mask::FILE_WRITE_EA, "FILE_WRITE_EA"),
264            (mask::FILE_DELETE_CHILD, "FILE_DELETE_CHILD"),
265            (mask::FILE_WRITE_ATTRIBUTES, "FILE_WRITE_ATTRIBUTES"),
266            (mask::DELETE, "DELETE"),
267            (mask::WRITE_DAC, "WRITE_DAC"),
268            (mask::WRITE_OWNER, "WRITE_OWNER"),
269        ];
270        NAMES
271            .iter()
272            .filter(|(bit, _)| self.0 & bit != 0)
273            .map(|(_, name)| *name)
274            .collect()
275    }
276}

307/// What an ACE does, as far as this model is concerned.
308#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
309pub enum AceKind {
310    /// `ACCESS_ALLOWED_ACE` (type 0).
311    Allow,
312    /// `ACCESS_DENIED_ACE` (type 1).
313    Deny,
314    /// A callback (conditional) allow ACE, types 9 and 11. Whether it
315    /// applies depends on an expression the model does not evaluate.
316    AllowConditional,
317    /// A callback (conditional) deny ACE, types 10 and 12.
318    DenyConditional,
319    /// An object allow ACE (type 5), which may be limited to an object type.
320    AllowObject,
321    /// An object deny ACE (type 6).
322    DenyObject,
323    /// Any other ACE type. Its layout is unknown, so it has no SID or mask.
324    Unknown(u8),
325}
326
327impl AceKind {
328    fn is_allow(self) -> bool {
329        matches!(
330            self,
331            Self::Allow | Self::AllowConditional | Self::AllowObject
332        )
333    }
334
335    fn is_deny(self) -> bool {
336        matches!(self, Self::Deny | Self::DenyConditional | Self::DenyObject)
337    }
338}

392        self.flags & ace_flags::INHERITED != 0
393    }
394}

396/// The parts of a security descriptor the writability check uses.
397#[derive(Debug, Clone, PartialEq, Eq, Hash)]
398pub struct SecurityDescriptor {
399    /// The owner. `None` if the descriptor has none.
400    pub owner: Option<Sid>,
401    /// The primary group. Not used by the evaluation.
402    pub group: Option<Sid>,
403    /// The DACL entries in stored order. `None` means there is no DACL (it
404    /// is absent or NULL), which grants everyone every right. `Some` of an
405    /// empty list grants nothing, apart from the owner's implicit rights.
406    pub dacl: Option<Vec<Ace>>,
407    /// The `SECURITY_DESCRIPTOR_CONTROL` bits, for diagnostics.
408    pub control: u16,
409}

411/// `SECURITY_DESCRIPTOR_CONTROL` bits used here.
412pub mod control {
413    /// `SE_DACL_PRESENT`.
414    pub const DACL_PRESENT: u16 = 0x0004;
415    /// `SE_DACL_PROTECTED`: the DACL does not inherit from the parent.
416    pub const DACL_PROTECTED: u16 = 0x1000;
417    /// `SE_SELF_RELATIVE`.
418    pub const SELF_RELATIVE: u16 = 0x8000;
419}

421/// The largest security descriptor accepted. The OS caps a self-relative
422/// descriptor well below this; the limit bounds work on hostile input.
423pub const MAX_DESCRIPTOR_BYTES: usize = 1 << 20;
424
425impl SecurityDescriptor {
426    /// A descriptor with this owner and DACL, and no group.
427    #[must_use]
428    pub fn new(owner: Option<Sid>, dacl: Option<Vec<Ace>>) -> Self {
429        let control = if dacl.is_some() {
430            control::SELF_RELATIVE | control::DACL_PRESENT
431        } else {
432            control::SELF_RELATIVE
433        };
434        Self {
435            owner,
436            group: None,
437            dacl,
438            control,
439        }
440    }
441
442    /// Serialises to the self-relative form [`Self::from_self_relative`]
443    /// reads: header, owner, group, then the DACL (revision 2, or 4 when it
444    /// holds object ACEs). It is for building fixtures, not for
445    /// round-tripping hostile input.
446    ///
447    /// Returns `None` if the DACL would exceed the 64 KiB an ACL can hold,
448    /// or holds an ACE of unknown type, which cannot be serialised.
449    #[must_use]
450    pub fn to_self_relative(&self) -> Option<Vec<u8>> {
451        let owner = self.owner.map(|s| s.to_bytes()).unwrap_or_default();
452        let group = self.group.map(|s| s.to_bytes()).unwrap_or_default();
453        let dacl = match &self.dacl {
454            Some(aces) => Some(write_acl(aces)?),
455            None => None,
456        };
457        let mut out = vec![0u8; 20];
458        let mut control = self.control | control::SELF_RELATIVE;
459        // With no DACL the offset stays zero. `DACL_PRESENT` is kept as
460        // given: set, it is a NULL DACL; clear, the DACL is absent. Both
461        // grant everyone everything.
462        if dacl.is_some() {
463            control |= control::DACL_PRESENT;
464        }
465        let put = |out: &mut Vec<u8>, at: usize, part: &[u8]| -> Option<()> {
466            if part.is_empty() {
467                return Some(());
468            }
469            let offset = u32::try_from(out.len()).ok()?;
470            out.get_mut(at..at + 4)?
471                .copy_from_slice(&offset.to_le_bytes());
472            out.extend_from_slice(part);
473            Some(())
474        };
475        put(&mut out, 4, &owner)?;
476        put(&mut out, 8, &group)?;
477        if let Some(d) = &dacl {
478            put(&mut out, 16, d)?;
479        }
480        *out.get_mut(0)? = 1;
481        out.get_mut(2..4)?.copy_from_slice(&control.to_le_bytes());
482        Some(out)
483    }
484}

486fn write_acl(aces: &[Ace]) -> Option<Vec<u8>> {
487    let mut body = Vec::new();
488    let mut count = 0u16;
489    for ace in aces {
490        let ace_type = match ace.kind {
491            AceKind::Allow => 0x00,
492            AceKind::Deny => 0x01,
493            AceKind::AllowConditional => 0x09,
494            AceKind::DenyConditional => 0x0A,
495            AceKind::AllowObject => 0x05,
496            AceKind::DenyObject => 0x06,
497            // An unknown ACE cannot be written back; dropping it would
498            // silently remove a fail-closed entry.
499            AceKind::Unknown(_) => return None,
500        };
501        let sid = ace.sid?.to_bytes();
502        let mut entry = vec![ace_type, ace.flags, 0, 0];
503        entry.extend_from_slice(&ace.mask.to_le_bytes());
504        if matches!(ace.kind, AceKind::AllowObject | AceKind::DenyObject) {
505            // Object flags 0: no object-type GUIDs.
506            entry.extend_from_slice(&0u32.to_le_bytes());
507        }
508        entry.extend_from_slice(&sid);
509        while entry.len() % 4 != 0 {
510            entry.push(0);
511        }
512        let size = u16::try_from(entry.len()).ok()?;
513        entry.get_mut(2..4)?.copy_from_slice(&size.to_le_bytes());
514        body.extend_from_slice(&entry);
515        count = count.checked_add(1)?;
516    }
517    let size = u16::try_from(body.len().checked_add(8)?).ok()?;
518    // Object ACEs need `ACL_REVISION_DS` (4).
519    let revision = if aces
520        .iter()
521        .any(|a| matches!(a.kind, AceKind::AllowObject | AceKind::DenyObject))
522    {
523        4
524    } else {
525        2
526    };
527    let mut out = vec![revision, 0];
528    out.extend_from_slice(&size.to_le_bytes());
529    out.extend_from_slice(&count.to_le_bytes());
530    out.extend_from_slice(&[0, 0]);
531    out.extend_from_slice(&body);
532    Some(out)
533}

535/// Rebuilds a self-relative descriptor from the owner, group and DACL of
536/// `bytes`, for handing to an OS API that takes no length.
537///
538/// The result has no SACL (`SE_SACL_PRESENT` cleared, offset zero), so no
539/// unvalidated offset reaches the OS; the owner defaults to `NULL SID`
540/// (which no token holds) and the group to the owner; and the DACL is the
541/// original DACL bytes, byte for byte, which [`SecurityDescriptor::from_self_relative`]
542/// has bounded and checked ACE by ACE. Every part is 4-byte aligned. An
543/// absent DACL and a NULL DACL both become a NULL DACL (`SE_DACL_PRESENT`
544/// set, offset zero): both grant everyone everything, and the OS access
545/// check accepts only the second. `Err` if `bytes` does not parse.
546pub fn sanitized_self_relative(bytes: &[u8]) -> Result<Vec<u8>, DescriptorError> {
547    let sd = SecurityDescriptor::from_self_relative(bytes)?;
548    let header = bytes.get(..20).ok_or(DescriptorError::Truncated)?;
549    let dacl_offset = to_index(read_u32(header, 16)?)?;
550    let dacl_bytes: Option<&[u8]> = if sd.dacl.is_some() && dacl_offset != 0 {
551        let size = usize::from(read_u16(bytes, dacl_offset + 2)?);
552        Some(
553            bytes
554                .get(
555                    dacl_offset
556                        ..dacl_offset
557                            .checked_add(size)
558                            .ok_or(DescriptorError::BadAcl)?,
559                )
560                .ok_or(DescriptorError::Truncated)?,
561        )
562    } else {
563        None
564    };
565    let owner = sd.owner.unwrap_or(well_known::NULL).to_bytes();
566    let group = sd.group.or(sd.owner).unwrap_or(well_known::NULL).to_bytes();
567    let pad = |v: &mut Vec<u8>| {
568        while !v.len().is_multiple_of(4) {
569            v.push(0);
570        }
571    };
572    let mut out = vec![0_u8; 20];
573    let mut control = (sd.control & !0x0010) | control::SELF_RELATIVE;
574    let put = |out: &mut Vec<u8>, at: usize, part: &[u8]| -> Result<(), DescriptorError> {
575        let offset = u32::try_from(out.len()).map_err(|_| DescriptorError::BadOffset)?;
576        out.get_mut(at..at + 4)
577            .ok_or(DescriptorError::BadOffset)?
578            .copy_from_slice(&offset.to_le_bytes());
579        out.extend_from_slice(part);
580        Ok(())
581    };
582    put(&mut out, 4, &owner)?;
583    pad(&mut out);
584    put(&mut out, 8, &group)?;
585    pad(&mut out);
586    match dacl_bytes {
587        Some(d) => {
588            control |= control::DACL_PRESENT;
589            put(&mut out, 16, d)?;
590        }
591        // A NULL DACL (present, offset zero), or an absent one.
592        None => control |= control::DACL_PRESENT,
593    }
594    if let Some(b) = out.get_mut(0) {
595        *b = 1;
596    }
597    out.get_mut(2..4)
598        .ok_or(DescriptorError::Truncated)?
599        .copy_from_slice(&control.to_le_bytes());
600    Ok(out)
601}

603impl SecurityDescriptor {
604    /// Parses a self-relative `SECURITY_DESCRIPTOR` (revision 1), as
605    /// returned by `GetFileSecurityW` or `MakeSelfRelativeSD`.
606    ///
607    /// The input is treated as untrusted: every offset and size is checked,
608    /// and nothing is allocated from a count the input declares beyond what
609    /// its length can hold. Any malformation is an error. A caller that
610    /// gets an error must treat the object as possibly writable (pass
611    /// `None` to [`assess_path`]).
612    pub fn from_self_relative(bytes: &[u8]) -> Result<Self, DescriptorError> {
613        if bytes.len() > MAX_DESCRIPTOR_BYTES {
614            return Err(DescriptorError::TooLarge);
615        }
616        let header = bytes.get(..20).ok_or(DescriptorError::Truncated)?;
617        let revision = read_u8(header, 0)?;
618        if revision != 1 {
619            return Err(DescriptorError::UnsupportedRevision(revision));
620        }
621        let control = read_u16(header, 2)?;
622        if control & control::SELF_RELATIVE == 0 {
623            return Err(DescriptorError::NotSelfRelative);
624        }
625        let owner = read_sid_at(bytes, read_u32(header, 4)?)?;
626        let group = read_sid_at(bytes, read_u32(header, 8)?)?;
627        let dacl_offset = read_u32(header, 16)?;
628        let dacl = if control & control::DACL_PRESENT == 0 {
629            // The self-relative format requires a zero offset here.
630            if dacl_offset != 0 {
631                return Err(DescriptorError::BadOffset);
632            }
633            None
634        } else if dacl_offset == 0 {
635            // A NULL DACL.
636            None
637        } else {
638            Some(read_acl(bytes, dacl_offset)?)
639        };
640        Ok(Self {
641            owner,
642            group,
643            dacl,
644            control,
645        })
646    }
647}

649fn read_u8(b: &[u8], at: usize) -> Result<u8, DescriptorError> {
650    b.get(at).copied().ok_or(DescriptorError::Truncated)
651}

653fn read_u16(b: &[u8], at: usize) -> Result<u16, DescriptorError> {
654    let end = at.checked_add(2).ok_or(DescriptorError::Truncated)?;
655    let s = b.get(at..end).ok_or(DescriptorError::Truncated)?;
656    let mut a = [0u8; 2];
657    a.copy_from_slice(s);
658    Ok(u16::from_le_bytes(a))
659}

661fn read_u32(b: &[u8], at: usize) -> Result<u32, DescriptorError> {
662    let end = at.checked_add(4).ok_or(DescriptorError::Truncated)?;
663    let s = b.get(at..end).ok_or(DescriptorError::Truncated)?;
664    let mut a = [0u8; 4];
665    a.copy_from_slice(s);
666    Ok(u32::from_le_bytes(a))
667}

669fn to_index(offset: u32) -> Result<usize, DescriptorError> {
670    usize::try_from(offset).map_err(|_| DescriptorError::BadOffset)
671}

673fn read_sid_at(bytes: &[u8], offset: u32) -> Result<Option<Sid>, DescriptorError> {
674    if offset == 0 {
675        return Ok(None);
676    }
677    let start = to_index(offset)?;
678    if start < 20 {
679        return Err(DescriptorError::BadOffset);
680    }
681    let tail = bytes.get(start..).ok_or(DescriptorError::BadOffset)?;
682    let (sid, _) = Sid::from_bytes(tail).map_err(DescriptorError::Sid)?;
683    Ok(Some(sid))
684}

686fn read_acl(bytes: &[u8], offset: u32) -> Result<Vec<Ace>, DescriptorError> {
687    let start = to_index(offset)?;
688    // An ACL starts on a DWORD boundary.
689    if start < 20 || start % 4 != 0 {
690        return Err(DescriptorError::BadOffset);
691    }
692    let header = bytes
693        .get(start..start.checked_add(8).ok_or(DescriptorError::BadOffset)?)
694        .ok_or(DescriptorError::Truncated)?;
695    let revision = read_u8(header, 0)?;
696    if revision != 2 && revision != 4 {
697        return Err(DescriptorError::UnsupportedAclRevision(revision));
698    }
699    let acl_size = usize::from(read_u16(header, 2)?);
700    let ace_count = usize::from(read_u16(header, 4)?);
701    if acl_size < 8 {
702        return Err(DescriptorError::BadAcl);
703    }
704    let acl = bytes
705        .get(start..start.checked_add(acl_size).ok_or(DescriptorError::BadAcl)?)
706        .ok_or(DescriptorError::Truncated)?;
707    // Each ACE is at least 8 bytes, so the ACL size bounds the count.
708    if ace_count > (acl_size - 8) / 8 {
709        return Err(DescriptorError::BadAcl);
710    }
711    let mut aces = Vec::with_capacity(ace_count);
712    let mut pos = 8usize;
713    for _ in 0..ace_count {
714        let ace_type = read_u8(acl, pos)?;
715        let flags = read_u8(acl, pos + 1)?;
716        let size = usize::from(read_u16(acl, pos + 2)?);
717        if size < 8 || size % 4 != 0 {
718            return Err(DescriptorError::BadAce);
719        }
720        let end = pos.checked_add(size).ok_or(DescriptorError::BadAce)?;
721        let body = acl.get(pos..end).ok_or(DescriptorError::BadAce)?;
722        aces.push(parse_ace(ace_type, flags, body)?);
723        pos = end;
724    }
725    Ok(aces)
726}

728fn parse_ace(ace_type: u8, flags: u8, body: &[u8]) -> Result<Ace, DescriptorError> {
729    let kind = match ace_type {
730        0x00 => AceKind::Allow,
731        0x01 => AceKind::Deny,
732        0x05 => AceKind::AllowObject,
733        0x06 => AceKind::DenyObject,
734        0x09 | 0x0B => AceKind::AllowConditional,
735        0x0A | 0x0C => AceKind::DenyConditional,
736        other => {
737            return Ok(Ace {
738                kind: AceKind::Unknown(other),
739                flags,
740                mask: 0,
741                sid: None,
742            });
743        }
744    };
745    let mask = read_u32(body, 4)?;
746    let sid_start = if matches!(ace_type, 0x05 | 0x06 | 0x0B | 0x0C) {
747        // ACCESS_*_OBJECT_ACE: Flags, then each GUID only if its flag is set.
748        let object_flags = read_u32(body, 8)?;
749        let mut at = 12usize;
750        if object_flags & 0x1 != 0 {
751            at += 16;
752        }
753        if object_flags & 0x2 != 0 {
754            at += 16;
755        }
756        at
757    } else {
758        8
759    };
760    let sid_bytes = body.get(sid_start..).ok_or(DescriptorError::BadAce)?;
761    let (sid, _) = Sid::from_bytes(sid_bytes).map_err(DescriptorError::Sid)?;
762    Ok(Ace {
763        kind,
764        flags,
765        mask,
766        sid: Some(sid),
767    })
768}

984/// The OS access check's part in an [`ObjectWritability`] (#332).
985///
986/// The portable evaluator and the OS check answer different questions: the
987/// evaluator covers every non-administrator principal and over-reports by
988/// design; the OS check is exact, but only for the synthetic standard
989/// user. So neither replaces the other. A policy decision uses their
990/// **union**: a right counts if either says the standard user may hold
991/// it. A right the OS grants is added (as certain), and a right only the
992/// evaluator reports is kept, so the OS check can only make a result more
993/// writable, never less (ADR 0018). If the check could not run, the
994/// evaluator's result stands, which already over-reports.
995#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
996pub enum OsCheck {
997    /// No OS check was asked for (any OS other than Windows, or a caller
998    /// that evaluates descriptors only).
999    #[default]
1000    NotRun,
1001    /// The check was asked for and failed, or the descriptor could not be
1002    /// handed to it. The portable result stands.
1003    Unavailable,
1004    /// The check ran.
1005    Ran {
1006        /// The write-type rights the OS grants the synthetic standard user.
1007        granted: WriteRights,
1008        /// The subset the portable evaluator had missed, now added. It
1009        /// should always be empty; anything here is an evaluator bug worth
1010        /// reporting.
1011        missed: WriteRights,
1012    },
1013}
1014
1015impl ObjectWritability {
1016    /// True if some non-administrator may hold any right.
1017    #[must_use]
1018    pub fn user_writable(&self) -> bool {
1019        !self.rights.is_empty()
1020    }
1021
1022    /// The result for an object whose descriptor could not be read: every
1023    /// right, all uncertain.
1024    #[must_use]
1025    pub fn unreadable(kind: ObjectKind) -> Self {
1026        let all = WriteRights::relevant(kind);
1027        Self {
1028            kind,
1029            rights: all,
1030            uncertain: all,
1031            standard_user: all,
1032            standard_user_uncertain: all,
1033            principals: vec![PrincipalRights {
1034                principal: Principal::Unknown,
1035                rights: all,
1036                uncertain: all,
1037                implicit_owner_rights: false,
1038            }],
1039            non_canonical: false,
1040            unreadable: true,
1041            os_check: OsCheck::NotRun,
1042        }
1043    }
1044
1045    /// Merges the OS access check's verdict for the synthetic standard user
1046    /// into this result, as [`OsCheck`] describes: `None` if the check
1047    /// could not run. Rights the OS grants become part of
1048    /// [`Self::standard_user`] and [`Self::rights`], and are certain; any
1049    /// the evaluator had missed are reported for an unknown principal, so
1050    /// they reach [`Writability::principals_with_write`]. Nothing is ever
1051    /// removed.
1052    pub fn merge_os_check(&mut self, os: Option<WriteRights>) {
1053        let Some(granted) = os else {
1054            self.os_check = OsCheck::Unavailable;
1055            return;
1056        };
1057        let granted = granted.intersection(WriteRights::relevant(self.kind));
1058        let missed = granted.difference(self.standard_user);
1059        self.standard_user = self.standard_user.union(granted);
1060        self.standard_user_uncertain = self.standard_user_uncertain.difference(granted);
1061        self.rights = self.rights.union(granted);
1062        self.uncertain = self.uncertain.difference(granted);
1063        if !missed.is_empty() {
1064            match self
1065                .principals
1066                .iter_mut()
1067                .find(|p| p.principal == Principal::Unknown)
1068            {
1069                Some(p) => {
1070                    p.rights = p.rights.union(missed);
1071                    p.uncertain = p.uncertain.difference(missed);
1072                }
1073                None => self.principals.push(PrincipalRights {
1074                    principal: Principal::Unknown,
1075                    rights: missed,
1076                    uncertain: WriteRights::NONE,
1077                    implicit_owner_rights: false,
1078                }),
1079            }
1080        }
1081        self.os_check = OsCheck::Ran { granted, missed };
1082    }
1083}

1085/// Maps the generic rights in an allow ACE to file rights.
1086fn map_generic_allow(access_mask: u32) -> u32 {
1087    let mut m = access_mask;
1088    if m & mask::GENERIC_ALL != 0 {
1089        m |= mask::FILE_ALL_ACCESS;
1090    }
1091    if m & mask::GENERIC_WRITE != 0 {
1092        m |= mask::FILE_GENERIC_WRITE;
1093    }
1094    m
1095}

1097/// Which question a DACL walk answers.
1098#[derive(Clone, Copy, PartialEq, Eq)]
1099enum Walk {
1100    /// What the token may hold: every allow ACE that might apply does, with
1101    /// generic bits mapped, and only unconditional deny ACEs apply.
1102    Possible,
1103    /// What the token holds for certain: only unconditional allow ACEs
1104    /// apply, without generic mapping, and every deny ACE that might apply
1105    /// does.
1106    Definite,
1107}
1108
1109/// What one applicable ACE does to a token holding its SID, in one walk
1110/// mode: the bits it grants and the bits it denies. At most one is
1111/// non-zero.
1112fn ace_effect(ace: &Ace, sid: &Sid, mode: Walk) -> (u32, u32) {
1113    let possible = mode == Walk::Possible;
1114    match ace.kind {
1115        AceKind::Allow if possible => (map_generic_allow(ace.mask), 0),
1116        AceKind::Allow => (ace.mask, 0),
1117        AceKind::AllowConditional | AceKind::AllowObject if possible => {
1118            (map_generic_allow(ace.mask), 0)
1119        }
1120        // A deny for `OWNER RIGHTS` is ignored when working out what may be
1121        // held, so that whether or not the OS applies it to the owner,
1122        // rights can only be over-reported.
1123        AceKind::Deny if !possible || *sid != well_known::OWNER_RIGHTS => (0, ace.mask),
1124        AceKind::DenyConditional | AceKind::DenyObject if !possible => (0, ace.mask),
1125        _ => (0, 0),
1126    }
1127}

1129/// The bits of [`WriteRights::ALL`], one at a time.
1130const TRACKED_BITS: [u32; 8] = [
1131    mask::FILE_WRITE_DATA,
1132    mask::FILE_APPEND_DATA,
1133    mask::FILE_WRITE_EA,
1134    mask::FILE_DELETE_CHILD,
1135    mask::FILE_WRITE_ATTRIBUTES,
1136    mask::DELETE,
1137    mask::WRITE_DAC,
1138    mask::WRITE_OWNER,
1139];
1140
1141/// For one SID and one walk mode: for each tracked bit, the position of
1142/// the first applicable ACE naming the SID that grants or denies the bit,
1143/// and whether it grants.
1144type FirstTouch = [Option<(usize, bool)>; TRACKED_BITS.len()];
1145
1146/// A DACL indexed by trustee, built in one pass.
1147///
1148/// Walking the DACL in stored order, as the OS does, a bit ends up granted
1149/// to a token exactly when the first applicable ACE that names a SID in the
1150/// token and grants or denies the bit grants it: a grant is never taken
1151/// back, and a deny is never overridden. So for each SID the index keeps
1152/// the first ACE that touches each bit, and a token's rights are the
1153/// earliest of its SIDs' entries, bit by bit. That is linear in the DACL
1154/// plus a constant per SID in a token, where walking the whole DACL once
1155/// per candidate principal was quadratic in the number of trustees.
1156struct DaclIndex {
1157    /// `[Definite, Possible]` entries for each SID.
1158    by_sid: HashMap<Sid, [FirstTouch; 2]>,
1159}
1160
1161impl DaclIndex {
1162    fn new(aces: &[Ace]) -> Self {
1163        let mut by_sid: HashMap<Sid, [FirstTouch; 2]> = HashMap::new();
1164        for (pos, ace) in aces.iter().enumerate() {
1165            if !ace.applies_to_object() {
1166                continue;
1167            }
1168            let Some(sid) = &ace.sid else { continue };
1169            let entry = by_sid.entry(*sid).or_default();
1170            for (mode, touch) in [Walk::Definite, Walk::Possible].into_iter().zip(entry) {
1171                let (grant, deny) = ace_effect(ace, sid, mode);
1172                for (bit, first) in TRACKED_BITS.iter().zip(touch.iter_mut()) {
1173                    if first.is_none() {
1174                        if grant & bit != 0 {
1175                            *first = Some((pos, true));
1176                        } else if deny & bit != 0 {
1177                            *first = Some((pos, false));
1178                        }
1179                    }
1180                }
1181            }
1182        }
1183        Self { by_sid }
1184    }
1185
1186    /// The tracked bits a token holding exactly `token` is granted, as the
1187    /// ordered walk in `mode` would grant them.
1188    fn granted(&self, token: &[Sid], mode: Walk) -> u32 {
1189        let m = usize::from(mode == Walk::Possible);
1190        let mut out = 0;
1191        for (i, bit) in TRACKED_BITS.iter().enumerate() {
1192            let first = token
1193                .iter()
1194                .filter_map(|s| self.by_sid.get(s))
1195                .filter_map(|e| e.get(m).and_then(|t| t.get(i)).copied().flatten())
1196                .min_by_key(|&(pos, _)| pos);
1197            if let Some((_, true)) = first {
1198                out |= bit;
1199            }
1200        }
1201        out
1202    }
1203
1204    /// Rights for one token: (all, uncertain).
1205    fn token_rights(&self, token: &[Sid], relevant: WriteRights) -> (WriteRights, WriteRights) {
1206        let definite =
1207            WriteRights::from_mask(self.granted(token, Walk::Definite)).intersection(relevant);
1208        let possible =
1209            WriteRights::from_mask(self.granted(token, Walk::Possible)).intersection(relevant);
1210        // `possible` is a superset of `definite`: the possible walk applies
1211        // more allow ACEs and fewer deny ACEs, so it grants each bit no
1212        // later.
1213        (possible.union(definite), possible.difference(definite))
1214    }
1215}

1217/// Walks the DACL in stored order for a token and returns the bits
1218/// granted: the reference [`DaclIndex`] is checked against.
1219#[cfg(test)]
1220fn walk(aces: &[Ace], in_token: &dyn Fn(&Sid) -> bool, mode: Walk) -> u32 {
1221    let mut granted = 0u32;
1222    let mut denied = 0u32;
1223    for ace in aces.iter().filter(|a| a.applies_to_object()) {
1224        let Some(sid) = &ace.sid else { continue };
1225        if !in_token(sid) {
1226            continue;
1227        }
1228        let (grant, deny) = ace_effect(ace, sid, mode);
1229        granted |= grant & !denied;
1230        denied |= deny & !granted;
1231    }
1232    granted
1233}

1235fn is_non_canonical(aces: &[Ace]) -> bool {
1236    let mut seen_inherited = false;
1237    let mut seen_explicit_allow = false;
1238    for ace in aces {
1239        if ace.is_inherited() {
1240            seen_inherited = true;
1241            continue;
1242        }
1243        if seen_inherited {
1244            return true;
1245        }
1246        if ace.kind.is_allow() {
1247            seen_explicit_allow = true;
1248        } else if ace.kind.is_deny() && seen_explicit_allow {
1249            return true;
1250        }
1251    }
1252    false
1253}

1255/// Works out which write-type rights any non-administrator principal may
1256/// hold on one object. See the module documentation for the method.
1257#[must_use]
1258pub fn evaluate(
1259    sd: &SecurityDescriptor,
1260    kind: ObjectKind,
1261    options: &EvaluationOptions,
1262) -> ObjectWritability {
1263    let relevant = WriteRights::relevant(kind);
1264    let admins = &options.admins;
1265    let Some(aces) = &sd.dacl else {
1266        // No DACL: everyone has every right.
1267        return ObjectWritability {
1268            kind,
1269            rights: relevant,
1270            uncertain: WriteRights::NONE,
1271            standard_user: relevant,
1272            standard_user_uncertain: WriteRights::NONE,
1273            principals: vec![PrincipalRights {
1274                principal: Principal::Sid(well_known::EVERYONE),
1275                rights: relevant,
1276                uncertain: WriteRights::NONE,
1277                implicit_owner_rights: false,
1278            }],
1279            non_canonical: false,
1280            unreadable: false,
1281            os_check: OsCheck::NotRun,
1282        };
1283    };
1284
1285    let owner = sd.owner.filter(|o| !admins.contains(o));
1286    // Only an unconditional allow ACE for `OWNER RIGHTS` is taken to replace
1287    // the owner's implicit rights. A conditional or object ACE may not
1288    // apply, and a deny is ignored (see `walk`), so in those cases the
1289    // implicit `WRITE_DAC` is still reported.
1290    let owner_rights_ace = aces.iter().any(|a| {
1291        a.applies_to_object() && a.kind == AceKind::Allow && a.sid == Some(well_known::OWNER_RIGHTS)
1292    });
1293
1294    // Candidate principals: every non-admin SID named by an applicable
1295    // allow ACE, plus a non-admin owner. Placeholders never match a token,
1296    // and OWNER RIGHTS stands for the owner, who is handled separately.
1297    let mut candidates: BTreeSet<Sid> = aces
1298        .iter()
1299        .filter(|a| a.applies_to_object() && a.kind.is_allow())
1300        .filter_map(|a| a.sid)
1301        .filter(|s| {
1302            !admins.contains(s)
1303                && !well_known::is_creator_placeholder(s)
1304                && *s != well_known::OWNER_RIGHTS
1305        })
1306        .collect();
1307    if let Some(o) = owner {
1308        candidates.insert(o);
1309    }
1310
1311    let index = DaclIndex::new(aces);
1312    let mut principals = Vec::new();
1313    for sid in candidates {
1314        let is_owner = owner == Some(sid);
1315        // An anonymous token does not hold `Everyone` by default, so a deny
1316        // for `Everyone` must not be assumed to stop it. It may hold
1317        // `NETWORK`, which is therefore evaluated both with and without
1318        // `Everyone`.
1319        let everyone_variants: &[bool] = if sid == well_known::ANONYMOUS {
1320            &[false]
1321        } else if sid == well_known::NETWORK {
1322            &[true, false]
1323        } else {
1324            &[true]
1325        };
1326        let mut rights = WriteRights::NONE;
1327        let mut definite = WriteRights::NONE;
1328        for &with_everyone in everyone_variants {
1329            let mut token = vec![sid];
1330            if with_everyone {
1331                token.push(well_known::EVERYONE);
1332            }
1333            if is_owner {
1334                token.push(well_known::OWNER_RIGHTS);
1335            }
1336            let (r, u) = index.token_rights(&token, relevant);
1337            rights = rights.union(r);
1338            definite = definite.union(r.difference(u));
1339        }
1340        let mut uncertain = rights.difference(definite);
1341        let implicit = is_owner && !owner_rights_ace;
1342        if implicit {
1343            // The owner's implicit READ_CONTROL | WRITE_DAC cannot be
1344            // removed by a deny ACE, and is certain.
1345            rights = rights.union(WriteRights::WRITE_DAC);
1346            uncertain = uncertain.difference(WriteRights::WRITE_DAC);
1347        }
1348        if !rights.is_empty() {
1349            principals.push(PrincipalRights {
1350                principal: Principal::Sid(sid),
1351                rights,
1352                uncertain,
1353                implicit_owner_rights: implicit,
1354            });
1355        }
1356    }
1357
1358    // An unknown owner (the descriptor has none) may be a non-administrator:
1359    // it may hold the implicit `WRITE_DAC` and whatever `OWNER RIGHTS` ACEs
1360    // grant. Both are reported as uncertain, for an unknown principal.
1361    let mut unknown = WriteRights::NONE;
1362    if sd.owner.is_none() {
1363        // Only `OWNER RIGHTS`: the unknown owner might not hold `Everyone`,
1364        // so a deny for `Everyone` is not assumed to stop it, and grants to
1365        // `Everyone` are already reported for `Everyone`.
1366        let (r, _) = index.token_rights(&[well_known::OWNER_RIGHTS], relevant);
1367        unknown = r.union(if owner_rights_ace {
1368            WriteRights::NONE
1369        } else {
1370            WriteRights::WRITE_DAC
1371        });
1372    }
1373    // ACE types whose layout is unknown might grant anything to anyone.
1374    if aces
1375        .iter()
1376        .any(|a| a.applies_to_object() && matches!(a.kind, AceKind::Unknown(_)))
1377    {
1378        unknown = relevant;
1379    }
1380    if !unknown.is_empty() {
1381        principals.push(PrincipalRights {
1382            principal: Principal::Unknown,
1383            rights: unknown,
1384            uncertain: unknown,
1385            implicit_owner_rights: false,
1386        });
1387    }
1388
1389    // The synthetic standard user is the owner if the owner SID is one of
1390    // its groups, as the OS access check decides ownership against every
1391    // SID in a token.
1392    let standard: BTreeSet<Sid> = options.standard_user.iter().copied().collect();
1393    let standard_is_owner = owner.is_some_and(|o| standard.contains(&o));
1394    let mut standard_token: Vec<Sid> = standard
1395        .iter()
1396        .copied()
1397        .filter(|s| !admins.contains(s))
1398        .collect();
1399    if standard_is_owner {
1400        standard_token.push(well_known::OWNER_RIGHTS);
1401    }
1402    let (mut standard_user, mut standard_uncertain) = index.token_rights(&standard_token, relevant);
1403    if standard_is_owner && !owner_rights_ace {
1404        standard_user = standard_user.union(WriteRights::WRITE_DAC);
1405        standard_uncertain = standard_uncertain.difference(WriteRights::WRITE_DAC);
1406    }
1407    // What an unknown owner or an unknown ACE type might grant may reach
1408    // the standard user too.
1409    let unknown_new = unknown.difference(standard_user);
1410    standard_user = standard_user.union(unknown);
1411    standard_uncertain = standard_uncertain.union(unknown_new);
1412
1413    let mut rights = standard_user;
1414    let mut uncertain = standard_uncertain;
1415    for p in &principals {
1416        rights = rights.union(p.rights);
1417        uncertain = uncertain.union(p.uncertain);
1418    }
1419    // A right is only uncertain overall if no principal holds it for sure.
1420    let definite = principals
1421        .iter()
1422        .map(|p| p.rights.difference(p.uncertain))
1423        .fold(
1424            standard_user.difference(standard_uncertain),
1425            WriteRights::union,
1426        );
1427    uncertain = uncertain.difference(definite);
1428
1429    ObjectWritability {
1430        kind,
1431        rights,
1432        uncertain,
1433        standard_user,
1434        standard_user_uncertain: standard_uncertain,
1435        principals,
1436        non_canonical: is_non_canonical(aces),
1437        unreadable: false,
1438        os_check: OsCheck::NotRun,
1439    }
1440}

1487/// Assesses an object and its ancestors.
1488///
1489/// `target` is the object's descriptor (`None` if unreadable) and kind.
1490/// `ancestors` lists every folder from the immediate parent up to and
1491/// including the volume root. The caller must list them all: a missing
1492/// ancestor cannot be detected here.
1493#[must_use]
1494pub fn assess_path(
1495    target: Option<&SecurityDescriptor>,
1496    kind: ObjectKind,
1497    ancestors: &[Ancestor],
1498    options: &EvaluationOptions,
1499) -> Writability {
1500    let target_w = match target {
1501        Some(sd) => evaluate(sd, kind, options),
1502        None => ObjectWritability::unreadable(kind),
1503    };
1504    let ancestor_w: Vec<ObjectWritability> = ancestors
1505        .iter()
1506        .map(|a| match &a.descriptor {
1507            Some(sd) => evaluate(sd, ObjectKind::Directory, options),
1508            None => ObjectWritability::unreadable(ObjectKind::Directory),
1509        })
1510        .collect();
1511
1512    let first_user_writable_ancestor = ancestors
1513        .iter()
1514        .zip(&ancestor_w)
1515        .find(|(_, w)| w.user_writable())
1516        .map(|(a, _)| a.path.clone());
1517    let change_perms_by_non_admin = std::iter::once(&target_w)
1518        .chain(&ancestor_w)
1519        .any(|w| w.rights.intersects(WriteRights::CHANGE_PERMISSIONS));
1520    let principals_with_write: Vec<Principal> = std::iter::once(&target_w)
1521        .chain(&ancestor_w)
1522        .flat_map(|w| w.principals.iter().map(|p| p.principal))
1523        .collect::<BTreeSet<_>>()
1524        .into_iter()
1525        .collect();
1526
1527    Writability {
1528        file_user_writable: target_w.user_writable(),
1529        owner_trust_blockers: target_w
1530            .rights
1531            .intersection(WriteRights::OWNER_TRUST_BLOCKING),
1532        target: target_w,
1533        ancestors: ancestor_w,
1534        first_user_writable_ancestor,
1535        change_perms_by_non_admin,
1536        principals_with_write,
1537    }
1538}

2027    fn arb_ace() -> impl proptest::strategy::Strategy<Value = Ace> {
2028        use proptest::prelude::*;
2029        let kinds = prop_oneof![
2030            Just(AceKind::Allow),
2031            Just(AceKind::Deny),
2032            Just(AceKind::AllowConditional),
2033            Just(AceKind::DenyConditional),
2034            Just(AceKind::AllowObject),
2035            Just(AceKind::DenyObject),
2036            Just(AceKind::Unknown(0x04)),
2037        ];
2038        // Masks built from the tracked bits and the generic bits, so the
2039        // walks overlap often.
2040        let bits = prop::collection::vec(
2041            prop::sample::select(vec![
2042                mask::FILE_WRITE_DATA,
2043                mask::FILE_APPEND_DATA,
2044                mask::FILE_WRITE_EA,
2045                mask::FILE_DELETE_CHILD,
2046                mask::FILE_WRITE_ATTRIBUTES,
2047                mask::DELETE,
2048                mask::WRITE_DAC,
2049                mask::WRITE_OWNER,
2050                mask::GENERIC_WRITE,
2051                mask::GENERIC_ALL,
2052            ]),
2053            0..4,
2054        );
2055        (
2056            kinds,
2057            prop::sample::select(vec![0u8, ace_flags::INHERIT_ONLY, ace_flags::INHERITED]),
2058            bits,
2059            prop::sample::select(POOL.to_vec()),
2060        )
2061            .prop_map(|(kind, flags, bits, sid)| Ace {
2062                kind,
2063                flags,
2064                mask: if matches!(kind, AceKind::Unknown(_)) {
2065                    0
2066                } else {
2067                    bits.into_iter().fold(0, |m, b| m | b)
2068                },
2069                sid: (!matches!(kind, AceKind::Unknown(_))).then_some(sid),
2070            })
2071    }

2378            let d = SecurityDescriptor::from_self_relative(&b).unwrap();
2379            assert_eq!(d.dacl, None);
2380        }

2385        b.extend_from_slice(&0u32.to_le_bytes()); // group

2392            SecurityDescriptor::from_self_relative(&b),

2398        b.extend_from_slice(&0u32.to_le_bytes());
