1//! The unified file identity record (#55).
2//!
3//! [`identify`] and [`identify_bytes`] run the other modules of this crate
4//! over one file and fold their outputs into one [`FileIdentity`]:
5//!
6//! | Group | From | Tier |
7//! |---|---|---|
8//! | `size`, `timestamps`, `fs.path` | the opened handle, [`crate::fsctx`] (#54) | stat (T0) |
9//! | `kind` | [`crate::filetype`] (#44) | classify (T1) |
10//! | `pe` | [`crate::pe`] (#45) | classify (T1) |
11//! | `hashes` | [`crate::hash`] (#46), [`crate::authenticode`] image and page hashes (#47) | hash (T2) |
12//! | `signing_state`, `signatures` | [`crate::authenticode`] signatures, chains, validity (#48, #49, #50) | trust (T3) |
13//! | `catalog_matches` | [`crate::catalog`] (#51) | trust (T3) |
14//! | `signing_state`, `signatures` of scripts, installers and packages | [`crate::script`] (#52), [`crate::installer`], [`crate::package`] (#53) | trust (T3) |
15//! | `hashes.script_normalised_sha256`, `hashes.msi_normalised_sha256` | [`crate::script`], [`crate::installer`] | hash (T2), when T3 or T5 read the content |
16//! | `fs.motw`, `fs.path_variables` | [`crate::fsctx`] (#54) | context (T4) |
17//! | `script`, `installer`, `package` | [`crate::script`], [`crate::installer`], [`crate::package`] | deep (T5) |
18//! | `content_tags` | `crate::tags` (#44, feature `content-rules`) | deep (T5) |
19//! | `os_cross_check` | [`crate::authenticode::cross_check`] and the OS trust API (#48, Windows, `os-trust`), **diagnostic only** | trust (T3), files on disk |
20//! | `derived`, `masquerade`, `strengths` | this module | always |
21//!
22//! Which reader runs is decided by the content the classifier saw, never by
23//! the name alone: a PE image named `.ps1` or `.msix` is judged only as a
24//! PE, so no script or package signature can vouch for it. The context
25//! tier reads the file ID, volume, owner, writability, streams and reparse
26//! point from the Windows file system (`os-trust`, #54); elsewhere they are
27//! [`Field::Unavailable`]. The provenance tag has no reader yet, so it holds
28//! [`Field::NotYetSupported`] with the issue number (#54).
29//!
30//! # Signing state
31//!
32//! The record folds embedded signatures and catalogs into one verdict,
33//! [`SigningStateKind`]. It is `trusted` only when a trusted signer vouches
34//! for the file: an embedded signature that passed every #48, #49 and #50
35//! check, or a catalog whose signer is trusted and whose match does not
36//! rely on SHA-1 (ADR 0008). It is `unsigned` only when the file has no
37//! embedded signature and a catalog lookup found nothing. A script, an
38//! installer and an app package are judged by their own signatures with
39//! the same trust and validity evaluation as a PE image's; a package whose
40//! manifest names another publisher than its signer, a script or package
41//! changed after signing, and a container the strict reader refuses are
42//! `invalid`. A file whose format's signatures are not read (a cabinet, an
43//! encoded script, a file over a reader's limit), or that was not looked
44//! up in any catalog, is `unverified`, never `unsigned`. So is a script or
45//! installer that no catalog lists: which digest catalogs made by OS
46//! tooling list them under is not yet checked (#51), so a miss proves
47//! nothing.
48//!
49//! # Diagnostics never decide
50//!
51//! `os_cross_check` records how the OS trust-verification API's verdict on
52//! a PE image's embedded signatures compares with this library's. It is a
53//! diagnostic (ADR 0018): `signing_state`, the masquerade assessment, the
54//! strengths and [`recommend`] never read it, so an OS that accepts or
55//! rejects a signature cannot change a verdict. `content_tags` are
56//! descriptive in the same way.
57//!
58//! # Fail-conservative
59//!
60//! Nothing in the record is guessed. A tier that fails leaves its fields
61//! [`Field::Unavailable`] and an entry in [`FileIdentity::errors`]; it
62//! never turns into "unsigned", "not a driver" or "clean". A masquerade
63//! check that could not run is listed in [`Masquerade::unassessed`]. A path
64//! counts as user-writable unless the access check proved that no
65//! non-administrator can write it or any folder above it.
66//!
67//! # Serialised form and evolution
68//!
69//! [`FileIdentity`] serialises with serde: `snake_case` field and variant
70//! names, digests as lowercase hex, times as seconds since the Unix epoch.
71//! Each [`Field`] is `{"status": "computed", "value": ...}` or a status
72//! without a value (`not_requested`, `not_applicable`, `unavailable` with a
73//! reason, `not_yet_supported` with the issue numbers). The schema is
74//! `fileid.v1` ([`SCHEMA_VERSION`]). Within `fileid.v1`:
75//!
76//! - fields and enum variants are only ever added, never renamed, removed
77//!   or given a new meaning;
78//! - a consumer must ignore fields and variants it does not know;
79//! - a breaking change is a new schema version, `fileid.v2`.
80//!
81//! The protobuf form for the agent-server protocol is `palisade-proto`'s
82//! (#55, follow-up), with the same field names; protobuf field numbers,
83//! once assigned, are never reused or renumbered.

117impl FileIdentity {
118    /// Folds `other`, a record of the same file computed for other tiers,
119    /// into this one: the agent computes T0 to T3 at execution and T4 and
120    /// T5 later. A field takes `other`'s value when it says more (a value
121    /// beats a reason, a reason beats "not requested"). The derived
122    /// attributes, masquerade assessment and strengths are recomputed with
123    /// `ctx`.
124    ///
125    /// Returns `false`, and changes nothing, when the records are shown to
126    /// describe different files or versions: a different path or name hint,
127    /// a different final path, file ID or change journal stamp, size,
128    /// last-write or creation time, or a different content digest; and when
129    /// both records hold attributes derived from the content, unless both
130    /// carry the same content digest. Otherwise an attribute only one record
131    /// has is not compared.
132    ///
133    /// The file ID and change journal stamp are read by the context tier
134    /// only, so they are compared only between two records that both ran
135    /// it. What joins an execution-time record (T0 to T3) to a later one
136    /// (T4 and T5) is the content digest: the deep tier reads the content
137    /// too, so both carry one and must agree. A later record of the context
138    /// tier alone carries no digest, and is joined on the path, final path,
139    /// size and times; a file rewritten in place with the same size and
140    /// restored times is not detected then.
141    pub fn merge(&mut self, other: Self, ctx: &IdentityContext<'_>) -> bool {
142        fn differ<T: PartialEq>(a: Option<T>, b: Option<T>) -> bool {
143            matches!((a, b), (Some(a), Some(b)) if a != b)
144        }
145        let final_path = |id: &Self| id.fs.path.computed().and_then(|p| p.final_path.clone());
146        let times = |id: &Self| id.timestamps.computed().copied();
147        let fid = |id: &Self| id.fs.file_id.computed().cloned();
148        let (a_id, b_id) = (fid(self), fid(&other));
149        // Each part of the file key is compared on its own: a part only one
150        // record knows is not compared, and a known part that differs
151        // refuses the merge.
152        let key_differs = {
153            let a = a_id.as_ref();
154            let b = b_id.as_ref();
155            differ(
156                a.and_then(|f| f.volume_serial),
157                b.and_then(|f| f.volume_serial),
158            ) || differ(
159                a.and_then(|f| f.file_id.clone()),
160                b.and_then(|f| f.file_id.clone()),
161            ) || differ(
162                a.and_then(|f| f.usn_journal_id),
163                b.and_then(|f| f.usn_journal_id),
164            ) || differ(a.and_then(|f| f.usn), b.and_then(|f| f.usn))
165        };
166        // Attributes derived from the content (classify, hash, trust) are
167        // joined only when both records carry the digest of the content
168        // they read, and it is the same: two records of the same size and
169        // name may still be of different content.
170        let reads_content = |id: &Self| {
171            [Tier::Classify, Tier::Hash, Tier::Trust, Tier::Deep]
172                .iter()
173                .any(|t| id.computed_tiers.contains(*t))
174        };
175        let content_unproven = reads_content(self)
176            && reads_content(&other)
177            && match (&self.content_sha256, &other.content_sha256) {
178                (Some(a), Some(b)) => a != b,
179                _ => true,
180            };
181        let disproven = self.path != other.path
182            || self.name_hint != other.name_hint
183            || differ(self.size.computed(), other.size.computed())
184            || differ(self.content_sha256.as_ref(), other.content_sha256.as_ref())
185            || content_unproven
186            || differ(final_path(self), final_path(&other))
187            || key_differs
188            || differ(
189                times(self).and_then(|t| t.modified),
190                times(&other).and_then(|t| t.modified),
191            )
192            || differ(
193                times(self).and_then(|t| t.created),
194                times(&other).and_then(|t| t.created),
195            );
196        if disproven {
197            return false;
198        }
199        self.requested_tiers = self.requested_tiers.union(other.requested_tiers);
200        self.computed_tiers = self.computed_tiers.union(other.computed_tiers);
201        self.size.absorb(other.size);
202        if self.content_sha256.is_none() {
203            self.content_sha256 = other.content_sha256;
204        }
205        self.timestamps.absorb(other.timestamps);
206        self.kind.absorb(other.kind);
207        self.pe.absorb(other.pe);
208        self.hashes.absorb(other.hashes);
209        self.signing_state.absorb(other.signing_state);
210        self.signatures.absorb(other.signatures);
211        self.catalog_matches.absorb(other.catalog_matches);
212        self.installer.absorb(other.installer);
213        self.package.absorb(other.package);
214        self.script.absorb(other.script);
215        self.content_tags.absorb(other.content_tags);
216        self.os_cross_check.absorb(other.os_cross_check);
217        self.fs.absorb(other.fs);
218        for e in other.errors {
219            if !self.errors.contains(&e) {
220                self.errors.push(e);
221            }
222        }
223        self.derived = compose::derived_for(self);
224        self.masquerade =
225            masquerade::assess(self, ctx.protected, ctx.code_trust, ctx.known_folders);
226        self.strengths = strength::classify(self);
227        true
228    }
229}

231/// One difference between two identities, from [`compare`].
232#[derive(Debug, Clone, PartialEq, Eq, serde::Serialize)]
233pub struct Difference {
234    /// The attribute.
235    pub attribute: &'static str,
236    /// Its value in the first record.
237    pub a: Option<String>,
238    /// Its value in the second record.
239    pub b: Option<String>,
240}
241
242/// The rule-relevant attributes in which `a` and `b` differ: content
243/// hashes, signing state, publisher, product, signer certificates, file
244/// names and versions. An update that keeps its publisher and product
245/// shows differences only in hashes and versions.
246#[must_use]
247pub fn compare(a: &FileIdentity, b: &FileIdentity) -> Vec<Difference> {
248    fn attrs(id: &FileIdentity) -> Vec<(&'static str, Option<String>)> {
249        let h = id.hashes.computed();
250        let v = id.version();
251        let s = id.trusted_signer();
252        vec![
253            ("sha256", h.and_then(|h| h.sha256.clone())),
254            (
255                "authenticode_sha256",
256                h.and_then(|h| h.authenticode.computed())
257                    .and_then(|a| a.sha256.clone()),
258            ),
259            (
260                "signing_state",
261                id.signing_state
262                    .computed()
263                    .map(|s| format!("{:?}", s.state).to_lowercase()),
264            ),
265            ("publisher", s.and_then(|s| s.publisher_name.clone())),
266            ("publisher_dn", s.and_then(|s| s.publisher_dn.clone())),
267            (
268                "signer_leaf_sha256_thumbprint",
269                s.and_then(|s| s.leaf.as_ref())
270                    .map(|c| c.sha256_thumbprint.clone()),
271            ),
272            (
273                "signer_pca_tbs_hash",
274                s.and_then(|s| s.pca.as_ref())
275                    .and_then(|c| c.tbs_hash.clone()),
276            ),
277            ("product_name", v.and_then(|v| v.product_name.clone())),
278            ("company_name", v.and_then(|v| v.company_name.clone())),
279            (
280                "original_file_name",
281                v.and_then(|v| v.original_file_name.clone()),
282            ),
283            ("file_version", v.and_then(|v| v.file_version_quad.clone())),
284            (
285                "product_version",
286                v.and_then(|v| v.product_version_quad.clone()),
287            ),
288            ("file_name", id.name.file_name.clone()),
289            ("size", id.size.computed().map(ToString::to_string)),
290        ]
291    }
292    attrs(a)
293        .into_iter()
294        .zip(attrs(b))
295        .filter(|((_, x), (_, y))| x != y)
296        .map(|((attribute, x), (_, y))| Difference {
297            attribute,
298            a: x,
299            b: y,
300        })
301        .collect()
