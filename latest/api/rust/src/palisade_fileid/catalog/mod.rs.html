1//! Catalog-signed files (#51): catalog parsing, catalog signature checks,
2//! the catalog store and its member index.
3//!
4//! Many OS components and drivers carry no embedded signature. A
5//! **catalog file** (`.cat`) signs them instead: a PKCS#7 SignedData whose
6//! content is a certificate trust list (CTL, `szOID_CTL`
7//! 1.3.6.1.4.1.311.10.1) of member digests. A file is catalog-signed when
8//! a catalog whose signature is valid lists its digest, and the catalog's
9//! signer is then the file's publisher.
10//!
11//! - [`parse_catalog`] decodes a catalog file and verifies its signature
12//!   with the same machinery as embedded Authenticode signatures (#48): the
13//!   strict DER reader, the SignedData decoder, the signer certificate
14//!   lookup, the `messageDigest` check over the CTL and the signature over
15//!   the authenticated attributes. The result is a [`Catalog`]: the decoded
16//!   [`CertificateTrustList`] and a [`SignatureReport`] with one
17//!   [`SignatureKind::Catalog`] signature, which
18//!   [`crate::authenticode::evaluate_trust`] takes like any other (#49).
19//! - [`parse_ctl`] decodes a CTL on its own.
20//! - [`CatalogStoreBuilder`] loads catalogs from bytes or from a directory
21//!   tree, within [`StoreLimits`], into a [`CatalogStore`] that indexes, by
22//!   digest, the members of catalogs whose signature is valid.
23//!   [`CatalogStore::lookup`] takes a file's [`FileDigests`] and returns
24//!   each catalog that lists it, trusted catalogs first, with the signer's
25//!   trust verdict and identity.
26//!
27//! # Which members are indexed
28//!
29//! Only members of a catalog whose signature is valid, and of those only
30//! members with an `SPC_INDIRECT_DATA` digest under SHA-256 or SHA-1.
31//! Members with no digest, or a digest under another algorithm, are kept
32//! in the [`CertificateTrustList`] but never indexed. Limits can leave out
33//! members that would otherwise be indexed: those past [`MAX_MEMBERS`] in
34//! one catalog ([`CertificateTrustList::members_truncated`]) and those past
35//! [`StoreLimits::max_members`] in the store
36//! ([`CatalogRecord::index_truncated`]). So a lookup that finds nothing does
37//! not show that no catalog lists the file; check those flags, and the
38//! store's records, before treating a miss as absence.
39//!
40//! # Member digests
41//!
42//! A member's `SPC_INDIRECT_DATA` attribute holds its digest and the
43//! indirect data type. For a PE member (`SPC_PE_IMAGE_DATA`) the digest is
44//! the Authenticode image hash (#47); for any other file it is the hash
45//! the file type's subject interface package computes, which for files
46//! without one is the flat hash (#46). v1 catalogs
47//! (`szOID_CATALOG_LIST_MEMBER`) use SHA-1, v2 catalogs
48//! (`szOID_CATALOG_LIST_MEMBER2`) SHA-256; the index takes whatever
49//! algorithm each member names. Members are indexed by digest, never by
50//! their tag string or `File` name, which the signature covers but which
51//! say nothing about the file's content.
52//!
53//! SHA-1 members are compatibility-only (ADR 0008): a match reports its
54//! algorithm, and policy must not let an allow decision rest on a SHA-1
55//! match alone (#40).
56//!
57//! # What a match means
58//!
59//! A [`CatalogMatch`] says that a catalog whose signature is
60//! cryptographically valid lists the file's digest. Whether its signer is
61//! trusted is [`CatalogMatch::trusted`], decided by the [`TrustConfig`]
62//! given when the catalog was loaded. Catalogs whose signature is not valid
63//! (tampered, unsupported, malformed) are recorded with their status but
64//! never indexed, so they match nothing.
65//!
66//! Given [`ValidityOptions`], the builder also judges each catalog's
67//! signature as of when it was made, with the same machinery as embedded
68//! signatures (#50): the catalog's own timestamps, expiry, revocation of
69//! its chain, and revocation of the catalog file by hash.
70//! [`CatalogMatch::usable`] is true only for a trusted catalog whose
71//! signature passed all of it; without validity options no match is
72//! usable.
73//!
74//! # Settings, the persistent index and authoring
75//!
76//! - [`CatalogSettings`]: `catalog_lookup_enabled`, `catalog_scope` and
77//!   `skip_catalog_for_paths`, applied by [`CatalogStore::lookup_with`] and
78//!   [`CatalogIndex::lookup_with`]. A skipped lookup says why, for the log.
79//! - [`CatalogIndex`]: the persistent index. It is built from a store,
80//!   written with an HMAC-SHA-256 tag ([`CatalogIndex::encode`]) and read
81//!   back only when the tag verifies and it was written by this library
82//!   version and index format ([`CatalogIndex::decode`]; anything else asks
83//!   for a full rebuild). It is updated in place as catalogs are added,
84//!   changed or removed ([`CatalogIndex::remove_path`],
85//!   [`CatalogIndex::merge`]), and reports [`IndexState::Building`] until
86//!   its first build is complete, during which a miss is
87//!   [`CatalogLookup::Indeterminate`], never a "not catalog-signed".
88//! - [`build_catalog`]: an unsigned catalog definition from a recorded set
89//!   of files, for organisation catalogs.
90//!
91//! # Not done here
92//!
93//! - Watching the catalog directories for changes is the change feed
94//!   (#60), and scheduling the first build at low priority is #65: both are
95//!   the agent's. This module takes their results.
96//! - The OS catalog database cross-check (`CryptCATAdmin*`, Windows,
97//!   `os-trust`) belongs to the Windows backend (#48).
98//! - Folding catalog matches into a file's signing state (`CatalogValid`)
99//!   is the unified file identity record (#55).
100//!
101//! # Untrusted input
102//!
103//! Catalog files are attacker-controlled. The same rules as for embedded
104//! signatures apply: DER only, typed errors, no panics, no allocation sized
105//! by a declared length, and fixed limits: [`MAX_CATALOG_SIZE`],
106//! [`MAX_MEMBERS`], [`MAX_ATTRIBUTES`], [`MAX_NAME_VALUES`],
107//! [`MAX_VALUE_BYTES`], [`MAX_CTL_WARNINGS`] and [`MAX_DECODED_BYTES`] per
108//! catalog, and [`StoreLimits`] for a store. The trust list is decoded
109//! before its signature is checked, so [`MAX_DECODED_BYTES`] bounds the
110//! memory an unsigned or forged catalog can take. The `fuzz_ctl` fuzz target covers parsing,
111//! loading and lookup.

153/// The largest catalog file read: 64 MiB.
154pub const MAX_CATALOG_SIZE: u64 = 64 * 1024 * 1024;
155
156/// Why a catalog file could not be read at all.
157#[derive(Debug, Clone, PartialEq, Eq, Hash)]
158#[non_exhaustive]
159pub enum CatalogError {
160    /// The file is larger than [`MAX_CATALOG_SIZE`].
161    TooLarge(u64),
162    /// The SignedData around the CTL could not be decoded (including a
163    /// content type other than `szOID_CTL`,
164    /// [`SignatureError::NotCatalog`]).
165    Envelope(SignatureError),
166    /// The CTL could not be decoded.
167    Ctl(CtlError),
168}
169
170impl fmt::Display for CatalogError {
171    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
172        match self {
173            Self::TooLarge(n) => write!(f, "catalog of {n} bytes exceeds {MAX_CATALOG_SIZE}"),
174            Self::Envelope(e) => write!(f, "catalog signature: {e}"),
175            Self::Ctl(e) => write!(f, "catalog trust list: {e}"),
176        }
177    }
178}

182/// Something unusual about a catalog file as a whole.
183#[derive(Debug, Clone, PartialEq, Eq, Hash)]
184#[non_exhaustive]
185pub enum CatalogWarning {
186    /// Bytes follow the SignedData. They are not signed.
187    TrailingData {
188        /// How many bytes.
189        len: usize,
190    },
191    /// The signer carries this many nested signatures (counted up to the
192    /// collection limit). They are checked as DER (tags, lengths and the
193    /// primitive encodings [`parse_catalog`] checks everywhere) but not
194    /// decoded or verified: only the catalog's own signature counts.
195    NestedSignaturesIgnored(usize),
196}

198/// A parsed catalog file.
199#[derive(Debug, Clone, PartialEq, Eq)]
200pub struct Catalog {
201    /// The catalog's identity: the SHA-256 of the whole file.
202    pub id: Digest,
203    /// The file's size in bytes.
204    pub size: u64,
205    /// The decoded trust list.
206    pub ctl: CertificateTrustList,
207    /// The catalog's signature, as one [`SignatureKind::Catalog`]
208    /// signature. Pass it to [`crate::authenticode::evaluate_trust`] for
209    /// the signer's chain, trust and identity (with the member file's
210    /// version resource, for the file-level identity), or use
211    /// [`Self::trust`].
212    ///
213    /// Unlike a PE report, it has no `WIN_CERTIFICATE` entries, and its
214    /// `image_status` is always conformant: a catalog has no image layout.
215    pub signatures: SignatureReport,
216    /// Anything unusual about the file.
217    pub warnings: Vec<CatalogWarning>,
218}

220impl Catalog {
221    /// The catalog's signature.
222    #[must_use]
223    pub fn signature(&self) -> Option<&SignatureInfo> {
224        self.signatures.signatures.first()
225    }
226
227    /// Whether the signature is cryptographically valid. Says nothing about
228    /// whether the signer is trusted.
229    #[must_use]
230    pub fn signature_valid(&self) -> bool {
231        self.signatures.primary.is_some()
232    }
233
234    /// The signer's chain and trust under `config`, with signer-level
235    /// identity (no file version resource).
236    #[must_use]
237    pub fn trust(&self, config: &TrustConfig) -> TrustReport {
238        evaluate_trust(&self.signatures, config, None)
239    }
240
241    /// Every member whose digest is `digest` under `alg`.
242    pub fn members_with_digest<'a>(
243        &'a self,
244        alg: DigestAlgorithm,
245        digest: &'a [u8],
246    ) -> impl Iterator<Item = &'a CatalogMember> + 'a {
247        self.ctl.members.iter().filter(move |m| {
248            m.digest
249                .as_ref()
250                .is_some_and(|d| d.alg == alg && d.digest == digest)
251        })
252    }
253}

255/// Parses a catalog file and verifies its signature.
256///
257/// Fails only when the file is too large, or its SignedData or CTL cannot
258/// be decoded. A catalog that decodes but whose signature does not verify
259/// is returned, with the reason in [`Catalog::signatures`].
260///
261/// Every element of the SignedData, including the parts no decoder reads
262/// (nested signatures), must be DER as far as tags and lengths go, and
263/// its INTEGER, BOOLEAN, NULL and OBJECT IDENTIFIER encodings must be
264/// valid: an INTEGER non-empty, a BOOLEAN `00` or `ff`, a NULL empty, an
265/// OBJECT IDENTIFIER well formed. (INTEGERs the CTL decoder reads must also
266/// be minimal; certificate serial numbers, as elsewhere in the crate, need
267/// not be.)
268pub fn parse_catalog(bytes: &[u8]) -> Result<Catalog, CatalogError> {
269    let size = u64::try_from(bytes.len()).unwrap_or(u64::MAX);
270    if size > MAX_CATALOG_SIZE {
271        return Err(CatalogError::TooLarge(size));
272    }
273    let (envelope, ctl_tlv, trailing) = pkcs7::parse_envelope(
274        bytes,
275        0,
276        ctl::oid::CTL,
277        SignatureError::NotCatalog,
278        |content, _| Ok(*content),
279    )
280    .map_err(CatalogError::Envelope)?;
281    let ctl = ctl::parse_ctl_tlv(&ctl_tlv).map_err(CatalogError::Ctl)?;
282    // Parts the decoders skip without reading (nested signatures on the
283    // signer, which the PE walker checks by parsing them) are still held
284    // to DER: check the whole element once.
285    let mut whole = asn1::Reader::new(bytes, 0);
286    whole
287        .read(asn1::tag::SEQUENCE)
288        .and_then(|tlv| asn1::validate_strict(&tlv))
289        .map_err(|e| CatalogError::Envelope(e.into()))?;
290
291    let mut warnings = Vec::new();
292    if !trailing.is_empty() {
293        warnings.push(CatalogWarning::TrailingData {
294            len: trailing.len(),
295        });
296    }
297    if !envelope.signer.nested.is_empty() {
298        warnings.push(CatalogWarning::NestedSignaturesIgnored(
299            envelope.signer.nested.len(),
300        ));
301    }
302
303    let info = check(&envelope, ctl_tlv.content);
304    let valid = info.status.is_valid();
305    let signing_state = if valid {
306        SigningState::Valid
307    } else {
308        SigningState::Invalid(InvalidReason::Signature(info.status.clone()))
309    };
310    let signatures = SignatureReport {
311        entries: Vec::new(),
312        signatures: vec![info],
313        primary: valid.then_some(0),
314        signing_state,
315        tolerate_digest_mismatch: false,
316        image_status: AuthenticodeStatus::Conformant,
317        warnings: Vec::new(),
318    };
319    // `hash_bytes` always returns the digests it was asked for; the error
320    // only keeps this free of a panic path.
321    let id = hash_bytes(bytes, AlgorithmSet::SHA256)
322        .get(HashAlgorithm::Sha256)
323        .cloned()
324        .ok_or(CatalogError::TooLarge(size))?;
325    Ok(Catalog {
326        id,
327        size,
328        ctl,
329        signatures,
330        warnings,
331    })
332}

334/// Checks the catalog's SignerInfo over `content`, the CTL's content
335/// octets. The signed content has no separate digest to compare (unlike a
336/// PE image digest), so the signature check alone decides the status.
337fn check(envelope: &pkcs7::Envelope<'_>, content: &[u8]) -> SignatureInfo {
338    let mut warnings = Warnings(envelope.warnings.0.clone());
339    let signer = &envelope.signer;
340    let signer_cert = find_signer_cert(&envelope.certificates, &signer.sid, &mut warnings);
341    let signer_alg = signer.digest_alg.as_ref().ok().copied();
342    if !envelope.signer_digest_listed {
343        warnings.push(SignatureWarning::SignerDigestNotListed);
344    }
345    if signer_alg == Some(DigestAlgorithm::Sha1) {
346        warnings.push(SignatureWarning::Sha1Digest);
347    }
348    let signature_valid = check_signature(signer, content, signer_cert.as_ref().map(|(_, c)| c));
349    let weak = signer_alg.filter(|a| a.is_broken());
350    let status = match (weak, &signature_valid) {
351        (Some(alg), _) => SignatureStatus::WeakAlgorithm(alg),
352        (None, SignatureCheck::Valid) => SignatureStatus::Valid,
353        (None, SignatureCheck::Invalid(why)) => SignatureStatus::BadSignature(*why),
354        (None, SignatureCheck::Unsupported(why)) => SignatureStatus::Unsupported(why.clone()),
355        // `check_signature` never returns this; fail closed if it does.
356        (None, SignatureCheck::NotChecked) => {
357            SignatureStatus::BadSignature(BadSignature::SignatureInvalid)
358        }
359    };
360    let (key_alg, key_bits) = match &signer_cert {
361        Some((_, cert)) => (Some(cert.key_alg.clone()), cert.key_bits),
362        None => (None, None),
363    };
364    if let (Some(KeyAlgorithm::Rsa), Some(bits)) = (&key_alg, key_bits)
365        && bits < 2048
366    {
367        warnings.push(SignatureWarning::SmallRsaKey(bits));
368    }
369    let os_ci_issues = os_ci_issues(key_alg.as_ref(), key_bits, weak);
370    let signer_attrs = match (&status, &signer_cert) {
371        (SignatureStatus::Valid, Some((i, _))) => Some(SignerAttributes {
372            program_name: signer.opus.program_name.clone(),
373            more_info_url: signer.opus.more_info_url.clone(),
374            statement_type: signer.statement_type,
375            signing_time: signer.signing_time,
376            signer_cert: *i,
377            signed_metadata: signer.signed_metadata.clone(),
378        }),
379        _ => None,
380    };
381    // Every field is spelled out, so a field added to `SignatureInfo`
382    // cannot be left at a default here unnoticed.
383    SignatureInfo {
384        index: 0,
385        total: 1,
386        kind: SignatureKind::Catalog,
387        entry: 0,
388        parent: None,
389        depth: 0,
390        // The signed content's digest is the signer's (`messageDigest`
391        // over the CTL), so primary selection and SHA-1 checks rank it.
392        digest_alg: signer_alg,
393        signed_image_digest: None,
394        signer_digest_alg: signer_alg,
395        sig_alg: Some(signer.sig_alg.clone()),
396        key_alg,
397        key_bits,
398        digest_match: None,
399        signature_valid,
400        status,
401        signer: signer_attrs,
402        untrusted_signer_attrs: false,
403        signer_id: Some(signer.sid.clone()),
404        certs_in_blob: envelope.certificates.iter().map(|c| c.to_vec()).collect(),
405        pe_image_flags: None,
406        page_hashes: None,
407        timestamp_tokens: signer.timestamps.clone(),
408        // What a timestamp on the catalog must imprint (#50).
409        signature_value: signer.signature.to_vec(),
410        os_ci_issues,
411        warnings: warnings.0,
412    }
