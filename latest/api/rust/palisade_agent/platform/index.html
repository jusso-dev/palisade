The agent’s implementations of the palisade_core::platform traits.

system holds the ones built on the standard library and safe wrapper crates, which build and run on every OS. signature is the SignatureVerifier, which delegates to palisade_fileid and so also runs on every OS. windows (compiled on Windows only) holds the ones that need the OS: the registry, identity (IdentityProvider), processes (ProcessInfo) and the file-system context (WindowsFileSystem). Each passes the contract checks in palisade_core::test_util::contract on the CI runners of its OS.

nt decodes the raw token and process records the Windows backends read through palisade_agent::ffi. It has no unsafe code and no OS calls, so it is compiled, and tested, on every OS.

The simulator (palisade-agent --simulate, feature test-util) runs the agent’s event building on the mocks.
