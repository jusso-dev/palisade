Expand description

Decides whether the service accepts STOP from the SCM (#56, #220).

The service offers STOP to the SCM only while stop_permission holds true. While it holds false, sc stop and the services console fail with “the requested control is not valid for this service”, and only a system shutdown stops the agent. The service re-reports its status whenever the value changes.

The gate is applied through the accepted controls, not by refusing a STOP that has arrived: the windows-service crate frees its handler once a stop control returns, so a refused STOP would leave the SCM calling freed memory (see palisade_agent::service). A STOP already in flight when the gate closes is therefore still honoured, and logged.

Tamper protection (#220) and the break-glass unlock (#222) implement this. Until they land, AllowStop is used.
