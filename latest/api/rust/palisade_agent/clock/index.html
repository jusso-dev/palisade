Module clock

Expand description

Wall-clock jump detection (ISM-0988).

Every timestamp the agent records is UTC from Clock::now_utc, paired with Clock::monotonic where order matters. The wall clock can be set by a local administrator; the monotonic clock cannot. Between two samples both should move by the same amount. When they differ by more than JUMP_THRESHOLD, the wall clock was changed (or corrected by a large amount), and the agent reports it.

ClockJumpDetector is the pure comparison. ClockMonitor is the clock subsystem that runs it: it samples every SAMPLE_INTERVAL and at once on HostEvent::TimeChange. Around a suspend it starts again from a new baseline without reporting, because on some platforms the monotonic clock stops while the machine sleeps and the wall clock does not. Jumps are logged and published through ClockMonitor::subscribe; the event pipeline (#63) turns them into events.
