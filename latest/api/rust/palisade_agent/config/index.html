Agent configuration: built-in defaults, overlaid by the install-time file.

Issue #56 defines four layers, lowest priority first: built-in defaults, the install-time file %ProgramData%\Palisade\agent.toml, policy-delivered agent settings, and local overrides. This module implements the first two. The policy and local-override layers arrive with the policy cache (#61).

The file is parsed strictly: unknown keys, wrong types and out-of-range values are errors, so a typo cannot silently fall back to a default. A file that exists but cannot be read or parsed stops the agent from starting instead of running with defaults, because the defaults could be weaker than what the file asked for (for example fail_mode). The OS-native policy keeps enforcing while the agent is down (ADR 0012). Only a file that does not exist (first install) falls back to the defaults.
