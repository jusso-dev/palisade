Required Methods§

Source

fn name(&self) -> &'static str

A unique, stable name, used in logs, health and dependency lists.

Source

fn criticality(&self) -> Criticality

Whether the agent can work without this subsystem.

Source

fn run( self: Arc<Self>, ctx: SubsystemContext, ) -> BoxFuture<Result<(), SubsystemError>>

Runs the subsystem until a stop is requested (see the module docs).

Provided Methods§

Source

fn dependencies(&self) -> &[&'static str]

Names of the subsystems that must be ready before this one starts.

Source

fn start_timeout(&self) -> Duration

How long the subsystem may take to call SubsystemContext::set_ready. A run that is not ready by then is aborted and counts as a failed start.

Source

fn stop_timeout(&self) -> Duration

How long the subsystem gets to finish after a stop is requested. The supervisor caps it by what is left of the overall shutdown budget.

Source

fn health(&self) -> Health

The subsystem’s own health. Called only while it is running, from health reports; it must be cheap and must not block.
