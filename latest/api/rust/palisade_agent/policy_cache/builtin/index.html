palisade_agent::policy_cache

Module builtin 

Source
Expand description

The built-in policies the agent runs when no bundle loads (ADR 0018).

  • First install: no policy was ever accepted. Audit mode, so nothing is blocked before the first bundle arrives; every would-block decision is reported (PolicyMissing). The mandatory blocklists of #87 join it when the agent ships them.
  • Emergency: a policy was accepted before, but neither active nor previous loads. Enforce mode, and every unknown object is blocked. #326 replaces the content with ADR 0018’s emergency policy (allow OS-signed binaries and Palisade itself), and makes it audit-only in native_only mode. Until then it is stricter than that policy, never weaker.

Neither has any rule, so both build without error; the tests check it.
