Module policy_cache

The local policy cache (#61): which policy the agent enforces, how a new bundle is activated, and how the agent behaves offline.

The decisions are made by palisade_proto::policy_bundle (#304): what loads at startup (select::startup), whether a downloaded bundle is accepted (select::pending), the anti-rollback record and staleness. This module reads and writes the files in the order ADR 0007 requires, and swaps the evaluator.

  • Startup (PolicyCache::load_startup): delete any leftover pending, read active, previous and the record copies, let select::startup choose, and decode only the bundle it chose. A bundle that then fails to decode, validate or compile counts as an unsupported schema, and the choice is made again. If nothing loads, the built-in emergency policy runs (enforce mode), or the first-install policy (audit mode) if no policy was ever accepted (builtin).
  • Activation (PolicyCache::activate): verify and compile the new bundle in memory, write pending and read it back, copy the verified active bytes to previous, clear the record’s fallback, rename pending over active with write-through, raise the floor, then swap the evaluator. Any failure before the rename leaves the current policy in force, in memory and on disk.
  • Evaluation (PolicyCache::current): the running policy is one Active behind an ArcSwap. A decision holds the Arc it started with, so it finishes on that policy, and its Verdict names the version and bundle hash that decided it.
  • Offline (PolicyCache::status): staleness is only reported. Nothing relaxes enforcement automatically (ADR 0018): there is no on_expiry = audit_only, and the stricter mode_disconnected of the policy model (#36) applies through the device state the caller passes.

A cache file holds one signed bundle envelope (#325). The EnvelopeVerifier checks it before anything past the bundle header is decoded; the agent’s is SignedEnvelopes, which verifies against the device’s trust set. A bundle the checks accept is then decoded, validated and compiled in one step ([palisade_policy::bundle::load()]), with the bundle’s inlined library sets and the agent’s system baseline.
