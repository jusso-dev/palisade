Envelope verification (#325): what a cache file holds, and whether it is trusted.

A cache file holds one signed bundle envelope (palisade_proto::policy_bundle::envelope). Before anything past the bundle header is decoded, an EnvelopeVerifier checks it in #225’s order and says where the bundle bytes are. The cache then loads only those bytes, and only when the signature verified or the signature mode tolerates that it did not.

SignedEnvelopes is the verifier the agent runs: it calls envelope::verify against the device’s current trust set. A cache file that is not an envelope, or whose signatures are not from a policy key the trust set lists inside its validity window, never verifies, so in the default enforce mode it never loads.
