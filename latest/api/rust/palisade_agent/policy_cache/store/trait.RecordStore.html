Expand description

Where the copies of the anti-rollback record are kept.

#225 asks for copies in separate stores (a DPAPI-protected file and a registry mirror, later a TPM-sealed blob), so that replacing one is detected by the others. That is #326; FileRecordStore keeps two files until it lands.

Required Methods§

Source

fn read(&self) -> Vec<Option<Vec<u8>>>

Every copy, always in the same order. None for a copy that does not exist. A copy that exists but cannot be read is returned as empty bytes, which never unseal, so it counts as corrupt rather than missing.

Source

fn write(&self, sealed: &[u8]) -> Result<()>

Writes sealed to every copy, trying them all.

§Errors

The first I/O error. Some copies may then hold the new value and some the old: startup tells that apart from tampering (RecordCopies::interrupted_activation).
