palisade_agent::policy_cache

Module events 

Source
Expand description

The policy-integrity events (#326, event types from #303), and the sink they go to until the event pipeline (#63) exists.

The cache never waits on a sink: PolicyEventSink::emit must not block, and a sink that is full drops the event and counts it. The pipeline (#63) will implement the trait and forward to the server; BoundedSink keeps the events in memory, bounded, until then.

BoundedSink
A bounded in-memory queue of events, for until #63. When full, it drops the new event and counts it, so the first events (the ones closest to what went wrong) are kept.
