Protecting the policy cache’s secrets at rest (#326): the data keyring and the anti-rollback record copies.

A Protector wraps small blobs so only this machine can read them. On Windows it is machine-scope DPAPI (Dpapi, through the agent’s ffi module). MemoryProtector is the portable backend for tests and non-Windows development builds: it seals under a key that lives only in the process, so nothing it protects survives a restart.

Each use passes a distinct purpose, bound into the protection (DPAPI’s optional entropy), so a blob protected for one use never unprotects for another.
