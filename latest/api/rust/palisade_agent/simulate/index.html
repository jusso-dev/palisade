The fake agent: palisade-agent --simulate (#29).

It replays a Scenario on the mock platform from palisade_core::test_util, on any OS, and emits canonical events (palisade_proto::events::Event): agent.started, one exec.decision per step, then agent.stopped. The events are built only through the platform traits, generically, so the same code builds them from the real platform once the agent has a process tracker (#59).

The binary writes the events to standard output as JSON lines, in their canonical form. Delivering them to a server needs the agent endpoints and enrolment, which do not exist yet (#62, #223, #126); until then, the output is what a server or console developer feeds to their code. See docs/dev/unix.md.

The decisions are scripted by the scenario, not evaluated: policy evaluation in the agent arrives with the policy cache (#61).
