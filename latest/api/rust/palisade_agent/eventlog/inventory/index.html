The per-device table of active OS-native policies (#58).

Each policy activation event (3099) names a policy (its ID, name, GUID and hash) and its option bits. The table keeps the latest activation of each policy, so health (#67) can report which OS-native policies are active and the server can check its deployed policies against it (#6). Periodic reads of the policy store (the OS policy tool’s JSON list, or the active policy directory) will reconcile it; they come with the E06 policy parser.
