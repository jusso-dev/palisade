OS code integrity and rule-collection event-log ingestion (#58).

The event log is the source of truth for what OS-native enforcement allowed, audited and blocked, and for which OS-native policies are active. Everything that reads the untrusted record text is portable, has no unsafe code, and is tested (and fuzzed) on every OS:

  • decode turns rendered event XML into a mapping Record.
  • correlate groups each decision with its per-signature records, behind a token-bucket rate limit.
  • ingest runs the chain: decode, rate limit, correlate, map through palisade_proto::mapping, add the process from the #59 process tree, keep the policy inventory, and emit into a sink.
  • inventory is the per-device table of active OS-native policies from policy activation events (3099).

The Windows subscription (EvtSubscribe with persisted bookmarks) comes with the agent local store (ADR 0007), which keeps the bookmarks.
