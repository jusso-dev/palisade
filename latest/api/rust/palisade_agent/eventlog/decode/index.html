palisade_agent::eventlog

Module decode 

Source
Expand description

Decoding rendered event-log XML into mapping records (#58).

The event-log subscription (Windows only) renders each record as XML (EvtRender with EvtRenderEventXml) and hands over the text. This module turns it into a Record, the input of the data-driven mapping in palisade_proto::mapping. It has no unsafe code and no OS calls, so it runs, is tested and is fuzzed on every OS.

The XML is parsed by the bounded, namespace-aware reader in palisade_fileid::package::xml, which refuses a document type declaration (so no entity is ever defined or expanded), undefined entities, undeclared prefixes, more than one root, and anything over its size, depth and element limits.

What is read:

  • System/EventID, System/TimeCreated/@SystemTime, System/EventRecordID, System/Channel, System/Provider/@Name, System/Correlation/@ActivityID, System/Execution/@ProcessID (as the field System.ProcessID) and System/Security/@UserID (as System.UserID).
  • EventData/Data[@Name] (the code integrity and script host events), or the children of the single element under UserData (the rule-collection events), as fields by name.

Field names are normalised to the mapping files’ form: the code integrity provider writes names with spaces (SHA256 Flat Hash), the template names have none (SHA256FlatHash), so spaces are removed.

Fail closed (ADR 0018): a record without a parseable event ID or time, a repeated field, more than MAX_RECORD_FIELDS fields, or a field with child elements is an error, not a partial record.
