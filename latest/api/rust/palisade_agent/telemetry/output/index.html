What the process monitor emits, and where it goes (#59).

The event pipeline (#63, #197) owns the canonical envelope (sequence numbers, the hash chain, the tenant and host), so the monitor emits TelemetryEvents into a TelemetrySink and the pipeline turns them into canonical events. process_fields builds the canonical process field set from the tree, so that translation is shared.

Until the pipeline exists, ChannelSink is the seam: a bounded channel that never blocks the producer. A full channel drops the event and counts it (Counters::dropped); a drop is never silent.
