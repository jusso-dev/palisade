The process monitor’s state machine (#59).

ProcessMonitor takes decoded kernel process records in order, keeps the ProcessTree, and emits TelemetryEvents. It reads the OS only through an Enricher (command line and token of a new process) and the startup snapshot, so it runs and is tested on every OS. The Windows subsystem (telemetry::windows) feeds it from the ETW session.

What it does with each record:

  • Process start: finds the parent (ProcessTree::find_parent: never a process that reused the parent’s ID), records the creator when it is not the parent, reads the command line and token through the enricher, records the process and emits ProcessStart. A creator that is not the recorded parent also emits an advisory ParentSpoof.
  • Process stop: marks the process exited (it is kept for late correlation) and, if enabled, emits ProcessStop.
  • Image load: a kernel-mode image is a driver and is always emitted. A user-mode library is emitted according to DllEvents. The process’s own main image is covered by ProcessStart.

Every event the sink refuses is counted in Counters::dropped.
