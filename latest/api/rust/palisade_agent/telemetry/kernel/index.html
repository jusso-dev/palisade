Decoding the kernel process provider’s ETW records (#59).

The ETW consumer (ffi::etw, Windows only) copies each record’s header fields and user data out of the OS buffer and hands them over as a RawEvent. This module turns the user data into a KernelEvent. It has no unsafe code and no OS calls, so it runs, is tested and is fuzzed on every OS.

The layouts are the provider’s manifest templates, bound by provider GUID (KERNEL_PROCESS), event ID and event version:

IDEventVersions
1process start0 to 4
2process stop0 to 2
5image load0
6image unload0

Fail closed (ADR 0018): a record that is short, has an unknown version, a string without its terminator or text that is not valid UTF-16 is an error, never a guessed value. A newer version than this module knows is DecodeError::UnknownVersion: later versions append fields, but this module does not assume that, so a new OS build is reported, not misread. Trailing bytes after the last known field are also an error.
