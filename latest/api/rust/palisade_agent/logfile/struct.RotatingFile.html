impl RotatingFile

Source

pub fn open(dir: &Path, files: usize, max_bytes: u64) -> Result<Self>

Opens (appending to) dir/agent.log, keeping files files of at most max_bytes each. files and max_bytes below 1 are raised to 1. The directory must exist: creating it, with its ACL, is the installer’s job.

Source

pub fn path(dir: &Path, index: usize) -> PathBuf

The path of the indexth file: 0 is agent.log, then agent.log.1 and so on.
