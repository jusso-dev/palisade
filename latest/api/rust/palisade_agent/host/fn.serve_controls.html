Expand description

Serves the controls the service control handler sends, until a stop.

Control::Events are published to the subsystems through events. Every change of the guard’s stop permission, and its value at the start, is passed to on_permission, which re-reports the accepted controls. A guard that goes away leaves the last permission in place. Returns the stop request, or a StopReason::ChannelClosed stop if the handler has gone away.
