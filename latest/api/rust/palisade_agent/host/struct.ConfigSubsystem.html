Struct ConfigSubsystem 

Source 
pub struct ConfigSubsystem { /* private fields */ }
Expand description

The config subsystem: holds the effective configuration and publishes every change of it.

Other subsystems get a receiver from ConfigSubsystem::subscribe when they are registered, and declare a dependency on ConfigSubsystem::NAME.

On HostEvent::ParamChange (the service’s PARAMCHANGE control), it reads the configuration again from where it was first read: the same file, or the default path if the agent started on built-in defaults. A reload that fails keeps the current configuration and logs the error; it never falls back to the defaults, which could be weaker (ADR 0018). The log level applies at once. Runtime sizes apply at the next start.

The policy-delivered and local-override layers come with the policy cache (#61).
