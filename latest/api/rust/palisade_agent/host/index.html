Functions§

agent_supervisor
The supervisor the console and service runs use: supervisor’s subsystems plus the ones that read the OS, such as the process monitor (#59). Kept apart from supervisor so tests never start the machine-wide trace session.
build_runtime
Builds the multi-threaded runtime: min(4, cores) workers unless configured, and a bounded blocking pool for file I/O and hashing.
builtin_subsystems
The subsystems the host registers. Subsystems from later issues (policy cache #61, server comms #62, ETW #59 and others) are added here as they land: construct them with what they need (for example a ConfigSubsystem::subscribe receiver), declare their dependencies, and push them after the subsystems they depend on.
finish_runtime
Shuts the runtime down without waiting indefinitely for blocking-pool work that outlived its subsystem.
init_logging
Sends tracing records at or above level to standard error and, if file is given, to a rotating log file as well. The event-log channel is still to come (#56). Safe to call more than once; only the first call has an effect. The level can be changed later with set_log_level.
install_panic_hook
Routes panics to the log, with a backtrace. Panics inside subsystem tasks are then contained by the supervisor; this only records them.
open_log_file
Opens the rotating log file in the default log directory (config::log_dir), if there is one. A directory that cannot be found or opened is reported on standard error, and the agent logs to standard error only: logging never stops the agent.
prepare
Loads configuration and starts logging. Errors are printed to standard error, since logging may not be set up yet.
run_console
--console: runs in the foreground on any OS until Ctrl-C.
run_until
Starts supervisor, runs until stop resolves, then shuts down within the requested budget. on_started runs once supervision has begun.
serve_controls
Serves the controls the service control handler sends, until a stop.
set_log_level
Changes the level of the subscriber init_logging installed, at run time (a reloaded configuration, and later IPC or policy). Returns false if this process’s subscriber was not installed by init_logging.
supervisor
The default supervisor for a loaded configuration, with the boot mode of the running system (boot::current).
supervisor_for
The default supervisor for a loaded configuration and a boot mode. In a safe-mode boot the agent reports AgentState::SafeMode, and enforcement applies the configured SafeModeBehaviour.
