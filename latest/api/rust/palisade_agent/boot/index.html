Safe-mode boot detection.

Windows creates HKLM\SYSTEM\CurrentControlSet\Control\SafeBoot\Option only for a safe-mode boot, with the DWORD OptionValue saying which kind. The agent reads it once at start-up. In safe mode the supervisor reports AgentState::SafeMode for the whole boot, and enforcement components (E06, E08) apply SafeModeBehaviour.

A registry read that fails is treated as a normal boot and logged. That is the fail-closed reading (ADR 0018): safe mode can only relax enforcement (the default behaviour is audit only), so a fact the agent could not read must not put it there.
