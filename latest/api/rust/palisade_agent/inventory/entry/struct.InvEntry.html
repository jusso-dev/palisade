Expand description

One file in the inventory.

Fields§

§key: EntryKey

The file’s key.

§path: String

Its current path.

§path_history: Vec<String>

Its earlier paths, oldest first, at most MAX_PATH_HISTORY.

§identity: Option<IdentitySummary>

Its identity summary, once identified.

§first_seen: UtcTime

When the agent first saw it.

§last_modified: Option<UtcTime>

When its content last changed, as far as the agent knows.

§last_executed: Option<UtcTime>

When it last ran (#59).

§discovery: Discovery

How the agent first learnt of it.

§existing_at_install: bool

It was found by the initial scan, so it existed at install (E05’s implicit baseline).

§user_writable_location: Option<bool>

Whether a non-administrator can write the file or a folder above it. None when not assessed; see InvEntry::in_user_writable_location.

§state: EntryState

Whether it is there and readable.

§deleted_at: Option<UtcTime>

When it was deleted, for EntryState::Deleted.

§stale: bool

Its content or metadata changed since identity was computed, so the identity must not be relied on until it is computed again.
