The inventory record (InvEntry) and its summary of a file’s identity.

Structs§

EntryKey
Identifies a file for the life of its inventory entry: the volume’s serial number and the file’s 128-bit ID. A rename or move within the volume keeps it; a copy, or a move to another volume, is a new file.
IdentitySummary
The identity facts the inventory keeps per file. The full record lives in the file repository cache (#64); this is the compact summary.
InvEntry
One file in the inventory.
