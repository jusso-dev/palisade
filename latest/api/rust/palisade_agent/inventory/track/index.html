palisade_agent::inventory

Module track 

Source
Expand description

Incremental change tracking: changes are coalesced per file, then applied to the inventory.

A change source (the NTFS change journal on Windows, directory notifications or a periodic rescan elsewhere) reports Changes. The Coalescer gathers every change to one file within COALESCE_WINDOW and releases them as one Coalesced once the file has been closed, or after MAX_HOLD if it never is. apply then updates the entry and says what work it needs (Action).

Fail closed (ADR 0018): Coalescer::push returns at once whether the change made the entry’s identity or location unreliable, and invalidate marks it so before the coalesced change is applied. A file never keeps its old identity while it is being rewritten.
