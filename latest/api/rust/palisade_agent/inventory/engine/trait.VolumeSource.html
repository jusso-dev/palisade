Required Methods§

Source

fn serial(&self) -> u64

The volume’s serial number.

Source

fn journal(&mut self) -> Result<Option<JournalData>, SourceError>

The journal’s state, or None if the volume keeps no journal (FAT, exFAT, network): it is then rescanned on a schedule instead.

Source

fn list( &mut self, start: u64, high_usn: i64, ) -> Result<Option<(u64, Vec<Listed>)>, SourceError>

One batch of the volume’s files from start (0 for the first), or None when every file has been listed. The cursor returned must be passed back to continue.

Source

fn changes( &mut self, cursor: JournalCursor, ) -> Result<(i64, Vec<Change>), SourceError>

Changes from cursor, and the cursor to continue from.

Source

fn resolve(&mut self, file_id: [u8; 16]) -> Option<String>

The full path of the file with file_id, from its ID, never a path a user could have swapped. None if it is gone.
