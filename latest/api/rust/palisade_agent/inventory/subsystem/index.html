palisade_agent::inventory

Module subsystem 

Source
Expand description

The inventory subsystem: runs the Engine over every volume the VolumeProvider gives, on a blocking thread, until a stop.

For each volume it finishes (or resumes) the initial scan, then polls the change journal every POLL_INTERVAL. A volume without a journal is rescanned every RESCAN_INTERVAL. Its health says Baseline: scanning until every volume’s first scan is complete, which the server shows as WaitingForBaseline (E05).

The resource budgets are #65. Until then the PacedThrottle waits between batches at low priority, and every throttle stops at once when a stop is requested; the checkpoint lets the scan resume.
