Expand description

One Authenticode signature: an embedded SignedData, a nested one, or a catalog’s (SignatureKind::Catalog).

Fields§

§index: usize

Position in SignatureReport::signatures: embedded signatures in table order, each followed by its nested signatures, depth first.

§total: usize

How many signatures the report holds.

§kind: SignatureKind

Where the signature was found.

§entry: usize

The WIN_CERTIFICATE entry it came from, an index into SignatureReport::entries. 0 for a catalog signature, which has no entry.

§parent: Option<usize>

For a nested signature, the index of the signature that carries it.

§depth: u8

0 for an embedded signature, 1 and up for nested ones.

§digest_alg: Option<DigestAlgorithm>

The image digest algorithm (SpcIndirectDataContent.messageDigest). For a SignatureKind::Catalog signature, the SignerInfo’s digest algorithm, the one that hashes the CTL (its messageDigest); not any member’s digest algorithm.

§signed_image_digest: Option<Vec<u8>>

The image digest the signature signs. None for a catalog signature.

§signer_digest_alg: Option<DigestAlgorithm>

The SignerInfo’s digest algorithm, used for the messageDigest attribute and the signature.

§sig_alg: Option<SignatureAlgorithm>

The SignerInfo’s signature algorithm.

§key_alg: Option<KeyAlgorithm>

The signer certificate’s key algorithm, if the certificate was found.

§key_bits: Option<u32>

The signer key’s size in bits (the RSA modulus, or the curve size).

§digest_match: Option<bool>

Whether the signed image digest equals the file’s Authenticode digest under the same algorithm. None if it could not be computed, and always None for a catalog signature, which signs no image.

§signature_valid: SignatureCheck

The cryptographic check.

§status: SignatureStatus

The overall verdict.

§signer: Option<SignerAttributes>

The signer attributes publisher rules use. Some only when Self::status is SignatureStatus::Valid, or when it is SignatureStatus::DigestMismatch and the tolerate_digest_mismatch knob is on; in the second case Self::untrusted_signer_attrs is true.

§untrusted_signer_attrs: bool

true when Self::signer is reported only because of tolerate_digest_mismatch: rules must not trust it, and should fall back to hash identity.

§signer_id: Option<SignerIdentifier>

How the SignerInfo names its certificate. Attacker-controlled; it is not covered by the signature.

§certs_in_blob: Vec<Vec<u8>>

Every certificate in the SignedData, DER-encoded, in blob order (at most super::MAX_CERTIFICATES).

§pe_image_flags: Option<u8>

The SpcPeImageData flags octet (bit 7 is includeResources).

§page_hashes: Option<PageHashes>

The page hash table, if the signature carries one (#47).

§timestamp_tokens: Vec<TimestampToken>

Timestamps in the unauthenticated attributes, verified by super::verify_timestamps (#50).

§signature_value: Vec<u8>

The SignerInfo’s signature value (encryptedDigest): what a timestamp covers. Empty if the signature did not parse.

§os_ci_issues: Vec<OsCiIssue>

Why the signer cannot back an OS-native code integrity signer rule; empty when it can.

§warnings: Vec<SignatureWarning>

Anything unusual that does not change the status.
