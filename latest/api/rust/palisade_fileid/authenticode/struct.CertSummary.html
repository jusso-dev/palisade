Expand description

Everything about one X.509 certificate that signer rules match on.

Field names are stable: they are the JSON names, and they follow the names used in issue #49. Hashes, thumbprints, key identifiers and the serial are lowercase hex; times are seconds since the Unix epoch (UTC).

Fields§

§version: u8

1, 2 or 3.

§serial: String

The serial number’s INTEGER content octets as encoded, in hex.

§subject: DistinguishedName

The subject.

§issuer: DistinguishedName

The issuer.

§not_before: i64

notBefore.

§not_after: i64

notAfter.

§sig_alg: SignatureAlgorithm

The algorithm the issuer signed this certificate with.

§public_key_alg: KeyAlgorithm

The subject key’s algorithm (with the curve, for EC keys).

§key_bits: Option<u32>

The key size in bits: the RSA modulus, or the curve size.

§sha1_thumbprint: String

SHA-1 of the whole certificate (the classic thumbprint).

§sha256_thumbprint: String

SHA-256 of the whole certificate.

§spki_sha256: String

SHA-256 of the DER subjectPublicKeyInfo: identifies the key, whatever certificate carries it.

§tbs_hash: Option<String>

The hash of the DER tbsCertificate, exactly as encoded, under the digest of Self::sig_alg: 40 hex characters for SHA-1, 64 for SHA-256, 96 for SHA-384 and 128 for SHA-512. This is the value OS code integrity signer rules and events use. None when the signature algorithm has no SHA digest (MD5, Ed25519, unknown).

§tbs_hash_alg: Option<DigestAlgorithm>

The digest Self::tbs_hash uses.

§tbs_hash_sha256: String

SHA-256 of the DER tbsCertificate, always: a uniform identity.

§subject_key_id: Option<String>

The subjectKeyIdentifier extension.

§authority_key_id: Option<String>

The keyIdentifier of the authorityKeyIdentifier extension.

§basic_constraints: Option<BasicConstraints>

The basicConstraints extension.

§key_usage: Option<KeyUsage>

The keyUsage extension.

§extended_key_usage: Option<Vec<Eku>>

The extKeyUsage extension, every OID in encoded order. None when the extension is absent.

§certificate_policies: Vec<ObjectId>

The policy OIDs of the certificatePolicies extension.

§crl_distribution_points: Vec<String>

The URIs of the cRLDistributionPoints extension’s full names.

§ocsp_urls: Vec<String>

The OCSP URIs of the authorityInfoAccess extension.

§ca_issuers_urls: Vec<String>

The caIssuers URIs of the authorityInfoAccess extension.

§is_self_signed: bool

The subject equals the issuer and the certificate’s signature verifies with its own key.

§unhandled_critical_extensions: Vec<ObjectId>

Critical extensions this crate does not process. A certificate with any is not used in a chain (RFC 5280, 4.2).

§der: Vec<u8>

The whole certificate, DER. Serialised as base64.
