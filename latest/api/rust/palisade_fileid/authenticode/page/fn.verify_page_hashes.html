Expand description

Checks the signed page hash table signed against data, the image info was parsed from, and reports the first entry that does not match.

This checks only that the table describes the file. Whether the table can be trusted depends on the signature that carries it; see verify_signature_page_hashes.

A page table covers the header page and each section’s raw data, not the bytes between the last section and the certificate table (an overlay) or after it. Only the whole-image Authenticode digest covers those, so a PageHashCheck::Match for a signature whose image digest does not match (SignatureStatus::DigestMismatch) does not mean the file is unmodified: it means every mapped page is.
