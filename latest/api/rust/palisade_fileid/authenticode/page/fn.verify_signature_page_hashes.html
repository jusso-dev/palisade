Checks the page hashes of signature against data, the image info was parsed from: the issue’s on-demand verify_page_hashes().

The table is checked only when the signature itself verifies: its SignatureInfo::signature_valid is SignatureCheck::Valid and its status is SignatureStatus::Valid or SignatureStatus::DigestMismatch. The second case is what page hashes are for: the file was changed after signing, and the check names the first page that changed. Any other signature (a bad or unsupported signature, MD5, a non-conformant image) gives PageHashCheck::SignatureNotValid, because a table it carries is attacker-controlled. Returns None when the signature has no page hash table.

“Verifies” here is the cryptographic check of #48. Whether the signer is trusted is the certificate chain’s business (#49). See verify_page_hashes for what a match does and does not cover.
