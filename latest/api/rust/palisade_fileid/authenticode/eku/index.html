The extended key usage (EKU) catalogue (#49): known EKU object identifiers and their friendly names.

Unknown EKUs are kept as raw OIDs; the catalogue only adds names. Eku::os_policy_value gives the form OS-native code integrity policy uses for an EKU’s Value attribute.
