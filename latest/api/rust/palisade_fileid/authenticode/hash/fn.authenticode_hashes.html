The Authenticode hashes of data, the image info was parsed from.

This is the issue’s authenticode_digest(pe, alg). SHA-256 and SHA-1 are always computed, plus any other algorithm in extra; pick one with AuthenticodeHashes::get. The page hash tables are built in the same pass (AuthenticodeHashes::page_hashes). Check AuthenticodeHashes::status before treating a digest as authoritative. Fails if data is not the length info was parsed from.
