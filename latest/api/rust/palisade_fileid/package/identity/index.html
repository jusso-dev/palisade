Package identity strings: the publisher ID, the package family name and the package full name.

§The publisher ID

The OS derives a 13-character ID from the publisher’s distinguished name string exactly as written in the manifest’s Identity@Publisher:

  1. Encode the string as UTF-16LE (no byte order mark, no terminator).
  2. Take the SHA-256 of those bytes and keep the first 8 bytes.
  3. Read those 64 bits as a big-endian bit string, pad it with one zero bit to 65 bits, and split it into 13 groups of 5 bits.
  4. Map each group to Crockford’s base32 alphabet in lowercase: 0123456789abcdefghjkmnpqrstvwxyz (no i, l, o, u).

The package family name is {Name}_{PublisherId} and the package full name {Name}_{Version}_{Architecture}_{ResourceId}_{PublisherId}, with the architecture in lowercase (neutral when none is given) and an empty resource ID for none, so Name_1.0.0.0_x64__8wekyb3d8bbwe. A bundle’s resource ID is ~: Bundle_1.0.0.0_neutral_~_8wekyb3d8bbwe.
