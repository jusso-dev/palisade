Module manifest 

Source
Expand description

AppxManifest.xml and AppxMetadata/AppxBundleManifest.xml.

Elements are matched by namespace URI and local name, so the prefix a manifest uses does not matter. The package schema namespaces are listed in ns; the “foundation” namespace (2010) and its successors carry Package, Identity, Properties, Applications, Capabilities, Extensions and Dependencies; the others add capability and extension vocabularies, which are recorded with their namespace.
