palisade_fileid::package

Module xml 

Source
Expand description

A bounded, namespace-aware XML tree for package manifests and block maps.

parse builds a small element tree with every element and attribute name resolved to (namespace URI, local name), so a manifest that binds the schema namespace to an unusual prefix reads the same as one that uses the default namespace, and an attribute with a foreign prefix is never taken for the schema’s.

Hostile input is refused rather than guessed at: a document type declaration (so no entity can ever be defined, let alone expanded), an undefined entity, an undeclared prefix, an attribute that appears twice after namespace resolution, text outside the root, more than one root, and anything past MAX_INPUT, MAX_DEPTH, MAX_ELEMENTS, MAX_ATTRS, MAX_ATTR_LEN or MAX_TREE_BYTES. Input must be UTF-8, optionally with a byte order mark, as app package XML is.

A namespace declaration’s value is bound as written. So that it binds the same here as in a reader that normalises attribute values first, a declaration whose value contains a reference (&), or whitespace other than a plain space, or that is longer than MAX_NS_LEN, is refused. Namespace URIs are shared between the elements that use them, so a long URI costs memory once.
