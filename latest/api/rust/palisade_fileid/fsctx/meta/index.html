A file’s identity, timestamps, attributes and hard links as file-system context (#54).

The Windows backend reads these from one open handle (FILE_BASIC_INFO, FILE_STANDARD_INFO, FILE_ID_INFO and the change-journal record) and from FindFirstFileNameW. The types here are portable, so a server or CLI can fill them from other metadata and a consumer can test them anywhere.
