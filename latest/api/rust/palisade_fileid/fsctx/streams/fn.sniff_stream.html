pub fn sniff_stream<R: Read + Seek + ?Sized>(reader: &mut R, name: &str) -> bool
Expand description

Classifies the content of the stream named name from reader, the open stream, and says whether it counts_as_executable.

The whole stream is available to the classifier, which bounds its own reads (the first 64 KiB, then a few targeted reads), so a structure past the first 64 KiB, such as an installer’s directory, is still found. The stream’s own name is the name hint: the classifier uses the extension to tell batch, PowerShell and HTML application content from plain text, and never lets a harmless extension hide content it recognises.
