Expand description

Alternate data streams as file-system context (#54): each named stream with its size, a tag for the streams the OS and common software write for their own bookkeeping, and whether its content looks executable.

A benign tag says who usually writes a stream of that name, not that its content is safe: anyone who can write the file can write a stream with any name. So a tagged stream is still listed, and still sniffed.

Functions§

counts_as_executable
Whether a classification of a stream’s content counts as executable for StreamInfo::is_executable_content: executable content, or any classification with a parse error. A parse error means the kind was not established (a compound file whose directory could not be read is OtherCfb, though it may be an installer), and a missing fact must not make the stream look like data (ADR 0018). Some(true) rather than None is used for it, so FsStreams::any_executable fails closed as well as FsStreams::may_hide_executable.
sniff_stream
Classifies the content of the stream named name from reader, the open stream, and says whether it counts_as_executable.
