Security identifiers (SIDs).

Sid is a plain value type: string form (S-1-5-32-544) and binary form (as stored in a security descriptor) both parse into it, and it formats back to the string form. Nothing here calls the OS, so name lookup (owner_name) is left to the Windows backend.

The well-known SIDs this crate needs are constants in well_known.
