Cached and streaming writability assessment (#54).

super::acl::assess_path needs every ancestor’s descriptor up front. This module adds what a scanner needs on top:

  • WritabilityCache: the result of super::acl::evaluate for each distinct security descriptor, keyed by the SHA-256 of its self-relative bytes and the object kind. Folders that inherit the same ACL (most of a volume) share one entry, so each distinct descriptor is evaluated once. A security-change journal record (#60) evicts by descriptor hash (WritabilityCache::evict) or clears the cache.
  • assess_ancestors: super::acl::assess_path over an iterator of ancestors, with the cache, so the chain is not built first, and with AssessOptions::stop_at_first_writable it stops at the first user-writable folder.
  • enumerate_user_writable_dirs: the folders under some roots that a principal set may write to, for the E8 self-test and path scanner (#17), and the path-rule guardrails (#212). It walks through a DirectorySource, so it is portable and tested here; the Windows backend provides the source that reads real folders.

Everything here is pure: no file system access happens in this module.
