fn descriptor( &mut self, path: &str, ) -> Result<Option<ReadDescriptor>, Self::Error>

The descriptor of the folder at path. Ok(None) if it cannot be read (counted as writable); Err stops the walk.

Source

fn subdirectories(&mut self, path: &str) -> Result<Listing, Self::Error>

The subfolders of path, as full paths. Links, junctions and mount points must not be listed: following them could leave the root or loop. A folder that cannot be listed (fully) is an incomplete Listing, never an empty complete one.
