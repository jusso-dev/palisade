Volume and drive classification.

The OS reports a volume’s file system name (GetVolumeInformationW), its drive type (GetDriveTypeW) and the bus of the disk behind it (IOCTL_STORAGE_QUERY_PROPERTY, STORAGE_BUS_TYPE). The functions here turn those raw values into enums, and the enums into a LocationClass that rules and guardrails can condition on. The storage-query results are parsed here too (parse_storage_device_descriptor, parse_hotplug_info); the Windows backend (palisade_fileid::win::volume) makes the calls.

The classification is conservative: when the inputs disagree, the less trusted class wins. A fixed drive on a USB bus is LocationClass::Removable, and a disk on a virtual bus is LocationClass::VirtualDisk unless it is the OS volume. When an input is missing, the result is LocationClass::Unknown, never a trusted class: the OS volume is only LocationClass::OsVolume when it is known not to be hot-pluggable, and another fixed disk is only LocationClass::OtherFixed when its file system, bus and hot-plug state are all known.

The location class and owner support are separate questions. A VHD the OS boots from is LocationClass::OsVolume for location rules, but its owners can still have been written on another machine, so VolumeInfo::supports_owner also requires a known, non-virtual bus.

Functions§

combined_hotplug
The value of VolumeInfo::is_hotplug from the two storage queries, either of which may have failed. Removable media counts as hot-pluggable: it can be swapped while the system runs, whatever the hot-plug flags say. Either query reporting removable media is enough. None only when neither query answered and so nothing is known.
nt_path_on_network
Whether an NT path, as GetFinalPathNameByHandleW reports it with VOLUME_NAME_NT, is under a network provider. Some(true) for \Device\Mup\…, \Device\LanmanRedirector\… and the other redirector devices; Some(false) for a local disk volume (\Device\HarddiskVolumeN\…); None for any other device or a path that is not under \Device\, which never counts as either.
opened_name_on_network
What the name a file was opened by says about the network, without the OS: Some(true) for a UNC path (also \\?\UNC\… and \\?\GLOBALROOT\Device\Mup\…), Some(false) for a volume GUID or local disk path, and None for a drive letter, which only the OS can map (it may be a mapped network drive), or anything else.
parse_hotplug_info
Parses the STORAGE_HOTPLUG_INFO bytes the OS returned: a u32 size and four one-byte flags. None if shorter.
parse_storage_device_descriptor
Parses the STORAGE_DEVICE_DESCRIPTOR bytes the OS returned. None if they are shorter than the header, or the descriptor’s own Size says it is.
