pub fn path_variables_matched(
    path: &NormalizedPath,
    folders: &KnownFolders,
    volume: Option<&VolumeInfo>,
) -> Result<Vec<PathVariable>, PathError>
Expand description

Every variable that covers path, in PathVariable::ALL order. A path usually matches several (a file under %SYSTEM32% is also under %WINDIR% and %OSDRIVE%). The location variables come from volume, the volume the path is on, when known.

Fails if path may still contain an unexpanded 8.3 short name. A known folder that may contain one is skipped, so it matches nothing.
