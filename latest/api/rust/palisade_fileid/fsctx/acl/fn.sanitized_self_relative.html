pub fn sanitized_self_relative(bytes: &[u8]) -> Result<Vec<u8>, DescriptorError>
Expand description

Rebuilds a self-relative descriptor from the owner, group and DACL of bytes, for handing to an OS API that takes no length.

The result has no SACL (SE_SACL_PRESENT cleared, offset zero), so no unvalidated offset reaches the OS; the owner defaults to NULL SID (which no token holds) and the group to the owner; and the DACL is the original DACL bytes, byte for byte, which SecurityDescriptor::from_self_relative has bounded and checked ACE by ACE. Every part is 4-byte aligned. An absent DACL and a NULL DACL both become a NULL DACL (SE_DACL_PRESENT set, offset zero): both grant everyone everything, and the OS access check accepts only the second. Err if bytes does not parse.
