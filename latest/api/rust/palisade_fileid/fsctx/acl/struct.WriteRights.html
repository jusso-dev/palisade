pub struct WriteRights(/* private fields */);

A set of write-type rights, as an access mask restricted to WriteRights::ALL.

The rights that let a non-administrator change a file’s content (or gain the means to) while NTFS keeps its owner (threat model T-engine-11): write, append, delete, WRITE_DAC and WRITE_OWNER.

pub fn names(self) -> Vec<&'static str>

The winnt.h name of each right that is set, in bit order. Bits 0x2 and 0x4 use their file names (FILE_WRITE_DATA, FILE_APPEND_DATA), which on a directory mean “add file” and “add subdirectory”.
