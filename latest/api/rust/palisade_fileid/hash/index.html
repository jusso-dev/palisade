Module hash 

Source
Expand description

Whole-file (“flat”) hashes, computed in one streaming pass (#46).

MultiHasher feeds every chunk of input to each selected algorithm at once, so a file is read a single time however many digests are needed. hash_reader and hash_file drive it over any Read source with a fixed-size buffer, so memory use does not grow with the file size.

SHA-256 is the primary identity. SHA-1 and MD5 are not collision resistant. They are computed only to match external lists, imported policies and OS events, and must never be the sole basis of an allow decision (ADR 0008). SHA-384 and SHA-512 are optional extras.

The digest of an empty input is a well-known constant that any attacker can produce, so FlatHashes::empty flags it and rules must never trust it.

The rest of #46 lives in submodules:

  • stamp: the FileKey that identifies one version of a file, and the FileStamp trait the OS backend implements to read it;
  • cache: the HashCache (an LRU bounded by entries and bytes, with tiered, versioned values and MAC-protected persisted records), the HashVerifyMode policy setting and hash_through, which ties them together and detects files that change while they are hashed;
  • limit: HashLimiter, the max_parallel_hashes bound;
  • metrics: bytes hashed, cache hit ratio, average latency, and tamper and unstable-file counts, for health reporting (#67);
  • skip_for_inventory: which files an inventory scan must not read, because reading them would recall them from cloud storage.
