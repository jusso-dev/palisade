Expand description

Hashes the file at path (its default data stream).

Anything that is not a regular file (a directory, pipe or device) returns HashError::NotAFile. The opened handle is what is checked and hashed, and it is opened without blocking, so replacing the path with a pipe, even after the path check, cannot stall the call. A file whose metadata length is over the limit returns HashStatus::TooLarge without reading any content. The limit is also enforced while reading, in case the file grows.

The file is opened with File::open. On Windows its default share mode already lets other processes read, write and delete the file while it is hashed. This portable version does not add FILE_FLAG_SEQUENTIAL_SCAN, skip cloud placeholders, or detect concurrent modification. The Windows backend does (palisade_fileid::win::file, with the os-trust feature): open_for_hashing, hash_open_file and WinStamps with cache::hash_through.
