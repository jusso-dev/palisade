palisade_fileid::installer

Module cfb 

Source
Expand description

A bounded reader for compound files (MS-CFB, “structured storage”), the container Windows Installer packages use.

The whole file is in memory. CompoundFile::parse checks the header, loads the FAT, the mini FAT and the directory, walks the directory tree from the root and builds an Entry tree of every reachable stream and storage. Stream data is read on demand by CompoundFile::stream.

§Fail closed

A package’s identity and its signature both rest on what this reader returns, so anything ambiguous is an error, never a guess:

  • a sector chain that loops, runs off the file or the FAT, or is shorter or longer than its stream (every chain of a known length must end in ENDOFCHAIN exactly where its data does), and a DIFAT chain longer than the FAT;
  • a sector (or mini sector) claimed by two chains, or by a chain and the FAT, DIFAT, directory or mini FAT, so no two streams can share bytes and no data is read twice;
  • a directory entry reached twice, a child of the wrong type, two siblings with the same name (names compare case-insensitively, as the format requires), or a name that is empty or has a character the format forbids (/, \, :, !);
  • a header that is not version 3 with 512-byte sectors or version 4 with 4096-byte sectors, a mini sector size other than 64, or a mini stream cutoff other than 4096.

Unreachable directory entries are ignored, as the OS ignores them.

For version 3 files, the upper 32 bits of a stream size are ignored, as the format specification recommends (older writers left them uninitialised).
