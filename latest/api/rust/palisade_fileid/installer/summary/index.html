palisade_fileid::installer

Module summary 

Source
Expand description

The summary information stream (\u{5}SummaryInformation): an OLE property set with one section, FMTID_SummaryInformation.

Layout: a 28-byte header (byte order 0xfffe, format, OS version, CLSID, section count), then one (FMTID, offset) pair per section. A section starts with its size and property count, then one (property ID, offset) pair per property, offsets relative to the section. Each value starts with its type: VT_I2 (2), VT_I4 (3), VT_LPSTR (30, a length including the terminator, then the bytes, in the codepage of property 1) or VT_FILETIME (64).

A property ID that appears twice, a value that runs past the section, or a value whose type is not the one the Windows Installer defines for its ID, makes the whole stream malformed: the summary information is either read exactly or not at all.
