pub fn metadata_digest(root: &Entry, alg: HashAlgorithm) -> Option<Digest>
Expand description

The metadata hash that \u{5}MsiDigitalSignatureEx must hold, under alg: a walk like the content hash, but over each entry’s name (except the root’s), its CLSID (storages) or the low 4 bytes of its size (streams), its state bits and, except for the root, its creation and modification times. Storages are entered where they sort, without the trailing CLSID of the content hash.
