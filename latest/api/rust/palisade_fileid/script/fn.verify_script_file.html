pub fn verify_script_file(
    path: &Path,
    kind: ScriptKind,
    options: &ScriptOptions,
) -> Result<ScriptReport>
Expand description

Reads the script at path as kind, within ScriptOptions::max_size (a larger file is not read), and checks its signature block. Fails with std::io::ErrorKind::InvalidInput for anything but a regular file, without blocking on a FIFO. An encoded script is not read at all.
