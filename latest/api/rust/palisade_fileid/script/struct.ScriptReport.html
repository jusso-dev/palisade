Expand description

A script’s signature, checked.

Fields§

§kind: ScriptKind

The format it was read as.

§size: u64

The file’s size in bytes.

§encoding: Option<TextEncoding>

The text encoding. None when the file was not read.

§text_issue: Option<TextIssue>

Why the text cannot be decoded without ambiguity, if it cannot. The digests are then None (for TextIssue::NonAsciiUtf8, only the package digests).

§signing_state: ScriptSigningState

The signing state.

§block: Option<BlockLocation>

The signature block, when it is well formed.

§signatures: SignatureReport

At most one SignatureKind::Script signature, present when the block decodes; for crate::authenticode::evaluate_trust and crate::authenticode::evaluate_validity. It has no WIN_CERTIFICATE entries, and its image_status is always conformant.

§sip_digests: Option<FlatHashes>

The package’s digests of the text without the block (SHA-256, SHA-1 and the signature’s own algorithm): what the signature, or a catalog, signs. None when the text was not read, does not decode or has no defined package digest (TextIssue::NonAsciiUtf8); when the signature block’s own structure cannot be read (a BlockError before Self::block is set); and for an unsigned .wsf, whose block position the package would choose.

§empty_text: bool

Whether the script’s text outside the block is empty (an empty or BOM-only file, or one holding only a signature block). Its digests are then well-known constants, never a file identity: Self::normalised_hash is None and Self::catalog_digests is empty. A signature over such text is still checked.

§normalised_hash: Option<Digest>

script_hash_normalised: the SHA-256 of the UTF-8 text without the block and its preceding line break, without the byte order mark, and with every CRLF and lone CR turned into LF. A tolerant identity (weak-medium), for explicit opt-in rules only: it stays the same when a script is re-encoded, its line endings change, or it is signed or re-signed. The flat hash stays the default identity. None when the text was not read, does not decode, or is empty (Self::empty_text), and when the signature block’s own structure cannot be read (a BlockError before Self::block is set).

§warnings: Vec<ScriptWarning>

Anything unusual.

pub fn catalog_digests(&self) -> FileDigests

The digests to look a script up in a crate::catalog::CatalogStore with: the package digests, as the non-PE (flat) digests a catalog lists a script under. Matching them against catalogs made by OS tooling is still to be checked (#51), so a miss does not show that no catalog lists the script. Empty for empty text (Self::empty_text), whose digest identifies nothing.
