pub fn evaluate_script_trust(
    report: &ScriptReport,
    anchors: &ScriptTrustAnchors<'_>,
    policy: ScriptAnchorPolicy,
) -> ScriptTrust
Expand description

Builds the chain of report’s signature against the anchor sets policy allows, and decides whether its signer is trusted. Only a ScriptSigningState::Valid script is ever trusted; check ScriptReport::signing_state for why another is not, since its ScriptReport::signatures holds no signature when the block itself could not be read (its state is then crate::authenticode::InvalidReason::ScriptSignatureBlock). Expiry, timestamps and revocation are crate::authenticode::evaluate_validity, with ScriptReport::signatures and ScriptTrust::trust.
