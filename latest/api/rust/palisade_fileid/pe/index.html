Module pe 

Source
Expand description

A hardened PE32 / PE32+ parser (#45).

parse reads headers, sections, data directories, the debug directory, the import and export tables, the resource tree, the version resource and the application manifest from an in-memory image, and classifies kernel drivers. The input is untrusted:

  • No input can make the parser panic. Every read is bounds-checked and all offset arithmetic is checked.
  • Nothing is allocated from a size the file declares. Every collection is bounded by the input length or by a fixed limit (see the MAX_* constants).
  • The parser fails with a PeError only when it cannot read the headers at all. Later problems are recorded as ParseWarnings and the rest of the result is still returned.

Every structure records the file offsets it came from, so later stages (such as the Authenticode image hash, #47) can work on the exact bytes.

At most this many ordinal table entries are scanned to learn which export slots have a name. With more names than this, which slots are unnamed is unknown, so none is listed as unnamed and the result is ExportInfo::truncated.
MAX_PDB_PATH
PDB paths longer than this many bytes are cut off.
MAX_READ_EXTENTS
A single read of a name, descriptor or thunk crosses at most this many mapped extents (runs of file-backed bytes or zero fill), so each read costs at most this many section lookups. Real images need two (into a section’s zero fill, or into the next section). A read that needs more is unreadable, and is reported as such, never taken as complete.
MAX_RESOURCE_DEPTH
Directory levels the general walk allows, counting the root as level 1.
MAX_RESOURCE_ENTRIES
Entries visited at most by the general walk, and by each direct lookup.
MAX_RESOURCE_NAME_UNITS
Resource names are cut to this many UTF-16 code units.
MAX_RESOURCE_TYPES
Distinct resource types recorded at most.
MAX_SECTIONS
At most this many section headers are read. The format allows 65,535, but every later lookup scans the section table, so the count is bounded to keep parsing time linear in practice. Real images have far fewer.
MAX_WARNINGS
At most this many warnings are kept. Further warnings set PeInfo::parse_warnings_truncated.
