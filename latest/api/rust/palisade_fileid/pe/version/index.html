Source
Expand description

The version resource (VS_VERSIONINFO, resource type RT_VERSION).

parse_version_info reads the fixed file info (numeric file and product versions, flags, OS and type) and every StringFileInfo language block. VersionInfo then selects one block, gives typed access to the standard keys, and provides the file-name fallback chain that OS-native policy rules use.

Only the 32-bit (UTF-16) layout is read; the 16-bit layout used by NE images is rejected with VersionIssueKind::BadRootKey.

The resource is untrusted. Its size is at most 64 KiB (wLength is a u16), every block length is checked against its parent, and the number of language blocks and strings kept is capped.
