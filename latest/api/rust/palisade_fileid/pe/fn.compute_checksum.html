Computes the PE image checksum with the standard algorithm.

The file is summed as little-endian 16-bit words with end-around carry, with the 4-byte CheckSum field at checksum_offset read as zeros. An odd final byte is treated as if followed by a zero byte. The 16-bit sum is then added to the file length, wrapping at 32 bits as the OS’s DWORD arithmetic does.

Returns None when the file length does not fit in 32 bits, because the algorithm is undefined there.
