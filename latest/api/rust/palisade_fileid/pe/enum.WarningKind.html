Expand description

The kind of a ParseWarning.

Variants (Non-exhaustive)§

This enum is marked as non-exhaustive
Non-exhaustive enums could have additional variants added in future. Therefore, when matching against variants of non-exhaustive enums, an extra wildcard arm must be added to account for any future variants.
§

SectionTableTruncated

The section table is cut off; only parsed of declared sections were read.

Fields

§declared: u16

NumberOfSections from the COFF header.

§parsed: u16

Section headers actually read.

§

TooManyDataDirectories(u32)

NumberOfRvaAndSizes is above 16. Only 16 directories are read.

§

DataDirectoriesTruncated

SizeOfOptionalHeader has room for fewer data directories than NumberOfRvaAndSizes declares.

Fields

§declared: u32

NumberOfRvaAndSizes (capped at 16).

§parsed: u32

Directories that fit.

§

TooManySections(u16)

More than MAX_SECTIONS sections are declared; only the first MAX_SECTIONS were read.

§

EntropyBudgetExhausted

Section raw data overlaps so much that computing every section’s entropy would scan more bytes than the file holds. Entropy is None from this section on.

Fields

§index: u16

Index of the first section without entropy.

§

SectionDataOutOfFile

A section’s raw data extends past the end of the input. Entropy is computed over the part that is present.

Fields

§index: u16

Index in the section table.

§

DirectoryNotMapped(DataDirectoryKind)

A data directory’s RVA range does not map to raw file data.

§

CertificateTableOutOfFile

The certificate table range lies outside the input.

§

CertificateTableInvalid

The certificate table entry has a zero offset or size, or points into the headers. It is ignored.

§

CertificateTableOverlapsSection

The certificate table range overlaps a section’s file data. The table always lies outside the mapped image, so it is ignored.

§

ChecksumUnavailable

The file is too large (over 4 GiB) for the PE checksum.

§

ResourceOutOfBounds

A resource directory or entry is out of bounds.

§

ResourceLoop

A resource directory refers back to one of its own ancestors. The loop was not followed.

§

ResourceIdInvalid(u32)

A resource entry has a numeric ID with bits 16 to 30 set. The OS compares the full field, so it matches no resource; it was skipped.

§

NoStandardVersionResource

RT_VERSION resources exist, but none is the one the OS loads (VS_VERSION_INFO, ID 1, at the language level), so no version information is reported.

§

ResourceDirectoryNotSorted

A resource directory on a loader lookup path has ID entries that are not strictly ascending (unsorted or duplicated). The OS loader binary-searches them, so which entry it finds is not well defined; the first match was used.

§

ResourceTooDeep

The resource tree is deeper than allowed; deeper levels were skipped.

§

ResourceEntryLimit

More than MAX_RESOURCE_ENTRIES resource entries; the rest were skipped.

§

DebugDirectoryMalformed

A debug directory entry or its data is out of bounds or malformed.

§

TooManyDebugEntries

More than MAX_DEBUG_ENTRIES debug directory entries; the rest were skipped.

§

VersionInfo(VersionInfoIssue)

The version resource could not be parsed, or parsed only in part.

§

ImportTableMalformed

An import descriptor or its data is out of bounds or malformed.

§

ImportTableTruncated

The import descriptor table has no terminating descriptor (one with no name or no import address table) within the mapped data or MAX_IMPORT_DESCRIPTORS.

§

ExportTableMalformed

The export directory’s tables are out of bounds or malformed.

§

Manifest(ManifestError)

The standard manifest could not be parsed.
