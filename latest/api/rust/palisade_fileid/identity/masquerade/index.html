Module masquerade

Expand description

Renamed and masquerading binary detection.

Rules and blocklists match on OriginalFilename, not on the on-disk name, so a renamed protected binary is still caught by them. This assessment adds visibility: it says why a file looks like it is pretending to be something else, so alerting (#7) can surface it. It never allows or blocks anything itself.

Each check adds a fixed weight once, and the score is the sum, capped at 100:

ReasonWeightWhen
known_binary_relocated70 renamed, 40 moved onlyOriginalFilename names a protected binary, its expected signer vouches for the file, and the on-disk name is not one of its names or the path is outside its expected folders
protected_name_claimed70OriginalFilename names a protected binary, but its expected signer does not vouch for the file
signer_impersonation60CompanyName or ProductName names a protected vendor, and that vendor’s signer does not vouch for the file
bidi_control60a path component holds a bidirectional control character (such as the right-to-left override)
double_extension50a decoy document extension before an executable one (invoice.pdf.exe), in the file’s name or a stream’s
alternate_data_stream50the path names an alternate data stream of a file (notes.txt:run.exe)
homoglyph40a path component mixes Latin letters with characters that look like them
extension_mismatch30PE content behind an extension the OS does not load PE files under
trailing_dot_or_space30a path component ends with a dot or a space, which Win32 drops
name_mismatch20the on-disk name differs from OriginalFilename and InternalName

A check whose input was not computed (a tier that was not requested or failed, or a context without known folders) is named in Masquerade::unassessed instead of being read as clean.

assess
Assesses id. trust is the code-signing trust configuration id was computed with, which says whether an expected signer can be recognised. folders are the known folders of the machine the path is on, for the location check; without them it is unassessed.
