Parses a catalog file and verifies its signature.

Fails only when the file is too large, or its SignedData or CTL cannot be decoded. A catalog that decodes but whose signature does not verify is returned, with the reason in Catalog::signatures.

Every element of the SignedData, including the parts no decoder reads (nested signatures), must be DER as far as tags and lengths go, and its INTEGER, BOOLEAN, NULL and OBJECT IDENTIFIER encodings must be valid: an INTEGER non-empty, a BOOLEAN 00 or ff, a NULL empty, an OBJECT IDENTIFIER well formed. (INTEGERs the CTL decoder reads must also be minimal; certificate serial numbers, as elsewhere in the crate, need not be.)
