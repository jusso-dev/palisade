Source

pub fn add_dir(&mut self, source: CatalogSource, root: &Path) -> LoadReport

Loads every *.cat file (any case) under root, descending at most StoreLimits::max_depth levels. Symbolic links (and other reparse points the OS reports as links) are not followed. Entries are read in name order, so the result does not depend on the directory’s order. The walk stops, before listing another directory or reading another catalog, once StoreLimits::max_catalogs, StoreLimits::max_total_bytes or StoreLimits::max_members is spent.

For the OS layout, load catroot (its {GUID} folders) as CatalogSource::System and DriverStore\FileRepository as CatalogSource::DriverStore. An exported catalog folder for offline analysis loads the same way.
