pub fn is_double_extension(name: &OsStr) -> bool
Expand description

Whether name has a disguising double extension (invoice.pdf.exe): an inert extension, or one of a kind that cannot run code, before one that claims executable content. The same rule as ContentFlags::name_double_extension, for a name alone.
