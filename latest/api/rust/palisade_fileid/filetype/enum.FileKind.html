Expand description

What a file is, judged from its content.

Variants (Non-exhaustive)§

This enum is marked as non-exhaustive
Non-exhaustive enums could have additional variants added in future. Therefore, when matching against variants of non-exhaustive enums, an extra wildcard arm must be added to account for any future variants.
§

Pe

A PE32 or PE32+ image. Classification::pe has the sub-kind.

§

Ne16

A 16-bit “new executable” (NE header).

§

Le

A “linear executable” (LE header), as used by 32-bit DOS extenders and old virtual device drivers.

§

Lx

A “linear executable” (LX header).

§

Mz16

A DOS MZ program without a newer header, or an MZ file whose PE headers could not be read.

§

Com

A DOS .com program. The format has no magic, so this is a heuristic (Classification::heuristic is set).

§

Msi

An installer database: a compound file whose root CLSID is {000C1084-0000-0000-C000-000000000046}.

§

Msp

An installer patch: root CLSID {000C1086-0000-0000-C000-000000000046}.

§

Mst

An installer transform: root CLSID {000C1082-0000-0000-C000-000000000046}.

§

Msm

An installer merge module. It has the installer database CLSID, so it is told apart from Msi only by a .msm name.

§

OtherCfb

Any other OLE compound file.

§

Cab

A cabinet archive (MSCF).

§

Zip

A ZIP archive not recognised as anything more specific.

§

Msix

An app package (AppxManifest.xml at the root).

§

Appx

An app package named .appx. The format is the same as Msix; only the name differs.

§

MsixBundle

An app bundle (AppxMetadata/AppxBundleManifest.xml).

§

AppxBundle

An app bundle named .appxbundle.

§

Jar

A Java archive (META-INF/MANIFEST.MF).

§

Chm

A compiled HTML help file (ITSF).

§

Lnk

A shell link (.lnk): header size 0x4C and the shell link CLSID.

§

Hta

An HTML application.

§

Script(ScriptKind)

A script run by an interpreter.

§

Reg

A registry import file.

§

Elf

An ELF object or executable.

§

MachO

A Mach-O object or executable, thin or fat.

§

Iso

An ISO 9660 or UDF disc image.

§

SevenZip

A 7z archive.

§

Rar

A RAR archive (version 4 or 5).

§

Gzip

A gzip stream.

§

Text

Text that is not recognised as a script.

§

Unknown

Nothing recognised.

impl FileKind

Source

pub const fn is_executable_content(self) -> bool

Whether files of this kind can run code, natively or through a host program: every PE sub-kind, NE, LE, LX, DOS MZ and .com programs, installer packages, app packages and bundles, Java archives, compiled help, HTML applications, shell links, every script kind and registry files. ELF and Mach-O executables are included too: they run natively on other systems, and some can run on Windows through a compatibility layer.
