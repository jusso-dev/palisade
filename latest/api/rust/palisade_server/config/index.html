Module config 

Source
Expand description

Server configuration.

The configuration is a TOML file, overridden key by key by PALISADE_* environment variables, then validated into a Config. Validation collects every problem it finds, so one run reports all of them.

The file holds no secret values. Secrets are only ever referenced by path (*_file keys) and read with crate::secret::read_secret_file, so the configuration, its error messages and check-config output never contain secret material.
