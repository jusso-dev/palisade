Structured logging.

serve writes one JSON object per line to standard error, with the timestamp, level, target, message and fields, the current span as span, and every enclosing span as spans, so the request span’s request_id, listener, method, route and peer stay on the line even when a handler opens a child span. Tenant and principal fields join the request span with #185 and #130; changing the level at runtime arrives with the admin API.

No secret value is ever passed to a log macro: the configuration holds secret paths only, and the secret reader’s errors never include file contents. The redaction layer for field names in #227 adds a second line of defence.
