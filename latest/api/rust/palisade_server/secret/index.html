Secret values and reading secret files (#227).

Secrets (the TLS private key and the database passwords) are supplied as paths, never as values in the configuration or the environment. This module reads them into Secret buffers, which are wiped when dropped and never print their contents. Its error messages name the path and the problem, never any part of the contents.
