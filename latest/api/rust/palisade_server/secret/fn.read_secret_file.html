pub fn read_secret_file(
    path: &Path,
    max_len: usize,
) -> Result<Zeroizing<Vec<u8>>, String>
Expand description

Reads a secret file of at most max_len bytes.

The file must be a regular file. On Unix it must not grant any permission to the group or to others (mode 0600 or stricter), so a key that other local users can read is refused rather than used. Windows ACL checks are part of the secrets work in #227.
