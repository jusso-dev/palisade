Variants§

§

UnsupportedSchemaVersion

schema_version is not readable by this crate.

§

CategoryMismatch

category is not the registered category of event_type.

§

MissingFieldSet(FieldSet)

A field set the event type requires is missing.

§

ChainLink

prev_hash is missing although seq is not 0, or present although seq is 0.

§

ScriptPathXorInline

A script has both a path and inline, or neither.

§

NewerThanVersion

The event uses a part of the schema that is newer than its schema_version (Event::min_version).

§

SourceFormat

source.format is missing although source.kind is third_party, or present although it is not.

§

ResolutionWithoutHostname

network.resolution is present without network.remote_hostname.

§

RegistryValueName

A registry value has both a value_name and default_value.

§

TruncatedWithoutPreview

Registry data is marked truncated but has no preview.

§

ChangeValues

An admin change does not have exactly the old and new values its op needs.
