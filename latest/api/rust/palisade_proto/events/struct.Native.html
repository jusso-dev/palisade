Expand description

Details from OS-native enforcement: the OS code integrity and legacy rule-collection engines.

These are the OS’s own identifiers. Linking them to the Palisade policy and rule that produced the native policy fills Event::policy (#90).

§status_code: Option<u32>

The OS status code (an NTSTATUS value).

§requested_signing_level: Option<u8>

The signing level the caller requested (code 0 to 14).

§validated_signing_level: Option<u8>

The signing level the OS validated (code 0 to 14).

§signing_scenario: Option<u32>

The signing scenario: 0 for kernel mode, 1 for user mode.

§policy_name: Option<Name>

The native policy’s name.

§policy_id: Option<Name>

The native policy’s ID string.

§policy_guid: Option<Guid>

The native policy’s GUID.

§policy_hash: Option<HexBytes>

The native policy’s hash.

§policy_options: Option<u32>

The native policy’s option bits, as the OS reports them on activation.

§policy_count: Option<u32>

How many policies an activation or refresh covered.

§clsid: Option<Guid>

The COM class ID, for COM activation events.

§rule_guid: Option<Guid>

The native rule’s GUID.

§rule_name: Option<Name>

The native rule’s name.

§rule_sddl: Option<LongText>

The native rule’s security descriptor (SDDL).

§rule_hash: Option<HexBytes>

The hash the rule-collection engine computed for hash rules. Its algorithm depends on the file type, so it is not one of Hashes.

§fqbn: Option<LongText>

The fully qualified binary name (publisher, product, file name and version), verbatim.

§catalog_sha256: Option<Sha256Hex>

The SHA-256 digest used for catalog lookup.

§catalog_sha1: Option<Sha1Hex>

The SHA-1 digest used for catalog lookup. Interop only.

§policy_audit_mode: Option<bool>

Whether the native policy was in audit mode.

§managed_installer_enabled: Option<bool>

Whether the native policy trusts files from a managed installer.

§passes_managed_installer: Option<bool>

Whether the file carried a managed-installer origin claim.
