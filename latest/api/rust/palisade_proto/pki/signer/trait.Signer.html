Expand description

A holder of private signing keys: a software key store, an HSM or a cloud key service (#224).

The interface takes a Domain and the payload, not a digest or raw message, so a back end always adds the domain-separation prefix itself and refuses a domain that the key’s purpose may not sign (threats: T-signer-02, T-signer-06). It never exposes private keys.

The signer does not track lifecycle state: the caller checks KeyRecord::can_sign against the key inventory first. Recording each signature in the admin audit log (T-signer-03) is #132.

§Errors

SignerError::UnknownKey if the signer does not hold kid, SignerError::WrongPurpose if the key’s purpose may not sign for domain, and SignerError::Failed if the back end fails.
