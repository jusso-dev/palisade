The key inventory: key IDs, purposes, algorithms, lifecycle states and public keys.

A device or relay certificate as the server enrolled it: its serial and the SHA-256 of its public key (threat: T-ca-02).

One key in the inventory: its public half and everything recorded about it. The private half lives in a Signer back end.
Kid
A key ID: the first 16 bytes of the SHA-256 of the key’s DER SubjectPublicKeyInfo, written as 32 lowercase hex digits.
PublicKey
A public key, held as its DER SubjectPublicKeyInfo.
