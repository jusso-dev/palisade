Struct TrustSet 

Source 
pub struct TrustSet { /* private fields */ }
Expand description

A trust-set manifest. The constructors check every rule the decoder checks, so every value has exactly one encoding, except that a set without trust keys is refused by Self::encode and by TrustAnchor::with_current.

pub fn verify( &self, domain: Domain, payload: &[u8], signature: &Signature, now: Timestamp, skew: SkewTolerance, ) -> Result<&TrustedKey, VerifyError>

Verifies a signature for domain against this set: the signing key must be listed for that domain, its algorithm must be accepted, and its validity window must contain now, allowing for skew.

This is the check that policy bundles (#225) and unlock tokens (#222) will use. For trust sets, use TrustAnchor::accept instead, which also trusts the pinned root and enforces the version rules.

§Errors

See VerifyError.

pub fn encode(&self) -> Result<Vec<u8>, TrustSetError>

The canonical payload bytes, the input to signing.

§Errors

TrustSetError::NoTrustKeys if no trust key is listed. The pinned root is outside the set, so a set without trust keys could still be followed by a root-signed one, but an empty list is almost always a mistake, so the format refuses it.
