Expand description

A revocation list (CRL, RFC 5280 section 5) signed by issuer, listing revoked, valid from this_update until next_update. crl_number must grow with each list the issuer publishes.

The root’s list names revoked issuing CAs, and an issuing CA’s list names revoked leaves. The server checks device certificates against its database as well, so a revocation takes effect at once (#223); lists are for relays and other verifiers.

§Errors

IssueError::BadCrlWindow unless next_update is after this_update and both are inside the issuer’s validity, IssueError::BadSerial for a serial that is empty or longer than 20 bytes, IssueError::WrongPurpose if signer does not hold the issuer’s key, and the encoding and signing errors.
