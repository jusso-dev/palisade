Verifies a bundle envelope for this agent (#225 steps 1, 2, 5 and 6; the module documentation has the order). trust is the agent’s current trust set and now trusted time (#220).

Every failure is reported in the result, never as an allow: an unreadable envelope is Examined::Unreadable, and anything else that fails, or was not checked, sets the matching flag of Examined::Parsed to false.
