palisade_proto::policy_bundle

Module record 

Source
Expand description

The anti-rollback record and its copies.

The record holds, for this device’s target (ADR 0007, which is still proposed):

  • the floor: the highest policy_version the agent has made active. It never exceeds the version of the bundle in active;
  • the fallback: the version of the previous bundle that the current active directly replaced, or none. Only that bundle may load under the one-step N-1 exception, and it is always below the floor.

The agent keeps several copies (#225: a DPAPI-protected file and a registry mirror, later a TPM-sealed blob). Each copy is sealed on its own with HMAC-SHA-256 under a device key that the agent holds in protected storage (#220), so a copy cannot be edited without the key. A copy can still be deleted or replaced by an older sealed copy, which is why RecordCopies compares them.

§Encoding

copy     = format:u8 (= 1)
           tenant:[u8;16] scope:u8 (1 group | 2 device) scope_id:[u8;16]
           floor:u64
           has_fallback:u8 (0 | 1) [fallback:u64]   if has_fallback = 1
           tag:[u8;32]
tag      = HMAC-SHA-256(key, "palisade-policy-record-v1\0" ‖ every byte before the tag)

Integers are big-endian, IDs are UUIDv7 bytes. The tag is checked before any field is read, and a copy for another target is refused, so a sealed copy cannot be moved between targets.
