The NTFS upcase table (#332).

NTFS compares two names by upper-casing each UTF-16 code unit through the volume’s upcase table ($UpCase), written when the volume is formatted. upcase_unit is the table that Windows 7 and every later version write, and that the OS itself upper-cases with (RtlUpcaseUnicodeChar; palisade-fileid’s Windows tests check every unit against it). fold upper-cases a name with it.

It is not Unicode’s upper-case mapping. It never maps a character outside ASCII into ASCII (ı, ſ and the Kelvin sign stay as they are, so ſetup.exe and SETUP.EXE are two names), it leaves characters outside the Basic Multilingual Plane alone, and it predates case pairs that later Unicode versions added. A volume formatted by an older Windows holds an older table; telling those apart is palisade-fileid’s job.

Pure and no_std.
