Expand description

File reads.

Not object safe (the open file is an associated type); code that holds a file system is generic over it.

Required Methods§

Source

fn open(&self, path: &str) -> Result<Self::File>

Opens path for reading, sharing read, write and delete with other processes. path:stream opens an alternate data stream.

Source

fn owner_sid(&self, path: &str) -> Result<Option<String>>

The owner SID of path, or None on file systems without owners (FAT, exFAT, network shares that do not report one).

Source

fn security_descriptor(&self, path: &str) -> Result<Option<Vec<u8>>>

The self-relative security descriptor of path (owner and DACL), for the writable-path checks, or None where the file system has none. palisade_fileid::fsctx::acl parses and evaluates it.

Source

fn streams(&self, path: &str) -> Result<Vec<StreamInfo>>

The alternate data streams of path, without the unnamed main stream. Empty on file systems without streams.
