In-memory mocks of the platform traits, and contract checks shared with the real implementations (#29).

Only for tests and the agent’s simulator: the test-util feature is never on in a release build (cargo xtask check-manifests enforces that no normal dependency turns it on).

Each mock is plain data with &self queries, so a test sets it up, hands it to the code under test, and asserts. MockPlatform bundles one of each. Paths, SIDs, registry paths and variable names are compared case-insensitively, as on Windows (with simple Unicode upper-casing, not the file system’s exact case table).

contract holds the checks every implementation must pass, mock or real, so the two cannot drift.
