Expand description

Registry reads, for a registry where the key key in hive holds the value name equal to value, and has at least one subkey:

  • the key exists, in any letter case, and with a trailing \\;
  • name reads as value, in any letter case;
  • a value and a key that do not exist read as None and false, not as errors;
  • the subkeys are listed, and listing a missing key fails with ErrorKind::NotFound;
  • a key path or value name with a NUL character fails with ErrorKind::InvalidInput, so it can never be read as a shorter, different name; so does a key path with a leading \\ or an empty component (a\\\\b).
