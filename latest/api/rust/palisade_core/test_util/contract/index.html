Behaviour every implementation of a platform trait must have.

Each function checks one trait against a fixture the caller has set up, and returns Err with a description of the first broken rule. The mocks run them in this crate’s tests. The agent runs the same functions against its OS implementations (on Windows CI for the Windows ones), so the mocks cannot drift from real behaviour.
