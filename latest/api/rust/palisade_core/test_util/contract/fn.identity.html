Expand description

Identity queries, for a provider where process is running with a readable token, and the local group group has member as a direct member:

  • IdentityProvider::current and IdentityProvider::token of process return tokens whose user and groups are SIDs, without the integrity label among the groups, whose session is SessionKind::Services exactly when its ID is 0, and whose elevation type agrees with elevated (Full is elevated, Limited is not);
  • the token of process under a different creation time (a reused ID) fails with ErrorKind::NotFound;
  • the members of group include member, in any letter case of group;
  • a SID argument that is not a SID fails with ErrorKind::InvalidInput or reads as nothing (None, or ErrorKind::NotFound), never as some other account.

The first rule identity breaks.
