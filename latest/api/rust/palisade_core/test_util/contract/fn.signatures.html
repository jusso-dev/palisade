Expand description

Signature queries, for a verifier where signed has exactly one embedded signature that is valid under its configuration, unsigned has none, and neither is catalog-signed, and missing does not exist:

  • signed has one embedded result, VerificationError::Ok, with a chain whose leaf is first and whose links name their issuer;
  • unsigned has no embedded result;
  • every result is from the source asked for;
  • missing fails with ErrorKind::NotFound on both paths, never “unsigned”;
  • the catalog path either answers or is ErrorKind::Unsupported (no store), and never claims a catalog signature for unsigned.

The first rule verifier breaks.
