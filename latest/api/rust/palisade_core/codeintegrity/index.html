Decoder tables for OS code integrity events (#58).

The OS code integrity log writes signing levels, signature types, policy option bits and status codes as numbers. These tables give each number its meaning, as data, next to the verification-error codes of #50 (VerificationError, which also decodes the per-signature VerificationError field).

A number the tables do not list is reported as unknown (None), never guessed: an OS update can add values, and a reader that mislabelled one would misreport what the OS enforced.
