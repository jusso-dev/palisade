pub fn to_json_value(input: &str, limits: &Limits) -> Result<Value, YamlError>
Expand description

Reads one YAML document into the JSON data model, with the same strict rules as from_str but without checking it against the policy model. The result can be checked with the JSON Schema.

§Errors

Returns YamlError if the input is not exactly one well-formed document within the limits.
