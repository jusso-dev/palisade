Evaluating a whole match tree (#33).

A Match is compiled once, when the policy is loaded, into a CompiledMatch: an arena of nodes with every criterion compiled (CompiledCriterion). Compiling checks the limits that validation checks (crate::model::limits), so a compiled tree is always within them, and evaluation needs no recursion limit of its own.

§Three-valued logic

A tree evaluates to a Tri with Kleene logic:

  • all is NoMatch if any child is NoMatch, else Unknown if any child is Unknown, else Match.
  • any is Match if any child is Match, else Unknown if any child is Unknown, else NoMatch.
  • not swaps Match and NoMatch, and keeps Unknown.

all stops at the first NoMatch and any at the first Match. Both operations are commutative, so the order of children never changes the result, and a later version may reorder them by cost (#42). The notes of an evaluation only come from the criteria that were evaluated, so they can depend on the order.

§Rule level

TreeEvaluation::matches decides whether the rule matches: only Match does. Unknown counts as no match for every action. For an allow rule that fails closed: an unknown fact never allows. For a deny rule it means the rule does not apply, so an unknown fact does not block either; that is the default (no_match) that #32 sets for deny rules.

A deny rule can change both halves (#35). unknown_as: match makes it apply on Unknown as well, which the pipeline in crate::evaluate checks. on_unparseable: match is applied here, by CompiledMatch::eval_with and Unparseable::FavourMatch: a criterion that is Unknown only because its version fact is not a version becomes Match where the tree would match with it, and NoMatch under an odd number of not nodes. So it always counts towards the deny applying, and the rest of the tree is evaluated as usual.

A criterion marked safety_critical in a mandatory blocklist works the same way for any unknown fact (CompiledMatch::eval_mandatory), so the shipped blocklists block an object whose facts are missing rather than let it through (#32, #87).
