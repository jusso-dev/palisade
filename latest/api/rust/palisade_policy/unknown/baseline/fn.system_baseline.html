pub fn system_baseline(

Expand description

The system_baseline rule set for facts, with the order and priority that make it valid under policy’s model: a catch-all order under first_match, and the weakest priority under priority. The evaluator treats it as a floor under every model anyway.

§Errors

Returns BaselineError if the facts do not fit in one rule.
