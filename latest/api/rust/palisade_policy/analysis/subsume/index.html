A conservative proof that one match tree matches whenever another does (#40): covers(a, b) is true only if every object and context for which b is Match also makes a Match. It never claims more, so a rule the policy assistant calls shadowed or ineffective truly never decides. It does not find every such pair: an unproven pair is just not reported.

The proof works on the trees’ shapes. a covers b when:

  • b is an any: a covers each child of b;
  • a is an all: each child of a covers b;
  • a is an any: some child of a covers b;
  • b is an all: some child of b is covered by a;
  • both are criteria, and the criterion a accepts every fact value the criterion b accepts (criterion_covers).

not is only covered by an identical not. The order of these rules matters only for how much is proven, never for soundness.
