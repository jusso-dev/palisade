Module model 

Source
Expand description

The canonical policy object model (#30).

A PolicyDocument is the unit that is stored, exchanged and versioned. It holds one Policy and the RuleSets that the policy references by ID. Every type here maps one-to-one to the JSON Schema in schemas/policy/v1.json (crate::schema).

Deserialising gives a structurally valid document. It is not yet safe to evaluate: PolicyDocument::validate checks limits, references and field types, and returns the ValidatedPolicy that later stages accept.

All structs reject unknown fields (strict mode). Enums are snake_case strings.
