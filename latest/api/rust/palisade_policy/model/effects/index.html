Effect flags: what a decision produces besides its outcome (#34).

Every rule has an Effects block. Each field is optional, and an unset field takes the default of the rule’s action (Effects::resolve), so a rule only states what it changes. The defaults are:

Actionloguploadnotifyseveritysuppress_duplicates_secs
allow, allow_containedsummarybatchednoneinfo86400
allow_elevatedalwaysimmediatenoneinfo600
denyalwaysimmediatedefaultmedium600
auditalwaysimmediatenonelow600
trust_sourcealwaysbatchednoneinfo600
ignore, deferneverlocal_onlynoneinfo0

The de-duplication default follows the effective log: 86400 for summary, 0 for never, and 600 otherwise. Rendering notifications is #11, summarising allowed executions is the agent’s (#4, #16), and alerting on severity is #16.
