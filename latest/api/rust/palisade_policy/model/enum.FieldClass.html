Expand description

The type of a field’s value, which decides the operators it accepts and how values are compared (#32).

Variants§

§

Hash

A hexadecimal digest of a fixed length.

Fields

§hex_len: usize

The number of hex digits.

§

Path

A full path or a directory: normalised before comparison, and the only class with path variables and the recursive ** wildcard.

§

FileName

One path component, such as a file name or an extension.

§

Text

Free text, such as a signer name.

§

Version

A dotted version number.

§

PrincipalName

A principal’s account name (#33): text, without regular expressions (#32).

§

Sid

One security identifier, such as S-1-5-32-544 (#33).

§

PrincipalSet

A set of principals: SIDs, and cloud-directory object IDs (#33).

§

TagSet

A set of tags (#33).

§

Bool

A yes-or-no fact (#33).

§

SessionType

The type of a session (#33).

§

Number

A whole number, such as a build number or a session ID (#32).

§

IntegrityLevel

A token integrity level, ordered from untrusted to protected (#33).

§

DistinguishedName

A directory distinguished name (#33): compared component by component.

§

Ip

One IP address (#32).

§

IpSet

A set of IP addresses (#32).

§

MacSet

A set of MAC addresses (#33).

§

NameSet

A set of DNS suffixes or names (#33).

§

Weekday

A day of the week (#32).

§

TimeOfDay

A time of day (#32).

§

Date

A calendar date (#32).

§

Digest

A hexadecimal digest of 40, 64, 96 or 128 digits: SHA-1 to SHA-512, as a certificate’s signature algorithm chose (#31).

§

OidSet

A set of object identifiers, in dotted form (#31).

§

Guid

A GUID, such as {12345678-9ABC-DEF0-1234-56789ABCDEF0}, compared with or without braces, in either case (#328).

§

Presence

Whether something the criterion’s target names exists: a registry key, a file or a folder (#329). Only exists and not_exists.

§

ProbeValue

A value the criterion’s target names, which may be absent: an environment variable or a registry value (#329). exists, not_exists, the text operators, and eq to between for a number.
