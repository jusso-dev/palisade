Rule lifecycle and governance types (#40): instants and dates, what happens when a rule expires, where a rule came from, and the tenant’s governance settings.

Instants are written as RFC 3339 date-times and dates as RFC 3339 full dates. Both are always UTC inside the engine: an offset is applied when a value is read, and values are written with Z. Fractions of a second are dropped, so an instant is a whole number of seconds since 1970-01-01T00:00:00Z.
