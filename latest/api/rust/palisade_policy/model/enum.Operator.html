Expand description

How a criterion compares the fact with its values (#32). Positive operators match if any value matches; negative operators (not_*) match if no value does, and never match a fact that is unknown.

Variants§

§

Equals

Equal to any value.

§

NotEquals

Equal to none of the values.

§

StartsWith

Starts with any value. On paths, the value must end at a component boundary: C:\Tools does not match C:\ToolsX.

§

EndsWith

Ends with any value.

§

Contains

Contains any value.

§

NotContains

Contains none of the values.

§

Wildcard

Matches any wildcard pattern.

§

NotWildcard

Matches none of the wildcard patterns.

§

Regex

Matches any regular expression. Anchored at both ends, and run by a linear-time engine without look-around or backreferences.

§

NotRegex

Matches none of the regular expressions.

§

VersionEq

Version equal to any value.

VersionGt

§

VersionLt

Version less than the value.

§

VersionLe

Version less than or equal to the value.

§

VersionBetween

Version within [min, max], both inclusive. Takes exactly two values, the minimum first.

§

MemberOf

The set holds any of the values (#33).

§

NotMemberOf

The set holds none of the values (#33).

§

IsTrue

The fact is true. Takes no values (#33).

§

IsFalse

The fact is false. Takes no values (#33). On an unknown fact it is unknown, like every other test.

§

Eq

Number, level or date equal to any value (#32).

§

Ne

Number, level or date equal to none of the values (#32).

§

Gt

Greater than the value (#32).

§

Ge

Greater than or equal to the value (#32).

§

Lt

Less than the value (#32).

§

Le

Less than or equal to the value (#32).

§

Between

Within [min, max], both inclusive. Takes exactly two values, the minimum first (#32).

§

IpInCidr

The address is in any of the CIDR blocks, such as 10.0.0.0/8 or 2001:db8::/32 (#32). On a set of addresses, any address may be.

§

IpBetween

The address is in any of the ranges, written first-last or, for IPv4, a.b.c.first-last (#32).

§

IpWildcard

The IPv4 address matches any whole-octet pattern, such as 10.*.*.* (#32).

§

AnyOf

The set holds at least one of the values (#32). The same test as member_of.

§

AllOf

The set holds every one of the values (#32).

§

WeekdayIn

The day of the week is any of the values, mon to sun (#32).

§

TimeBetween

The time of day is within [start, end), both HH:MM. A window whose end is before its start wraps midnight: 22:00 to 06:00 (#32).

§

DateBetween

The date is within [from, to], both YYYY-MM-DD and inclusive (#32).
