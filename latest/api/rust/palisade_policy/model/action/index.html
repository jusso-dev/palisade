Rule actions and their options (#34).

An Action says what a matching rule asks the engine to do. It is a closed set: every action is an object with a type, and the options of that action as optional keys. The directives that some actions carry (containment, elevation, trust source) are references and settings that the engine passes through unchanged; their meaning belongs to the epics that own them (#9, #12, #14).

The directive types are typed and strict, like the rest of the model, so a misspelt option is an error rather than a silently ignored key. The owning epics add options as optional fields in a minor schema version.

ActionKind::valid_for_object_type and ActionKind::valid_in_rule_set are the static validity matrix that validation applies.
