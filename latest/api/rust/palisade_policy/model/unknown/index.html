The unknown-application policy: what happens when no rule decides (#39).

Stage 6 of the pipeline (crate::evaluate) runs only when stages 1 to 5 decided nothing, so it never overrides an explicit allow or deny. An UnknownPolicy chooses a Level for the object from its type, its location classes and its origins, and crate::unknown turns that level into a decision.

The level is the most restrictive of every entry that applies: the by_type entry for the object’s type, the by_location entry of each location class the object is in, and the by_origin entry of each origin. default applies only when no entry does. The order is block > restrict > prompt > detect > allow (Level’s Ord).
