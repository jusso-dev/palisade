pub fn compile(schedule: &Schedule, default_basis: TimeZoneBasis) -> Self

Compiles a schedule. default_basis is the policy’s settings.time_zone_basis, used when the schedule sets none.

Validation rejects a schedule that is not well formed, but a library schedule (#37) arrives unvalidated. If a window is not well formed (Window::minutes is None), a date range ends before it starts, or a list is over its limit, the schedule is compiled as invalid: it then evaluates as a schedule read without trusted time does, keeping permitting rules inactive and restricting rules active (fact_malformed).

pub fn closes_at(&self, unix_secs: i64, tz: &TimeZone) -> Option<i64>

The instant the schedule next stops being active, after unix_secs, if it is active then and stops within 64 window or date boundaries. The agent re-evaluates on every heartbeat, so a later close is still acted on.
