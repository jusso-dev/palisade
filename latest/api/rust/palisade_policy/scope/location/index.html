Network location profiles and the debounced location the agent reports (#38).

A policy names locations in location_profiles, such as corporate: every test of a profile must match. The agent evaluates the profiles on each network change event and on every heartbeat (by default every HEARTBEAT_SECS seconds) with CompiledProfiles::active, and feeds the result to a LocationTracker. The tracker keeps the previous location until a new one has been observed unchanged for DEBOUNCE_MS, so a network that flaps while it connects does not flip scopes back and forth. Scopes read the tracker’s location as NetworkContext::locations and test it with location_profile.

Evaluating a profile is pure, like everything in this crate: the agent supplies the network facts and the monotonic time.
