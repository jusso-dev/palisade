palisade_policy::scope

Module text 

Source
Expand description

Parsing and matching of the text forms scopes use: address blocks and ranges, hardware addresses, DNS suffixes, wildcards and distinguished names. Validation and compilation share these, so a value that validates always compiles to the same test.

Structs§

IpRange
An inclusive range of addresses of one family.
Wildcard
A wildcard: * matches any run of characters (including none) and ? exactly one. Compared without case (Unicode simple case folding, after NFC), unless built case-sensitive.

Constants§

MAX_DN_BYTES
The longest distinguished name read, in bytes.

Functions§

dn
A distinguished name as its relative names, each trimmed and folded to lowercase, from the object up. None if s is not one.
dns_suffix
The canonical form of a DNS suffix: lowercase ASCII, without a leading or trailing dot. Each label is 1 to 63 letters, digits or hyphens, not starting or ending with a hyphen, and the whole is at most 253 bytes.
dns_within
Whether the fact name is suffix or a name below it. suffix is canonical (dns_suffix).
group_name

in_ou
Whether the object named object is directly in the OU ou, or with sub anywhere below it. Both are parsed with dn.
mac
Parses a hardware address: six pairs of hex digits separated by - or :, in either case.
plain
Checks a free-text scope value: not empty, at most MAX_SCOPE_VALUE_BYTES bytes, no control characters, and not starting or ending with whitespace.
