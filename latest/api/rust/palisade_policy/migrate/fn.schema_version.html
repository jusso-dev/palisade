pub fn schema_version(document: &Value) -> Result<SchemaVersion, MigrateError>
Expand description

The version a document was written for.

That is the document’s schema_version. A v0 document has none, and keeps its version in policy.schema_version instead; that place is only read for a major version of 0.

§Errors

MigrateError::MissingSchemaVersion if neither place holds a version string.
