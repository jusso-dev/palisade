pub fn v0_to_v1(document: Object) -> Result<Object, StepError>
Expand description

v0 to v1.

  • policy.schema_version is removed, and the document’s schema_version is set to 1.0.0.
  • Each rule’s flags is renamed effects. A rule with both is refused, because which one the author meant is unknown.

Anything else is left as it is.

§Errors

Returns StepError if a rule has both flags and effects.
