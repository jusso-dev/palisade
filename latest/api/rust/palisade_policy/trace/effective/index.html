The effective-policy view of one device (#41): what it enforces.

effective_view flattens the policy for a device in a given state: every rule with where it comes from and whether it takes part, the settings with their sources, the effective mode per object type, the active override session and lockdown, and the protection status (#36). Each rule’s provenance is its policy and rule set. effective_view_with_groups puts first the hierarchy nodes it came from, when the policy is a device’s effective policy from the group hierarchy (#37, crate::hierarchy::EffectivePolicy): which global, tenant, group, dynamic-group, template or device layer contributed its rule set, how, and which node suppressed it, if one did (super::groups). The view is for administrators, so it writes names unredacted (Privacy::DEFAULT); pass a Privacy to effective_view_with_groups to redact them as a trace would.
