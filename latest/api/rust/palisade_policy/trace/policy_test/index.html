Policy-as-code tests (#41): given facts, expect a decision.

A test file sits next to a policy and holds its tests:

policy_tests_version: "1.0.0"
tests:
  - name: the signed tool runs
    given:
      object_type: executable
      facts:
        signers: [{status: valid, publisher: Example Ltd}]
    expect:
      outcome: allowed
      rule: R-000123

given is a facts snapshot (super::simulate::FactsSnapshot) without the event fields. expect checks any of outcome, would_have_been, reason_code, mode and the deciding rule (by short ID or rule ID; no_rule: true expects the implicit deny). Each test is decided by the simulator, so by the agent’s evaluator.

run gives a TestReport: TestReport::exit_code is non-zero when a test fails, and TestReport::junit writes JUnit XML for CI. The pal policy test command (#15) reads the files and prints these.
