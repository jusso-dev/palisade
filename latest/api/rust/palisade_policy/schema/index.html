The versioned JSON Schema (2020-12) of PolicyDocument.

The schema is generated from the Rust types, so it cannot drift from them. The generated text is committed at schemas/policy/v{major}.json, and the test committed_schema_is_current fails when the committed file differs from what generate produces. Regenerate it with:

PALISADE_BLESS=1 cargo test -p palisade-policy --test schema

§Versioning

CURRENT is the version this crate writes and the major version it reads. A minor bump adds optional fields; a major bump is a breaking change, gets a new file (v2.json) and a migration step (crate::migrate). The schema’s $id names the major version only, because every minor version of a major is a valid instance of the latest schema for that major.
