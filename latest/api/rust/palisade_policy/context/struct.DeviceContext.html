The device the decision is made on.

Fields§

§hostname: Option<String>

The host name.

§fqdn: Option<String>

The fully qualified domain name.

§domain: Option<String>

The DNS name of the domain.

§netbios: Option<String>

The NetBIOS name.

§ad_site: Option<String>

The directory site.

§groups: Option<Vec<String>>

The computer groups, as SIDs, and cloud-directory device groups, as object IDs.

§tags: Option<Vec<String>>

The Palisade tags assigned to the device.

§os_version: Option<String>

The operating system version, such as 10.0.22631.4460.

§os_edition: Option<String>

The operating system edition.

§arch: Option<String>

The processor architecture, such as x64 or arm64.

§is_server: Option<bool>

The device runs a server edition.

§is_domain_controller: Option<bool>

The device is a domain controller.

§is_laptop: Option<bool>

The device is a laptop.

§is_vdi: Option<bool>

The device is a virtual desktop.

§is_terminal_server: Option<bool>

The device is a multi-session terminal server.

§os_build: Option<u32>

The operating system build number, such as 22631.

§dn: Option<String>

The distinguished name of the device’s computer object in the directory, such as CN=WS-0042,OU=Finance,DC=corp,DC=example,DC=org. device.ou tests the unit it is in.

§boot_phase: Option<BootPhase>

How far the device has booted (#39). Drivers loaded in BootPhase::Early follow the unknown policy’s driver_boot_policy.

§containment_available: Option<bool>

Whether the application containment component (#14) is installed and running. The unknown policy’s restrict level blocks instead unless this is Some(true) (#39).
