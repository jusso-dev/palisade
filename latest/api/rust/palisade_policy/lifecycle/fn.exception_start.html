pub const fn exception_start(m: &Metadata) -> Option<Timestamp>
Expand description

When an exception’s year starts: its approval, approved_at. Neither created_at nor last_reviewed_at counts, so a creation date written in the future or an attestation cannot stretch it. Only a renewal in a review (ReviewAction::Renew) re-approves an exception and so moves its start.
