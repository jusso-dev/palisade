pub fn inactive_matches(
    validated: &ValidatedPolicy,
    subject: &Subject<'_>,
    clock: &RuleClock,
) -> Vec<(RuleRef, Activity)>
Expand description

The rules that would have matched subject but are inactive at clock, with why, sorted by rule ID: what the decision trace (#41) reports as “would have matched disabled rule R” or “expired rule R”. Not for the hot path: it compiles each inactive rule’s tree.
