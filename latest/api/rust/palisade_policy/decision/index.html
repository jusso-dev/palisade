Module decision 

Source
Expand description

The typed output of an evaluation (#34).

Every consumer gets the same Decision: the agent acts on it, the decision trace explains it (#41), and events embed it (#16). Its JSON form is stable: fields are always present, in declaration order, with null for an absent value, and the snapshot tests in tests/snapshots/decision/ fail on any change to it.

This module builds the decision of one terminal rule (Decision::from_rule) and the implicit deny for an object no rule decides (Decision::implicit_deny), both as enforce mode sees them. The pipeline in crate::evaluate combines the matching rules (#35): it adds the audit annotations, the rules the deciding rule overrode, and the trust-source grants. It then applies the effective mode (#36, crate::mode), which can change Decision::outcome and keeps the enforce-mode result in Decision::would_have_been.
