Expand description

The directives a decision carries for the components that act on it. The engine passes them through; their meaning belongs to the owning epics. These are separate from the model’s directive types, which leave defaults out when written, so that a decision’s JSON always has every field.

Fields§

§containment: Option<Containment>

Run inside this containment profile (#14).

§elevation: Option<Elevation>

Run with this elevation (#12).

§trust_sources: Vec<TrustGrant>

Treat the process as a trusted source (#9): the grant of every matching trust_source rule, by rule ID. Only an allowed object gets grants (#35).

§kill_running: bool

Terminate running instances that match.

§request: Option<RequestDirective>

The user may ask for approval.

§window_close: Option<WindowClose>

What to do with the running process when the deciding allow’s schedule closes (#38). Only an allowed object gets one.

§prompt: Option<PromptDirective>

The prompt to show, for a pending_user decision (#39).
