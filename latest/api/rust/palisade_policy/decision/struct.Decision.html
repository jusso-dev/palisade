Struct Decision 

Source 
pub struct Decision { /* private fields */ }
Expand description

The typed result of evaluating one object.

The fields are read through accessors, so a decision is always one of the forms its constructors build. Serialising it gives the stable JSON form described in the module documentation.

pub fn from_rule( policy: &Policy, set: &RuleSet, rule: &Rule, trace_id: TraceId, ) -> Option<Self>

The decision of rule, held by set, which policy references, as enforce mode sees it. The caller has already found that the rule matches and wins (#35).

Returns None for a disabled rule, which never decides, and for an action that does not decide by itself (audit, defer, trust_source; see ActionKind::is_terminal).

Source

pub fn implicit_deny(trace_id: TraceId) -> Self

The implicit deny for an object that no rule decides, as enforce mode sees it (#39). It has the effects of a deny with default effect flags.

Whether the object is a learning candidate (#36, #5): the effective mode is learning, and only the implicit deny would have blocked it. An object that a deny rule would block is never learned (#69).
