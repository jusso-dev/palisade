Semantic validation of a policy document (#30).

PolicyDocument::validate collects every problem in one pass. Each ValidationError has a stable ErrorCode, a Severity, the JSON Pointer of the field (RFC 6901), and a message. A document with no error-severity findings becomes a ValidatedPolicy, which is the only form later stages (compiler, evaluator) accept.
