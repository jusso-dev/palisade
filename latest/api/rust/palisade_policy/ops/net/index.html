IP addresses, address ranges, octet wildcards and MAC addresses (#32).

These are the values of the network operators (ip_in_cidr, ip_between, ip_wildcard) and of net.mac. They are public so that scopes (#38) parse and compare addresses exactly as criteria do.

An IPv4 address written in IPv6 form (::ffff:192.0.2.1) is the IPv4 address: canonical maps it, on both sides, so a rule written for one form matches a fact in the other. A CIDR block is checked in the form it is written in, so ::ffff:10.0.0.0/104 is 10.0.0.0/8 and ::ffff:10.0.0.0/8 is rejected for its host bits. An IPv6 block wider than ::ffff:0:0/96, such as ::/0, or an explicit IPv6 range (ip_between) that spans part of ::ffff:0:0/96, holds the IPv4 addresses it covers in mapped form: every IPv6 range tests an IPv4 address by its mapped form. Otherwise IPv4 and IPv6 never match each other.
