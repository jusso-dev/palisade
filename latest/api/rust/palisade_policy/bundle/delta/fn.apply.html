Function apply 

Source 
pub fn apply(
    old_bytes: &[u8],
    delta: &BundleDelta,
    limits: &BundleLimits,
) -> Result<(PolicyBundle, Vec<u8>), DeltaError>
Expand description

Applies delta to the bundle whose canonical bytes are old_bytes, as the agent holds them, giving the new bundle and its canonical bytes.

The base is checked by hashing old_bytes, the bytes that were verified, not by encoding a decoded bundle again. The result takes the delta header’s schema version, so a delta can cross a schema change.

§Errors

DeltaError::WrongBase unless old_bytes hash to the delta’s base, DeltaError::Decode if they are not a bundle within limits, DeltaError::ResultMismatch unless the result hashes to its result, and the errors of operations that do not fit the base.
