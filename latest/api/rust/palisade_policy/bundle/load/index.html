palisade_policy::bundle

Module load 

Source
Expand description

Loading a bundle in one step (#43, #42).

load turns bundle bytes into a LoadedPolicy: it decodes them strictly (PolicyBundle::decode), validates the body as a policy (PolicyBundle::validate), adds the agent’s own system_baseline if it has one, and builds the evaluation indexes with the bundle’s inlined library sets (BundleSets), so scopes and location profiles read exactly the sets the server compiled in. Any failure leaves nothing half-built: the caller keeps its current policy.

The bytes must already be verified (#225). load does not check a signature, the target or min_agent_version; it reads what it is given, safely, and refuses anything that is not a valid bundle.
