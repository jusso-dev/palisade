Module cbor 

Source
Expand description

Canonical CBOR for policy bundles (#43).

This is the subset of CBOR (RFC 8949) that bundles use, in the core deterministic encoding of RFC 8949 §4.2:

  • integers, lengths and counts in their shortest form;
  • definite lengths only;
  • map keys sorted bytewise by their encoded form, with no duplicates;
  • no floating point, no tags, and no simple values other than false, true and null;
  • text strings are valid UTF-8 in Unicode Normalization Form C.

The encoder can only write canonical bytes: a Map keeps its entries sorted and unique, and encode refuses text that is not NFC and nesting the decoder would refuse. The decoder (decode) is strict: it rejects every input that is not exactly what encode writes for the value it reads, so encode(decode(b)) == b for every b it accepts. It is safe on untrusted input: it never panics, checks every declared length against the bytes that remain before it allocates, and bounds the input size, the nesting depth and the number of items (Limits).
