Module serial 

Source
Expand description

The policy model through serde, as canonical CBOR values (#43).

to_value writes any Serialize model type as a Value, and from_value reads it back with the type’s own Deserialize, so the bundle reuses the model’s strict readers (unknown fields, duplicate keys, null handling) rather than a second copy of them.

The mapping:

  • a struct is a map whose keys are the registry IDs of its field names. A field name that is not registered cannot be written (Error::UnregisteredKey), so a field added to the model without a key fails loudly instead of being dropped;
  • a unit variant is its registered ID; a newtype, tuple or struct variant is a one-entry map from its ID to its content. Internally tagged enums (an action’s type) keep their tag as text, as serde writes it;
  • strings are written in Unicode Normalization Form C. Matching already compares text after NFC (crate::ops), so this changes no decision;
  • floating point is refused (Error::Float); the model has none;
  • governance metadata is refused by type (Error::ServerOnly), as well as having no keys;
  • maps of data (such as mode_by_type) keep their own keys.

When reading a struct, a key whose ID is not registered is skipped if it is ignorable (negative) and refused if it is critical (Error::UnknownCriticalKey).
