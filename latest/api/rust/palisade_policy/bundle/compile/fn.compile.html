Expand description

Compiles source into a bundle with header.

Every library set a scope or a location profile reads is inlined, at the version its reference resolves to, and each reference is rewritten to pin that version: a bundle never says latest, so it means the same on every agent whatever else it holds.

The bundle is then read back as an agent reads it: decoded within limits (the agents’ size and item limits) and validated. A bundle an agent would refuse fails here instead, so the server keeps its last good bundle. This also catches a policy that writing text in NFC makes invalid (two tags that differ only in normal form, or a name that grows past its limit in NFC).

Before anything is built, the policy assistant’s static analysis (#40) runs on the policy, as of the header’s generated_at. An error finding stops compilation (CompileError::Blocked) unless source.admin overrides it with a reason; the override and the findings it covers are returned in Compiled::gate for the caller to record.

The same inputs always give the same bytes, on every platform: the body is canonical (Body::new) and the encoding deterministic.

§Errors

CompileError if the analysis has error findings that are not overridden, a set does not resolve, the header and the policy disagree on the schema version, the bundle is over limits, or the bundle an agent would read is not valid.
