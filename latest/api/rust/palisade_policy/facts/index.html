Observed facts about one object, as criteria see them (#31).

The agent and the file-identity parser (#3, #4) compute facts. This module only defines their shape, so evaluation stays pure: nothing here reads a file or calls the OS. A fact that was not computed is absent, and every criterion on an absent fact evaluates to Tri::Unknown, never to a match.
