Enum Decided 

Source 
pub enum Decided {
    Fresh(Decision),
    Cached(Arc<Decision>),
}
Expand description

A decision, made now or shared from the cache.

Variants§

§

Fresh(Decision)

Made by this evaluation.

§

Cached(Arc<Decision>)

From the cache. It is the decision of the evaluation that cached it, including that evaluation’s trace ID, so an event about this launch can link back to the full trace (#41).

The outcome in enforce mode. Equal to outcome in enforce mode; in the others, the simulated result that readiness reports use (#41, #5). Always set.

The action that decided. deny for the implicit deny.

The rule that decided, or None when no rule did: stage 6 (the unknown-application policy) or a pinned Palisade image.

Source

pub fn overridden(&self) -> &[RuleRef]

The rules that matched and would have decided or attached a grant, but lost to matched_rule, by rule ID (#35). Empty when one rule matched alone.

Source

pub fn annotations(&self) -> &[RuleRef]

The audit rules that also matched, by rule ID.

Source

pub fn mode(&self) -> Mode

The effective mode the decision was made in (#36).

Source

pub fn learning_candidate(&self) -> bool

Whether the object is a learning candidate (#36, #5): the effective mode is learning, and no rule decided it, so the unknown-application policy did (stage 6, #39), whatever its level. An object that a deny rule would block is never learned (#69).

pub fn scope_notes(&self) -> &[ScopeNote]

What the scope evaluations noticed (#38), such as scope_stale or clock_untrusted: the notes of every rule whose tree was not NoMatch, including one its scopes took out, sorted.

Source

pub fn unknown(&self) -> Option<&UnknownHandling>

How the unknown-application policy handled the object, when no rule decided it (stage 6, #39). None when a rule decided.
