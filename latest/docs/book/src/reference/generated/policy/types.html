Value types

Enumerations, identifiers and string formats used by the Palisade policy document.

AdvancedValue

A scalar value in advanced.

Type: boolean or integer or string.

AllowTiebreak

Which allow decides among allows of different kinds.

ValueMeaning
most_restrictiveallow_contained, then allow, then allow_elevated (with condition: always before if_required). The default.
most_permissiveThe reverse: allow_elevated (if_required before always), then allow, then allow_contained.

ApprovalScope

Who a device-local approval applies to.

ValueMeaning
userOnly the user who approved it. The default.
deviceEvery user of the device.

Combine

How a scope's dimensions combine.

ValueMeaning
allEvery dimension that is set must match. The default.
anyAt least one dimension that is set must match.

CompliancePreset

A compliance preset: a named starting configuration. Changes that make the policy weaker than its preset raise a compliance warning (#17). Ordered from the least to the most demanding.

ValueMeaning
e8_ml1Essential Eight maturity level 1: block in user profiles, temporary folders and other user-writable locations, detect elsewhere (ISM-1870).
e8_ml2Essential Eight maturity level 2: block in every location (ISM-1871).
e8_ml3Essential Eight maturity level 3: level 2, drivers blocked, and a mandatory blocklist required (ISM-1658). Drivers loaded during early boot are only audited unless driver_boot_policy is enforce; validation warns about that exemption.

ContainmentProfileRef

The ID of a containment profile (#14, #173).

Type: Uuid7.

ControlLevel

Whether a class of object is controlled.

ValueMeaning
offNot evaluated.
auditEvaluated, and would-block decisions are reported only.
enforceEvaluated and enforced.

Date

A calendar date, YYYY-MM-DD.

Type: string; matches ^[0-9]{4}-[0-9]{2}-[0-9]{2}$.

DigestAlgorithm

A digest algorithm a signature uses (#31, ADR 0008).

ValueMeaning
md2MD2.
md5MD5.
sha1SHA-1.
sha256SHA-256.
sha384SHA-384.
sha512SHA-512.

DriverBootPolicy

How unknown drivers are handled while the device boots, before the agent has fully started (boot_phase: early).

ValueMeaning
auditReport what would be blocked, and block nothing. The default, until the tenant enables enforcement explicitly.
enforceApply the unknown-handling level.

ElevationAuth

The confirmation an allow_elevated action asks for.

ValueMeaning
noneNo confirmation. The default.
reauthThe user authenticates again.
mfaThe user completes a multi-factor challenge.

ElevationCondition

When an allow_elevated action elevates.

ValueMeaning
alwaysEvery time the object runs.
if_requiredOnly when the object asks for administrator rights.

EnforcementOverride

How one rule relates to the policy mode (#36).

ValueMeaning
inheritFollow the effective mode. The default.
always_enforceEnforce this rule even in audit or learning mode.
never_enforceNever enforce this rule: it only reports what it would block.

ValueMeaning
infoInformational.
lowLow.
mediumMedium.
highHigh.
criticalCritical.

Field

The identity facts a criterion can test (#31).

This is the part of the #31 catalogue that has a matcher: hashes, the signer and its certificates, the path and the version resource. The other families (packaged apps, installers, ownership, origin and process relationships) arrive in later minor versions, each with its facts and matcher.

ValueMeaning
hash.sha256SHA-256 of the whole file. The primary identity (ADR 0008).
hash.sha384SHA-384 of the whole file.
hash.sha512SHA-512 of the whole file.
hash.authenticode_sha256SHA-256 Authenticode image hash: the PE image without its checksum, security directory entry and certificate table.
hash.authenticode_sha1SHA-1 Authenticode image hash. Compatibility only (ADR 0008).
hash.page_sha256SHA-256 hash of the first page of the image, for OS-native policy formats. It covers only that page, so it is a weak identity alone.
hash.page_sha1SHA-1 hash of the first page of the image. Compatibility only (ADR 0008).
hash.msi_fuzzy_sha256SHA-256 of an installer package with its timestamps left out, so rebuilds of the same content share one value (#3).
hash.sha1SHA-1 of the whole file. Compatibility only (ADR 0008).
hash.md5MD5 of the whole file. Compatibility only (ADR 0008).
signer.publisherThe leaf signer's subject common name.
signer.issuerThe common name of the leaf certificate's issuer.
signer.leaf_thumbprintThe SHA-256 thumbprint of the leaf certificate.
path.fullThe normalised full path.
path.directoryThe parent directory.
path.file_nameThe on-disk file name.
path.extensionThe file extension, without its leading dot.
meta.original_filenameThe original file name from the version resource.
meta.internal_nameThe internal name from the version resource.
meta.file_descriptionThe file description from the version resource.
meta.product_nameThe product name from the version resource.
meta.company_nameThe company name from the version resource.
meta.file_versionThe file version from the version resource.
meta.product_versionThe product version from the version resource.
user.sidContext (#33): the SID of the user the process runs as.
user.nameContext (#33): the user's account name, as DOMAIN\user or as a user principal name (user@example.org). Either form can match. Regular expressions are not allowed: match principals by SID where you can (#32).
user.groupsContext (#33): the groups in the user's token, as SIDs, and the user's cloud-directory groups, as object IDs.
user.primary_groupContext (#33): the SID of the user's primary group.
user.is_adminContext (#33): the token holds the local Administrators group, enabled or filtered by UAC.
user.is_elevatedContext (#33): the token is elevated.
user.is_service_accountContext (#33): the user is a service account.
user.is_systemContext (#33): the user is the local system account.
device.hostnameContext (#33): the device's host name.
device.fqdnContext (#33): the device's fully qualified domain name.
device.domainContext (#33): the DNS name of the device's domain.
device.netbiosContext (#33): the device's NetBIOS name.
device.ad_siteContext (#33): the directory site the device is in.
device.groupsContext (#33): the device's computer groups, as SIDs, and its cloud-directory device groups, as object IDs.
device.tagsContext (#33): the Palisade tags assigned to the device.
device.os_versionContext (#33): the operating system version.
device.os_editionContext (#33): the operating system edition.
device.archContext (#33): the processor architecture, such as x64 or arm64.
device.is_serverContext (#33): the device runs a server edition.
device.is_domain_controllerContext (#33): the device is a domain controller.
device.is_laptopContext (#33): the device is a laptop.
device.is_vdiContext (#33): the device is a virtual desktop.
device.is_terminal_serverContext (#33): the device is a multi-session terminal server.
session.typeContext (#33): how the session was started: console, rdp, remote_shell, service, batch or network.
session.client_hostnameContext (#33): the host name of the client connected to the session, on a multi-session host.
session.is_remoteContext (#33): the session is remote.
user.integrity_levelContext (#33): the integrity level of the process token: untrusted, low, medium, medium_plus, high, system or protected. Ordered, so ge and le compare levels.
user.ouContext (#33): the organisational unit of the user's directory object, as a distinguished name such as OU=Finance,DC=corp,DC=example. With include_sub_ous, units below it match too.
device.ouContext (#33): the organisational unit of the device's directory object, as for user.ou.
device.os_buildContext (#33): the operating system build number, such as 22631.
session.idContext (#33): the session ID.
session.client_ipContext (#33): the IP address of the client connected to the session, on a multi-session host.
net.ipContext (#33): every local interface address. A network test (ip_in_cidr, ip_between, ip_wildcard) matches if any address does; a set test holds the addresses as a set, so all_of needs every listed address to be present.
net.macContext (#33): every local interface MAC address.
net.dns_suffixContext (#33): every connection-specific DNS suffix.
net.connected_to_serverContext (#33): the device can reach its server now.
net.locationContext (#33, #38): the names of the network locations the device is in, such as corporate, remote or offline.
time.weekdayContext (#33): the day of the week of the evaluation, as mon to sun, in the clock the policy's time_zone_basis names.
time.local_timeContext (#33): the time of day of the evaluation, as HH:MM, in the policy's clock.
time.dateContext (#33): the date of the evaluation, as YYYY-MM-DD, in the policy's clock.
signer.leaf_thumbprint_sha1The SHA-1 thumbprint of the leaf certificate. Compatibility only (ADR 0008).
signer.pcaThe subject common name of the highest certificate below the root, as the signature provides it: the PCA.
signer.root_thumbprintThe SHA-256 thumbprint of the chain's root certificate.
signer.root_thumbprint_sha1The SHA-1 thumbprint of the chain's root certificate. Compatibility only (ADR 0008).
signer.tbs_hashThe hash of a chain certificate's tbsCertificate, under the certificate's own signature digest (40, 64, 96 or 128 hex digits). It identifies that one certificate: the tbsCertificate includes the serial number and the validity period (RFC 5280), so a certificate reissued with the same key has another TBS hash, and each issue needs its own rule. No criterion yet names a key across the certificates that carry it. signer.position says which certificate. A 40-digit (SHA-1) value is compatibility only (ADR 0008).
signer.ekuThe extended key usages of the leaf certificate, as dotted OIDs, such as 1.3.6.1.5.5.7.3.3 (code signing). A leaf without the extension has none.

FindingSeverity

How serious a policy-assistant finding is (#40).

ValueMeaning
infoInformational.
warningProbably a mistake or a risk.
errorBlocks publishing unless a tenant administrator overrides it.

Level

How an unknown object is handled. The variants are declared from least to most restrictive, so Ord is the restrictiveness order.

ValueMeaning
allowAllowed silently. Validation warns, and Essential Eight presets do not permit it for user profiles or temporary folders.
detectAllowed, but logged with severity medium and flagged unhandled.
promptThe user is asked (#11). Not for libraries, drivers, objects that a blocklist matched, or sessions with no interactive user; those get the prompt's fallback.
restrictAllowed inside the restrict_profile containment profile (#14). Only for executables, scripts and installers. It fails closed to block when the containment component is not installed.
blockBlocked. The default.

LibraryId

A UUID version 7 in canonical lowercase form.

Type: string; matches ^[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$.

LogLevel

Whether a decision produces a local event.

ValueMeaning
alwaysEvery decision produces an event.
summaryDecisions are aggregated into periodic summaries per device, user, object and rule. The default for allow rules.
sampledA sample of decisions produces events.
neverNo event.

Mode

How a policy's decisions take effect (#36).

The variants are declared from weakest to strongest, so the derived ordering ranks them. The "strictest" merge in #36 treats learning and audit as equally strong; that rule belongs to the merge code, not to this ordering.

ValueMeaning
disabledThe engine is not consulted. The device is reported as unprotected.
monitorEvaluate fully, allow everything, and report would-block decisions.
auditLike monitor, with a full event for every decision.
learningAudit, and report every would-block object as a learning candidate.
enforceDecisions take effect: blocked means blocked.

Notify

Whether the user is shown a notification (#11).

ValueMeaning
noneNo notification.
defaultThe policy's default notification.
customThe rule's notification_text.

ObjectType

The class of object being evaluated. Scripts are script.<kind>.

Values: executable, library, driver, script.powershell, script.batch, script.cmd, script.vbscript, script.jscript, script.wsf, script.wsc, script.python, script.java, script.reg, script.other, installer, compiled_html, html_application, control_panel_applet, packaged_app, command, com_object.

OnWindowClose

What happens to processes a scheduled allow let run, when its schedule closes. The engine sends a directive; the agent and the tray act on it (#4, #11).

ValueMeaning
noneNothing: they keep running. The default.
warnWarn the user.
warn_then_terminateWarn the user, then terminate them after the grace period.

Operator

How a criterion compares the fact with its values (#32). Positive operators match if any value matches; negative operators (not_*) match if no value does, and never match a fact that is unknown.

ValueMeaning
equalsEqual to any value.
not_equalsEqual to none of the values.
starts_withStarts with any value. On paths, the value must end at a component boundary: C:\Tools does not match C:\ToolsX.
ends_withEnds with any value.
containsContains any value.
not_containsContains none of the values.
wildcardMatches any wildcard pattern.
not_wildcardMatches none of the wildcard patterns.
regexMatches any regular expression. Anchored at both ends, and run by a linear-time engine without look-around or backreferences.
not_regexMatches none of the regular expressions.
version_eqVersion equal to any value.
version_gtVersion greater than the value.
version_geVersion greater than or equal to the value.
version_ltVersion less than the value.
version_leVersion less than or equal to the value.
version_betweenVersion within [min, max], both inclusive. Takes exactly two values, the minimum first.
member_ofThe set holds any of the values (#33).
not_member_ofThe set holds none of the values (#33).
is_trueThe fact is true. Takes no values (#33).
is_falseThe fact is false. Takes no values (#33). On an unknown fact it is unknown, like every other test.
eqNumber, level or date equal to any value (#32).
neNumber, level or date equal to none of the values (#32).
gtGreater than the value (#32).
geGreater than or equal to the value (#32).
ltLess than the value (#32).
leLess than or equal to the value (#32).
betweenWithin [min, max], both inclusive. Takes exactly two values, the minimum first (#32).
ip_in_cidrThe address is in any of the CIDR blocks, such as 10.0.0.0/8 or 2001:db8::/32 (#32). On a set of addresses, any address may be.
ip_betweenThe address is in any of the ranges, written first-last or, for IPv4, a.b.c.first-last (#32).
ip_wildcardThe IPv4 address matches any whole-octet pattern, such as 10.*.*.* (#32).
any_ofThe set holds at least one of the values (#32). The same test as member_of.
all_ofThe set holds every one of the values (#32).
weekday_inThe day of the week is any of the values, mon to sun (#32).
time_betweenThe time of day is within [start, end), both HH:MM. A window whose end is before its start wraps midnight: 22:00 to 06:00 (#32).
date_betweenThe date is within [from, to], both YYYY-MM-DD and inclusive (#32).

PrecedenceModel

How the matching rules of the ordinary rule sets are combined (#35).

The mandatory-deny tier and the implicit deny for unmatched files apply under every model (ADR 0004). The semantics of each model are in crate::precedence.

ValueMeaning
deny_winsAny matching deny blocks; otherwise any matching allow allows. The default.
allow_winsAny matching allow allows. Not recommended for Essential Eight.
specificityThe rule with the most specific identity wins.
first_matchRules are ordered, and the first match decides.
priorityThe rule with the winning numeric priority decides.

PreexistingPolicy

What happens to files that were on the device when the agent was installed (origin preexisting).

ValueMeaning
treat_as_unknownThey are unknown like any other object.
local_approveThe agent approves each one locally at install (#69). The engine then sees the approvals as rules, and treats a file without one as unknown.
baseline_onlyThey run only if the approved baseline (#5) allows them: at stage 6 they are blocked, whatever the levels say. The default.

PriorityDirection

ValueMeaning

request_approvalDo not run it, and ask an administrator to approve it (#11).
