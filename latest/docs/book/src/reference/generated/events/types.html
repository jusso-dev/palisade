Palisade

Value types

Enumerations, identifiers and string formats used by the Palisade canonical event.

AdminChannel

The channel an administrative action came through.

ValueMeaning
consoleThe console.
apiThe REST API.
cliThe command-line tool.
scimDirectory provisioning.
webhook_callbackA webhook callback.
email_linkAn e-mail link.
chatA team-chat action.
itsmAn ITSM integration.
jobA scheduled job.
agentAn agent's own report.

ApprovalChannel

The channel an approval was requested or decided through.

ValueMeaning
consoleThe console.
emailAn e-mail link.
chatA team-chat message.
itsmAn ITSM ticket.
mobileA mobile notification.
offline_codeAn offline code read out to the user (#120, #159).

ApprovalDecision

Where an approval request stands.

ValueMeaning
pendingNot decided yet.
approvedApproved.
deniedRefused.
expiredNot decided in time.
cancelledWithdrawn by the requester.

ApprovalKind

What an approval request asks for.

ValueMeaning
executeRunning an application.
installInstalling software.
elevateElevated rights.
deviceUsing a device.
networkNetwork or web access.
exceptionA policy exception.
overrideA temporary override of the policy (#120).

ApprovalScope

What an approval would cover.

ValueMeaning
onceThis one action.
user_on_deviceThis user on this device.
deviceThis device, for every user.
userThis user, on every device.
device_groupA group of devices.
tenantThe whole tenant.

AuditCategory

A category of the OS audit policy.

ValueMeaning
systemSystem.
logon_logoffLogon and logoff.
object_accessObject access.
privilege_usePrivilege use.
detailed_trackingDetailed tracking (process creation and the like).
policy_changePolicy change.
account_managementAccount management.
directory_service_accessDirectory service access.
account_logonAccount logon.

AuditPolicyChange

One change to an audit policy subcategory.

ValueMeaning
success_addedSuccess auditing was turned on.
success_removedSuccess auditing was turned off.
failure_addedFailure auditing was turned on.
failure_removedFailure auditing was turned off.

Category

The broad class of an event.

ValueMeaning
executionRunning an executable.
scriptRunning a script.
libraryLoading a library into a process.
driverLoading a kernel driver.
installerRunning an installer.
packaged_appInstalling or activating a packaged app.
containmentApplication containment.
deviceDevice control.
networkNetwork control.
webWeb access control.
elevationPrivilege elevation.
approvalApproval requests.
exceptionPolicy exceptions.
policyPolicy distribution and activation.
agentThe agent itself.
admin_auditAdministrative actions on the server.
identityIdentity changes, such as local group membership.
complianceCompliance probes.
detectionDetections.
integrityFile integrity monitoring.

ChangeOp

One kind of change in a JSON Patch-like diff.

ValueMeaning
addA member was added: new only.
removeA member was removed: old only.
replaceA member's value changed: old and new.

DeviceClass

What kind of peripheral it is.

ValueMeaning
storageRemovable or external storage.
hidA keyboard, mouse or other human interface device.
networkA network adapter.
imagingA camera or scanner.
mediaAudio or video.
printerA printer.
smart_cardA smart card reader.
portableA phone or portable media device.
opticalAn optical drive.
otherAnything else.

DeviceInterface

The bus a peripheral is connected through.

ValueMeaning
usbUSB.
thunderboltThunderbolt.
firewireIEEE 1394.
bluetoothBluetooth.
sd_cardAn SD or other memory-card reader.
sataSATA or eSATA.
nvmeNVMe.
serialA serial or parallel port.
otherAnything else.

DeviceType

The kind of device a file is stored on.

ValueMeaning
fixedA fixed disk.
removableA removable drive.
networkA network share.
cdromAn optical drive.
virtualA virtual disk.

Direction

Which way a connection goes, seen from the device.

ValueMeaning
inboundTowards the device.
outboundAway from the device.
localBetween two endpoints on the device.

DnsName

A lowercase DNS name without a trailing dot.

Type: string; 1 to 253 characters; matches ^[a-z0-9_]([a-z0-9_-]{0,61}[a-z0-9_])?(\.[a-z0-9_]([a-z0-9_-]{0,61}[a-z0-9_])?)*$.

ElevationMethod

How elevation was obtained.

ValueMeaning
jitA just-in-time grant, requested and approved (#158).
on_demandThe user asked for it on one application (#155).
autoA rule elevated the application without asking.
challenge_responseAn offline challenge/response code (#159).
uac_replacementPalisade's replacement for the OS consent prompt (#155).

EncryptionState

Whether a storage device's contents are encrypted.

ValueMeaning
encryptedFully encrypted and protected.
unencryptedNot encrypted.
suspendedEncrypted, with protection suspended.
in_progressEncryption or decryption is in progress.

EventMode

The enforcement mode in effect when the event happened.

This is the policy Mode as seen by an event, plus two states the agent can be in. EventMode::from_policy_mode converts.

ValueMeaning
enforceDecisions take effect.
monitorDecisions are evaluated and would-block decisions reported.
auditLike monitor, with a full event for every decision.
learningAudit, collecting would-block objects as learning candidates.
maintenanceAn unlocked maintenance window (#222).
simulateA simulation of a policy that is not deployed.

EventType

A registered event type (crates/palisade-proto/events/registry.yaml).

Values: exec.decision, library.decision, driver.decision, script.decision, installer.decision, packaged_app.decision, com.decision, exec.origin_check, policy.applied, policy.failed, policy.activated, agent.started, agent.stopped, agent.health, agent.tamper, agent.throttled, agent.dropped, agent.clock_unsynced, process.created, script.block_logged, script.language_audit, containment.decision, device.attached, device.detached, storage.decision, network.app.decision, network.host.decision, web.decision, elevation.requested, elevation.decision, elevation.ended, approval.requested, approval.decided, exception.created, exception.changed, exception.removed, exception.expired, otp.session.started, otp.session.ended, admin.action, admin.login, admin.login_failed, identity.logon, identity.logon_failed, identity.local_group.changed, identity.group.changed, detection.log_cleared, detection.audit_policy_changed, integrity.fim.changed, compliance.probe.result, policy.signature.invalid, policy.rollback_rejected, policy.target_mismatch, policy.stale, policy.lkg_loaded, policy.emergency_loaded, policy.schema_unsupported, tamper.policy.rollback_suspected.

FimChange

What happened to a monitored file.

ValueMeaning
createdThe file was created.
modifiedThe file's content changed.
deletedThe file was deleted.
renamedThe file was renamed or moved: the old path is in old_path.
permissions_changedThe file's owner or permissions changed.
attributes_changedThe file's attributes or timestamps changed.

GroupScope

The scope of a security group.

ValueMeaning
localA group on one device, or a domain-local group.
globalA directory global group.
universalA directory universal group.

Guid

A GUID in canonical lowercase form, without braces.

Type: string; matches ^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$.

HealthStatus

The agent's overall health.

ValueMeaning
healthyEverything works.
degradedWorking, with a problem that needs attention.
unhealthyNot protecting the device.

HostId

The ID of an enrolled device, assigned by the server at enrolment.

Type: Uuid7.

IntegrityLevel

A process integrity level.

ValueMeaning
untrustedUntrusted.
lowLow.
mediumMedium.
medium_plusMedium plus.
highHigh.
systemSystem.
protectedProtected process.

IpAddress

An IPv4 or IPv6 address in canonical form.

Type: string; format ipv4 or ipv6.

JsonPointer

A non-empty JSON Pointer (RFC 6901).

Type: string; at most 1024 characters; matches ^(/([^~/]\|~[01])*)+$.

JsonValue

A JSON value without null or non-integer numbers. Nesting (at most 16) and size (at most 1024 values) are checked by the reader.

Type: boolean or integer or string or array of JsonValue or map of JsonValue.

Labels

Free-form labels from policy tags.

Type: map of string; at most 64 entries; keys: matches ^[a-z][a-z0-9_.:-]{0,63}$.

LanguageMode

The PowerShell language mode a script ran in.

ValueMeaning
full_languageFull language.
constrained_languageConstrained language.
restricted_languageRestricted language.
no_languageNo language.

LogonType

How a logon session was created. The names follow the OS logon types 2 to 13.

ValueMeaning
interactive2: at the console.
network3: from the network.
batch4: a batch job.
service5: a service.
unlock7: a workstation unlock.
network_cleartext8: from the network with a cleartext password.
new_credentials9: new credentials for outbound connections.
remote_interactive10: remote desktop.
cached_interactive11: with cached credentials.
cached_remote_interactive12: remote desktop with cached credentials.
cached_unlock13: an unlock with cached credentials.

ObjectType

The class of object being evaluated. Scripts are script.<kind>.

Values: executable, library, driver, script.powershell, script.batch, script.cmd, script.vbscript, script.jscript, script.wsf, script.wsc, script.python, script.java, script.reg, script.other, installer, compiled_html, html_application, control_panel_applet, packaged_app, command, com_object.

Outcome

What happened.

ValueMeaning
allowedThe action was allowed.
blockedThe action was blocked.
auditedThe action was allowed, but would have been blocked if enforced.
elevatedThe action ran with elevated rights.
cancelledThe user or the system cancelled the action.
failedThe action failed.
infoInformation only: no allow or block decision.

PolicyId

The stable ID of a policy.

Type: Uuid7.

PrincipalKind

Who acted: a person, a client or a component.

ValueMeaning
userA person signed in to the console or a client.
api_clientAn API client, identified by its token or client ID.
service_accountA service account.
scimDirectory provisioning (SCIM).
system_jobA scheduled server job.
instance_operatorAn operator of the Palisade instance, outside the tenant.
agentA Palisade agent.

ProbeStatus

The result of a compliance probe.

ValueMeaning
passThe device meets the requirement.
failThe device does not meet the requirement.
errorThe probe could not run.
not_applicableThe requirement does not apply to this device.

RegistryKey

A registry key path: the full root key name, then components of 1 to 255 characters separated by \.

Type: string; at most 32767 characters; matches ^HKEY_(LOCAL_MACHINE\|USERS\|CURRENT_USER\|CLASSES_ROOT\|CURRENT_CONFIG)(\\[^\\]{1,255})*$.

RegistryOperation

What was done to a registry key or value.

ValueMeaning
create_keyA key was created.
delete_keyA key was deleted.
set_valueA value was written.
delete_valueA value was deleted.
read_keyA key's values or subkeys were read.
read_valueA value was read.

RegistryValueType

The type of registry value data. The names follow the OS value types.

ValueMeaning
noneNo type.
stringA string.
expand_stringA string with unexpanded environment variables.
binaryBinary data.
dwordA 32-bit number.
dword_big_endianA 32-bit number, big-endian.
linkA symbolic link.
multi_stringA list of strings.
resource_listA hardware resource list.
full_resource_descriptorA hardware resource descriptor.
resource_requirements_listA hardware resource requirements list.
qwordA 64-bit number.

ResolutionMethod

How a remote host name was learned.

ValueMeaning
dnsA DNS query the agent observed.
dns_cacheThe OS resolver cache.
hosts_fileThe local hosts file.
local_nameNetBIOS, LLMNR or multicast DNS.
tls_sniThe TLS server name indication.
http_hostThe HTTP Host header.
reverse_dnsA reverse lookup of the remote address.
requestedThe name the application asked for, before resolution.

RuleId

The stable ID of a rule. It is never reused, even after the rule is deleted.

Type: Uuid7.

SchemaVersion

A semantic version MAJOR.MINOR.PATCH, without pre-release or build suffixes.

Type: string; matches ^(0\|[1-9][0-9]*)\.(0\|[1-9][0-9]*)\.(0\|[1-9][0-9]*)$.

ScriptKind

The kind of script, for ObjectType::Script.

ValueMeaning
powershell.ps1, .psm1, .psd1.
batch.bat.
cmd.cmd.
vbscript.vbs, .vbe.
jscript.js, .jse run by the OS script host.
wsf.wsf.
wsc.wsc, .sct scriptlets.
python.py, .pyw, .pyc, .pyo.
java.jar, .class.
reg.reg registry scripts.
otherAny other interpreted script.

Severity

Event severity, 0 (lowest) to 10 (highest).

Type: integer; 0 to 10.

Sid

A Windows security identifier in its canonical text form.

Type: string; matches ^S-1-(0\|[1-9][0-9]{0,9}\|0x[0-9A-F]{12})(-(0\|[1-9][0-9]{0,9})){0,15}$.

SourceKind

A kind of log that events can be translated from.

ValueMeaning
os_code_integrityThe OS code integrity log.
os_legacy_rule_collectionThe OS legacy rule-collection logs.
os_securityThe OS Security log.
os_powershellThe PowerShell logs.
third_partyEvents imported from another product, in a generic format named by source.format. Since 1.1.

TenantId

The ID of a tenant.

Type: Uuid7.

Timestamp

An RFC 3339 UTC timestamp with exactly six fractional digits and Z.

Type: string; format date-time; matches ^[0-9]{4}-(0[1-9]\|1[0-2])-(0[1-9]\|[12][0-9]\|3[01])T([01][0-9]\|2[0-3]):[0-5][0-9]:[0-5][0-9]\.[0-9]{6}Z$.

Token

A lowercase machine-readable word.

Type: string; matches ^[a-z][a-z0-9_]{0,63}$.

TokenElevationType

The elevation type of a process token.

ValueMeaning
defaultNo split token (UAC off, or a built-in or service account).
fullThe elevated half of a split token.
limitedThe filtered half of a split token.

Uuid7

A UUID version 7 in canonical lowercase form.

Type: string; matches ^[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$.

Zone

The security zone a file was downloaded from (its mark of the web).

ValueMeaning
local_machineZone 0: the local machine.
intranetZone 1: the local intranet.
trustedZone 2: trusted sites.
internetZone 3: the internet.
restrictedZone 4: restricted sites.
